# 月曜に見る　確認画面と再送

6/24に鈴木さん、伊藤さんと見た配送便変更。確認から編集に戻っても控え・対象・希望が残った。15:30便を16:00便に直して再確認もできた。集荷時間変更の結果不明画面は一覧まで進めた。

6/27の資料を開いて実機の枠から決める。最終送信を続けて操作したときの保存件数と、結果を待ってから送り直したときの一覧・保存記録が持越し。表示と記録を操作の前後で合わせる。もし二つ出たら、控え・種別・変更内容を見て、両番号全文と保存時刻を残す。

- 伊藤さんに、受付が保存されて一覧から引ける確認環境と空いている枠を聞く。
- 鈴木さんに、連続操作と待ち後の再送を別々に追ってもらう。どちらも前後の受付記録を見て件数を数える。
- 高橋さんに、控えが聞けない電話と候補が二つ出たときの引渡しを中村さんと相談してもらう。誰が取り消しを判断するか、確認中の相手に何と伝えるかもそこで聞く。
