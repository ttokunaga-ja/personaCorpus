# 佐藤さんに持っていく論点

小林さんが確認した4〜7月の問い合わせ控えは10件。これを月間頻度に換算する案は取り下げる。確認できた控えの範囲であって、全問い合わせの発生率を示す数字ではない。

90日以内が6件、90日を超えたのは発行から104日、121日、147日、168日後に各1件。締め後の訂正などで当時の原本を照合したいという話なので、一番遅い168日後まで見ておく必要がある。90日保存案では超過4件の原本照合を保存仕様で支えられない。180日案を費用に掛け、追加額と内訳を渡辺さんに相談する。

問い合わせの経過日は発行日からの目安。実際の期限判定の起点は保存完了時刻なので、例の日数をそのまま個別帳票の判定結果とはしない。部署の日常閲覧を180日に延ばす話ではない。
