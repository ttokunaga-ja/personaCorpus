# 印刷は1頁だけでは見ない

12/24 伊藤さんと短く相談。

CP-28は18行ちょうどが1ページに収まっても、それだけでは判定できない。前に欠けたのは004319の納品内訳24行で、A4縦・倍率100%のプレビューが1ページ、18行までしか出なかったケース。24行の2ページ目に19〜24行が出るか、行の抜けや重なりがないかを見る。

18行が1ページに収まる正常対照も、24行と同じ候補版で確認する。両方の版、条件と実結果を残して鈴木さんに見てもらう。18行が通っただけでCP-28を消さない。
