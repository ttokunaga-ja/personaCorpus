# 記録票から空表まで

左から右へ、矢印を付けた箱を並べる。

- 「記録票・予定」→「項目別に対象条件を確認」
- 判定が「対象外」→「集計の外（分母・欠測に入れない）」で終了。
- 判定が「対象内」→「記録の有無を確認」。対象判定の根拠が足りなければ「照会」へ。
- 「記録あり（確認して記録した数値0を含む）」→右端の空表の「記録あり数」。
- 「記録なし」→「理由を確認」。「未実施」「原記録なし」と確定した場合は各理由別欠測数へ。「確認待ち」は理由別欠測数に置き、照会へ進む。
- 「照会」→「回答後に根拠を確認・再判定」→「項目別に対象条件を確認」に戻る。再判定後は上記の対象外・対象内の分岐を再び通り、対象外なら終了、記録ありなら記録あり数、なお対象内で記録なしの場合だけ理由確認へ進む。根拠不足なら確認待ちのまま照会へ戻る。

右端の空表は横に読む。数値欄は空欄。

| 項目 | 単位 | 項目別対象数 | 記録あり数 | 未実施 | 原記録なし | 確認待ち |
|---|---|---|---|---|---|---|
| | | | | | | |

空表の下に「対象数＝記録あり数＋理由別欠測数の合計（項目ごと）」と記す。
