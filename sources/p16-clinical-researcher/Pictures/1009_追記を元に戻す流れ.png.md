# 受領から会議資料の件数へ

左から右へ読む図。左の箱に「受領一覧 7通」。中央の上段に「初報 5行」として「R01」「R02」「R03」「R04」「R05」を並べ、下段に「追記 2行」として「R06」「R07」を置く。

中央で番号付きの矢印を描く。①「R06 → R02」、②「R07 → R04」。それぞれ追記の箱から元の初報へ向ける。

右に別々の出口を置く。「集計 5件」と「照合用の行 7行」。初報5行から集計への実線には「計上する行を選ぶ」と書く。受領一覧から全7行を通って照合用の出口へ向かう破線には「受領順を保存」と書く。追記2行は照合用の出口にもつながり、集計には加えない。

中央に「対応が未確認」の分岐を置き、点線矢印で左下の「担当へ確認に戻す」へ戻す。確認できるまで計上を決めない。図の下に「会議資料の見出しは事象5件。欄外に受領7通（うち追記2通）を添える」と記す。
