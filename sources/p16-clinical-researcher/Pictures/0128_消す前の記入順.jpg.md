# 写真に写るもの
京都のセンター会議室の白板を正面から少し斜めに撮る。板面が画面の大半を占め、書き込み全体が読める。人物や個票は写らない。

板面の黒い文字は左から3区画。「開く」の下に「記入日・担当」。「観察」の下に「来所 → 用量区分 → 追記」。「引継ぎ」の下に「未記入理由 → 確認先」。3区画の流れも左から右への矢印でつなぐ。

赤い文字で「6件／11箇所」。観察の「追記」を赤で二重丸にする。消す前の会議中の板として、矢印や文字は手書きで少し不揃いにする。
