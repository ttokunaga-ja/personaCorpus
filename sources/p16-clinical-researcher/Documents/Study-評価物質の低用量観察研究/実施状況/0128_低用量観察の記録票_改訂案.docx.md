# 低用量観察 記録票
文書番号：KRC-LDO-20250120-FRM-001　版：v0.2  
作成日：2025-01-28　作成者：鈴木 美津子

開始前の読み合わせ案。1月23〜27日の机上試行6件で記入漏れが11箇所あったため、記入できる順に欄を並べ直した。正式配布用ではない。

## 記録を開く
| 項目 | 記入欄 | 確認事項 |
|---|---|---|
| 記入日 | | 記入するときに日付を記す |
| 記入担当 | | 記入者を記す |

## 観察の記録
| 項目 | 記入欄 | 確認事項 |
|---|---|---|
| 来所の記録 | | 来所の状況を確認して記す |
| 用量区分 | | 来所の記録に続けて、記録を確認し区分を記す |
| 追記件数 | | 追記を確認して件数を記す。追記がないと確認した場合は0、未確認なら0としない |

## 未記入欄の確認と引継ぎ
| 項目 | 記入欄 | 確認事項 |
|---|---|---|
| 未記入欄 | | 記録を終える前に、空いている欄を記す |
| 対象外 | | 対象外と判断した欄を記す |
| 未記入理由 | | 対象内で未記入の欄について、未実施・原記録なし・確認待ちを区別する。理由未確定は確認待ちとする |
| 確認先 | | 確認が必要な内容と担当を記す |
