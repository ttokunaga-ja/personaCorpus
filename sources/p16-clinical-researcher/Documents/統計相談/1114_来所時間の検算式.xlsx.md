# 来所時間の検算式

## シート「端点と検算」
紙の点検票の記入を独立に照合する。確認できた端点を「○」、確認できなかった端点を「未確認」とする。分は紙の差を転記し、欠測は空欄とする。

| 行 | A：例 | B：受付完了 | C：説明開始 | D：説明終了 | E：待機分 | F：説明分 | G：待機の両端確認 | H：説明の両端確認 |
|---|---|---|---|---|---|---|---|---|
| 7 | A | ○ | ○ | ○ | 8 | 21 | =IF(AND(B7="○",C7="○"),1,0) | =IF(AND(C7="○",D7="○"),1,0) |
| 8 | B | ○ | ○ | 未確認 | 14 | | =IF(AND(B8="○",C8="○"),1,0) | =IF(AND(C8="○",D8="○"),1,0) |
| 9 | C | 未確認 | ○ | ○ | | 27 | =IF(AND(B9="○",C9="○"),1,0) | =IF(AND(C9="○",D9="○"),1,0) |

| セル | 内容 |
|---|---|
| A11 | 端点確認からの集計 |
| A12 | 待機：対象／有効／欠測（例） |
| B12 | =COUNTA(A7:A9) |
| C12 | =SUM(G7:G9) |
| D12 | =B12-C12 |
| A13 | 説明：対象／有効／欠測（例） |
| B13 | =COUNTA(A7:A9) |
| C13 | =SUM(H7:H9) |
| D13 | =B13-C13 |
| E11 | 中央値（分） |
| E12 | =IF(COUNT(E7:E9)=0,"",MEDIAN(E7:E9)) |
| E13 | =IF(COUNT(F7:F9)=0,"",MEDIAN(F7:F9)) |
| F11 | 対象＝有効＋欠測 |
| F12 | =IF(B12=C12+D12,"一致","不一致") |
| F13 | =IF(B13=C13+D13,"一致","不一致") |

## シート「度数照合」
6行目を見出し、7〜10行目を明細とする。分の値は紙の有効な差を昇順に置き、件数は端点確認が有効な例だけから数える。

| 行 | A：区間 | B：分 | C：件数 |
|---|---|---|---|
| 7 | 待機 | 8 | =COUNTIFS('端点と検算'!$E$7:$E$9,B7,'端点と検算'!$G$7:$G$9,1) |
| 8 | 待機 | 14 | =COUNTIFS('端点と検算'!$E$7:$E$9,B8,'端点と検算'!$G$7:$G$9,1) |
| 9 | 説明 | 21 | =COUNTIFS('端点と検算'!$F$7:$F$9,B9,'端点と検算'!$H$7:$H$9,1) |
| 10 | 説明 | 27 | =COUNTIFS('端点と検算'!$F$7:$F$9,B10,'端点と検算'!$H$7:$H$9,1) |

| セル | 内容 |
|---|---|
| A12 | 待機の度数計 |
| C12 | =SUM(C7:C8) |
| D12 | =IF(C12='端点と検算'!C12,"一致","不一致") |
| A13 | 説明の度数計 |
| C13 | =SUM(C9:C10) |
| D13 | =IF(C13='端点と検算'!C13,"一致","不一致") |

端点確認による有効数と度数計は待機2、説明2。いずれも対象3＝有効2＋欠測1。中央値は待機11分、説明24分。有効な数値がない区間の中央値は空欄とし、0分とはしない。机上3例であり、共同観察の実績ではない。
参照：11月8日三例の端点点検票、11月13日来所時間の区間別集計 v0.2。
