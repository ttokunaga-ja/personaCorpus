# シート：分母の比較

題を「1月20日朝の項目別分母」に、版を v0.2 に変更する。基準は2026年1月20日9:00。

12行目の照会回答日は、回答日ありの絞り込みを外し、発行済み照会行を対象とする。D12を8から12、G12を0から4に変更し、H12を「今回の観察記録に対する発行済み照会行。回答日あり8行、確認待ち4行」とする。E12の記録あり8行は変えない。

13〜16行目に項目ごとの検算を置く。D列の対象数からE列の記録あり数とG列の該当する理由別欠測数を引く。

| 行 | A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|---|
| 13 | | 来所の記録（例）検算差 | | | | | | =D7-E7-G7 |
| 14 | | 用量区分の記録（例）検算差 | | | | | | =D8-E8-SUM(G8:G9) |
| 15 | | 追記件数（例）検算差 | | | | | | =D10-E10-SUM(G10:G11) |
| 16 | | 照会回答日（照会行）検算差 | | | | | | =D12-E12-G12 |

各検算差は0。表外の注記は「予定48例、初回観察済み31例、未観察17例。48例は項目の対象数ではない。各項目は対象条件と単位が異なるため合算しない」とする。旧版の照会回答日の絞り込み中・対象確認前の注記は削除する。
