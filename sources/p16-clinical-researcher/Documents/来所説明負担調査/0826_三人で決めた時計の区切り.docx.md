# 来所説明負担調査　計時点の協議記録
文書番号：KRC-VEB-20240826-MIN-001　版：v1.0
作成日：2024-08-26　作成者：鈴木美津子

日時：2024年8月26日 14:00〜14:40
場所：泉台研究病院
出席：鈴木美津子、斎藤久美香、村上美季

## 議題
観察予定12件について、来所の流れに沿った待機と説明の境目を決める。

## 確認事項
待機は来所受付完了から研究説明の第一声の直前まで、説明は第一声から研究説明とそれに関する質疑の終了までとする。案内・着席・説明前の資料準備は待機に含める。

机上で受付完了13:40、呼出し13:46、説明開始13:49、説明終了14:03と紙に置いた。呼出しで待機を終え、説明開始から説明を数えると、席に着いて資料を待った3分がどちらにも入らない。呼出しは計時の区切りから外し、説明開始を共通の境目とする。紙上の待機9分、説明14分は机上確認の値であり、観察12件には含めない。

## 対応と担当
| 対応 | 担当 |

| 決めた3時点と二区間を観察12件の共同計画・記入要領に反映する | 鈴木 |
| 受付完了の合図が伝わる方法を確認する | 村上 |
| 説明開始と研究に関する質疑終了の合図を確認する | 斎藤 |
