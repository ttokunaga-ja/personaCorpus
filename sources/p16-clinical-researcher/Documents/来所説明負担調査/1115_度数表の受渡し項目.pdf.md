# 度数表の受渡し項目
文書番号：KRC-VEB-20241115-SUM-001　版：v1.0
作成日：2024年11月15日　作成者：森裕平
宛先：鈴木美津子・石川由美香

## CSVの列と並び
列名は「区間」「分」「件数」の3列。分は整数の分、件数の単位は件とする。区間は待機、説明の順に掲載し、それぞれの区間内は分の昇順に並べる。同じ区間で同じ分が複数あるときは1行にまとめ、件数を足す。

## 書き出し前の確認
1. 各区間について両端点を確認できた分だけを集める。欠測は分の明細に混ぜず、0分として追加しない。
2. 区間別の対象・有効・欠測を確認し、対象＝有効＋欠測となることを確かめる。
3. 各区間の度数を合計し、その区間の有効件数と照合する。一致を確認してから3列を書き出す。
4. 出力に例符号、時刻、例ごとの区間の組合せ、個別の欠測理由が含まれていないことを確認する。
