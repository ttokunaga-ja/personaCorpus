# 受付から説明までの流れ
文書番号：IZM-20240821-FLW-001　発行日：2024-08-21
作成：泉台研究病院 事務局長 村上美季　宛先：かつら川臨床研究センター 鈴木美津子 様

26日の打合せに向けて、現在の来所時の流れを整理しました。担当が引き継ぐ位置をご確認ください。

| 場所 | 段階 | 担当 | その場で行うこと |
|---|---|---|---|
| 受付 | 受付確認 | 受付担当 | 来所を確認し、受付の確認を終える |
| 待合 | 待合 | 受付担当 | 待合で待っていただくよう案内する |
| 待合から説明室 | 案内 | 案内係 | 呼出し、説明室まで案内する |
| 説明室 | 着席 | 案内係 | 席へ案内する |
| 説明室 | 資料の準備 | 説明担当 | 説明に使う資料をそろえる |
| 説明室 | 最初の説明 | 説明担当 | 研究の説明を始める |
| 説明室 | 質問 | 説明担当 | 研究についての質問に答える |
| 説明室 | 説明終了 | 説明担当 | 研究説明と質問への対応を終える |

呼出し後、席に着いてからも説明担当の資料準備が残る場合があります。

欄外・26日の協議事項：観察予定12件の計時をどこで区切るか。呼出しと説明開始は同じ時点とは限りません。
