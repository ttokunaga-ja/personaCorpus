# HPT visit — what the walk-through can show

HBC-HPT-20260212-WRK-01 v1.0 | February 12, 2026  
Prepared by Divya Rao | Account: HPT Regional Freight LLC  
For Michelle Whitaker

## Decision

Albert Hensley has asked for a dedicated private connection from HPT terminals to Branch Connect. That connection is outside the scope we can provide. The standard service connection can be explained, but Albert has said it does not satisfy HPT's condition. Do not describe the standard path as an HPT-dedicated route.

## Visit scope

| Topic | What we can cover | Boundary |
|---|---|---|
| Connection | Explain the standard connection from a branch to the service. | No HPT-dedicated private connection is offered. |
| Branch operations | Explain branch communications and the terminal user's role. | An explanation is not a connection test on HPT's line. |
| Administration | Explain the central administrator's role in the service. | No HPT network changes or individually designed connection method are part of the visit. |

## Responsibilities and follow-up

| Owner | Action | When |
|---|---|---|
| Michelle | Lead with the connection boundary and confirm whether Albert's condition remains mandatory. | February 17 visit, 10:30 a.m. |
| Divya | Explain the standard connection and operating roles within the available scope. | At the visit, as appropriate after the boundary discussion. |

The visit does not include testing a connection to HPT's line, making network-side changes, or designing a customer-specific connection. There is no committed availability date for the dedicated connection. If the required condition remains unchanged, the explanation of standard operation does not resolve it.
