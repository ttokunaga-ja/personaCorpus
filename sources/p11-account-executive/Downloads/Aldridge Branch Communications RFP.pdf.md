# Branch Communications Request for Proposal

ASG-RFP-20241008-01 | Version 1.0 | October 8, 2024  
Issued by: Ahmed Farouk, Business Planning, Aldridge Service Group  
To: Michelle Whitaker, Halstead Branch Communications Inc

## Response instructions

Aldridge is evaluating a branch communications service for routine site coordination and handoffs. Please respond to all 56 numbered requirements below by October 23, 2024 at 4:00 p.m. Denver time. For each number identify the section and item in your response that addresses it. Distinguish a requirement met by the current service from a proposed alternative. If any condition is not met, identify it expressly as an exception, even when an alternative is available. Mandatory exceptions will be considered separately in scoring. Desired items should also receive a response. Commercial terms will be discussed separately from this technical response.
