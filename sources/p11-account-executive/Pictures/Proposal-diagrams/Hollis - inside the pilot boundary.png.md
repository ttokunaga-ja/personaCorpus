# Hollis: inside the pilot boundary

A labeled boundary encloses “One Hollis site · up to 30 seats”. Inside, connect these boxes in order with directional arrows:

1. “Hollis IT roster” → 2. “Administrator: manual CSV import” → 3. “Site staff: send business communication” → 4. “Delivery log: confirms sending” (not receipt).

From the administrator/import box, a separate branch points to “Administrator: export usage CSV”. From the site communication box, a separate branch points to “Recipient callback — Hollis operating process”. The callback branch is outside the service flow and is not a delivery-log result.

Outside the boundary place “Other sites” and “Company-wide roster”, with no arrows into the pilot. The diagram is for Michelle and Lawrence's discussion of the scope, not a production deployment map.
