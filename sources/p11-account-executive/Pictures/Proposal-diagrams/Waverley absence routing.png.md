# Waverley | absence intake routing

Flow from top to bottom. Start box: “Inquiry while Tracy is away”. A decision box asks “Chicago weekday, 9:00 a.m.–3:00 p.m.?”

- Yes → “Office shift lead: receive and record time, site, callback for the inquiry and request”. From this intake box, solid arrows lead to three boxes:
  - “Procedure guidance → Darren”
  - “Roster, distribution list or access decision → hold for Tracy”
  - “Contract inquiry → Michelle”
- No → “Hold for Tracy's next working period”.

A dashed arrow from the intake box to “Tracy: receive outstanding items on return” denotes the handoff. The hold-for-Tracy decision box also points to that return box. Key: solid arrow = route; dashed arrow = handoff to Tracy. The shift lead acknowledges receipt and does not promise a decision or answer time.
