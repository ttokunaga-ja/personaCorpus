# One release and one list

A flow diagram for Claire and Hannah.

Above a horizontal divider labelled “before cue”: a box labelled “Claire + Hannah: agree exercise wording and desk list”. An arrow leads down across the divider to “Daniel: 09:20 UTC cue”.

Below the divider, an arrow from Daniel's cue goes to “Hannah: one group message”. A single arrow goes from that box to “12 staffed desks — existing group channel”. An arrow labelled “individual readbacks in order” returns from the desks to “Hannah: one receipt list”. A loop from that list labelled “Missing at 180 seconds: Hannah rings missing desk” returns to the same list.

Beside the flow, a box “Daniel: observe clock and exceptions” connects by an observation line to the cue and receipt list. Claire has no send route to the desks after the divider.
