# Before I send a review

- Check the recorded closure UTC, not the last draft-save time.
- Find the next UK working day and calculate 17:00 Europe/London, then compare in UTC. Keep the time-zone abbreviation with the working.
- Read the impact against the evidence. Separate the estimate from confirmed impact and leave anything still unconfirmed as such.
- Record the first formal issue UTC once the report is sent. A saved draft does not count.
- If I am off before the deadline, hand the deadline and outstanding evidence to a named duty recipient; check that the issue timestamp is captured.

## Walk-through: RR-221

Closed Friday 6 February 2026 at 16:20 UTC. The next working day is Monday 9 February, so the deadline is 17:00 GMT / 17:00 UTC on the 9th. The first formal issue was 09:16 UTC on Monday: on time.
