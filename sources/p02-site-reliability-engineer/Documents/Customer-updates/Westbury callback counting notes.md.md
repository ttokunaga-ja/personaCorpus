# Stephen's question about repeat calls

For Daniel — call with Stephen Cartledge, 15 September 2026, 13:00 UTC (14:00 BST).

Stephen asked if a phone call following up an existing question would be counted again in the desk figures. I explained that a follow-up on the same case and question does not add another enquiry; the first category is retained. The comparison counts newly opened questions, not every call.

He also asked whether the desk should still use the same Support route. Yes: staff can keep the original booking and contact Support through the existing route to check refund progress. I will send the September desk update for the desk leads to use.
