# Leave the verification with a name

For the next duty engineer: if the second engineer has not recorded their readback when the shift changes, carry the verification as open. Give the receiving engineer a person to call and a time to check back. The rollout end is a separate observation, not a substitute for the readback.

## Worked handover example

- Rollout end observed: 16:10 UTC, recorded in the rollout end field.
- Outstanding: second engineer's named, timed closeout readback has not been entered.
- Owner of next check: Daniel Jennings. Contact Matthew Pickering, the named second engineer, for his readback.
- Next check due: 16:40 UTC. Receiving duty engineer: call Daniel if the entry is still missing at that time.
- Closeout: open pending the recorded readback.

If Matthew provides it later, record his name, the readback and its actual time. Do not use 16:10 as the readback time. This is an example for handover, not a current change.
