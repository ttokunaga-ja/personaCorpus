# Ticket archive trial notice

19 September 2024 · Customer Support · Internal

At today's review, Operations agreed to keep the 10-minute archive interval for a test under load in the isolated archive. The 15-minute interval will serve as the comparator. For internal questions about what was approved, see the [signed-off trial scope (BRT-CD-20240919-001 v1.0, PDF)](Ticket%20archive%20trial%20scope.pdf).

When speaking to operators, continue to use the existing ticket archive recovery wording. The live schedule and the recovery terms operators have been given still apply. If an operator asks whether tickets from a particular time are recoverable, send the query to Customer Support with the time and time zone they gave so we can check before replying.
