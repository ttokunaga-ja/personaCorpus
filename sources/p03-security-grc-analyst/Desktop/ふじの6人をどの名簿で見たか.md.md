# ふじの6人をどの名簿で見たか

斎藤さんからの29日の連絡では、石川さんが9月19日に6人を確認したというところまで。人数だけでは、その日に対象だった6人の名簿の版も、点検結果との対応も分からない。

今の名簿で置き換えて照合したことにする案は保留。斎藤さんに、石川さんから9月19日現在の対象名簿の版と、同日の確認者署名入り原票を取り寄せてもらう。届いたら両方を突き合わせ、木村さんに確認を頼む。

池田さんには、どの版の名簿で対象人数を確認したかを説明できるようにする。版が分からない間は6人を照合済みとは書かない。
