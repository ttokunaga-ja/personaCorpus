# 点検の証跡を出すとき

文書番号：CD-IM-202404-ANS-01  
版：v0  
作成日：2024年4月19日  
作成者：山田 美由紀  
確認／承認：佐々木 和夫に確認予定、配布前  
宛先：情報管理統制の点検担当者（配布予定）

## 対象

四半期の締め時点で、担当する統制の点検結果と、その結果を確かめられる記録の控えを山田へ提出してください。控えには年間点検表と同じ統制番号を添えます。一つの統制で複数の控えを出すときは、資料ごとに一覧の行を分けてください。

## 提出する記録

月次の点検は、締めた月の月報か点検票を提出してください。人事の手続をまとめた資料は、個人名を除いて件数と実施状況が分かる形にし、必要なときに元の記録を照会できる人を知らせてください。締め時点の記録を取り出せないときは、理由と、どこに聞けば確認できそうかを山田に知らせてください。

## 記入例

## 佐々木さんへの確認事項

9月分を10月に出力して受け取る場合、「資料の日付」には9月末と10月の出力日のどちらを入れてもらうか。出力日だけだと締めた月が表から見えない。月報以外にも同じ欄で足りるか、表の見本を見ながら相談したい。

担当確定後に配布する。
