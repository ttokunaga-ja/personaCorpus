# 発令日で揃えてから数える

受付月で絞った一覧をそのまま使うと、12月に受け付けて1月1日に発令された所属変更が抜ける。受付日と発令日は同じ条件ではない。

棚卸は松本さんの1月24日09:00の固定範囲、権限136件に戻して見る。差異9件だけを別の抽出条件で数え直さない。

- 山口さんに、12月受付分と1月1日発令の対応を確認する。発令控えは人事窓口で見る。
- 松本さんに、24日の元の抽出条件と固定範囲が残っているか聞く。再照合も同じ範囲でできるか確かめる。
