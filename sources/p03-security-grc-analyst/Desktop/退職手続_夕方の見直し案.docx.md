# 退職手続の夕方の確認　見直し案
文書番号：CD-IM-202407-ANS-01　版：v0
作成日：2024年7月16日　作成者：山田 美由紀
確認者：山口 久美子　宛先：山口 久美子
承認：未了

## 対象
退職当日の停止処理と、人事による停止確認を対象とする。7月1日〜11日処理分18件では、2件の確認記入が翌営業日午前になった。7月12日の元票照合では、2件とも停止自体は処理日内だった。

## 確認の流れ（案）
運用は退職当日の16:00までに処理結果を人事へ共有する。人事は連絡を受けたら確認する。17:00までに確認欄を埋め、確認日時を残す。夕方に結果を確認する担当をあらかじめ決める。

| 時点 | 担当 | 残す記録 |
|---|---|---|
| 退職当日16:00まで | 運用・松本 | 処理結果の共有記録 |
| 連絡を受けた後、17:00まで | 人事・山口 | 確認欄と確認日時 |
| 終業前 | 人事 | 確認欄の記入状況 |

## 山口さんへの確認
「連絡を受けたら確認する」とした箇所で、運用の停止実施記録の元票をどこまで見るか確認したいです。16時までに停止できない日の申送りは、誰から誰へ何を伝える扱いにするか。人事主担当が不在のときの代行者と引継ぎ方法も決めたいです。

## 承認
回覧中。確認と例外時の扱いを整理してから承認を依頼する。
