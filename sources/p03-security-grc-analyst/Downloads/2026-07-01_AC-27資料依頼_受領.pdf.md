# AC-27 権限承認に関する資料のお願い

発信番号：SK-2026-REQ-01　2026年7月1日
宛先：中京文書配送サービス株式会社　山田 美由紀 様
発信：さくら情報管理審査合同会社　池田 千代美

2026年度の情報管理審査にあたり、2026年4月1日から6月30日までの権限承認について、以下の資料をご準備ください。期間と対象の定義を明らかにしたうえで、申請から承認、権限反映までを追える資料をお願いします。

| 項目 | ご依頼内容 |
|---|---|
| Q1 | 対象業務、対象期間、抽出条件と件数。対象外としたものがあればその範囲 |
| Q2 | 対象期間の全件一覧と、各申請に対応する承認根拠の参照先。承認者、承認日、権限反映日を確認できるもの |
| Q3 | 権限承認を点検する手順と、対象期間に実施した点検の記録 |
| Q4 | 点検で見つかった不備への対応、対応根拠および責任者の承認を確認できる記録 |

初回提出は7月7日までにお願いします。7月9日10:00〜11:30にオンラインで一覧と根拠を読み合わせます。確認の結果、追加の調査が必要な場合は対象と見通しをご連絡ください。責任者承認を含む最終回答期限は8月21日です。

以上、よろしくお願いいたします。
