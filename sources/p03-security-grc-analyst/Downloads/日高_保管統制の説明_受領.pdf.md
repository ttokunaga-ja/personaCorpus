# 東棟 保管統制の説明

発行番号：HD-HK-202408-01　版：v1  
発行日：2024年8月26日　作成者：橋本哲弘  
宛先：中京文書配送サービス株式会社　井上美枝子様、山田美由紀様

## 対象

契約 HD-2023-07 に基づき、東棟書庫でお預かりする文書の入庫受付、棚への格納、出庫引渡しに関する取扱いを説明します。

## 入庫から格納まで

入庫受付担当は受領した箱と入庫依頼の対象を照合し、受付記録に受付日、対象、箱の識別及び担当を残します。相違があれば格納を進めず、依頼元へ確認します。保管担当は受付記録を受けて対象区画と棚を確認し、格納先を保管台帳に記録します。受付記録と保管台帳をたどることで、受領から格納までの担当と所在を確認できます。

## 出庫と引渡し

出庫担当は依頼内容と保管台帳を照合し、対象箱を取り出します。引渡担当は出庫指示と箱の封緘番号を照合し、引渡日、対象、封緘番号及び担当を引渡控えに残します。相違があれば引渡しを保留し、依頼元に確認します。出庫指示と引渡控えを月ごとに照合し、結果を封緘照合記録に残します。

## 点検と時間外の連絡

管理責任者は月次で東棟の保管区画、受付及び引渡しの運用を点検し、点検票に対象、実施日、確認内容、所見及び確認者を記録します。異常があれば初動手順に従い連絡し、対応を記録します。時間外の異常は適用中の夜間連絡表に従い当番へ連絡し、応答がない場合は表に定めた引継ぎ先へ連絡します。連絡表は担当変更時に改訂し、適用開始日を明示します。

本書は運用の設計を示すものです。各月の点検、連絡及び封緘照合の実施状況は、それぞれの当該記録でご確認ください。
