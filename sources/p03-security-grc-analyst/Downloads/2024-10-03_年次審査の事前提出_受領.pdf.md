# 2024年度 年次審査の事前提出について

発信番号：SK-2024-REQ-01  
版：v1  
発行日：2024年10月3日  
作成・発行者：さくら情報管理審査合同会社　池田 千代美  
確認／承認：発行者とは別の確認者・承認者の記載なし  
宛先：中京文書配送サービス株式会社　山田 美由紀 様

## 確認日と事前提出

2024年10月29日（火）10:00〜11:30に、貴社本社で情報管理統制の運用実績を確認します。事前確認のため、2024年4月1日〜9月30日の運用実績を示す資料と提出一覧を、10月24日（木）までに池田へご提示ください。

## 提出一覧の記載事項

各資料の統制番号、資料名、担当者と、確認対象として指定された月・四半期・実施回を記載してください。指定した範囲と、資料に記載された日付を個別に照合します。

| 確認単位 | 一覧の指定対象 | 資料から採る日付 |
|---|---|---|
| 月次 | 指定された年月 | 月報や点検票に記載された対象年月、または対象開始日と終了日 |
| 四半期 | 指定された四半期 | 集計または点検記録の対象開始日と終了日 |
| 実施回 | 指定期間内に行った回 | 訓練等の記録にある実施日 |

発行・出力日は独立した欄に記入してください。月末を過ぎて控えを出力した場合も、発行日で対象期間や実施日を代用することはできません。

## 当日にご用意いただきたい元記録

提出一覧の該当行から、月報の表題と対象年月、紙の点検票の点検期間欄、訓練記録の実施日欄を当日確認できるようご準備ください。特に、月末の締めを翌月に出力した資料は、締めの範囲が示された箇所をご提示ください。集計資料は、対象の開始・終了と対象回を抽出した条件、および元の実施日を確認できる記録が対象です。提出した控えから必要な日付が読み取れない場合は、元記録の保管箇所と照会先をお知らせください。
