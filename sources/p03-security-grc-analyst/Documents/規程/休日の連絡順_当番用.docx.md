# 休日の連絡順 当番用
文書番号：CD-IM-202604-ANS-02　版：v1
作成日：2026年4月27日　作成者：山田美由紀　承認者：佐々木和夫　宛先：運用当番

## 連絡と記録
| 場面 | 連絡順・切替条件 | 記録担当 |
|---|---|---|
| 現場から運用へ | 現場は運用当番を呼び、初回連絡から5分間応答がなければ運用副当番へ回す。 | 現場が初回連絡と副当番への切替を記す。 |
| 運用から責任者へ | 引き継いだ運用役は情報管理責任者を呼び、初回連絡から5分間応答がなければ当番表に指定された責任者代理へ回す。 | 引き継いだ運用役が送信と受領確認を記す。 |

責任者または責任者代理から受領が返った時刻と、受けた役割を記す。責任者代理から正担当への引継ぎは、受領確認とは別に記す。

適用日：2026年4月29日。連絡先は当日に有効な当番表で確認する。
