# 2024年度の情報管理点検

掲載日：2024年4月24日

点検担当の皆さんへ。年間点検表を開き、ご自身の統制番号と対象の月・四半期・実施回を確認してください。

| 点検対象 | 証跡の回収日 |
|---|---|
| 2024年4月〜6月 | 2024年7月5日（金） |
| 2024年7月〜9月 | 2024年10月4日（金） |
| 2024年10月〜12月 | 2025年1月10日（金） |
| 2025年1月〜3月 | 2025年4月4日（金） |

次の7月5日は、4月から6月までの点検結果と、その期間に年間点検表で指定された実施回の記録を回収します。資料の対象期間と、控えを発行・出力した日を分けて記入し、提出要領に沿って山田へお送りください。

- [2024年度 年間点検表（Excel）](../統制/情報管理統制/2024年度_年間点検表.xlsx)
- [点検の証跡を出すとき（PDF）](2024年度_情報管理点検の証跡提出要領.pdf)

担当の表示が実際の分担と異なる場合は、統制番号、表に載っている担当、実際の担当または候補、元記録を確認できる人を山田までお知らせください。
