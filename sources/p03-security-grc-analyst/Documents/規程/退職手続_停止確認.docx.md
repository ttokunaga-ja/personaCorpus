# 退職手続における停止確認

文書番号：CD-IM-202407-ANS-01　版：v1  
作成日：2024年7月18日　作成者：山田 美由紀  
確認者：佐々木 和夫（2024年7月17日 15:10確認）  
宛先：人事・運用の退職手続担当者  
適用開始日：2024年7月22日

## 対象

退職当日の停止処理について、運用から人事への連絡と、人事が停止実施記録を確認して確認日時を残すまでを対象とする。人事主担当が不在の場合は人事当番が確認を代行する。

7月1日から11日までの退職処理18件のうち、2件は人事の確認記入が翌営業日午前になった。7月12日に元票を照合したところ、いずれも停止自体は処理日内に実施されていた。終業前に運用の結果を開き直す人事側の担当が決まっていなかったため、以下の役割と時点を定める。

## 当日の確認手順

運用の松本は、退職当日の16:00までに、処理結果を人事主担当または人事当番へ連絡する。16:00以降に停止予定の分は、16:00までに予定を連絡し、実施後に結果を渡す。予定の連絡は停止実施の根拠ではない。

人事主担当は、運用の停止実施記録の元票を確認し、17:00までに人事の確認欄へ確認日時を記入する。主担当が不在のときは対象と結果の受け取りを人事当番へ引き継ぎ、当番が同じ確認と記入を行う。

17:00に停止実施の根拠を確認できない場合、人事主担当または当番は確認欄を未確認のまま残し、松本と佐々木へ当日中に連絡して根拠の受渡しを引き継ぐ。根拠を得るまでは確認済みとせず、入手後に元票を照合して確認日時を記入する。

| 時点 | 担当 | 残す記録 |
|---|---|---|
| 退職当日16:00まで | 運用・松本 | 人事主担当または当番への処理結果の連絡。16:00以降に停止予定の場合は予定の連絡を残し、実施後に結果を渡す |
| 元票を確認できた後、17:00まで | 人事主担当、不在時は人事当番 | 停止実施記録の元票を確認し、人事の確認欄に確認日時を記入 |
| 17:00に根拠を確認できない場合 | 人事主担当、不在時は人事当番 | 確認欄は未確認のまま、松本・佐々木への当日中の連絡と根拠の受渡しを引き継ぐ記録 |
| 根拠の入手後 | 人事主担当または人事当番 | 元票を照合し、確認欄に確認日時を記入 |

## 未確認の取扱い例

16:00までに松本から16:00以降の停止予定を受け取ったが、17:00になっても停止実施記録を確認できない場合、人事当番は予定連絡だけで確認欄を埋めない。未確認のまま松本と佐々木へ当日中に連絡し、実施の根拠を受け取るために引き継ぐ。根拠を入手して元票と照合できた時点で、確認日時を記入する。
