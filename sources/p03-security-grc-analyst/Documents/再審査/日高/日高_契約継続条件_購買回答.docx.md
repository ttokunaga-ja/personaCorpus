# 日高文書保管の継続条件と確認事項
文書番号：CD-IM-202409-ANS-02　版：v1
作成日：2024年9月20日　作成者：山田 美由紀
宛先：購買課長 井上 美枝子様
判断者：情報管理責任者 佐々木 和夫

## 対象と判断
管理会議記録 CD-IM-202409-MTG-02 v1 に基づき、契約 HD-2023-07 の東棟書庫保管、入庫受付、出庫引渡しについて、2024年10月1日から12月31日まで、現行範囲に限って継続可とします。下記の配布確認を発注前の条件とします。

## 照合した根拠
提出12資料のうち更新待ちだった現地点検報告、夜間連絡表、8月封緘照合記録を受領し、使用可12点となりました。現地点検報告の受領版にあった9月13日は月次台帳への登録日で、実施日は署名原票と訂正版により9月12日と確認しました。対象と是正所見0件は原票と両版で一致しています。受領版、訂正版、署名原票を別々に保存します。

## 継続条件
井上さんと松本さんは9月27日までに、購買と運用で10月1日適用の夜間連絡表への入替えと配布を確認してください。井上さんはその確認後に発注処理を進めてください。期限までに確認できない場合は発注を留め、佐々木さんへ再判断を求めます。

## 担当と次の確認
橋本さんには10月18日までに、次回点検の原票と報告の実施日を提出前に突き合わせていただきます。山田が照合の根拠を確認します。期限に間に合わない場合や日付に不一致がある場合は、山田から佐々木さんへ戻して再判断を求めます。9月20日時点ではいずれの確認も未了です。
