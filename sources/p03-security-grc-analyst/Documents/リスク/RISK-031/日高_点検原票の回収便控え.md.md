# 日高の回収便　封筒の控え

9月8日　井上さんから予定を聞いた。原票はそれぞれ別便。

- 9月18日：保管区画の紙票を受け取る予定。封筒表記は「保管区画点検票」。
- 9月25日：返却箱の受渡照合票を受け取る予定。封筒表記は「返却箱受渡照合票」。

封筒の表には中身の種類だけを書く。点検結果や取引先の情報は書かない。

松本さんに確認：
- [ ] 保管区画図は保管区画の紙票に付けてもらえるか。
- [ ] 受渡台帳の控えは返却箱の照合票に付けてもらえるか。訂正があればその控えも追えるようにする。

着いた日と点検日を分けて控える。届いた後、対象と署名を確認して木村さんの照合へ回す。
