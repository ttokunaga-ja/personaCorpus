# 休日連絡演習 進行票

文書番号：CD-IM-202604-MTG-01　版：v1
作成日：2026年4月10日　更新日：2026年4月16日　作成者：山田 美由紀
確認：松本 秀一　宛先：松本 秀一、佐々木 和夫

## 日時・目的

2026年4月22日、本社。13:25に開始前の時計を合わせ、13:30から休日の連絡を通す。現場が想定を把握してから情報管理責任者役が受領を確認するまでを30分以内とする。送信操作は終了ではなく、別の記録点とする。

## 資料・想定

引渡確認が取れない想定を1件だけ現場役に渡す。演習の連絡は室内で扱い、社外へ発信しない。復旧に要する時間は測定対象に含めない。当日は新しい代理経路を試さず、その時点の手順で進め、迷ったところを残す。

## 役割と進行

| 時点・順 | 進行 | 役割・記録点 |
|---|---|---|
| 13:25 | 開始前の確認 | 山田が松本・佐々木と時計を合わせ、送出側と受領側の紙票をそれぞれの席に置く。 |
| 13:30 | 想定を1件渡す | 山田が投入し、現場役の松本が把握時刻を送出側の票に記す。 |
| 以後 | 運用当番を呼ぶ | 松本が当時の手順で連絡し、初回連絡、応答の有無と待ちの経過を送出側に記す。山田が当番の不応答と折返しを演じる。 |
| 折返し後 | 責任者へ連絡 | 松本は運用当番役に交代し、責任者への送信操作時刻を送出側の別欄に記す。山田は進行を観察する。 |
| 受領時 | 受領を返す | 責任者役の佐々木が受領を確認し、その時刻を受領側の票に記す。ここを計測の終了とする。 |
| 終了後 | 紙票を回収 | 山田が運用席、責任者席の順に別々に回収し、後で出来事と時刻を照合する。 |

## 確認事項と次の対応

送出側は把握・呼出し・応答・送信操作を、受領側は受領確認を記す。送信と受領を同じ時刻として扱わない。山田は止まった区間と判断に迷った点を観察欄に残し、回収した票を松本と照合する。
