# 松本さんに開始前に聞くこと

4月22日 13:25、本社で時計を合わせるときに確認。進行票を手元に置く。

- 最初に運用当番を呼び出して応答がない場合、手元の手順ではどの表示のまま待つことになるか。応答がないと分かった時点は紙に残せるか。
- 当番から折返しが来た後、責任者への連絡は誰が引き継いで送るか。現場役から運用当番役へ交代するところを確認する。
- 応答を待って止まっている間の状況は、送出側の紙票のどこに書くか。時刻だけでなく、そのとき待っていたことも分かるようにしたい。

現行手順で判断できないところは、その場で新しい経路を補わず、観察欄に残す。送信操作と佐々木さんの受領確認は別々の時刻として記録し、終了後に票を回収して照合する。
