# 松本さんと紙票を見たところ

## 日時

2026年4月23日 10:00〜10:25。山田 美由紀、松本 秀一。

## 資料

4月22日の送出側時刻票 CD-IM-202604-CHK-02 v1、受領側時刻票 CD-IM-202604-CHK-03 v1、演習ボードの記録。

## 確認事項

送出側の票では、想定の把握が13:30、運用当番への初回連絡が13:34、応答なしの確認が13:38、当番からの折返しが14:09。13:38の欄には「折返し待ち」とある。ボードの待ち区間も13:38〜14:09で、31分間だった。

13:38には応答がないことは分かっていたが、旧手順では当番が出ないときの次の相手が決まっていなかった。松本さんは折返しを待ち、14:09の折返し後に運用当番役へ交代した。待ちの区間を、連絡済みの時間として扱わない。

松本さんの14:16は責任者への送信操作、佐々木さんの14:17は連絡を開いて受領確認を返した時刻。同じ連絡の別々の記録点として両方採用する。13:25に時計を合わせており、1分の差を時計差として補正しない。把握13:30から受領確認14:17までは47分、目標30分を17分超えた。14:16までの46分は送信操作までの時間。

## 次の対応

山田が両票の時刻を照合表 CD-IM-202604-IDX-01 v1 にまとめ、4月24日の振り返りで31分の待ちと代理先の決め方を示す。運用当番側と責任者側の不応答は分けて相談する。
