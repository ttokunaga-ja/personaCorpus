# 三和契約　配送と一時保管の条項抜粋

文書番号：付番なし　版：版管理なし
作成日：2025年2月3日　作成者：清水宏之
確認／承認：別途承認なし　宛先：山田美由紀
社内照合用・社外持出し不可

## 日時

2025年2月3日　質問票の照合に先立ち作成。

## 資料

三和オフィス機器株式会社・中京文書配送サービス株式会社間の文書配送契約 SW-CD-2024-12。以下は質問票の範囲確認に必要な箇所の抜粋。原契約全体の代わりにはならない。

## 確認事項

| 原契約の位置 | 該当箇所 |
|---|---|
| 第2条（業務の範囲） | 中京が行う業務は、別紙1に定める場所における文書の引取受付から指定先への引渡までの配送及びその業務に伴う一時保管とする。 |
| 別紙1 第1項（指定拠点・受渡場所） | 引取及び引渡の場所は、三和が指定し、中京が受付時に確認した拠点又は場所とする。 |
| 別紙1 第2項（役務範囲） | 指定場所での引取受付、配送中の取扱い、業務に伴う一時保管及び指定先での引渡を対象とする。引取受付前及び引渡後の三和側の保管は含まない。 |
| 第5条（一時保管） | 業務に伴い一時保管する場合の期間は、引取日の翌営業日の終業までとする。これを超える取扱いは別途協議する。 |
| 第8条（事故時の連絡） | 中京は事故を把握したとき、把握後30分以内に三和へ第一報を行う。 |

第8条の30分は第一報までの時間であり、復旧完了までの時間ではない。事故時の責任の扱いは原契約第10条を参照すること。本抜粋は責任条項の全文を掲載していない。

## 次の対応

山田さんは質問票の各項目を第2条と別紙1の境界に照らしてください。保管期限や事故時の条件を超える要望は、回答前に法務へ確認してください。原契約及びこの抜粋の利用は社内に限ります。
