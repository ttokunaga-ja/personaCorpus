# 三和に答えた後も残す留保

清水さんの修正文を明細に反映する。回答を出したことと、次の範囲を超えて約束したことは別。

- Q12：松本さんの24件は1月20〜31日の三和向け配送からの抽出。24件の受付・引渡を照合した結果を、全期間・全配送の無事故や将来の紛失ゼロに広げない。
- Q24：契約第5条は引取日の翌営業日終業まで。延長を希望されたら期間や対象など依頼条件を聞き、清水さんに戻す。個別協議の結果を先に約束しない。
- Q39：1月17日・29日の演習は把握から初報まで21分・26分。復旧所要時間は測っていない。第8条の30分以内は初報で、復旧完了時刻ではない。
