# 三和　対象外6問の読み合わせ

文書番号：CD-IM-202502-MTG-01　版：v1
作成日：2025年2月7日　作成者：山田 美由紀
確認者：清水 宏之、林 直子　宛先：清水、林

## 日時
2025年2月7日 10:30〜11:10。出席：山田、清水、林。

## 資料
SW-PQ-2025-02 v1.0、48問と契約を並べた表 CD-IM-202502-CHK-01 v0.1、契約 SW-CD-2024-12 の条項抜粋。

## 確認事項
契約第2条・別紙1の役務は指定場所での引取受付から指定先での引渡までで、業務中の一時保管を含む。次の6問はその範囲外とすることを清水、林と確認した。回答欄には各理由を記し、空欄にはしない。

| 質問 | 対象外の理由 |
|---|---|
| Q08 | 引取受付前の三和社内の仮置きであり、中京の引受け前 |
| Q17 | 引渡後の三和社内保管であり、中京の役務終了後 |
| Q26 | 三和の購買ポータルの認証管理であり、配送役務外 |
| Q34 | 三和社内の警報の調査であり、配送役務外 |
| Q41 | 引渡後に三和が手配する廃棄業者の管理であり、引渡後の役務外 |
| Q47 | 三和の関係会社が独自に契約した委託先の監査であり、中京の役務外 |

残る39問は実施状況を、Q12・Q24・Q39は現契約の条件まで答える。Q12の抽出照合は将来の紛失ゼロの保証ではない。Q24は引取日の翌営業日終業まで、延長は個別協議。Q39の30分は事故把握から初報までであり復旧完了ではない。内訳は39＋3＋6＝48問、対象外も理由を記した回答として未回答に数えない。

## 次の対応
清水は無条件の保証文を契約と記録に合う文に修正する。山田は質問番号ごとの回答明細を作り、6問に個別理由を入れる。林は山崎に境界と3問の条件を説明し、確認後に提出する。期限は2月10日15時。
