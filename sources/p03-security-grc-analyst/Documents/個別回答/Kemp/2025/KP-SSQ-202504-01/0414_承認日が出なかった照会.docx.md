# Kemp 再委託先の原記録についての照会
文書番号：CD-IM-202504-MTG-01　版：v1
作成日：2025-04-14　作成者：山田 美由紀
確認／承認：山田 美由紀（整理）　宛先：林 直子、井上 美枝子、松本 秀一

## 照会の結果
4月11日に井上さんと松本さんへ依頼した原記録について、14日午後に分かる範囲を確認した。購買の現用先一覧には対象先が載っているが、承認日が出ない。承認された時点をこの一覧だけでは確認できない。

松本さんの運用月報は自社便と再委託便を分けられない。月報の件数から再委託便の受渡の両側が一致したとは言えず、一次連絡の演習または実施記録も対象経路を特定できない。

## 未確認と次の確認
| 設問 | 現時点の不足 | 次の確認先と探すもの |
|---|---|---|
| 78 | 承認日入り原票 | 井上：原票の保存元 |
| 79 | 再委託便の受渡双方の対記録 | 松本：対象期間と保存元 |
| 80 | 対象経路の演習票または実施記録 | 松本：記録の保存元 |
| 81 | 現行の業務別紙と適用日 | 井上：契約別紙の保存元 |
| 82 | 顧客の記録確認条件の条項 | 清水：契約原本の該当条項 |

No.78〜82は不足のまま維持する。井上さんと松本さんに原票の保存元を改めて確認し、清水さんには閲覧条件を別途相談する。林さんには5問を確認済み回答に混ぜないよう共有する。
