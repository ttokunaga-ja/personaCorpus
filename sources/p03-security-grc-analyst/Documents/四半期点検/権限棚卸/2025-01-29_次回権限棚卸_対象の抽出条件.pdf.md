# 次の棚卸に渡す抽出条件

文書番号：CD-IM-202501-CHK-05　版：v1  
記録日：2025年1月29日　記録者：山田 美由紀  
宛先：松本 秀一、次の点検担当

## 範囲を決める前に

松本さん、次回の所属変更後の権限棚卸では、受付月ではなく発令日を基準に対象を決めてください。受付が前月でも対象の発令日に該当する変更は含めます。発令控えに訂正があれば、確認時点で有効な控えに戻って範囲を確かめてください。個人を特定する発令控えは人事窓口内で確認し、この紙には転記しません。

抽出したら、差異だけを取り出す前に、発令日、対象を固定した日時、対象件数と業務別の内訳、照会条件を控えます。再照合ではその固定範囲に戻り、同じ条件で全対象の権限状態を確認します。対象を取り直して件数が変わった場合は、元の範囲と区別して理由を確かめてください。

## 今回の記入例

| 記録する項目 | 今回の値・確認した記録 |
|---|---|
| 発令日 | 2025年1月1日。前年12月受付でも同日発令なら対象に含む |
| 対象固定時刻 | 2025年1月24日 09:00 |
| 固定対象 | 権限136件。配送依頼管理60件、変更実績照会46件、保管照会30件 |
| 再照合時刻 | 2025年1月28日 09:30 |
| 照会・照合の記録 | CD-IM-202501-CHK-03 v1「24日 判定」「28日 再照合」。同じ固定範囲を照合 |
| 結果 | 固定時は一致127件、未反映9件。再照合は一致136件、未反映0件 |

1月27日の処置は旧所属権限の解除6件、付替3件。28日に解除後の旧権限と変更後の権限状態を照合し、今回の136件について未解消0件と佐々木さんへ報告した。今回の是正を次回分として再起票せず、この結果と区別して次の点検を行う。

## 突き合わせる順番

1. 山口さんの発令控えで対象の発令日と、確認時点で有効な所属を確かめる。受付日だけで対象を除かない。
2. 松本さんが対象を固定し、固定日時、権限件数、業務別内訳と照会条件を記録する。差異を抽出する前の範囲を控えておく。
3. 固定範囲の各権限を変更後の所属と照合し、一致と未反映を分ける。差異は旧所属の権限を解除するものか、新所属へ付け替えるものかを確認する。
4. 対応後は控えた元の範囲に戻り、差異を抽出し直す。初回に一致した権限も含めて同じ条件で再照合し、再照合時刻と結果を残す。根拠が確認できないものは未確認として分け、確認先を残す。
5. 対象件数と二つの時点、差異の処置と確認根拠をまとめる。次回の結果は今回の結論と混ぜずに報告する。
