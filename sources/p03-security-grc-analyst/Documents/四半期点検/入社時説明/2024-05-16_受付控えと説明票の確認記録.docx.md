# 受付控えと説明票の確認記録

文書番号：CD-IM-202405-MTG-01  
版：v1  
作成日：2024-05-16  
作成者：山田 美由紀  
確認者：山口 久美子、松本 秀一  
宛先：山口 久美子、松本 秀一

## 日時
2024年5月16日 14:00〜14:30。出席：山田、山口、松本。

## 資料
人事窓口の受付控え・配属予定と発令控え、運用管理の入社時説明票。年間点検表の IM-HR-03 は実施日を照会できる匿名集計を求めている。

## 確認事項
山口さんの受付控えで受付日を確認し、配属予定と発令控えを見比べ、配属月は発令で確かめる。松本さんの説明票では実施回の日付を確認する。受付の日付を説明日として扱わない。

5月7日の説明は2人。そのうち1人は4月受付で、5月に配属され同日に説明を受けた。受付月は4月、配属月と説明月は5月になり、月ごとの数を引くだけでは個々の未実施を判断できない。

原票の氏名照合は人事・運用の担当窓口内で行う。山田の控えには氏名を写さず、実施回ごとの人数と紙票の照会先を渡す。

## 次の対応
- 山口：受付月と発令による配属月を窓口で照合する。
- 松本：説明票の実施日と回ごとの人数を確認し、紙票の参照先を山田に知らせる。
- 山田：回収先と照会する日付を一覧にし、月末の回収に備える。
