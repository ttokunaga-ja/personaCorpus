# 来週、7件が戻ってきたら

10/31の終わりで受領0、待ち7。森さんからはS24-064の9月締めが10月出力でもよいかという照会だけ。S24-074は4〜6月の原票を総務で確認してからとのこと。添付は来ていないので受領欄は空けておく。

10/24の「池田さんへ出した証跡一覧」は提出したときのまま残す。取直し版は証跡IDと受領日をファイル名に付けて別に保存。受領日はまず「出し直し7件　担当と必要な期間」の作業控えへ入れる。対象開始・終了（訓練なら実施日）と原記録の所在を見てから、照合済みを付ける。出力が翌月の紙は、期間欄を先に読む。

11/5の15時を過ぎたら、まず松本さんにS24-021。9月中に実施した回の記録があるかを聞く。10/1の記録はそのまま。見つからなければ、どこまで見てもらったかを控えて「未確認」で返す。11/7の池田さんへの連絡に残った理由も入れること。
