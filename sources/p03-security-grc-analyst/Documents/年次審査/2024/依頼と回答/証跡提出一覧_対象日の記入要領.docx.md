# 提出一覧の対象日をどこから取るか

## 日時

2024年10月9日。10月24日の事前提出に向けた、一覧の記入方法の共有です。

## 資料

- さくら情報管理審査「2024年度 年次審査の事前提出について」SK-2024-REQ-01 v1
- 社内配布「点検の証跡を出すとき」CD-IM-202404-ANS-01 v1

## 確認事項

指定対象には、確認のために求められた月・四半期・実施回を入れてください。対象開始、対象終了、実施日の各欄には、手元の資料に載っている日付を入れます。指定と違うものが出てきたときも、資料から採った日付を指定月に合わせて上書きしないでください。

| 資料 | 日付を採る箇所 | 記入例 |
|---|---|---|
| 運用の月報 | 表題の対象年月 | 表題が「2024年9月分」なら対象開始9月1日、終了9月30日。10月2日に取り出した場合は発行・出力日を10月2日とする。 |
| 紙の照合票 | 帳票の「点検期間」欄 | 「7月1日〜9月30日」とあれば対象開始7月1日、終了9月30日。受付印の日付はこの欄に入れない。 |
| 訓練の記録 | 「実施」欄の実施日 | 実施欄の日付を実施日に転記する。指定が「9月中の実施回」なら、その文言は指定対象に残す。回の記録に開始・終了の記載がなければ両欄は空欄。 |

人事の集計は、実施分を拾った開始日・終了日を集計条件で確かめてください。抽出した日しか分からない資料は、確認できた日を出力日として記入し、対象日は空欄のまま、資料名と元記録の確認先を併記してください。月報と訓練は松本さん、人事集計は山口さん、総務の紙の照合票は森さんに元記録の所在を確認します。

## 次の対応

各担当で日付の出典が分かるようにし、一覧用の記入内容を山田へ戻してください。指定対象から外れる記録や、対象の欄を読めない控えがあれば、資料名と元記録の確認先を添えて山田にお知らせください。こちらで提出一覧へまとめる際に照合します。
