# 8月月次是正会議　確認した5件

文書番号：CD-IM-202508-MTG-01　版：v1　作成日：2025年8月25日
作成者：山田 美由紀　確認者：木村 孝之　宛先：木村 孝之、佐々木 和夫、松本 秀一、井上 美枝子

## 日時

2025年8月25日 14:00〜14:45、会議室C。出席：佐々木 和夫、木村 孝之、松本 秀一、井上 美枝子、山田 美由紀。

## 資料

月次是正会議「期限超過と閉じ方」CD-IM-202508-BRF-01 v1、RISK-031評価表 CD-IM-202507-CHK-01 v1、受容見送りから判定までの図。

## 確認事項

木村さんが月次会議全体の期限超過候補の元期限と状態を照合し、期限超過5件を確認した。この5件は会議全体の集計である。RISK-031の未実施3対象は別の議題で、証拠回収期限は9月30日。期限超過5件には含めず、両者を足し合わせない。

佐々木さんから閉じ方について口頭了解があったが、それ自体を決裁欄へ転記して完了にはしない。原記録を受領し、対象・実施日・確認者および照合した記録の対応を木村さんが独立確認した対象だけを、佐々木さんの書面決裁に回す。根拠が不足する対象は担当者に戻し、状態を継続する。

## 次の対応

| 担当 | 対応 | 期限 |
|---|---|---|
| 松本 | 日高の保管区画と返却箱の点検を別々に進め、原記録と票を用意する | 9月30日の回収に向けて |
| 井上 | 日高・ふじの窓口と資料回収を調整する | 9月30日 |
| 山田 | 受領日と対象を記録し、木村さんに照合を依頼する | 受領の都度 |
| 木村 | 受領した記録と対象範囲を独立照合し、不足を山田へ伝える | 受領後 |
| 佐々木 | 照合結果を受け対象ごとに書面で判断する | 独立確認後 |

ふじの派遣者取扱は斎藤さんが対象名簿と確認記録を手配する。山田から会議後に伝える。
