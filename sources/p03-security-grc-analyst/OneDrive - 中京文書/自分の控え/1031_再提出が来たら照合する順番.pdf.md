# 再提出が来たら照合する順番
文書番号：CD-IM-202410-MTG-03　版：v1　作成日：2024年10月31日  
作成者：山田 美由紀　宛先：山田（自分用）  
確認・承認：自分用の確認手順

## 日時

11月5日15:00の社内回収に向けた控え。届いた分から着手する。

## 開く資料

CD-IM-202410-CHK-02 v1「出し直し7件　担当と必要な期間」と、10月24日に池田さんへ出した一覧。指定期間は差戻し一覧、提出時にどの資料を出したかは10月24日の一覧で引く。

## 受領から照合まで

1. **まず受領を控える。** 返信の証跡IDを差戻し一覧の行に当て、添付があれば受領日と再提出版を記録する。版表記がなければファイル名と受領日で区別する。照会だけ届いた行は受領欄を空けたままにする。
2. **日付は原記録から読む。** 月次・四半期は対象開始日と終了日、実施回は記録の実施日を指定と照らす。集計資料は集計条件も見る。出力日は別に控え、対象欄が読めなければ担当に元記録を聞く。
3. **一致したら所在地を控える。** 原記録の所在と版、照合した日付を差戻し一覧の作業控えに記入し、ここで初めて「照合済み」とする。
4. **違う場合も届いた資料を保存する。** 証跡IDと受領日を付けた別ファイルで残し、差戻し一覧に実際の期間、不足箇所、再確認先を追記する。原記録を確認できない場合は「未確認」として、確認した範囲も残す。

## 森さんへ返す前に

10月30日の照会はS24-064。9月締めを10月に出力した控えなら、貸出と返却の照合結果があり、対象欄で9月1日〜30日を読めるかを先に見る。10月出力というだけでは差戻しにならない。最初に出した方の10月1日〜15日の途中集計とはファイルを分ける。照会の返信に資料は付いていないので、現時点で受領日も照合結果も入れない。

## 次の対応

11月7日までの池田さんへの連絡では、照合済みの行は対象と根拠を、未確認の行は確認した範囲と残った理由を伝える。
