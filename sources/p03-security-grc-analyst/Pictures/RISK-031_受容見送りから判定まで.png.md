# 図：RISK-031 受容見送りから判定まで

上から下へ矢印でつなぐ判断フロー。図中の文字は以下のとおり。

1. 「7月18日　委託先点検未実施 3件／佐々木：受容見送り」
2. 「01 日高・保管区画」「02 日高・返却箱受渡」「03 ふじ・派遣者取扱」の3対象を並べ、次の共通箱へ矢印を集める。
3. 「原記録の所在確認：7月31日まで」→「是正証拠の回収：9月30日予定」→「山田：受領を記録」→「木村：独立確認」
4. 判断ひし形「点検日・対象範囲・確認者と照合した原記録が揃うか」。いいえは「不足を担当へ差戻し・回収」に進み、回収へ戻る。はいは「佐々木：対象ごとに書面決裁」に進む。
5. 決裁から「根拠を確認し完了と決裁 → 完了」と「不足または判断保留 → 継続・追加確認」の2枝に分かれる。

件数は起点の未実施3件のみ。終点の完了・継続の件数は記さない。軸・単位・数値系列はない。
