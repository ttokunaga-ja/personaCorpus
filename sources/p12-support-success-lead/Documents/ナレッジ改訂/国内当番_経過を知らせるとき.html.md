# 国内当番　経過を知らせるとき

2025年10月23日改訂　原 美佐子  
10月23日16:30から適用

## 対象

顧客への回答や調査が続いている受付。まず問い合わせ管理サービスの対応履歴を読み、直前に何を返し、顧客が何の回答を待っているか確かめる。受領の連絡だけで用件への回答が済んだと扱わない。

## 当番記録を書く順番

1. 根拠が確認できた解決予定日を書く。根拠が取れなければ「未定」とする。予想だけで日付を埋めない。
2. 確認先と確認する内容を記す。予定が未定でも、顧客に知らせる次回連絡日時を置く。遅くとも2営業日以内とする。
3. 発信担当を決め、その人が時刻と内容を引き受けたことを確かめる。交替時は原が引受けと顧客に伝えた時刻を確認する。
4. 約束時刻に確認できたことと未確認のことを伝える。回答がまだなくても連絡し、次の連絡時刻を取り直す。予定日が決まった場合も次報の枠は残す。予定が変われば担当から知らせる。
5. 送信時刻を対応履歴に残す。顧客が業務を再び行えることを確認するまで受付を開いたままにする。

## 021の記入例

谷口さんが待っているのは、共有受信箱に通常の受付通知が届かない理由と復旧見通し。21日15:40の宮本さんの発信は照会の受領で、通知経路の回答ではない。22日10:20の再連絡と合わせて読む。

| 当番記録 | 内容 |
|---|---|
| 解決予定日 | 未定（修正日の根拠を確認できていない） |
| 確認先・確認事項 | 柴田さんに通知経路と再現範囲を確認 |
| 次回連絡日 | 10月27日15:00 |
| 発信担当 | 上田 |

上田さんは27日15時に、その時点で確認できた分を谷口さんに知らせる。確認結果が揃っていなければ、未確認の範囲と次回の約束も伝える。
