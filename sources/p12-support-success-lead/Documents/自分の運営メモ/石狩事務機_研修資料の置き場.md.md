# 石狩事務機 研修資料の置き場

2024年8月30日

研修机で使った割当表と、候補の見せ方を試読した版は顧客会議の控えに置く。次に配る資料と混ぜない。

- `Documents/顧客会議/石狩事務機/送付先演習の割当.xlsx`：札と卓、題材の割当。
- `Documents/顧客会議/石狩事務機/宛先選択演習_試読版.pptx`：酒井さんと確認した試読版。候補名の前半だけを見せていた版なので、当日の説明には使わない。
- `OneDrive - 灯枝サービス/配布用の説明/石狩事務機_宛先確認の早見.pdf`：管理者が次回も参照する早見。
- `Documents/既知問題と案内/石狩事務機_初週の宛先確認.html`：管理者用の確認案内。選択、送信前の詳細、札番号付き返信の順を確認するときに開く。

記録を探すときは日付と目的を見る。19日の初回選択と送信前停止は `Downloads/宛先演習_0819.csv`。20〜23日の受領と介助は `Documents/顧客会議/石狩事務機/0823_初週の宛先確認.csv` と `0823_初週の介助箇所.xlsx`。27日に題材を替えた07・14の結果は同じ顧客会議フォルダの `0827_介助後の再確認.csv`。27日の2人を初週の本人3人に足さない。

大野さんの29日の返信では、練習専用の受領当番は今日30日で終了。次に演習を組むときは、同じ札番号で返信できる受領役を大野さんに改めて確保してもらう。送信済みの表示と先方の受領は別に確認する。
