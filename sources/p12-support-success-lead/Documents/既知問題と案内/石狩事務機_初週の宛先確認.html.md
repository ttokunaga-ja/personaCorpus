# 石狩事務機 初週の宛先確認

対象：8月19日の演習で送信前に確認を止めた5人。8月20日から23日の確認枠で、演習用メールを使います。実際のお客様の連絡先や業務データは使いません。

## 確認する順番
1. 件名に自分の演習札番号を入れます。貸出台帳の照会または納品日程の連絡を、指定された題材で作ります。
2. 宛先候補を開き、題材に合う「窓口」を選びます。「控え」と末尾まで読み比べてください。
3. 送る前に宛先の詳細を開き、表示名とアドレスを読みます。貸出台帳の窓口は loan-desk@ishikari-jimuki.example、納品日程の窓口は delivery-desk@ishikari-jimuki.example です。異なるときは送らず、候補を開き直します。
4. 送信後、大野さん側から同じ札番号の入った返信を受け取ったことを確認します。「送信済み」の表示だけでは先方の受領を確認できません。

## 注意
- 表示の差に気づいたら、まず自分で候補を開き直してください。当番が具体的な候補や宛先欄を示した場合は、介助として記録します。見守って待っただけの場合とは分けます。
- 受領役が不在のときは送信を待ち、当番に知らせてください。受領役が戻れる枠で同じ札を使って確認します。
