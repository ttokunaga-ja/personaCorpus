# 権限の確認と操作のご案内

文書番号：TS-CS-202502-ANS-001　版：1.0  
日付：2025年2月25日　作成：上田 由美香  
宛先：円山印章株式会社　丸山 和宏 様  
発信者：灯枝サービス株式会社　上田 由美香

## ご相談

受注・出荷の担当を決めるにあたり、お送りいただいた14件について、現在の設定を確かめる順にご案内します。まず役割と所属の現在値を確認し、変更が必要な場合にだけ個別に操作してください。

## 確認結果

| 番号 | ご質問 | 確認できること・操作できる方 |
|---|---|---|
| 01 | 新しい担当者の招待 | 現在の管理者が一人ずつ招待できます。 |
| 02 | 利用停止 | 現在の管理者が対象者を確認して個別に停止できます。 |
| 03 | 既存班への所属追加 | 現在の管理者が利用者ごとに追加できます。 |
| 04 | 管理者の追加 | 現在の管理者が別の利用者に管理者を付与できます。 |
| 05 | 現在の役割 | 管理者が利用者一覧で確認できます。 |
| 06 | 担当替え後の表示 | 現在の閲覧範囲と本人の検索条件を確認します。以前の閲覧範囲の復元はできません。 |
| 07 | 保存済み検索条件 | 保存した本人が外せます。管理者が他の方の条件を変更することはできません。 |
| 08 | 他班の受付 | 現在許可された閲覧範囲内で確認します。検索条件を外しても他班全体を閲覧できるようにはなりません。 |
| 09 | 現在の所属 | 管理者が利用者一覧で確認できます。 |
| 10 | 通知先 | 通知を受ける本人が確認します。 |
| 11 | 担当履歴 | 閲覧できる個別の受付で担当履歴を確認できます。利用者の権限変更履歴ではありません。 |

## 進め方

### 現在値を確認する（05・09）

現管理者で「利用者一覧」を開き、確認したい方の「役割」と「所属」をご覧ください。例えば役割が「担当者」、所属が「受注班」と表示されていれば、それがその方の現在値です。受注・出荷それぞれの対象者について、氏名と表示を照合してください。この確認だけでは設定は変わりません。

### 必要なときだけ個別操作する（01〜04）

- 01 招待：現管理者で「利用者一覧」の「招待」を選び、招待先と必要な役割・所属を入力します。招待先と入力内容を確かめてから招待します。新しい担当者ごとに行ってください。
- 02 利用停止：一覧から対象者を開き、氏名・現在の役割・所属を確認して「利用停止」を選びます。停止する方を再確認して保存します。
- 03 所属追加：一覧から対象者を開いて所属の編集を選び、既存の班を指定します。例えば出荷班を追加するときは、対象者と追加先が意図したとおりか確かめて保存します。
- 04 管理者の追加：現管理者が一覧から付与先の別の利用者を選び、役割の編集で管理者を選びます。対象者と変更内容を確認して保存します。

いずれも一人ずつ行います。対象と内容を保存前に照合し、必要のない変更は行わないでください。

### 検索と履歴を確認する（06〜08・10・11）

担当替え後に受付が見当たらない場合は、先に上記の役割・所属を確認し、同じ利用者で受付一覧を開いてください。保存済み検索条件は、その条件を保存した本人が確認し、必要に応じて外します。管理者が代わりに他の方の保存条件を外すことはできません。

例えば受注班だけを閲覧できる方が「未完了」の保存条件を外すと、現在見られる受注班の完了分も一覧に現れます。一方、出荷班だけの受付が加わるわけではありません。条件を外しても現在の閲覧範囲は広がらず、担当替え前の範囲も復元されません。表示件数だけで以前の範囲を判断しないでください。

通知先は、通知を受けるご本人に現在の設定を確認していただきます。引継ぎの経緯は、現在閲覧できる個別の受付を開き、その受付の担当履歴で確認できます。担当履歴は権限の変更履歴とは別です。

## 継続確認

12〜14のご相談は、営業が別途前提を確認します。まずは現在の役割と所属からご確認ください。確認中に表示や手順でご不明な点がありましたら、対象の質問番号とあわせてお知らせください。
