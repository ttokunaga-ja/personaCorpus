# 返却分だけ順に回す

図の流れは上から下。箱と矢印に次の文字を入れる。

開始：返却分を1件ずつ確認

↓

谷口さん：返却分の受付記録にある受付番号を1件確認

↓

谷口さん：問い合わせ管理サービスの対象受付を開き、画面の受付番号と、返却分の受付記録の番号を照合

↓

判断：受付記録と画面の受付番号は一致？

- はい → 谷口さん：その受付の担当を返却班に手動設定 → 返却班の当番：担当一覧で同じ受付番号の受け取りを確認 → 次の返却分へ
- いいえ → 担当設定を止める → 上田に照会する

注記：機材名だけではまとめない。同じ機材の別受付を動かさないよう、受付番号で確認する。返却班以外には広げない。手動設定は自動振分けの復旧ではない。
