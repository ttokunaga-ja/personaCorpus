# 対応履歴を見て次報の2欄を書く

左に既存の「問い合わせ管理サービス」の受付詳細画面。上部に「苦情受付番号 CR-2510-021」「露原機材販売株式会社」「対応履歴」。履歴に次の二行を表示する。

- 2025/10/21 15:40　発信　宮本　照会を受け付けました。
- 2025/10/22 10:20　再連絡　谷口　共有受信箱に通常の受付通知が届かない理由と復旧見通しを確認したい。

二行を指す注記「発信内容と、その後に求められた返事を読む」。画面の外に矢印を引き、右側に別紙「当番記録の記入例」を置く。画面の入力欄に見せない。

| 項目 | 記入例 |
|---|---|
| 解決予定日 | 未定 |
| 次回連絡日 | 10月27日15:00 |
| 発信担当 | 上田 |
| 確認先 | 柴田 |
| 確認事項 | 通知経路と再現範囲 |

下に「予定日が決まらなくても、確認できたことを約束の時刻に知らせる」。
