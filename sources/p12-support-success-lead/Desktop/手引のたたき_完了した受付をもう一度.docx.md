# 当番で受付を扱うとき

文書番号：TS-CS-202505-ANS-001　版：第0.1版
日付：2025年5月19日　作成者：上田 由美香
宛先：白樺ビルメンテナンス株式会社　参加拠点の当番の皆さま
発信者：灯枝サービス株式会社　上田由美香

## 相談
当番の日に受付を引き取り、対応後に同じ受付をもう一度確かめるまでを、研修で一緒に練習します。

## 確認結果
演習では受付番号4806を使います。一覧に見当たらないときは、表示の条件を確認します。

## 進め方
1. 受付を開き、番号4806を控えます。自分が当番として引き取る受付の番号を声に出して確認します。
2. 対応を終えたら状態を「完了」にし、表示された番号と状態を読みます。
3. 一覧へ戻り、受付番号4806を探します。保存条件の「未完了」を外して一覧を表示し直します。
4. 同じ番号と「完了」を確認します。見つからない場合は操作を止め、受付番号と止まったところを灯枝サービスの担当へお知らせください。
