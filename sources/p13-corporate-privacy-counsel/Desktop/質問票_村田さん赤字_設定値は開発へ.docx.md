# 委託先質問票の回答担当案
文書番号：TDS-LG-202407-CON-001／版：0.2／作成日：2024年7月11日／作成者：高田 美奈子／宛先：村田 幸一／確認者：村田 幸一／確認日：2024年7月19日

## 相談の背景
村田さんから、購買で受けた回答を法務に回した後、保存設定を誰に確認し直すか決まらず、先方への再質問が止まったと伺った。まず契約に関係する質問を法務にまとめる案を置く。

## 担当案
64問のうちQ17〜Q28は契約に関係するので、法務が一括回答する。購買は先方への送付と回答の受領を担い、受領した資料を法務に渡す。残る52問は現行の担当のままとする。

| 対象 | 法務で記載する内容 |
|---|---|
| Q17 権限 | 購買が先方の権限一覧を取り寄せ、開発が権限の実態と適用対象を点検し、法務が契約上の許容条件を判断する。 |
| Q20〜Q22 証跡 | ログの対象・期間、閲覧者、例外時の連絡を法務で整理する。 |
| Q23 保存 | 購買が先方の設定の証跡を取り寄せ、開発が通常領域とバックアップの設定と適用範囲を点検し、法務が契約上の許容条件を判断する。 |
| Q24〜Q25 削除 | 指示の対象領域と結果確認を法務で整理する。 |
| Q26〜Q28 再委託 | 作業・アクセスの範囲、下流への義務、変更連絡を法務で整理する。 |

## 記入の運び
先方からの説明と、それを踏まえた自社の契約上の判断は現行の同じ回答欄に続けて書く。根拠資料欄には先方から受けた資料名を記す。追加の質問が必要なら法務から購買に依頼する。

## 村田さんへの確認
このまとめ方で購買の照会担当が迷わず受け渡せるか、特に権限と保存設定について見ていただきたい。
