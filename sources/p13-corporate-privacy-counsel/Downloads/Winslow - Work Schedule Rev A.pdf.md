# Work Schedule — Image Intake Separation

Document: WR-202411-SCH-001  
Revision: A  
Date: 5 November 2024  
Prepared by: Andrea Powell  
For: Toto Document Data Services

## Scope of this proposal

This schedule accompanies WR-202411-FLW-001 Rev A for review of the proposed separation of image intake and deskewing. The destinations below identify the handoff or return for each step. They do not themselves authorize work to start.

## Schedule

| No. | Step | Destination or return | Treatment in order schedule |
|---:|---|---|---|
| 1 | Receipt of items for intake | Image Intake | Receive the items identified for intake. |
| 2 | Image intake | Image Intake | Perform image intake. |
| 3 | Normal handoff | Winslow Quality Review | Send normal intake output directly for quality review. |
| 4 | Quality review | Winslow Quality Review | Review the intake output for intake defects. |
| 5 | Return of intake defects | Image Intake | Return defective intake items from quality review for re-intake. |
| 6 | Return after re-intake | Image Deskewing | Send the re-intake output and reprocessing work instruction to the deskewing provider. |
| 7 | Index verification reference | Existing review | Refer to the prior review treatment for index verification; no start arrangement is requested by this schedule. |
