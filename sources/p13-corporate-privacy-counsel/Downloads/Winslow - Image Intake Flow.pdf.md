# Image Intake Flow

Document: WR-202411-FLW-001  
Revision: A  
Date: 5 November 2024  
Prepared by: Andrea Powell  
For: Toto Document Data Services

## Earlier proposed handoff

The earlier proposal routed images from intake through the image deskewing provider before Winslow's quality review:

Image Intake → Image Deskewing → Winslow Quality Review

## Proposed separation

For a normal intake, the proposed route bypasses deskewing:

Image Intake → Winslow Quality Review

If Winslow Quality Review identifies an intake defect, the item is returned to Image Intake for re-intake. Once re-intake is complete, it returns to Winslow Quality Review:

Winslow Quality Review → Image Intake → Winslow Quality Review

The first arrow is the return of a defective intake; the second is the return after re-intake. This diagram describes the image handoffs only. Responsibility for index verification and the status of any start arrangements are outside its scope.
