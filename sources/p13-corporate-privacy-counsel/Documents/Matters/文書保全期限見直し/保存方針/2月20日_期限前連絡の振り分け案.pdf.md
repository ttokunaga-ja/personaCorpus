# 期限前の連絡を誰に回すか

文書番号：TDS-LG-202502-BRF-001　版：0.1  
作成日：2025年2月20日　作成者：高田 美奈子  
打合せ先：藤本 美佳

## 今日、藤本さんと確かめたいこと

河野部長から、期限前に根拠を確認する人と、異動で担当が抜けたときの引取先を試すよう依頼を受けた。例外の終期が近づいたら、原記録をまだ要する業務とその根拠を確認できる人に連絡したい。連絡が部署に届いたことと、本人が確認を引き受けたことは分けて記録する。

## 連絡の振り分け

対象区分の所管と連絡先を確認する。

```text
所管と連絡先を確認
 ├─ 両方明らか → 所管担当本人へ → 本人が引受け → 担当欄
 ├─ 異動先だけ判明 → 異動した本人へ後任を尋ねる
 │    ├─ 後任判明 → 後任本人が引受け → 担当欄
 │    └─ 後任不明 → 旧所属の代表窓口 → 下の経路へ
 └─ 所管未定 → 関係部署の代表窓口へ
      ├─ 正式な所管担当が判明 → 本人が引受け → 担当欄
      ├─ 代行候補を紹介 → 本人が照合を引受け → 代行欄
      └─ 未回答・引受けなし → 担当欄・代行欄は空欄
```

**1　所管と連絡先が明らか**  
藤本さんから所管の担当者本人へ、対象の記録、例外の終期、確認したい根拠を伝える。本人からその区分の確認を担当すると回答があれば、担当欄に氏名を記し、回答日と連絡の記録を残す。別の担当者を知らせる回答なら、その人に本人の引受けを確かめてから担当欄に入れる。返事待ちなら担当欄は確定せず、連絡先と照会日を控える。

**2　前の担当者の異動先だけが判明**  
まず異動した本人に、後任または現在の所管部署を尋ねる。異動先が分かっただけで、異動した人を現在の担当欄に入れない。後任が分かれば、その本人へ確認の引受けを照会し、本人の回答を得て担当欄に氏名を記す。後任が分からなければ、旧所属の部署の代表窓口へ現在の所管を尋ね、経路3へ進む。

**3　所管が決まらない**  
まず対象に関係する部署の代表窓口へ、現在の所管担当を確認し、決まっていなければ確認を引き受けられる代行候補の紹介を頼む。正式な所管担当が判明したと回答された場合は、その本人に対象区分の確認を担うことを確かめ、本人の引受けを得てから担当欄に氏名を記す。本人が代行として根拠の照合まで引き受ける場合は、担当欄は空欄のまま、代行欄に本人の氏名を記し、引受日と回答を控える。候補の紹介だけ、本人の未回答、または確認を引き受けられないという回答では、担当欄も代行欄も埋めず、照会先・照会日・次に尋ねる先を残す。

## 引受けの後に確認すること

担当または代行に、原記録を引き続き要する理由と終期に関係する記録の参照先を尋ね、実際に照合した事実と確認日を残してもらう。氏名の記入や引受けだけでは根拠の確認完了にはしない。終期の扱いを判断するときは、通常保存の残期間と別の有効な保存根拠も先に確かめる。確認の連絡に対する回答期限は、保存期間や例外の終期とは別に扱う。

## 見送る案

部署の代表窓口に連絡が届いた時点で担当者の引受けとする案は採らない。窓口への到達だけでは、誰も証跡を見ないまま期日が過ぎるおそれがある。窓口には所管または候補を尋ね、確認作業を担う本人の返答まで追う。
