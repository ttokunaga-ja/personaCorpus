# 従業員情報の取扱いについて
文書番号：TDS-LG-202408-INS-001　版：1.2　作成日：2024年8月1日
作成者：人事部 小島久美代　宛先：従業員各位　確認者：人事部

## お知らせ
東都文書データサービス株式会社は、皆さんの情報を次の目的で取り扱います。登録した内容に変更がある場合や、取扱いについて質問がある場合は人事部へご連絡ください。

## 取り扱う情報と目的
| 番号 | 情報 | 利用目的 |
|---|---|---|
| 01 | 氏名・連絡先 | 本人の確認と必要な連絡のため |
| 02 | 入社日・配属先 | 入社手続と配属の管理のため |
| 03 | 雇用条件 | 雇用契約の確認と管理のため |
| 04 | 緊急連絡先 | 人事管理のため |
| 05 | 給与・社会保険の手続情報 | 給与計算と社会保険の手続のため |
| 06 | 給与振込先 | 給与の振込みのため |
| 07 | 勤怠記録 | 勤務状況の確認と給与計算のため |
| 08 | 入退館履歴 | 施設管理のため |
| 09 | 休暇申請 | 休暇の取得と残日数の管理のため |
| 10 | 給与明細・支給記録 | 給与の支給と支給内容の確認のため |
| 11 | 異動・職務変更 | 配属と職務の管理のため |
| 12 | 研修受講履歴 | 社員教育のため |
| 13 | 業務連絡先 | 業務上の連絡のため |
| 14 | 貸与物の管理記録 | 貸与物の交付と返却の管理のため |
| 15 | 社内アカウント | 社内システムの利用管理のため |
| 16 | 貸与端末の利用ログ | システム管理のため |
| 17 | 経費精算 | 申請内容の確認と精算のため |
| 18 | 退職時の返却・精算 | 退職時の貸与物の返却と精算の確認のため |

## 変更・お問い合わせ
氏名、連絡先、緊急連絡先、給与振込先などに変更がある場合は、人事部へお申し出ください。情報の取扱いについてのご質問も人事部で受け付けます。

東都文書データサービス株式会社　人事部
