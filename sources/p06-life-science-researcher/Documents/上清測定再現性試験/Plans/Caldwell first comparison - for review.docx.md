# First Bennett–Caldwell comparison

BCE-CE-2024-PLN-003-R00 | Nov 12, 2024 | Melissa Watkins | Review draft

For Robert Nguyen and Lauren Brooks

## 1. Purpose and scope

Run a first comparison of supernatant measurements at Bennett Cell Evaluation and Caldwell Assay Services under current conditions. Set aside 18 fresh nonclinical samples for measurement at both sites. The October readings are outside this sample list. Continue to handle the 44 held results under BCE-CE-2024-HLD-001-R00.

## 2. Study design and records

Use a common label list at handoff. Lauren will keep Bennett's measurement dates, record numbers and readings together. Ask Angela Price at Caldwell to return the measurements in ng/mL with the shared labels. Retain the two source exports as received.

If Angela can return the export in the same order as the Bennett list, we could line up the two files by row for the first pass. Compare the returned labels with the handoff list before using any of those pairs. If a label differs or a row is missing, set the pair aside and resolve the discrepancy with Angela before calculating the mean.

For review with Lauren: Can we keep the same order at the two sites? Do we need a dedicated return field for Caldwell's own record ID? Confirm which copy of the shared label list should go with the handoff.

## 3. Acceptance and reporting

For each confirmed pair, take the absolute difference between the Caldwell and Bennett readings, divide by the Bennett reading and express the result as a percentage. Average those percentages across the 18 pairs. The proposed upper limit is 10%, inclusive, applied to the mean before rounding. List the pair differences and note any unresolved identity or missing-value issues. Hold the comparison open if the full set of 18 pairs cannot be confirmed or a relative difference cannot be calculated.

Retain the pair list and both exports with the comparison summary so the underlying readings can be checked during review.

## 4. Review and approval

Prepared by Melissa Watkins, Cell Evaluation Researcher. Lauren Brooks to review the handoff and return fields. Robert Nguyen, Laboratory Director, to confirm the design and criterion before we arrange the run. Approval pending.
