# Which records went into the August check

Document ID: MDR-LDI-20260804-DD-01-R01  
Issued: August 4, 2026  
Author: Joshua Ramirez  
For: Fatima Rahman and Vanessa Nguyen

## Collection and separation

The August assessment contains 4,000 new signed inspection records. One record is one inspection form; a correction or reinspection can be another record in the same series. I checked the record-series links against the 2025 training, development and fixed evaluation partitions. None of the August records shares a series with those partitions. The separation is by series, not merely by record identifier.

For example, when a received original and a later correction refer to the same equipment and the reviewed ledger links them as one series, both are checked under that series key. A new identifier on the correction is not evidence of independence. The reviewed link is used for the partition check, not appended to the text passed to the classifier.

## Reference at signature

We retain the eight classes in Fatima's signed-disposition guide. The reference is the action effective at signature, not necessarily the first status or a quoted earlier instruction. The four action-required classes and the other four classes make the following reference groups:

| Reference group | Records |
|---|---:|
| Repair required | 350 |
| Repeat inspection | 280 |
| Remove from service | 210 |
| Engineering review | 160 |
| Action required total | 1,000 |
| Routine closeout, Monitor at next service, Record correction, or No equipment finding | 3,000 |
| Total | 4,000 |

## What enters the comparison

Measure length on the original body before any cap. The classifier receives the body window only; the series key and reference label stay in the ledger for separation and scoring. Both routes use the same records and references. This collection description does not claim a result for either route.
