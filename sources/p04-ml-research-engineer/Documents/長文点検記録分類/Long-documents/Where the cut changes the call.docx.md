## Working interpretation

The first record is particularly misleading: a plausible earlier permission survives while the controlling stop does not. In the second, taking only the end would give us a signature rather than the repair direction. A useful comparison should expose both kinds of loss rather than assume that the last paragraph always carries the answer.

The last column is my current shorthand for what the input supports and the corresponding answer. Fatima, please mark where this obscures a distinction we need for the next pass. We should read the full record alongside each window before drawing a conclusion from any score.
