# August 3 — intake call with Brandon

Brandon and I went through the unit and the cost boundary before putting another comparison on the calendar.

The incoming item is one signed inspection record as received. If the classifier reads that same record a second time, it is still one received record for monthly volume, although both passes consume resources. Normal planning volume is 100,000 original records per month; a busy month is 120,000. The application-side ceiling is USD 4,500 per month, not a research funding request.

The current human review remains in place. We did not establish how arrivals cluster by time of day or what happens if a second inference cannot return in time. I need those answers before treating a monthly average as an operating plan. For the cost discussion, Brandon and I should put both conditions on the same count of original records and include the work of any second pass.
