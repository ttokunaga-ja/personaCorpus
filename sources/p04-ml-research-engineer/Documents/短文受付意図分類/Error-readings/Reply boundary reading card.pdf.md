# Reply boundary reading card

Document ID: MDR-STI-20241107-RM-01-R01  
Issued: November 7, 2024  
Author: Vanessa Nguyen  
For: Emily Chen

## Record three things from the received body

Read the whole body first. Use one entry per matching ID so we can return to the same lines when we compare readings.

| Field | What to enter |
|---|---|
| Current action phrase | Copy the words that carry the request in the reply. If it points back to an earlier booking or request, note the reference separately from the action phrase. |
| Candidate start of older wording | Copy the first line that would mark the start of the older passage, including an attribution if it introduces the passage. When the line contains both voices, note where in the line the switch seems to occur. |
| Cue and boundary | Copy the mark or words that led you to that spot. Record a clear or unclear boundary. If only the sense of the passage suggests the switch, record what changes in the voice or time reference. |

## Compare the cues

| Cue | What to look for | Boundary |
|---|---|---|
| Line-initial quote marker | “Please keep the Friday slot.” is followed on the next line by “> Could I take the Friday slot?” The marker identifies the older line. | Clear |
| Separate attribution line | “Please keep the Friday slot.” is followed by a standalone “On Tuesday you wrote:” and then the older request. The attribution has its own line. | Clear |
| Wrapped attribution | “Please keep Friday, and as I wrote” continues on the next line with “on Tuesday, Thursday won't work.” The attribution runs through the reply, with no independent line to mark the switch. | Unclear |
| Context only | “Friday works now.” followed by “Thursday is the only slot I can take.” may switch back to older wording. Without a marker or a separate attribution, the timing and context are the only clues. | Unclear |

If the reply repeats “Friday slot” from an older line, underline it where it helps identify the booking. The repetition alone gives you no reason to mark a boundary there. Record the actual cue on the line where you think the older passage begins.
