## Reading the pairs

Nicole, would you check whether these contrasts preserve our Monday readings, especially the second pair? Each side has one supported intent. The examples isolate the issue we discussed in the 41 scope readings; they are minimal contrasts, not a reproduction of the 160 records or additional errors to add to the count.

| Contrast | First body; evidence; reference intent; candidate if misread | Paired body; evidence; reference intent; candidate if misread |
|---|---|---|
| Cancellation rejected / requested | “Don't cancel the visit; move it to Tuesday.” Evidence: “Don't cancel” rejects cancellation; “move it to Tuesday” requests a move. Reference: Reschedule. Misread candidate: Cancel request. | “Please cancel the Tuesday visit; don't move it to another day.” Evidence: “cancel the Tuesday visit” requests cancellation; “don't move” rejects rescheduling. Reference: Cancel request. Misread candidate: Reschedule. |
| Date rejected / move rejected | “Move the visit, but not to Friday; Tuesday works.” Evidence: “Move the visit” requests a move; “not to Friday” rejects a date. Reference: Reschedule. Misread candidate: Cancel request. | “Don't move the visit from Friday; please cancel it.” Evidence: “Don't move” rejects the move; “please cancel it” requests cancellation. Reference: Cancel request. Misread candidate: Reschedule. |
| Replacement document / withdrawal | “Cancel my earlier request for the invoice; please send the inspection report instead.” Evidence: “send the inspection report instead” explicitly requests a different document; the earlier request is withdrawn. Reference: Request document. Misread candidate: Cancel request. | “Please cancel my request for the invoice; I no longer need it.” Evidence: “cancel my request” withdraws the existing request; no other document is requested. Reference: Cancel request. Misread candidate: Request document. |

## What the contrasts do and do not show

In the first pair the negative attaches to the action not wanted; the other action is the request. In the second, “not” can limit the destination day while leaving the move intact. In the third, an explicit alternative document request gives the reader a different action to identify; mere withdrawal does not. These distinctions describe the evidence a reader uses. They do not establish which input feature caused a prediction. The remaining 119 readings require their own textual evidence and are not explained by these pairs.
