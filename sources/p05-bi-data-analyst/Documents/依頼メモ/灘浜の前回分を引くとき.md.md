# 灘浜の前回分を引くとき

8月16日は2024年の確認日。比較する窓は予定着日で8月1日から14日まで、両端を含む14日間。

浜野坂・汐見台・稲波・青笹への配送停車を数えた控えは、遅配84件、そのうち欠品確認19件。19件は84件の内数。

残り65件について当時の判定内訳は手元にない。全配送件数もないので、欠品なし65件とは書かず、前回の明細を起こさない。遅配率も計算しない。今回と並べるときは対象店、予定着日、停車単位を明記する。
