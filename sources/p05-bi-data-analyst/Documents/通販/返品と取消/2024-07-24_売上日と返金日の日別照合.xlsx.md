## シート「日別照合」

6行目 A:I：日付／売上日基準（件）／売上日基準（円）／返金完了日基準（件）／返金完了日基準（円）／受領日計（件）／受領日計（円）／件数差／金額差（円）。7〜29行のA列に7月1〜23日を順に日付値で置く。7行の式を29行まで各行にコピーする。

| セル | 式 |
|---|---|
| B7 | `=COUNTIF('受領明細'!$B$7:$B$292,A7)` |
| C7 | `=SUMIF('受領明細'!$B$7:$B$292,A7,'受領明細'!$D$7:$D$292)` |
| D7 | `=COUNTIF('受領明細'!$C$7:$C$292,A7)` |
| E7 | `=SUMIF('受領明細'!$C$7:$C$292,A7,'受領明細'!$D$7:$D$292)` |
| F7 | `=SUMIF('受領日計'!$A$7:$A$29,A7,'受領日計'!$B$7:$B$29)` |
| G7 | `=SUMIF('受領日計'!$A$7:$A$29,A7,'受領日計'!$C$7:$C$29)` |
| H7 | `=D7-F7` |
| I7 | `=E7-G7` |

30行 A「7月小計（23日終了分）」、B30〜I30 はそれぞれ同じ列の7〜29行の `SUM`。B30 `=SUM(B7:B29)`、C30 `=SUM(C7:C29)`、D30 `=SUM(D7:D29)`、E30 `=SUM(E7:E29)`、F30 `=SUM(F7:F29)`、G30 `=SUM(G7:G29)`、H30 `=SUM(H7:H29)`、I30 `=SUM(I7:I29)`。

31行 A「5月売上」、B31 `=COUNTIFS('受領明細'!$B$7:$B$292,">="&DATE(2024,5,1),'受領明細'!$B$7:$B$292,"<"&DATE(2024,6,1))`、C31 `=SUMIFS('受領明細'!$D$7:$D$292,'受領明細'!$B$7:$B$292,">="&DATE(2024,5,1),'受領明細'!$B$7:$B$292,"<"&DATE(2024,6,1))`。

32行 A「6月売上」、B32 `=COUNTIFS('受領明細'!$B$7:$B$292,">="&DATE(2024,6,1),'受領明細'!$B$7:$B$292,"<"&DATE(2024,7,1))`、C32 `=SUMIFS('受領明細'!$D$7:$D$292,'受領明細'!$B$7:$B$292,">="&DATE(2024,6,1),'受領明細'!$B$7:$B$292,"<"&DATE(2024,7,1))`。31・32行のD:Iは空欄。これらの売上は比較する7月の日別期間外だが、返金完了日基準の7月欄には含まれる。
