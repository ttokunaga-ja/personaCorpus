# 8月来店調査 報告書

文書番号：ORI-BI-202608-報告-01  
版：v1.0  
提出日：2026年8月27日  
作成者：吉田 美佐（営業企画部・分析室）  
確認者・状況：石井 美智、8月27日確認済み  
宛先：岡田 美代 営業企画部長

## 月報への掲載内容

8月の月報では、来店当日の目的と再来店意向を別の欄に掲載します。意向の欄は「再来店意向 62%」とし、「対象6店の店頭調査で、また来たい側の選択肢を選んだ回答が62%」と添えます。

集計の対象は、2026年8月3日から16日までに対象6店の店頭で得た960回答です。薄帆リサーチ合同会社から受領した6店合計の設問別集計を使用しました。以下のQ2・Q3はともに単一回答で、初めて来店した方にも同じ設問を提示しています。

## 今日の来店目的

Q2「今日の主な来店目的は何ですか」の回答を設問票の選択肢順に示します。「目的の商品を買う」が403件で最多で、次いで「立ち寄り」が259件でした。

| 来店目的 | 回答数（件） |
|---|---:|
| 目的の商品を買う | 403 |
| 商品を見比べる | 235 |
| 立ち寄り | 259 |
| その他 | 63 |
| 計 | 960 |

## 再来店意向

Q3「今後もこの店に来たいと思いますか」への回答のうち、受領CSVでコード1・2に当たる2区分を肯定として集計しました。

| 回答区分 | 受領集計の内訳 | 回答数（件） |
|---|---|---:|
| 肯定 | 1「ぜひ来たい」348件、2「どちらかといえば来たい」247件 | 595 |
| 中立 | 3「どちらともいえない」211件 | 211 |
| 否定 | 4「どちらかといえば来たくない」105件、5「来たくない」49件 | 154 |
| 計 | Q3の全回答 | 960 |

肯定2区分の合計は348＋247＝595件です。中立・否定も含むQ3の全960件を分母とし、595÷960×100＝約61.98%を整数に四捨五入して62%と表示します。

## 設問と母数の確認

8月26日10:00〜10:25に薄帆リサーチの坂本 雅美さんと、8月3日発行の設問票 UHR-QST-202608-01-R01 と「薄帆_8月来店調査_設問別集計_受領時点.csv」を画面で照合しました。Q3の回答コードと選択肢が対応し、5区分の件数計がCSVの回答母数960件と一致しました。Q4「また来たいと思う主な理由は何ですか」はQ3でコード1・2を選んだ595件への分岐です。理由別の構成比は別の分母になるため、今回の掲載から外します。

8月27日9:15に石井さんと設問別の検算表を開き、肯定2区分の件数とQ3の分母を確認しました。本版では石井さんの指摘を受け、見出しと併せて設問文、選択肢、計算根拠を明記しました。

## 8月の事前配布分への対応

8月24日に岡田部長と藤田さんへ送った説明資料 ORI-BI-202608-説明-01 v0.8 の4ページ目は「来店継続率 62%」としていました。25日に藤田さんから、実際に店に戻った人を数えた割合として朝礼で話してよいかと質問がありました。月報と営業会議資料は「再来店意向」にそろえ、62%は据え置きます。私から藤田さんにも差し替えを連絡し、売場で使う場合は対象6店の店頭回答であることを最初の一文に入れてもらいます。

設問には次の来店時期の指定がありません。受領した集計で示せるのは対象6店を合わせた回答までです。実際の再訪や、個店・対象外の店舗の割合にはこの数字を使いません。
