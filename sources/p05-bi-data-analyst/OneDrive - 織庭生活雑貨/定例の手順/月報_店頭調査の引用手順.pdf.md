# 店頭調査を月報に引くとき

文書番号　ORI-BI-202608-手順-01  
版　v1.0  
日付　2026年8月31日  
作成者　吉田 美佐（営業企画部・分析室）  
確認状況　確認依頼前  
宛先　営業企画部・分析室　月報担当

## 見出しを決める前に見る順番

1. **設問文をそのまま読む。** 設問票から、何を誰に聞いたかを抜き出す。今回はQ3「今後もこの店に来たいと思いますか」で、聞いたのは今後の意向。初めて来た方にも同じ問いを出しており、次の来店時期の指定はない。見出しは「再来店意向」とする。
2. **選択肢のコードと分岐を合わせる。** 受領表の数字に設問票の選択肢を当てる。8月26日に坂本さんと照合した結果、Q3の1「ぜひ来たい」と2「どちらかといえば来たい」が肯定。続くQ4「また来たいと思う主な理由は何ですか」はこの2区分にだけ提示された。Q3の3〜5を選んだ365件はQ4の分岐対象外。
3. **設問別に件数を足し、受領表の母数と照合する。** Q3は肯定348＋247＝595件、中立211件、否定105＋49＝154件の計960件。掲載値は595÷960＝約61.98%を整数に丸めた62%。Q4は248＋173＋119＋55＝595件。たとえば「品ぞろえ」の理由構成比は248÷595で約41.7%。理由欄を載せる場合はQ4の分母595件を理由表に添える。
4. **対象と期間を見出しの近くに置く。** 今回は2026年8月3〜16日、対象6店の店頭回答を合わせた値。売場でも「対象6店の店頭調査で、また来たい側を選んだ回答が62%」までを伝える。店別や全店の割合、実際の再訪人数や時期はこの集計の範囲外。
5. **誰にどの版を回したかを確かめる。** 送信済みメールで日付・宛先・添付の版を調べ、報告書と会議資料で同じ見出しを使う。転記先は担当者に更新箇所を返してもらう。今回は8月24日の事前稿の4ページ目が「来店継続率 62%」だったため、岡田さん・藤田さんへ27日に配布PDFとQ3の別添集計を送り、藤田さんには店長向けの転用分も28日中に知らせてもらうよう頼んだ。

## 出典と差し替え履歴の置き場所

受領CSVと発行時の設問票はDownloadsの受領控えを保管する。訂正日、対象月、旧版と新版、変えた見出しと回覧先は、該当月の営業会議フォルダに残す。今回の履歴は「Documents／営業会議／2026／08」の事前稿と訂正版を対にしてたどれるようにする。報告書側の訂正理由は下記の報告書「8月の事前配布分への対応」にある。
