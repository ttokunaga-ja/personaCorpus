# Handoff evidence coding

| Code | Situation | Apply when | If uncertain |
|---|---|---|---|
| W-SOURCE | Window | The person identifies where a window value came from; record the value and source. | If the source is not established, leave unknown; do not infer it from the displayed value. |
| W-PASSED | Window | The content of a window value passed to the next person is heard or shown. | Repetition alone does not establish which version was passed; record the words and mark the value unknown if unclear. |
| H-SEEN | Hold | The person sees or reports seeing a held state; record the evidence. | Do not infer the reason or authority to release it from the status. |
| H-ROUTE | Hold | The person identifies a source they approached or would approach for the reason; distinguish actual from intended contact. | If no source is established, mark unknown, not no contact. |
| V-SHOWN | Replacement vehicle | A vehicle number is shown to or identified by the receiver. | Record the number if available; display is not confirmation. |
| V-BASIS | Replacement vehicle | The evidence used to regard the assignment as confirmed is identified. | If the basis cannot be established, mark unknown; do not derive it from the vehicle field. |
| N-NOT-SHOWN | Exception Note | The observation establishes that the relevant Note was not displayed during the observed handoff. | If visibility was not observed, mark unknown. Opening the route is not reading the Note. |
| N-SHOWN-NOT-PASSED | Exception Note | The Note was displayed and the observed handoff did not include its exception. | If the handoff was incomplete or not observed, mark passage unknown. Display alone does not prove reading. |
