# 取次ぎ二例　設問対照

CWR-TC-20250314-DEC-01　v1.0  
2025年3月14日　作成：金子美穂子  
宛先：Jennifer Salazar、Brian Chen

## Scope

休憩前に本人が保存した設問と、休憩後に本人が見て止まった箇所を比べる。どちらも受講一覧から同じ章を開いたが、章を開くと最初の設問が表示される。

## Comparison

|  | TCS-01 | TCS-02 |
|---|---|---|
| 保存した位置 | 取次ぎ／折り返し先 | 取次ぎ／対応期限 |
| 最初に開いた位置 | 取次ぎ／折り返し先 | 取次ぎ／折り返し先 |
| 本人が見た情報・行動 | 折り返し先に残る入力を指し、「ここに入れました」と止まった。 | 折り返し先を通過し、次の対応期限の入力を指して「こっちです」と止まった。 |
| 金子の解釈 | 最初に表示された設問で本人の既入力を確認できた。 | 同じ章への到着だけでは保存した設問への到着にならない。次の設問で本人の既入力を確かめた。 |

## Implication

章名が同じでも保存回答の設問は異なる。二例は案内に必要な情報を考える材料になるが、設問見出しを示す案の効果をこの観察だけで確かめたわけではない。両人とも今回の提示で見出し付き案内を見ていない。
