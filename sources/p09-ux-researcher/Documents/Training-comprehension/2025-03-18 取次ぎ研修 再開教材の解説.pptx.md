## 2枚目
レイアウト：本文と手順
題：練習と休憩の進め方
本文：2月に参加していない新人6人に、取次ぎの練習教材で本人の回答を入力・途中保存してもらいました。開始時は担当する設問を開き、他の設問は未入力です。
手順：許可 2分 → 入力と保存 8分 → タブを閉じて休憩 5分 → 同じ端末の受講一覧から探索 7分 → 確認 3分。
進行者の声かけ：「休憩の前に入力した答えを見つけて、見つけたと思ったところで手を止めてください」。止まるまでは章や設問の名前を伝えません。
発表者メモ：章を開くとその章の最初の設問が表示される。既入力はその設問を開いて確認する。休憩後は履歴からではなく一覧から始めたことを説明する。

## 3枚目
レイアウト：分岐図
題：6人が一覧からたどった道
図：受講一覧から次の枝を引く。
- 取次ぎ → 折り返し先の既入力を確認：1人。
- 取次ぎ → 折り返し先を通過 → 対応期限の既入力を確認：1人。
- 初動 → 受付時刻の既入力を確認：1人。
- 初動 → 入力せず取次ぎへ移動 → 折り返し先の既入力を確認：1人。
- 初動 → 受付時刻を冒頭から入力し直す：2人。探索中に元の回答は見つからなかった。
図の下：既入力を自力で見つけた人 4人／冒頭から入力し直した人 2人。6人の観察であり、発生率を表すものではありません。
発表者メモ：初動を見た後に取次ぎへ移った人は、初動では入力していない。最初に開いた章と、最後に答えを見つけた設問を分けて見てほしい。

## 4枚目
レイアウト：二例の対照表
題：同じ「取次ぎ」でも、残した設問は違う
| | 例A | 例B |
|---|---|---|
| 休憩前の保存位置 | 取次ぎ／折り返し先 | 取次ぎ／対応期限 |
| 再開後に最初に開いた設問 | 折り返し先 | 折り返し先 |
| その後 | その場で既入力を確かめた | 次の対応期限へ進み、既入力を確かめた |
| 本人が見た手掛かり | 折り返し先の入力 | 対応期限の入力 |
本文：章に着いたことと、自分の答えが残る設問を見つけたことは別です。
発表者メモ：Bは正しい章を開いた時点では、保存先の設問にまだ到達していない。二例に共通する表示と異なる位置を指して確認する。

## 5枚目
レイアウト：二案の比較
題：再開案内に何を載せるか
| | 例A | 例B |
|---|---|---|
| 章名のみ | 取次ぎ | 取次ぎ |
| 章名＋設問見出し | 取次ぎ／折り返し先 | 取次ぎ／対応期限 |
本文：下の案は設問の見出しまでを示し、回答の値は載せません。これは観察後に考えた案で、6人には提示していません。
