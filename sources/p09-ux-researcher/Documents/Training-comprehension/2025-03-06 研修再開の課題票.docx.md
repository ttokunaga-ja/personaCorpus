# 休憩後の研修再開 課題票

CWR-TC-20250304-TSK-01 · v1.0  
2025年3月6日　改訂 金子 美穂子  
進行：金子 美穂子　控え：Jennifer Salazar

## 1. 準備と許可（2分）

2月の確認に参加していない新人6人に、個別に実施する。取次ぎの練習教材と同じ練習端末を前半・後半に使う。本人が担当する設問を開いた状態で始め、他の設問は未入力にしておく。実務の回答は使わない。

開始時に、操作と回答の要旨を記録してよいか本人に確認する。録音・録画はしない。参加や辞退は成績に影響しないことを伝える。

参加符号：＿＿＿＿＿＿　記録の許可：＿＿＿＿＿＿

## 2. 入力と保存（8分）・休憩（5分）

提示文：「練習教材を読んで、開いている欄に答えを入力し、途中保存してください。」

本人の入力と保存を見守る。保存した章と設問、入力の要旨を進行者が控え、保存後にタブを閉じる。5分の休憩後、同じ端末の受講一覧を開いておく。ブラウザの履歴から戻らない。

| 休憩前に控えること | 記入 |
|---|---|
| 保存した章 | |
| 保存した設問見出し | |
| 入力の要旨・保存の確認 | |

## 3. 休憩後の探索（7分）

提示文：「休憩の前に入力した答えを見つけて、見つけたと思ったところで手を止めてください」

受講一覧から本人に操作してもらう。本人が止まるまでは章名や設問名を知らせず、迷っても見守る。最初に開いた位置と、その後の操作を順に控える。空欄への新しい入力と、残っていた入力の確認を区別する。

| 観察すること | 記入 |
|---|---|
| 最初に開いた章・設問 | |
| その後の操作・本人の言葉 | |
| 本人が止まった位置（章・設問） | |

## 4. 確認（3分）

本人が止まったら「どこを見て、ここだと思いましたか」と尋ね、見た情報と発言を控える。章を開いただけでは保存回答の発見としない。7分で止まらず援助が必要な場合は、援助の内容とその後の経路を自力での探索とは別に記す。受講管理側の履歴は後で照合に使い、参加者には提示しない。

| 確認すること | 記入 |
|---|---|
| 見つけた根拠：本人が見た情報・発言 | |
| 自力で確認した保存回答の章・設問 | |
| 7分後に行った援助 | |
| 援助後の経路・到達した章と設問 | |
| 管理側の履歴との照合 | |
