# Aisle visit plan

CWR-NS-20241105-OBS-01 · v0.1  
November 5, 2024 · Jennifer Salazar  
For Patrick Delgado and Ayesha Siddiqui

## Scope and site access

I propose two 40-minute observations at Kenton's Chicago warehouse, November 7 and 14, 19:45–20:25 CST each night. Work from the south ends of aisles E and F. Follow a counter who takes the same tablet across the south passage and comes back to the aisle where the check started. Ronald can tell us where to stand and when we need to clear the passage. Let cart traffic and the count run as they normally would.

September's readout left us with a question about how useful a last confirmed bin would be as a reference. Here I want to see what happens when the tablet goes with the counter. We'll watch the current Count List in use. The read-only line discussed in September is still a proposal.

## Before the count stops

Start the note while the check is still in view. Write the time and starting bin, and note the last bin where we saw the counter reconcile the count and press Save. When the counter leaves, write the direction the tablet went, E to F or F to E, and the time it passed the aisle mouth. A quantity visible in Count List can still be awaiting Save.

## From interruption to resumption

Capture the time and aisle of return, then the first Count List row the counter opens. Use one field, **Tablet / saved bin cue**, for either looking at the tablet or using the saved bin number to get oriented. Add a short note for any other cue you see, such as a shelf tag or a mark on the counter's own sheet. In a separate field, write the time and bin where the counter starts checking the stock again. The return time belongs at the aisle mouth even if the check resumes farther in.

## Debrief and evidence handling

Ayesha should confirm with each counter before we take notes on their work. Use a scene code in the notes and keep the consent record separately. No audio. After the visit, compare the recorded return and restart while both sequences are fresh. Mark gaps in the note when a row or an action was out of view. Keep the action notes with Carver.
