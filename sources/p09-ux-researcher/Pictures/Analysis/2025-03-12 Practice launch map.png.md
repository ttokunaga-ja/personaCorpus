# Practice launch map

図題：Practice launch map — device check

左から右へ、矢印で次の操作を結ぶ。

受講一覧 → 初動 → 受付時刻 → タブを閉じる → 受講一覧

受講一覧からもう一つの枝：取次ぎ → 折り返し先 → 対応期限。章を開くと最初の設問「折り返し先」が表示され、そこから「対応期限」へ進む。折り返し先または対応期限からタブを閉じ、受講一覧へ戻す矢印を描く。

凡例：
- 入力欄に文字が見える：その設問に保存済みの入力がある。
- 入力欄に文字がない：空欄。
- 矢印：端末確認で操作した順路。

図中の補足：休憩前に担当する設問で入力・途中保存し、タブを閉じる。休憩後は同じ端末の受講一覧から開始。別の設問の入力は、その設問を開いて確かめる。
