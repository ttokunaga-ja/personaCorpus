# Arrival window overlap

横軸：Destination local time (EST)、05:30から07:15まで。目盛は05:30、05:45、06:00、06:15、06:30、06:45、07:00、07:15。横方向の2つの区画を上下に配置する。

上段左に「December 6, 2024」。同じ日付の中に R-611 の06:00–07:00 と R-612 の05:45–06:30 の帯を別々の行として描く。06:00–06:30の共通区間を両方の帯にまたがって示し、「30 minutes in common」と記す。

下段左に「December 13, 2024」。R-614 の06:00–07:00 の帯を描く。上段の R-611 と時計上の位置が一致することを「Same clock window as R-611; different date」と記す。両区画は別の日として離して示し、同じ時刻位置が暦日上の重なりを意味しないことを示す。

凡例：R-611、R-612、R-614、同じ日の共通区間。出典：Overnight Dispatch Windows, ODC-DSP-20241202-REF-01 v1.0。いずれも予定枠。
