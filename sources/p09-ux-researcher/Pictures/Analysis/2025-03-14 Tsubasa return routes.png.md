# Tsubasa return routes

図題：Return routes after the break

図中の矢印は参加者の操作順を示す。受講一覧から各枝をたどる。章名・設問見出しは画面どおり日本語で表示する。

- TCS-01：受講一覧 → 取次ぎ／折り返し先 → Saved answer confirmed
- TCS-02：受講一覧 → 取次ぎ／折り返し先 → 取次ぎ／対応期限 → Saved answer confirmed
- TCS-04：受講一覧 → 初動／受付時刻 → Saved answer confirmed
- TCS-05：受講一覧 → 初動／受付時刻（Viewed only; no entry）→ 受講一覧（Returned without entering）→ 取次ぎ／折り返し先 → Saved answer confirmed
- TCS-03, TCS-06：受講一覧 → 初動／受付時刻 → Re-entered from beginning → Saved answer not found during search

終点の集計：Saved answer confirmed: 4 participants（01, 02, 04, 05）；Re-entered from beginning: 2 participants（03, 06）。06 asked whether the training had been submitted; that question is separate from the return outcome. A chapter opened is not by itself confirmation of the saved answer.
