# BR-2410 穴あけ直後と面取り後に見る面

## 図の内容

同じ姿勢のBR-2410を穴あけ直後と現行面取り後の二つに並べる。どちらも底面が水平で、左から右に低段・中段・最高段と上がる三段の輪郭。最高段の横穴は左右方向に貫通し、最高段の左の垂直面を入口、右の垂直面を出口と示す。右側の出口縁を丸で囲む。低段から中段へ上がる垂直面と中段上面が交わる角を「低段側の段差肩」と示す。底面手前の長い縁を「底面の長辺」と示す。

各図に右側から左向きの実線矢印を一つ置き、横穴の出口縁を見る向きとして矢印の先を出口側の垂直面に向ける。両時点で同じ向きから同一個体の出口縁を見る。図の下に「穴あけ直後 → 現行面取り後 → 最終検査」と工程矢印を置く。

段差肩には、低段側の上方から肩へ向かい、中段の上面と平行に左から右へ抜ける水平の破線矢印を描く。これは工具が肩を越えて中段側へ抜ける候補の向きであり、実際の工具経路を確定したものではない。立会いで品物の置き方と工具の抜け側を上田が指して確かめる。

最終検査の右に「後工程で出口縁を見つけても、前の加工時点の状態には戻れない」と記す。返りの発生時点や原因は未確認。

凡例：実線矢印＝出口縁を見る向き、破線矢印＝段差肩の工具が抜ける候補方向、工程間の矢印＝現行工程の順序。
