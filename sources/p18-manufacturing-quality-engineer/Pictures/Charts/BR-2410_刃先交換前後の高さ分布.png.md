# BR-2410　仕上げ刃先交換前後の高さ

横軸：底面から最高段上面の高さ（mm、読値の階級）。縦軸：個数。各階級で交換前・交換後の棒を並べる。凡例：交換前001〜012、交換後037〜048。BR260406、一次測定24個（各群12個）、HG-02、分解能0.01 mm。

| 読値の階級 mm（両端含む） | 交換前 | 交換後 |
|---|---:|---:|
| 23.95〜23.99 | 2 | 0 |
| 24.00〜24.04 | 4 | 1 |
| 24.05〜24.09 | 4 | 2 |
| 24.10〜24.14 | 2 | 3 |
| 24.15〜24.18 | 0 | 4 |
| 24.19〜24.22 | 0 | 2 |

24.15〜24.18と24.19〜24.22の境に「現行上限 24.18 mm」の線を引く。後群の2個は上限超過。再据え直しの6読取りは含めない。
