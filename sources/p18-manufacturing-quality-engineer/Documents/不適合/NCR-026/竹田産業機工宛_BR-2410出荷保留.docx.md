# BR-2410 出荷保留のご連絡

文書番号：KS-QA-2026-COM-026　第1版　2026年8月11日  
竹田産業機工株式会社　品質課長　谷口美奈美様  
金原産業精機株式会社　営業　宮本孝太郎  
寸法根拠確認：品質保証部　中山由紀子

平素よりお世話になっております。8月26日に納入を予定しておりましたBR-2410位置決めブラケットにつきまして、寸法の上限を超えるものが検出されたため、対象ロットの出荷を保留しております。ご迷惑をおかけしますことをお詫び申し上げます。

## 対象と確認内容

| 項目 | 内容 |
|---|---|
| 品番・品名 | BR-2410 位置決めブラケット |
| 製造ロット | BR260810 |
| 対象数量 | 600個 |
| 当初納入予定日 | 2026年8月26日 |
| 対象寸法 | 底面から上面までの高さ |
| 要求寸法 | 24.00 ±0.18 mm（23.82〜24.18 mm） |
| 検出値 | 24.23 mm（上限を0.05 mm超過） |

8月10日の抜取測定で上記の値を確認し、据え直しても上限超過が解消しないことを確認しました。対象ロット600個は出荷せず保留しています。選別前のため、適合数量は確定しておりません。検出結果は600個すべてが不適合であることを意味するものではありません。

## 今後のご連絡

対象品を選別し、適合数量と代替納期について、8月24日までにご連絡いたします。原因は調査中です。判明した内容は、確認のうえ改めてご説明いたします。

納入予定に影響を生じますことを重ねてお詫び申し上げます。状況を確認のうえ、上記期限までにご連絡いたします。
