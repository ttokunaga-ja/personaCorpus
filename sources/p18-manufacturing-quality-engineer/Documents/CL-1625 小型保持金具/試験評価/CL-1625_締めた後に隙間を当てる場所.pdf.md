# CL-1625 締めた後に隙間を当てる場所
文書番号：KS-QA-2025-FLD-023　第1版　2025年7月16日
対象：CL-1625 小型保持金具／CL250708、治具CL-J01
作成：上田裕美子　使用者：柴田千代子・原智之

## 位置の見方
左右は装置正面から見た向き。無孔側の縁を奥の当て止めに寄せる。図の左右端はその無孔側の縁の両端と基台面の間を指す。

### 平面図
```text
                 奥：当て止め
          ━━━━━━━━━━━━━━━━━
          左測点↓             ↓右測点
          ┌─────────────────┐
          │ 金具の無孔側の縁 │
          │   左ねじ    右ねじ  │
          └──────丸ピン──────┘
                 手前：装置正面
```

### 側面図（左右いずれかの端）
```text
奥：当て止め                         手前
   ┃  金具無孔側の端
   ┃  ──────────
   ┃   ← 隙間にゲージを当てる
   ┗━━━━━━━━━━━━━━ 基台面
```

## 確認の手順
左右のねじを割付の順に各1.6 N·mで締めた後、荷重をかける前に、金具を押し直さず、左端と右端の各隙間に0.05 mmのすきまゲージを無理なく当てる。片側ずつ確認し、試験片番号と締付順に対応させて左右別に記録する。

| 記録 | 取り扱い |
|---|---|
| 入り | 0.05 mmが無理なく入った |
| 入らず | 無理なくは入らなかった。押し込まない |
| 未確認 | 接近できない等で確認できない。理由を記す |

確認できない状態を「入らず」にしない。締め直しや押し直しで状態を変えてから記録しない。異常や作業を続けられない場合は理由を残して原に知らせる。
