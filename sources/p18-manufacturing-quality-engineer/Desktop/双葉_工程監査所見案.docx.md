# 双葉表面処理 工程監査所見案
文書番号：KS-QA-2025-REV-002　第0.1版
日付：2025年4月10日　対象：BR-2410　作成：中山由紀子　回付先：石田正雄　状態：承認前

4月9日、安藤さんと受入から返却まで3処理を確認し、15時の出口で7件を読み合わせた。区分は金原で確認後に通知する旨を伝えている。

## 所見と提案
| 番号 | 工程・根拠 | 提案 |
|---|---|---|
| 01 | 4日受入A48・B32と処理80、返却2箱各40の総数は一致。処理票の元ロット欄、返却の箱別内訳がない。入荷順との説明だけでは各箱の構成を確定できない。 | 重大。振分・梱包の記録と対象範囲を確認したい。 |
| 02 | 4日ST-2日報08:10の48.3℃は重ね書きで旧値が読めず、訂正者・訂正日もない。投入は08:35。 | 重大。転記を直したとの説明では投入前の判定を再現できない。元読みと訂正の根拠を求めたい。 |
| 03 | 掲示台にFB-WI-12第2版が残る一方、作業記録は管理原本第3版を参照。 | 軽微案。回収と配布の記録を確認。 |
| 04 | 4月3日のFB-I-0403-01控えに確認印なし。電子承認は確認。 | 軽微案。承認履歴を確認。 |
| 05 | 4月2日返却箱の開梱後副札の数量がかすれ。外札と返却控えは40個で一致。 | 軽微案。副札の交換と照合を確認。 |
| 06 | 仮置き区画の位置札1枚が外れた。品札と保留台帳は一致、箱は区画内。 | 軽微案。復旧を確認。 |
| 07 | 3月分検査原票バインダーの索引は旧棚のまま。移動先で原票を閲覧。 | 軽微案。索引と移動記録を確認。 |

## 石田さんに相談
01は片方の箱に対象を絞れない場合の影響範囲、02は当時の元読みと槽の使用範囲をどう求めるか、ご確認ください。提出資料の内容と期限も工藤さんと詰めたいです。証拠は未受領です。
