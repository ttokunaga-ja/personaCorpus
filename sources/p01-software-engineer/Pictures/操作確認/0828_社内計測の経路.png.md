# 社内計測の経路

図の左に「計測端末」、中央に「社内評価環境 申請デスク 2.5.3」、右に上下二つの箱「申請データ」「添付保管」を置く。端末から評価環境へ右向きの矢印「操作送信」、評価環境から端末へ左向きの矢印「応答受信」。評価環境と二つの保管先の間にそれぞれ双方向の矢印を引く。

操作送信の端点に「計時開始」、応答受信の端点に「計時終了」と記し、その二つを括って「測定範囲：操作送信から応答受信まで」と示す。括弧の外に「人による入力」「端末での描画」「受付後の人の業務処理」を置き、「測定範囲外」と明記する。
