# 同姓の担当者をどう見分けるか

横に3列の比較図。各列に同じ大きさの候補枠を上下2行置く。

現行：検索「佐々木」→ 候補「佐々木」「佐々木」。姓だけでは2人を区別できない。

案A：検索「佐々木」→ 候補「佐々木 千紘（配車班）」「佐々木 律子（集荷班）」。下に小さな送信前確認欄を置き、「担当者　佐々木 千紘（配車班）」と表示する。候補から確認まで氏名と班を残す。

案B：検索「佐々木」→ 候補「配車班」「集荷班」。枠の下に「同じ班の別人は区別できない」と記す。
