# 配送便変更を訂正して再度開いた確認画面

6月24日13:46、田中・伊藤との画面案の読み合わせで鈴木が保存。「入力に戻る」で編集画面を開き、変更希望だけを15:30便から16:00便へ直して「内容を確認する」を押した直後。6月18日の送信前確認と同じ画面構成で、値の違いは変更希望の1か所。

画面の上部に「申請デスク」。その下の題は「配送便変更　申請内容の確認」。題の直下に「まだ申請は送信されていません。内容を確認してください。」と表示されている。確認欄は左に項目名、右に値を並べた読み取り専用の3行。

| 項目 | 表示値 |
|---|---|
| 依頼控え | 配車控-0529-07 |
| 対象 | 午後の配送便 |
| 変更希望 | 16:00便 |

確認欄の下に、左から「入力に戻る」「この内容で申請する」。どちらも操作できる状態で、確定ボタンは押していない。
