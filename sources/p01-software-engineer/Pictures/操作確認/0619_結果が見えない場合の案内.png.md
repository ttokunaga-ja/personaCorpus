# 集荷時間変更の送信後、受付結果を取得できない画面

田中が伊藤の社内画面案で、集荷時間変更を確定送信した後に結果が取れない状態を保存した。

アプリのヘッダに「申請デスク」、画面の題に「集荷時間変更」。中央の結果欄に見出し「受付結果を確認できません」と、次の案内を表示する。

> この画面では、申請が受け付けられたかどうかは分かりません。送り直す前に受付一覧を確認してください。受付一覧で確認できない場合は受付窓口にお問い合わせください。

案内の下には操作できる「受付一覧を開く」ボタンが一つある。結果欄に受付番号は表示しない。
