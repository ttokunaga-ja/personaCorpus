# 確認案から入力へ戻った画面

伊藤の社内画面案で田中が「入力に戻る」を押した直後。アプリの上部は「申請デスク」。フォームの題に「配送便変更」、その下に「申請内容を入力してください。」。

次の順で、各ラベルの右に編集可能な入力欄がある。値は確認を開く前に入力したとおり残っており、戻ってから値には触れていない。

| ラベル | 入力欄の値 |
|---|---|
| 依頼控え | 配車控-0529-07 |
| 対象 | 午後の配送便 |
| 変更希望 | 15:30便 |

フォームの下には「内容を確認する」ボタンが一つある。確認画面の二つのボタンは表示されていない。
