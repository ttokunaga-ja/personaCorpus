# 配送便変更の入力直後

田中が高橋と操作順を確認するため、5月末と同じ試行版を社内で開いて採取した画面。値を入れ終え、送信ボタンを押す前。アプリ上部の「申請デスク」に続いて、ページ見出しは「配送便変更」。

フォームには次の3行が上から並ぶ。左にラベル、右に値の入った編集欄。

| ラベル | 入力欄の値 |
|---|---|
| 依頼控え | 配車控-0529-07 |
| 対象 | 午後の配送便 |
| 変更希望 | 15:30便 |

入力欄のすぐ下、フォーム最下段のボタンは「申請する」。このボタンで入力から直接送る。画面に写る文字は、アプリ名、ページ見出し、3つのラベルと値、ボタンの文字。
