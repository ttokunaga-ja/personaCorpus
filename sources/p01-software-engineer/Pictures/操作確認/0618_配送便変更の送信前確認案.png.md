# 配送便変更の送信前確認

伊藤の社内画面案を田中が保存した。6月4日の試行版と同じ内容を入れ、「内容を確認する」から確認へ進んだ時点。アプリのヘッダから確認欄の操作部までを表示する。

上から「申請デスク」、題「配送便変更　申請内容の確認」、案内「まだ申請は送信されていません。内容を確認してください。」。

続く3行は、左に項目名、その右に読み取り専用の値が並ぶ。

| 項目 | 表示値 |
|---|---|
| 依頼控え | 配車控-0529-07 |
| 対象 | 午後の配送便 |
| 変更希望 | 15:30便 |

欄の下の左に「入力に戻る」、右に「この内容で申請する」を別々のボタンとして表示する。確定ボタンは押下前の通常状態。受付番号と結果欄は表示されていない。
