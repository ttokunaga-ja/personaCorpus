# 受付はそのまま、一覧だけを調べる

田中さんへの説明図。左に「操作」、中央に「申請デスク」、右に「申請・受付の保存先」の箱を置く。

上段は実線矢印で「受付送信」→「申請デスク」→「申請・受付を保存」→「保存確認」→「受付番号を返却」と結ぶ。

中段は「一覧要求」から「申請デスク」への矢印、そこから表示に必要な項目を取得し「一覧に必要な項目だけを返す」までを破線で結ぶ。下段は「詳細要求」から「申請デスク」を経て「詳細専用項目を取得」し「詳細を返す」別の矢印を引く。

凡例：実線＝維持する部分、破線＝検討中の部分。図の下に「保存確認前に番号を返さない」と記す。
