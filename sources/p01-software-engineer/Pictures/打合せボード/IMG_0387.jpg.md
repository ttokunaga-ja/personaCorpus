# 写真の内容

大島の打合せ室の白板を正面から少し斜めに撮った写真。白板の左に上下二枚の付箋があり、どちらにも「時刻変更」と手書きされている。上の付箋から中央の「車庫出発」を経て右の「配車班」へ、下の付箋から中央の「訪問集荷」を経て右の「集荷班」へ、それぞれ手描きの矢印が伸びる。二つの経路は交差せず別々につながる。

右端の小さな図では「車両変更」と「車番差替え」のそれぞれから矢印が出て、一枚の「配車票」に合流する。板面の図と文字が読め、白板の枠と打合せ室の壁の一部も写っている。
