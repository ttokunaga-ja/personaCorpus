# 打合せ後のホワイトボード

2025年2月21日14:00〜14:40、田中・山本・鈴木の机上検討後に田中が社内のホワイトボードを撮影した写真。ボード全体が写る。

左側には手書きで「共栄」、その下に「再発行承認」と「経理閲覧」が並び、承認から閲覧へ向かう矢印の境目に赤い「×」。右側には「藤崎」、その下に「購買承認」と「未着一覧」が並び、同じく承認から閲覧への矢印の境目に赤い「×」。端に「当日だけも×」と手書きされ、その近くに消しかけた矢印が残る。写真に読める文字は以上。
