# スライド2

レイアウト：表

題：同じ月間量での容量と費用

| 比較項目 | 90日 | 180日 |
|---|---:|---:|
| 原本の想定件数 | 9,600件 | 19,200件 |
| 一次保管量 | 49.20 GB | 98.40 GB |
| 税別月額 | 90,000円 | 150,000円 |

月3,200件・一次16.40 GB、30日を1か月とした平準化見積り。GBは10億バイト。二次保管量は一次容量に含めない。初期作業費は別。

発表者ノート：増分6万円の内訳は一次保管3万6千円、二次保管1万2千円、復元確認と記録点検1万2千円。

# スライド3

レイアウト：図と本文

題：遅い問い合わせ4件と保存範囲

図：横軸を発行からの経過日数として0、90、104、121、147、168、180日を順に表示。90日案の帯を0から90まで、180日案の帯を0から180まで引く。104・121・147・168日に各1件の印を置く。

| 問い合わせ | 90日案の範囲 | 180日案の範囲 |
|---|---|---|
| 104日後 | 外 | 内 |
| 121日後 | 外 | 内 |
| 147日後 | 外 | 内 |
| 168日後 | 外 | 内 |

発表者ノート：小林さんが確認した10件のうち残り6件は90日以内。発行日からの日数は比較上の目安で、実際の期限は保存完了時刻から数える。実機の復元確認はこれから。

# スライド4

レイアウト：本文

題：本日の判断依頼

- 共栄向け初期導入の設計に、原本180日保存を採用する。
- 90日案に対する税別月額60,000円の増分を認める。
- 初期作業費は月額の外で整理する。利用開始日と全社展開の可否は別途判断する。

発表者ノート：部署別の日常閲覧期限は現行の設計どおりであり、本日の判断対象は原本の保存と費用に限る。
