# スライド4

レイアウト：図  
題：待ち後の再送｜番号が出ないまま待った場合

各段を左から右へつなぐ。「一覧で確認」から右端へは、実機確認の枠内で同じ入力を送り直す経路。

| 層 | 初回送信と待機 | 一覧で確認 | 確認枠で再送 |
|---|---|---|---|
| 操作 | 集荷時間変更を送信し、結果を待つ | 「受付一覧を開く」を押す | 同じ内容で入力し直し、確認を開いて確定 |
| 表示 | 番号の有無と「受付結果を確認できません」の表示 | 一覧の検索条件と表示された行 | 再送時の表示と結果 |
| 受付記録 | 初回操作の時刻を控える | 控え・種別・希望の訪問枠で該当行を照会 | 再送前後の増分と両回の番号・保存時刻を照合 |

発表者メモ：5月30日の集荷時間変更（集荷控-0530-04、希望14:00〜15:00）は、聞き取りでは番号が出ず約2分待って入力し直した。SD-0530-014とSD-0530-019の保存差は2分16秒。利用者には先に一覧、一覧で確認できなければ受付窓口へ案内する。

# スライド5

レイアウト：2段  
題：確認枠で揃えるもの

左欄「伊藤さんと決める」

- 受付を保存し、操作前後で同じ条件の一覧と記録を照会できる環境
- 送信中の連続操作と、結果が得られない状態の両方を追える時間枠

右欄「鈴木さんに残してほしい記録」

- 経路ごとの操作時刻、再操作の可否、その時点の画面表示
- 操作前後の一覧と保存記録、増えた件数
- 2記録が残ったら、双方の依頼控え・種別・変更内容、受付番号全文と保存時刻

発表者メモ：二つ保存された場合は、当番が一覧で両方の番号と保存時刻を確認でき、中村さんへ二つとも渡せることを確かめる。二つの記録が得られなければ、その枠での2記録の照合は未確認で返してほしい。
