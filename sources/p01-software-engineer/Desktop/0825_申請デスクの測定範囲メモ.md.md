# 佐藤さんに出す数字の範囲

「送信を押してから待たされる」と言われたとき、何の待ちかを分けて聞く。入力に迷う時間、送信した操作への応答が戻るまで、受付後に人が内容を確認して処理する時間は別物。最後までを一つの応答時間として言わない。

手元で揃えて測るのは、計測端末が操作を送ってから応答を受け取るまで。申請送信だけでなく、受付一覧の確認と申請詳細の取得も同じ採取窓に入れる。配分と負荷を先に決め、どの操作を何件含む数字かを添える。入力や端末での描画、受付後の人の作業はこの数字に入らない。

佐藤さんには、社内の経路で分かる範囲を説明する。本番の利用者の回線や作業時間まで言えるかは別途確認が必要。
