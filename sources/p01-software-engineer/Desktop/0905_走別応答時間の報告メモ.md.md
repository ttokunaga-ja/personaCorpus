# 三回分をまとめた値を聞かれたら

佐藤さんに「三回分を一緒にすると何msか」と聞かれたら、今の集計だけでは出せないと答える。CSVにあるのは各走の件数とp50・p95で、10,800件の個別応答時間はない。全部を並べ替えて95%位置を見ることができない。走別のp95を平均しても、その値にはならない。

246msを使うときは「採用した3走のうち最も遅い側の走別p95」と一息で言う。各走は242、246、244ms。社内経路・固定配分での操作送信から応答受信までの値で、端末の表示や受付後の業務完了までの時間ではない。
