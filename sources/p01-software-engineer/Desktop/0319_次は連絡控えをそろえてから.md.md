# 次は連絡控えをそろえてから

次の出勤日、旧受付の終了日を聞かれたら「今は併用中です」と答える。日付を予想して伝えない。

6日に高橋さん・中村さんと確認した条件は、2/26正午に固定した未処理23件を旧番号で追い、終結を確認するまで旧受付を続けること。中村さんが結果と連絡控えを集め、高橋さんが番号と根拠を突き合わせる。終了日は別に決める。

19日は照合のやり方を見た。受-260225-017は配車への照会を引けたが、結果連絡の控えは示せなかった。全件の終結根拠が揃ったかは確かめられていない。23は基準時点の対象数で、今日の残数としては使わない。点検後の残数も終了日もまだ数字を出せない。

中村さんから控えが揃った連絡を受けたら、高橋さんと全件を突合する。未処理・証跡不足がともに0件かを確認し、旧側の保留照会と基準日後の折返しの扱いも確認してから、終了提案が必要か考える。
