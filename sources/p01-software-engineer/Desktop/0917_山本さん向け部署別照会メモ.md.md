# 山本さんへの説明前

営業部の30日を過ぎた帳票が、経理部の90日枠ではまだ閲覧できる場合でも、「経理から取り直してもらう」と案内しない。営業の期限が終わったことと、原本が保存されていることは別。経理の権限を営業に貸す設計ではない。

部署をまたぐ問い合わせは、小林さんに対象帳票と理由を受けてもらい、保存範囲内にある必要な原本の照合を担当者へ依頼する。照合の依頼であって、日常一覧を再公開したり他部署から再取得したりする案内にはしない。保存日数はまだ判断前。
