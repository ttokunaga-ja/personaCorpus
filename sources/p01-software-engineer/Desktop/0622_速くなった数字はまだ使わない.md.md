# 速くなった数字はまだ使わない

今日、伊藤さんと試した候補でp95が176msに見えた。比較前版より速いと思って共有しかけたが、設定を見直すと同時利用が20になっていた。固定条件は40。結果がよく見えても、今回の比較には使えない。

176msは判定資料へ転記しない。この試行は失敗として残す。40に戻して、慣らし・計測時間、操作割合、データ量、成功件数とエラーを条件表に照らしてから3走を測り直す。

鈴木さんに、結果だけでなく開始前の条件と記録を目視で照合してもらうよう頼む。測り直すまで候補の合否は未判定。
