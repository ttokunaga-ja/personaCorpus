# 大島の受付棚卸し　明日聞くこと

中村さんへ、まず今の呼び方を窓口ごとに出してもらう。電話で何と呼ばれるか、どの窓口が受けるか、最後に票を持つ班はどこかを別々に聞く。名前だけで同じ仕事と決めない。社内で言い換えている呼び方も抜けないよう頼む。

数え方の候補：
- 受付票の枚数：仕事量は分かるが、同じ名前を別の窓口が使うと分類が分からない。今回の名前の棚卸しには向かない。
- 窓口ごとの呼称の行数：同名でも窓口が違えばそれぞれ残せる。まずこちらで一覧をもらい、用件と票の行き先を見てから整理する。

配車・集荷・配送・伝票を一通り。4日までにお願いする。
