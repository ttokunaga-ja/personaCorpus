# 開いた回数で数えると全部多い

納品控えを1回開いたら、便名も控え番号もそれぞれ1件、と仮に数えてみた。残数量だけを答える電話でも、紙に並んでいる欄を全部使ったように増えてしまう。これでは何を確認する仕事なのか見えない。

加藤さんの控えの「確認に使った項目」で数える。同じ照会で同じ項目を何度見ても1件、別の項目を実際に使ったら別に1件。表示や紙を開いただけでは数えない。12月〜2月の3か月分を項目ごとに見る。

閲覧総数を母数にした割合は会議に出さない。項目の延べ参照と照会の回数は同じではない。月平均は3か月合計を3で割る。
