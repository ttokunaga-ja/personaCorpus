# 当日だけならよさそうに見えた

終了時刻をその日の終わりにして兼任を認める案は取り下げる。時間が短くても、見せる範囲そのものが広がる。

- 共栄：課長不在日の再発行代理承認と経理の閲覧。保存後75日目は業務課の日常閲覧60日を過ぎている。経理の90日を代理担当に使わせると、業務課の閲覧範囲を越える。山本さんへ：承認後の照合依頼を誰が取りまとめるか、小林さんに聞けるか？
- 藤崎：購買承認の代番と購買閲覧者。承認のための個別申請だけでなく、発注・納品の横断一覧まで見せることになる。山本さんへ：朝の未着を追う仕事を別の閲覧担当に回す場合、何を引き継ぐ必要があるか？

両社は理由も業務も別。各社には自社の条件で説明する。
