# 集荷時間変更の聞き返し

25日の読み合わせ。「そちらが出る時間を後ろに」で、当番は自社の車庫から便が出る時間だと思って、最初に配車の票を取った。聞き返すと集荷先への訪問時間の話で、集荷指示票を集荷班に渡す例だった。

最初に「何時ですか」と聞く案はやめる。時刻を聞いても配車と集荷のどちらかは分からない。先に「車庫から便が出る時間ですか、それとも集荷先へ伺う時間ですか」と確かめる。

高橋さんへ：当番が普段使う言い方でもこの問いが通じるか、次の整理で確認する。配車票と集荷指示票の見本も並べておきたい。
