# 保管という言葉を先に分ける

午後、渡辺さんに領域の話をする前に小林さんへ聞く。

「締めた後に見たい」は、部署の担当者が日常の画面からもう一度取得したい話か。それとも問い合わせがあったとき、当時の原本と内容を照合したい話か。両方なら、誰が何のために、いつ頃まで必要なのかを別々に聞く。経理の締め直しに必要な期間を、そのまま営業の閲覧期間にするとは限らない。

月3,200件は発行した帳票の数か、再発行や再取得も含む操作回数か。取消分をどう数えているかも確認する。同じ帳票を二つの場所に置いて比較するなら、対象の数え方を先にそろえる。

閲覧を閉じる時期と原本を残す期間は別の問い。回答が来るまで削除日は決めない。
