# 再送注意文の読み合わせ

6/7、鈴木さんと高橋さんと紙で一文だけ読んだ。

> 受付番号が表示されるまで再度送信しないでください

高橋さんは、待っても番号が出なかったら送り直してよい、と読んだ。集荷の人が迷ったのはそこで、何分待つかより、最初の分が受け付けられたかをどこで見られるか。

鈴木さんからは、押した後で入力違いに気づいても、そのまま待ち続けるように読める、との指摘。待っている間に内容を直したい人には行き先がない。

この一文だけの案は11日の比較材料に残す。内容を直したい場面と、送った後に番号が見えない場面を一つずつ読んでもらい、その次の操作までたどれるか比べる。
