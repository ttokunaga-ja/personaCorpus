# 照会ポータル　3月末の控え

高橋さんと33候補から初回設計の28項目を選んだ。残り5項目は画面の対象外だが、購買で不要という意味ではない。3/24に藤崎の加藤さんへ範囲を説明し、3/26に、電話では発注と品目を合わせて購買台帳と納品控えを突き合わせること、紙の検収回付は納品控えで続けることを確認してもらった。

次は伊藤さん・鈴木さんとの画面照合から。番号を先頭のゼロも含めて扱えるか、発注明細の品目別の残数量と分納の内訳を照らせるか、内訳から元の条件・ページの一覧に戻って次の未着を追えるかを見る。納品控えがそろわないときは空欄をゼロとして判断しない。

困ったときに開くもの：

- 3/14の古い赤字版「照会項目の定義_田中コメント」：一覧の状態、受領日、数量の単位について、どこで迷ったかを戻って見る。選定反映後の定義そのものではない。
- 3/26の加藤さんの回答「納品控えを続ける範囲」：電話での照合と紙の回付を確認する。
- 3/28の「次回の画面確認に持っていく経路」：分納を含む経路の確認票。まだ実施結果は入っていない。

設計どおりに動くかを実際に確認する日：保留。公開日：保留。選定と説明が済んだことを、画面確認や公開が済んだことにしない。
