# 候補の順番だけでは説明できない

候補の並びを固定すれば防げるのでは、と考えていたが、聞取りを踏まえて取り下げる。

SD-5229は前日の別受付にある「佐々木」を同じ担当者だと思い、集荷の引継ぎ票の代わりに配車の引継ぎ票を選んでいた。SD-5233も、並べて見た別受付の「佐々木」を同じ人物と思い、配車の振替控えではなく集荷の振替控えを選んでいた。どちらも候補を選び直す前の参照で誤認している。

候補順を固定しても、別受付の姓だけの表示から二人を見分けられない。選択候補だけでなく確定前の画面にも、同じ識別情報が要る。どの情報を出すかは確認画面と合わせて検討する。
