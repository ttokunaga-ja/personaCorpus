# 同じ名前でも操作が違う

山本さんとの最初の棚卸しで、名前だけを並べて同じ役割と決めない。

- 何ができるか。申請を入力する、訂正する、承認する、照会する、の操作を別に聞く。
- どこまで届くか。部署や購買の対象範囲を聞く。個別の申請を見ることと一覧を見ることも分ける。
- 担当が休むとき、どの仕事を誰へ回すか。本人が持つ権限と代わりに処理したい仕事を混ぜない。

藤崎の「7」は設計資料上の役割数。人数ではない。共栄は再発行の代理承認が必要な日の条件を別に聞く。
