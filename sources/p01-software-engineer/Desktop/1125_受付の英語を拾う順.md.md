# 受付の英語を拾う順

まず利用者が申請を出す順に画面をたどる。同じ語でも表示場所が違えば一つずつ拾う。単語の種類ではなく、前後の操作と一緒に読めるかを見たい。

1. 入力 10箇所（01〜10）
2. 送信前の確認 12箇所（11〜22）
3. 受付結果 8箇所（23〜30）
4. 結果が見えないときの案内 6箇所（31〜36）
5. 受付一覧 12箇所（37〜48）
6. 申請詳細 16箇所（49〜64）

計64箇所。画面に繰り返し出る語はまとめず、どこに出るかを表に添える。番号を見た後に一覧と詳細を開く道筋も追えるようにする。

管理者画面は設定する人の操作で、今回の申請者の道筋とは分ける。帳票は画面の前後関係が異なり、通知メールも受け取る時点と文脈が違うので64件には入れない。製品サイトも同じく範囲外。まず利用者画面の表を作ってLauraに見てもらう。
