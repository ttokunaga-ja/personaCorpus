# 加藤さんに聞くこと（5日）

朝、未着を追い始めるときと、納品先から電話が来たときでは、最初に手元にある情報が違いそう。どちらも同じ入口でよいか、先に紙の順番を聞く。

- 発注番号が手元にないとき、発注月と納品先から探せるか。品名だけで見つかるのか、同じ品の発注が重なることがあるか。
- 残りを答える前に、どの紙を開き、注文数と届いた数をどう照らすか。朝の確認と電話で順番は変わるか。

画面の欄の話から始めず、普段の仕事を一度たどってもらう。
