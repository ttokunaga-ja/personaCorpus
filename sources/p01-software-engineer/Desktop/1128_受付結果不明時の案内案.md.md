# 結果が見えない時に鈴木さんに聞く

送信直後に応答が途切れ、受付番号を表示できなかった場合。いまの下書きの「送信に失敗しました」は言い切れない。画面で結果を取得できないことと、申請が届いていないことは同じではない。

結果を確認できない旨を伝えて、まず受付一覧で今送った申請を探してもらう案にしたい。その場ですぐもう一度送る指示は外す。同じ依頼が受け付けられていた場合に重ねて送るおそれがある。

鈴木さんに、一覧で同じ申請を見つけるための案内が足りるか、見つからない場合に窓口へ何を伝えてもらうか相談する。表示がないことだけで未受領と決めない。
