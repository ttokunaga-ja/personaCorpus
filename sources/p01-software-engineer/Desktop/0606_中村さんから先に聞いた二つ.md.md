# 中村さんから先に聞いた二つ

6/6 朝の短い連絡。受付後の班内点検で予定と違う控えに気づいたとのこと。

- SD-5213（6/3）：候補がどちらも「佐々木」。先頭を配車班と思って選び、便割当控えのつもりで集荷順控えを添付した。後から違いに気づいた。
- SD-5219（6/5）：いつもの並びを頼りに選び、集荷時間表のつもりで配車時間表を添付した。

次に聞くことを分ける。まず選択時に何を見て、どの控えを選んだか。次に受付後、その控えを誰が見て、どこへ渡したか。選び間違えたことだけで閲覧先や送付先は決められない。番号ごとに控えを合わせる。
