# R7 判定までに確かめること

7/13に佐藤さんと判断するための材料。判定日と公開日は別。公開日はまだ決めない。

- 性能：p95 184ms以下は目標。実績ではない。比較前版と候補版で同じ条件になるよう、同時利用数、データ量、操作割合、慣らしと計測時間を先に固定する。各走の件数とエラーも残し、条件を鈴木さんに照合してもらう。2025年の246msは参考値として分ける。
- 指摘：重大なものは修正したという連絡だけで閉じない。二重受付、代理申請の確認先、添付差替え後の表示を、鈴木さんと再審査する。通常指摘も残件と担当を見えるようにする。
- 判断の理由：同期受付を残す案と他の案を並べ、採る理由だけでなく採らない理由もADR-042に残す。性能の結果と重大指摘の状態を根拠として添える。

判定表には目標と実績を別に記入する。結果や再審査が揃わなければ、揃っていないことをそのまま佐藤さんに伝える。
