# 重大の付け方、午後に鈴木さんへ

集約の前に境界を合わせる。操作に困ることと、結果を信じて業務判断を誤ることを同じ重さにしない。

- 照会結果が誤り、発注してよいか判断を止めなければならない場合は重大に置くか。結果が出ない場合も、対象がないと誤認する危険を含めて聞く。
- 一覧から元の列に戻す操作が一手間増えるだけなら、通常で扱えるか。作業が続けられることと、毎回迷わず戻れることは別。
- 文字の折返しだけで内容を読める場合は軽微でよいか。隠れて読めない場合は分ける。

午後に鈴木さんへ、回避手順があるかだけでなく、現場で毎回使えるか、注文の取り違えを防げるかを聞く。判断が割れる例は観測条件と一緒に残す。
