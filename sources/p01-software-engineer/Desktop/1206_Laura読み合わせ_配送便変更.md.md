# 読み合わせは同じ申請で一周

12月9日 15:00 Lauraと。配送便変更 SD-241126-018 で、送信後の受付結果から始める。

1. 結果画面の番号を控える。番号を見た時に何が済んだと感じるか聞く。
2. 一覧で同じ申請を探す。詳細を開く前に一覧だけから何が分かると思うか聞く。
3. 詳細を開き、処理欄の In review を見せる。受付と担当部門の仕事の違いを踏まえて、結果画面と一覧をもう一度読む。
4. 残る入力、送信前確認、結果不明の案内は用語表の表示位置を追って確認する。結果不明は受領できたかどうかの判定ではないことも説明する。

64箇所を単語だけでなく、表示位置と前後の操作で見る。迷った箇所と理由を控え、表に戻す。
