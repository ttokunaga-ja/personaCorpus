# 一覧だけ速くても見るところ

伊藤さん、鈴木さんに確認。取得項目を減らしても、一覧の抜けや見える範囲が変わるなら先に直したい。

- 更新日時が同じ2件をページ境界の前後に置いたとき、次のページで片方が消えないか。順序を決める条件を揃え、全ページをたどって申請ごとの出現回数を比べる。重複も数える。
- 同じ条件に閲覧できない申請が混じるとき、見える件数とページ送りはどうなるか。見えない件を含めてページを切ってから除外すると、途中のページが欠けて見えないか。
- 変更前後で、同じ利用者・同じ検索条件の表示対象件数、各ページの申請、全ページの重複・欠落を数える。閲覧不可の件は結果に出ないことも確認する。

詳細の表示内容は別に確認。受付送信は保存を確認してから番号を返す経路を変えない。
