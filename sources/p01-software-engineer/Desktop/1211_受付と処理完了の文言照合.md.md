# ボタンの単語だけでは照合しない

12/12 伊藤さんに相談する前の整理。

完了を表す英語をまとめて検索し、同じ語を一括置換する案は引っ込める。受付一覧の **Completion status / Completed** は、処理途中でも一覧に行が出るため **Receipt status / Received** に直す対象。一方、詳細の処理欄で担当部門の作業が実際に終わった場合の **Processing completed** は、その仕事が終わったことを表す意図どおりの値で、残す。

検索語は候補を拾うために使い、照合の単位は「表示欄と値」の組にする。まず ABS-2024-EX-001 v1.0 の表示位置を見て、受付結果・一覧・詳細のどこかを確かめる。次にその欄が受領と処理のどちらを表すかを見る。ボタンの単語だけで採否を決めない。

相談したいこと：変更箇所を画面で追うとき、同じ配送便変更を一覧から詳細まで開き、Received と In review が別欄で読めることも確認できるか。結果が見えない場合は受領済みとも未送信とも決めず、先に一覧を確認する経路も用意する。
