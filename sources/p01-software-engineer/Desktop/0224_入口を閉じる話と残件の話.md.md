# 入口を閉じる話と残件の話

午後、高橋さんに聞く前に。

旧受付に新しい依頼を入れないことと、進行中の依頼者が返事を返せなくなることは別に考えたい。たとえば集荷時間の変更を電話で受け、配車からの折返しを待っている間に依頼者が時間を補足したくなったら、前に伝えた旧番号のままで返せるのか。新しい入口を案内して最初から書いてもらうと、配車への確認がもう一度走らないか。

受付側も、番号から元の控えと追記を見つけられる必要がある。入口を止める日を先に置く前に、残っている依頼の数え方と、折返しを元の記録へ戻せるかを確かめる。
