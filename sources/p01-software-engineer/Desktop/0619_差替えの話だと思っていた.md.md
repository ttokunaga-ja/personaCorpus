# SD-5244、名前だけでは分からない

差替え後に表示だけが古い話だと思って聞き始めたが、ファイル名だけでは、正しい資料を選んだ後に表示が古い場合と、最初に違う資料を選んだ場合を区別できない。どちらかに決めない。

鈴木さんに二つに分けて確認する。

1. 選択時の名前と受付後の控えの名前は一致するか。表示と保存を照らす。
2. 添付内容の対象班は、予定していた配車班と一致するか。連絡票の中身と予定の控えを照らす。

名前が一致しても中身が予定どおりとは限らない。閲覧・送付の範囲も別に確認する。
