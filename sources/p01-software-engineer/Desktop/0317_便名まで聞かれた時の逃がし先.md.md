# 便名を聞かれたら

17日の選定では納品便名を初回画面の対象外にした。購買3人の控えでは3か月に3件。ただ、急ぎの電話で配送便を聞かれることはある。

発注番号と、内訳で確認した納品書番号を手掛かりに納品控えへ戻ってもらう案。まず発注と品目を合わせ、該当の納品書を確かめてから便名を探す。控えが手元になければ確認して折り返す。

「画面にない」は「業務に不要」と同じではない。加藤さんに説明するときは、必要な場合にどの控えを見るかまで伝える。
