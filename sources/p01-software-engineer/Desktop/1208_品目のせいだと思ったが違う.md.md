# 品目のせいだと思ったが違う

朝は複数品目の注文だから一覧の表示がずれるのではと思った。鈴木さんの画面を見て、この仮説は取り下げる。

004286は単一品目。注文10のうち4を納品した時点で、詳細は残6なのに一覧は「納品済み」。品目数を増やして調べるより、残数量がある注文の状態を一覧がどう扱っているか先に確認する。

全量納品の注文も同じ版で一覧と詳細を見比べる。いま分かるのは不一致であって、原因がどこにあるかまではまだ決めない。
