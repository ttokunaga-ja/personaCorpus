# 照会ポータル 公開延期と営業への影響説明

文書番号：ABS-2025-EV-003  
版：v1.0  
日付：2025年12月16日  
作成者：田中美由  
宛先：山本真由子  
確認者：佐藤雅之

## 判断

12月16日16:00の公開は取り消しました。12月30日16:00は、品質の再判定を通った場合に使う社内候補枠です。公開日としてお客様に約束しないでください。12月29日10:00に再判定し、その可否に応じた状況を同日午後に連絡する予定です。

## 購買の試行で生じた支障

加藤さんの購買部門内の試行では、朝の未着照合で対象を検索できない、詳細から戻ると一覧の条件が消える場面がありました。納品先への回答前には一覧の納品状態と詳細の残数が一致せず、一覧だけで残数を決められませんでした。検収の紙回付では分納内訳の後半が印刷されず、全行を確認できませんでした。

## 営業が案内できること

| 場面 | 案内 |
|---|---|
| 朝の未着照合 | 従来の購買台帳を使って確認を続けてください。 |
| 納品先への残数回答 | 購買台帳と納品控えを照合してから回答してください。 |
| 検収回付 | 従来の納品控えによる紙の回付を続けてください。 |
| 問い合わせ | 営業への問い合わせは山本が受け、購買内の試行で困ったことは加藤さんが取りまとめ、田中へ連絡します。 |

## 電話での伝え方と次の連絡

「本日予定していた公開は延期します。今の照会と検収の手順を続けてください。次の状況は12月29日午後にお伝えする予定です。」

30日の枠は社内の再判定次第です。日付を聞かれても公開日とは答えず、次回の状況連絡を案内してください。購買部門内の試行で見えた支障と、取引先へ案内できる既存手順を混ぜないでください。
