# 試行中に通常の持越しを聞かれたら

鈴木さんへ。16日の消し込み表 v1.1 の持越し7件のうち、通常3件について、問い合わせを受けたときの聞き取りを整理しました。画面を見ずに使い方や修正時期を断定せず、加藤さんから受けた内容を田中から鈴木さんへ渡します。

| 指摘 | 問い合わせで聞くこと | 受けた後の扱い |
|---|---|---|
| CP-06 日付欄の入力案内 | どの欄に、どのような日付を入力しようとしたか。表示された案内と、入力後に進めたか | 案内文と入力状況を控え、鈴木さんに照合を依頼する。判断できないまま入力値を変えるよう勧めない |
| CP-23 並び順の見出し | どの一覧の、どの見出しを見たか。並んでいると思った順と、実際に見えた順 | 見出しと実際の順を分けて記録し、鈴木さんへ渡す。見出しだけで並び順を約束しない |
| CP-34 印刷フッタ表記 | どの帳票を印刷したか。フッタに出た表記と、問い合わせの対象になった箇所 | 表記を控え、鈴木さんへ渡す。本文の明細欠落に関する問い合わせは別途取り上げる |

受けた日時、連絡者、対象の画面または帳票、上の各項目と回答状況を残す。未確認なら未確認のままとし、問い合わせがなかったことと解決済みを混同しない。

これは通常3件の問い合わせ控え。重大4件の再現・正常対照・品質確認の証跡提出とは別に管理する。印刷について明細の欠落が疑われる場合は CP-28 の確認先にも伝えるが、問い合わせの記録だけで重大指摘を消し込まない。
