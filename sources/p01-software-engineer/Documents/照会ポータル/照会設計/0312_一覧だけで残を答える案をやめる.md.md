# 一覧だけで残を答える案をやめる

1品目なら、12個注文、初便5個、次便3個で残4個。一覧の1セルに「残4」とあれば電話で答えられそうに見えた。

複数品目を同じセルにまとめると、例えば箱と個を足すことになり、どの品目が不足しているかも消える。同じ単位でも品目が違えば合計の残数だけでは問い合わせに答えられない。発注全体の状態から品目の残りを推測するのも危ない。

一覧は対象の発注を特定し、どれから開くかの目安に使う。回答前に発注明細を開いて、該当品目の注文・納品・残数量と単位を読む。分納は納品内訳と控えを照らす。草稿の一覧状態の使い方は高橋さんへの確認事項のままにする。
