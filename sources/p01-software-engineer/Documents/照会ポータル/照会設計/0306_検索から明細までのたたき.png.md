# 経路案

図は左から右へ。左上に「朝の未着：発注月から」、左下に「電話：発注番号が分かる」を置き、それぞれ矢印で中央の「検索」へつなぐ。

検索の箱には「発注月」「発注番号」と書く。そこから実線矢印で「発注一覧」→「発注明細」→「納品内訳」と結ぶ。発注一覧には「対象の発注を選ぶ」、発注明細には「品目ごとの残数量」、納品内訳には「便ごとの数量を控えと照合」と記す。

納品内訳から発注一覧へ戻る曲線を破線で描き、線のそばに「絞込を保って戻る？（未決）」と書く。設計相談用の経路図であり、実際の画面の操作結果ではない。
