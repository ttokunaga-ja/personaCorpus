# 照会項目の定義　草稿

文書番号：ABS-2025-EV-010  
版：v0.1  
日付：2025年3月11日  
作成：田中 美由  
確認依頼先：高橋 和典

## 背景と範囲

藤崎購買では朝に台帳から未着を追い、電話では発注と品目を合わせてから納品控えと数量を照合する。候補33項目を、検索の入口、発注一覧、発注明細、納品内訳および別資料で参照する候補に整理した。以下は配置案であり、採否の決定ではない。項目は主な置き場所で数え、発注番号や納品状態を一覧にも表示しても別項目として数えない。

## 入口：検索条件 5項目

| 番号・項目 | 意味と使う場面・配置案 |
|---|---|
| Q01 発注番号 | 個々の発注を識別する番号。番号を聞いた電話の検索に使い、一覧にも表示する |
| Q02 対象月（発注月） | 発注された月。朝の未着を期間で探す入口 |
| Q03 納品先 | 届け先。発注を絞り、同じ品の注文を区別する |
| Q04 納品状態 | 発注の納品状況を示す区分。検索条件および一覧の確認順に使う案 |
| Q05 品目コード | 品目を識別するコード。品目から発注を探す条件 |

## 発注一覧：7項目

| 番号・項目 | 意味と使う場面・配置案 |
|---|---|
| Q06 発注日 | 発注した日。納品先と合わせて発注を特定する |
| Q07 代表品名 | 一覧で発注の内容を見分ける代表の品名。全品目の代わりにはしない |
| Q08 発注行数 | その発注に含まれる明細行の数。開く対象の概況を見る |
| Q09 未納行数 | 未納がある明細行の数。未着を追う順を考える |
| Q10 未納分の最早納品予定日 | 未納の明細のうち最も早い予定日。朝の確認順の手掛かり |
| Q11 最終受領日 | 発注に対して最後に受領した日。直近の動きを見る |
| Q12 発注部門 | 発注した部門。対象を見分ける補助 |

一覧には発注番号と納品状態も繰り返し表示する。状態を回答にどこまで使えるかは未決。数量の回答に使う場合は明細との関係を確認する。

## 発注明細：10項目

| 番号・項目 | 意味と使う場面・配置案 |
|---|---|
| Q13 発注明細行 | 発注内の明細を区別する行。該当品目を特定する |
| Q14 品名 | 注文した品目の名称。電話の対象と合わせる |
| Q15 規格 | 品目の規格。似た品名の区別に使う |
| Q16 注文数量 | その明細で注文した数量。納品・残数量との照合に使う |
| Q17 累計納品数量 | 当該品目について届いた数量の累計。注文数量と照らす |
| Q18 残数量 | 当該品目でまだ届いていない数量。電話での回答前に確認する |
| Q19 数量単位 | 注文・納品・残数量の単位。数量の意味を読むために表示する案 |
| Q20 明細別納品予定日 | その品目の納品予定日。未着の確認に使う |
| Q21 発注時備考 | 発注時に記した補足。明細についての確認に使う |
| Q22 納品先補足 | 納品先についての補足。対象の明細の届け先を確認する |

## 納品内訳：6項目

| 番号・項目 | 意味と使う場面・配置案 |
|---|---|
| Q23 納品書番号 | 納品控えと照らす番号。便ごとの記録に置く |
| Q24 受領日 | 納品を受け取った日として表示する候補。同じ納品を受領日と検収日のどちらで表すか確認が必要 |
| Q25 便別納品数量 | その便で届いた品目の数量。分納の内訳と控えを照らす |
| Q26 納品明細行 | 納品書内の明細を区別する行。発注明細と控えを対応させる |
| Q27 分納回 | 何回目の分納かを示す。複数便をたどる手掛かり |
| Q28 受領場所 | 納品を受け取った場所。控えの対象を確認する |

## 別資料で参照する候補：5項目

| 番号・項目 | 意味と確認する場面・資料案 |
|---|---|
| Q29 旧品番 | 古い呼称から現品目を調べる。購買台帳の旧品番欄 |
| Q30 梱包入数 | 包装ごとの入数。発注控えの包装欄。数量単位とは別 |
| Q31 納品便名 | 配送便を尋ねられた際に使う。納品控え |
| Q32 検収回付先 | 紙の検収事務で回付先を確認する。検収回付簿 |
| Q33 検収控え番号 | 購買内部の検収控えをたどる番号。検収回付簿。納品書番号とは別 |

## 集計と確認したい点

購買3人の2024年12月〜2025年2月の控えについて、1回の照会で実際に使った各項目を1件まで数え、3か月合計を3で割った。開いただけの欄は数えない。月平均2件未満の候補が5項目あるが、頻度だけで業務上の必要性を決めない。

高橋さんに確認したい点：

1. 一覧の納品状態は、発注を開く順の目安にとどめるか、回答にも使えるか。
2. 同じ納品を示す日付は受領日と検収日のどちらか。両者の意味の違いをどう表すか。
3. 数量単位は3か月合計6件、平均ちょうど2.0件。閾値ちょうどをどう扱うか、残数量の読み取りに必要か。

上記の回答と基本経路での必要性を踏まえて、項目の配置と対象範囲を選定する。
