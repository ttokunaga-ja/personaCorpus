# CP-20 ブラウザで戻る案を保留

伊藤さんへ。12月・納品待ちの一覧2ページ目から詳細を開き、画面内の「一覧へ戻る」を押すと条件が消え、状態は「すべて」、1ページ目に戻る。9日の保存画面はこの操作の直後。

暫定案としてブラウザの「戻る」を試した。元の一覧からそのまま詳細へ進んだ直後なら、戻った画面で条件が見えた。一方、購買担当が明細を別タブで開くと、そのタブには元の一覧への同じ履歴がない。ブラウザの戻るを通常の経路の代わりとして案内する案は見送る。

画面内のボタンで戻る操作を引き続き確認対象にする。2ページ目の条件とページを残せるか、1ページ目からの復帰も同じ候補版で確認したい。ブラウザで一度戻れたことをCP-20の解消とは扱わない。
