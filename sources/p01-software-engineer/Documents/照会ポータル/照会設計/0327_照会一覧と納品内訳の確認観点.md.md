# 一覧と内訳をつなぐとき見ること

伊藤さん、鈴木さんへ。実装前に次の3点を設計と確認観点に入れたいです。

1. 発注番号は文字列として扱う。003764の先頭のゼロを落とさず、検索から一覧・明細まで同じ番号で結ぶ。
2. 同じ品目の分納2行を発注明細の累計納品数量と照らす。003764なら控えがそろうとき、5箱と3箱で累計8箱、注文12箱との差が残4箱。控えや数量が欠けている場合は空欄を0とせず、紙を確認する。
3. 内訳から一覧へ戻る操作で、元の対象月・状態・ページを保つ。2月の納品待ちを追う途中、検索をやり直さず次の発注を選べること。

一覧の状態は開く順の目安。品目別数量と控えの照合を省いて残数を回答しない。上記は確認したい設計であり、画面の動作を確認済みという意味ではない。
