# 発注と納品の照会　対象範囲のご説明

文書番号：ABS-2025-EV-012  
版：v1.0  
作成日：2025年3月24日  
作成者：あさひ業務システムズ株式会社　田中 美由  
確認者：高橋 和典  
宛先：藤崎医療資材株式会社　購買主任 加藤 博典様

## ご説明の目的

加藤様から伺った朝の未着確認と、納品先からの電話への回答をもとに、照会ポータルの初回設計で扱う範囲を整理しました。画面の情報と、引き続き購買の皆様に照合いただく資料を以下にご説明します。

## 業務の順に見る範囲

1. **未着の発注を探す**：対象月や納品状態などを条件に発注一覧を確認します。発注番号が分かる電話では番号を手掛かりに対象を絞ります。品名だけで決めず、納品先や発注日も見て対象の発注を特定します。一覧の状態は確認する順番の目安です。
2. **品目ごとの数量を見る**：発注明細を開き、品目を合わせて注文数量、累計納品数量、残数量と単位を確認します。異なる品目や単位の残数量を合算して回答することは想定していません。
3. **分納を照らす**：必要に応じて納品内訳を開き、便ごとの受領日・数量と納品書番号を手掛かりに納品控えを照合します。例えば、1品目を12箱注文し、5箱と3箱を受領した場合は累計8箱、残り4箱です。受領日は検収が完了した日を意味しません。
4. **次の未着へ進む**：確認後は元の条件とページの一覧に戻り、次の発注を選べる設計とします。

## 採用する項目と既存資料で確認する項目

33候補のうち、検索条件5、発注一覧7、発注明細10、納品内訳6の計28項目を初回設計に採用します。発注番号などを複数の場所に表示しても固有の1項目として数えます。残る5項目は採用28項目の外です。

| 項目 | 引き続き確認する資料と場面 |
|---|---|
| 旧品番 | 古い呼称から現品目を調べるとき、購買台帳の旧品番欄 |
| 梱包入数 | 包装ごとの入数を確認するとき、発注控えの包装欄。明細の数量単位とは別です |
| 納品便名 | 配送便を確認するとき、納品控え |
| 検収回付先 | 紙の検収事務で、検収回付簿 |
| 検収控え番号 | 購買内部の検収控えをたどるとき、検収回付簿。納品書番号とは別です |

5項目は購買担当3人の2024年12月から2025年2月までの参照控えで、各項目の月平均が2件未満でした。発注の特定と品目別の残数量照合を先に通せる範囲として選んでおり、これらの確認が不要になるわけではありません。

## 回答と検収で続けていただくこと

納品先への回答前には、発注と品目を合わせたうえで購買台帳と納品控えを照合してください。分納の数量や番号も必要に応じて控えで確認します。紙の検収回付は従来どおり納品控えを使って続けてください。照会上の受領情報だけで検収完了とは判断しません。

記載した順序が購買の実際の確認手順に沿うか、また紙の回付で続ける確認に不足がないか、ご確認をお願いします。本書は設計対象の説明であり、利用開始をお知らせするものではありません。
