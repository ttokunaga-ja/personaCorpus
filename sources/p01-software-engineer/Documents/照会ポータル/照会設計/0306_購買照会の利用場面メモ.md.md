# 未着を見る日と電話を受けた時

加藤さんの紙の順番から。高橋さんに相談する前の案。

## 朝

発注月などの条件を入れる → 発注一覧で未着を探す → 発注明細で品目ごとの注文数・届いた数・残りを見る → 必要なら納品内訳を開いて控えと照らす。終わったら同じ条件の一覧に戻し、次の発注を選ぶ。

## 電話

発注番号が分かる電話なら番号を入力し、一覧の該当行へ絞る。発注と品目を合わせてから明細を開き、どの品目があといくつか確認する。必要な便は納品内訳と納品控えで照らす。確認後は同じ条件の一覧へ戻る。

番号がないときは月や納品先を手掛かりに一覧で特定する。品名だけで決めない。一覧の状態だけで残数量を答えず、明細まで進む。戻る際に条件を保持できるかは高橋さんと詰める。
