# 申請デスク　確認画面案の確認記録

文書番号：ABS-2024-MT-007  
版：v1.0  
日付：2024年6月24日  
作成：鈴木 裕佳  
共有先：田中 美由、伊藤 裕章

## 日時・資料

2024年6月24日 13:30〜14:05（JST）。出席は鈴木 裕佳、田中 美由、伊藤 裕章。伊藤さんの画面案を、6月20日の操作チェック（ABS-2024-RL-004 v0.1）に沿って操作した。

## 論点

配送便変更では、入力した値が確定前に読めることと、訂正するために編集へ戻れることを一続きで確認した。集荷時間変更では、結果が見えない状態から一覧へ移る経路を確認した。

| 操作 | 実施手順 | 画面で確認したこと |
|---|---|---|
| 入力内容を表示 | 配送便変更で依頼控え「配車控-0529-07」、対象「午後の配送便」、変更希望「15:30便」を入れ、「内容を確認する」を押した。 | 確認画面の種別は「配送便変更」。控え・対象・変更希望も入力と一致し、未送信の案内が表示された。 |
| 入力へ戻る | 確認画面の「入力に戻る」を押した。 | 編集できる入力画面に戻り、控え・対象・15:30便が各欄に残った。次の操作は「内容を確認する」だった。 |
| 訂正後に再確認 | 変更希望だけを16:00便に直し、「内容を確認する」を押した。 | 控えと対象を保ったまま変更希望が16:00便になった。未送信の案内と「入力に戻る」「この内容で申請する」の両方を確認し、この状態を13:46に保存した。 |
| 結果不明から一覧を開く | 集荷時間変更の「受付結果を確認できません」を開き、「受付一覧を開く」を押した。 | 受付番号が表示されていない状態から、再送操作を挟まず受付一覧へ移れた。該当する受付が一覧にあるかは実機で確認する。 |

## 決定

画面案では上の4操作を確認済みとする。以下の4観点は、受付記録につながる実機で確認する。

| 持越し | 実機で確認する根拠 |
|---|---|
| 送信中の連続操作 | 確定を続けて試し、送信開始後の表示と再操作を受け付けたかを控える。 |
| 待ち後の再送 | 結果を待ち、一覧での確認から同じ入力を送り直すところまで追い、初回と再送の表示・記録を照らす。 |
| 二つの受付記録の照合 | 控え・種別・変更内容を候補ごとに合わせ、両方の受付番号全文と保存時刻を確認する。 |
| 保存件数 | 経路ごとに対象の受付記録を操作前後で照会し、新たに保存された件数を数える。 |

## 担当と期限

伊藤さんが受付を記録して一覧から照会できる環境を用意する。田中さんと確認枠を相談し、環境と日程が決まり次第、鈴木が上の4観点を追う。当日は操作時刻と表示を控え、受付記録を照合する。実機の実施日は環境の準備状況を確認してから決める。
