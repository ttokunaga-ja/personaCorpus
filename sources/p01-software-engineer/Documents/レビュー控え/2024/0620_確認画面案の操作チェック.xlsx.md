# 確認画面案の操作チェック

## シート「画面案の操作」

### 確認画面案の操作チェック

| 順番 | 操作 | 手順 | 確認条件 | 状態 | 合否 |
|---:|---|---|---|---|---|
| 1 | 入力内容の表示 | 配送便変更で依頼控え「配車控-0529-07」、対象「午後の配送便」、変更希望「15:30便」を入れ、「内容を確認する」を押す。 | 種別と3項目が入力どおりに表示され、未送信と分かる。 | 確認予定 | |
| 2 | 入力への復帰 | 送信前確認で「入力に戻る」を押す。 | 編集可能な入力画面に戻る。控え・対象・変更希望が残り、「内容を確認する」が表示される。 | 確認予定 | |
| 3 | 訂正後の再確認 | 入力に戻って変更希望だけを15:30便から16:00便に訂正し、「内容を確認する」を押す。 | 控えと対象が残り、変更希望だけが16:00便になる。未送信の表示と「入力に戻る」「この内容で申請する」がある。 | 確認予定 | |
| 4 | 結果不明から一覧への遷移 | 集荷時間変更の「受付結果を確認できません」の画面で「受付一覧を開く」を押す。 | 結果不明画面には受付番号が表示されない。送り直す操作を挟まず受付一覧が開く。 | 確認予定 | |

## シート「受付記録が必要な確認」

### 実機で追う操作と受付記録

| 順番 | 観点 | 手順 | 確認条件 | 状態 | 合否 |
|---:|---|---|---|---|---|
| 1 | 送信中の連続操作 | 配送便変更の確認から「この内容で申請する」を押し、送信処理中に同じ操作をもう一度試す。 | 送信が始まったと分かる。送信中は確定を繰り返せない。表示と操作の可否をそれぞれ確認する。 | 実機待ち | |
| 2 | 待った後の再送 | 集荷時間変更を送り、番号が出ない条件で待ってから受付一覧を開く。初回の記録を利用者が確認できず、同じ入力で送った場合まで追う。 | 照会の経路と再送時の表示を控える。初回と再送で記録が残ったかを受付側からそれぞれ確認できる。 | 実機待ち | |
| 3 | 2記録の照合 | 同じ依頼に見える二つの候補の詳細を開き、控え・種別・変更内容を見比べる。 | 3項目で一致を判断し、両方の受付番号全文と保存時刻を控えられる。時刻が近くても訪問枠などが違うものは分けられる。 | 実機待ち | |
| 4 | 保存件数 | 連続操作と待ち後の再送を別々に行い、各操作の前後で対象の控え・種別・変更内容の保存記録を照会する。 | 操作前からあった記録を除き、新たに保存された件数を数えられる。確定ボタンの状態とは別に結果を残せる。 | 実機待ち | |
