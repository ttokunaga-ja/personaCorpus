# 申請デスクR7 公開後の振り返り

文書番号：ABS-2026-MT-003  
作成日：2026年7月24日  
記録：田中美由

## 日時・資料

日時：2026年7月24日 14:00〜14:40  
出席：佐藤雅之、田中美由、鈴木裕佳、伊藤裕章

資料：7月17日の中村さんとの初動確認メモ、ADR-042第1.0版、指摘一覧ABS-2026-RL-001第1.0版

## 論点

7月15日16時の公開後、17日に中村さん・鈴木さん・田中で大島の42受付を確認した。二重受付と確認先取り違えの申告は各0件、添付差替え6件のうち旧名残りは0件。印刷見出しの問い合わせ1件は既存の通常指摘R7-08に該当する。

これとは別に、7月24日時点で新規の重大指摘は0件。17日の42件は利用者からの初動確認であり、性能の再測定でも、その件数だけから性能合格を推定する根拠でもない。

測定の振り返りでは、6月22日に同時利用20の試行で得た176msを早く共有しかけた点を確認した。判定用の同時利用40の条件とは異なる。候補版は固定条件の3走で最大p95 184ms、目標と同値で余裕はない。数字だけが先に伝わると比較可能な結果と誤解される。

## 決定

- 次回の測定では、結果を共有する前に鈴木が測定条件も照合する。条件が異なる試行値は判定用の結果と区別する。
- R7-08の印刷見出しは未完了。公開済みでも完了扱いにせず、伊藤の7月31日までの対応期限を維持する。
- 今回の同期受付維持の採用理由と非同期化・注意文のみの案を採らなかった理由は、ADR-042第1.0版を参照する。
