# 申請デスク改訂のお知らせ

文書番号：ABS-2026-NT-001　第1.0版  
2026年7月14日  
大島ルート配送株式会社　中村美喜子様、受付ご担当の皆様  
あさひ業務システムズ株式会社　田中美由

平素より申請デスクをご利用いただきありがとうございます。7月15日の改訂に伴い、申請時にご確認いただきたい点をご案内します。受付担当の皆様へご周知をお願いいたします。

## 改訂日時

2026年7月15日（水）16時。改訂後の画面から、以下の点をご確認ください。

## 申請時に確認いただきたいこと

- 代理申請では、申請を確定する前に確認画面の「確認先」が意図した宛先になっているか見直してください。
- 添付ファイルを差し替えた場合は、確定前に表示される添付名が差し替え後のファイル名になっているか確認してください。違う場合は戻って添付を確認してください。
- 送信後に再送しようとするときは、まず受付完了画面や一覧で受付番号を確認してください。受付番号が分からない場合は、重ねて送信する前にお問い合わせください。

受付完了は申請を受け付けたことを示します。業務上の処理が完了したことを示すものではありません。処理状況は一覧でご確認ください。

## 今回変わらない点とお問い合わせ

印刷時の見出しは今回の改訂では変わりません。こちらは7月末の対応を予定しています。対応後に改めてご案内します。

操作中に確認先や添付名が意図したものと異なる場合、または受付番号を確認できない場合は、あさひ業務システムズの田中美由（miyu.tanaka@asahi-business-systems.example）まで、操作した内容と表示された状況をお知らせください。
