# 申請デスクR7 性能評価
ABS-2026-EV-001　第1.0版　2026年7月8日
作成：田中美由　宛先：佐藤雅之、鈴木裕佳

## 背景
公開判定に向け、比較前版と判定候補版を同じ条件で測った。目標はp95 184ms以下。2025年の246msは過去評価であり、今回の比較前版の実測ではない。

## 条件と結果
ABS-2026-PF-001の条件を用い、同じ評価環境、同時利用40、申請60000件・添付120000件で実施した。各走は5分の慣らし後30分計測し、成功応答12000件を標本とする。操作は受付6000件、一覧3600件、詳細2400件。両版を各3走し、エラーはいずれも0件。

| 対象 | 走 | p50 (ms) | p95 (ms) |
|---|---:|---:|---:|
| 比較前 | 1 | 112 | 206 |
| 比較前 | 2 | 110 | 203 |
| 比較前 | 3 | 111 | 205 |
| 判定候補 | 1 | 96 | 184 |
| 判定候補 | 2 | 94 | 181 |
| 判定候補 | 3 | 95 | 183 |

比較前の最大206msから候補の最大184msへ22ms短縮した。各走のp95はその走の12000件から求めた値であり、走別p95の平均を全体p95とはしない。詳細はABS-2026-PF-002を参照。

## 採否と適用範囲
候補の3走は固定条件で目標以下となり合格。ただし最大184msは目標と等しく、余裕は0msである。これは同時利用40と上記の操作比・データ量に限る判断であり、負荷が増えた場合は条件を定め直して別途測定・判断する。

6月22日の176msは同時利用20での先行試行だったため比較に採用しない。40に戻し、条件を照合した上で7月7日に3走をやり直した。性能合格だけで公開可とはせず、重大指摘の再審査結果と合わせて判断する。
