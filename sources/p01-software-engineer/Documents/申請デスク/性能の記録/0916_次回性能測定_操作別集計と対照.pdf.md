# 全体の値に埋もれるときの見方

文書番号：ABS-2025-PF-005　版：v1.0  
日付：2025-09-16　作成：鈴木裕佳　宛先：田中美由、伊藤裕章

## 全操作と操作別を並べる

一覧から詳細専用項目を外す候補では、一覧の応答が短くなっても、詳細を開く際の取得に待ちが移るかもしれません。全操作のp95だけではその移動先を読み取れないため、各走の全操作p95に、受付送信・受付一覧・申請詳細それぞれの応答と件数を補助情報として並べます。操作別の値を平均して全操作のp95にすることはできません。

## 正式走の条件

比較に使う3走は、受付送信40%、受付一覧35%、申請詳細25%の配分を保ちます。各走は4分の慣らし後20分を採取し、毎秒3操作で合計3,600件、内訳は1,440件、1,260件、900件です。各走前の復元と退避の確認、同時24の条件も揃えます。候補版の識別を記録し、各走の条件と件数を確かめてから比較してください。

| 読む値 | 目的 |
|---|---|
| 各走の全操作p95 | 3走それぞれが184ms以下か判定 |
| 一覧と詳細の操作別応答・件数 | 待ちがどこに移ったかを確認 |
| 受付送信の応答・件数、エラー | 受付側の変化と失敗を確認 |
| 返された番号による照会 | 同じ申請の受付状態を確かめる |

## 切り分け走の扱い

原因を調べるため操作配分を変える場合は、その条件と結果を正式走とは別に記録します。固定配分でない走は全3走の判定表に入れません。候補の測定値はまだなく、操作別の改善や悪化は今後の確認事項です。
