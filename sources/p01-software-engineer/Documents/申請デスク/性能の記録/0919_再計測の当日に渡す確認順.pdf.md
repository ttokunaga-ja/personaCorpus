# 再計測の当日に渡す確認順

文書番号：ABS-2025-PF-007　版：v1.0  
日付：2025-09-19　作成：田中美由　宛先：渡辺典美、鈴木裕佳

## 開始前

候補版の識別と実施日は引継ぎ時点では未定です。伊藤さんから識別を受け取った後、渡辺さんに測定枠を相談します。版を記録し、全走で同じ候補版を使います。

渡辺さんは各走の直前に、申請18,000件・添付27,000件の復元点に戻したことと、手動退避を含め退避が動いていないことを確認してください。確認が揃うまで慣らしを始めません。

## 走行と引渡し

| 順 | 担当 | 実施内容 |
|---|---|---|
| 1 | 渡辺 | 復元完了と退避の有無を田中へ連絡 |
| 2 | 田中 | 同一経路・仮想利用者24・全体毎秒3操作を確認し、4分慣らす |
| 3 | 田中 | 続けて20分採取し、開始・終了時刻と条件を控える |
| 4 | 鈴木 | 受付送信1,440・一覧1,260・詳細900、計3,600件とエラーを確認し、各走p95を集計 |
| 5 | 鈴木 | 受付番号から同じ申請と受付状態を照合し、3走の集計とともに渡す |

各走の前に1へ戻ります。配分は40・35・25%です。途中で止めた走は停止時刻と理由を控え、その部分を正規走に継ぎ足さず、復元からやり直します。条件が揃った正規3走を渡してください。

## 判定に必要なもの

各走のp95が184ms以下でも、エラーがある、または受付番号の照会が一致しない場合は合格にしません。条件と結果をABS-2025-PF-006に分けて記録します。9月8日に提出した246msは前回の採用3走の最大で、今回の実測ではありません。
