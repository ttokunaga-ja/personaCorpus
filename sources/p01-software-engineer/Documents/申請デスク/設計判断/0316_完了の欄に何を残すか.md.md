# 完了の欄に何を残すか

高橋さんと照合表の見方を詰める前の整理。2/26正午の23件を旧番号ごとに追う。処理欄だけ見て閉じたことにしない。

| 控え | 分かること | それだけでは分からないこと |
|---|---|---|
| 配車の回答 | 集荷枠など、配車が何と回答したか | 依頼者へ結果を伝えたか |
| 依頼者からの補足 | 確認を求めていた条件を受け取ったこと | その条件で処理が終わり、結果を伝えたか |
| 結果連絡の控え | いつ、何を依頼者に伝えたか | 元の依頼と対応しているかは旧番号と合わせて見る |

たとえば受-260225-017は3/13の夕番引継ぎで配車返答待ち、連絡控えは未。配車が回答した時点で完了にすると、受付班から依頼者への結果連絡が残ったまま取りこぼす。旧番号にひもづく終結理由・日付・結果連絡控えを一組で残し、処理結果もたどれるようにする。

依頼の取下げも、処理欄に「取下げ」とあるだけでは足りない。依頼者が取り下げる意思を示した控えを確認し、その根拠と日付、結果の連絡控えを番号に結び付けてから閉じる。控えが見つからないものは確認待ちとして残す。

中村さんに結果と連絡控えを取りまとめてもらい、高橋さんと旧番号・状態・根拠を照合する。23件が解消したか、終了日をいつにするかはまだ決めていない。
