# 送信中の表示と操作

6/19　田中 → 伊藤さん

昨日の「配送便変更の送信前確認案」では「この内容で申請する」が静止画の間ずっと青く見えます。押す前の位置は分かりますが、押した直後に続けて操作できるかはこの画面から読み取れません。

- **表示**　最初に押した時点で送信が始まったと分かる表示を出してください。番号が返る前の段階なので、受付済みと読める文言は避けたいです。
- **操作**　送信中は確定ボタンを押せないようにしてください。押せない見た目になることと、続けて操作しても確定がもう一度実行されないことを、それぞれ確認したいです。

結果が取得できなければ、今日の案の「受付結果を確認できません」から一覧へ進む経路を見ます。結果が見えないだけでは受付の有無は分かりません。

鈴木さんと実機で見るときは、同じ依頼控え・種別・変更内容で操作前後の受付記録を比べましょう。無効表示だけで保存を1件と判定すると、画面で止まったことと受付側に残った件数を取り違えます。
