# 旧受付を止める条件案

文書番号：ABS-2026-EV-002
版：0.1
日付：2026年3月4日
作成：田中美由
レビュー依頼先：高橋和典

## 背景

大島ルート配送の旧受付には、2月26日正午時点で未処理が23件ある。旧番号単位で数え、配車回答待ち11件、依頼者の補足待ち7件、結果連絡待ち5件に分かれる。電話の追記などは同じ旧番号に束ねる。

## 条件案

基準時点の23件を旧番号ごとに追い、未処理が残る間は旧受付を維持する。依頼者の折返しを元の番号で受け、受付担当が旧台帳を参照できる状態を確保する。照合時には番号と台帳の処理欄を参照し、対象が残っていないか確認する。

## 比較と採否案

3月末を仮に置いた一律停止は、補足の折返し先がなくなるおそれがある。新受付への再登録は、同じ依頼について配車への確認が二重になるおそれがある。旧番号で追い、閉じてから止める案を採用候補とする。3月末は比較用の日付であり、終了日ではない。

## レビューいただきたい点

台帳の処理欄に加えて、結果連絡の控えまで揃えることを終了の条件にするか。受付経路が分からない照会を受けたとき、再登録前にどのように確認するか。いずれも高橋さんと相談したい。終了日は未定。
