## シート：表示変更後の確認

題：申請デスク 担当者の識別表示　変更後の確認

| No. | 条件・操作 | 期待される画面 | 判断の基準 | 実施日 | 判定 |
|---|---|---|---|---|---|
| 1 | 同姓で所属班の異なる2人を検索する | 候補に「佐々木 千紘（配車班）」「佐々木 律子（集荷班）」がそれぞれ表示される | 氏名と班の両方で2人を区別でき、選択した人が意図した人と一致する |  |  |
| 2 | 所属班が空欄の候補を表示する | 班が確認できないことが分かり、受付責任者に確認する案内が出る | 他の班名で空欄を補わず、見分けられない候補を選ぶ前に確認先が分かる |  |  |
| 3 | 氏名と所属班の組合せが同じ候補を表示する | 同じ氏名・班の候補が並び、受付責任者に確認する案内が出る | 氏名と班だけで判別できないことを確認でき、確認前に一方を決めつけない |  |  |
| 4 | 候補と送信前の確認を狭い画面幅で開く | 氏名と所属班がいずれの画面でも読める | 表示幅を狭めても識別に必要な氏名・班を確認できる |  |  |
| 5 | 候補から担当者を選び、送信前の確認へ進む | 候補で選んだ氏名と所属班が確認画面にも表示される | 候補と確認の氏名・班が一致し、姓だけの表示に戻らない |  |  |
| 6 | 予定の資料を添付し、送信前の確認を開く | 選んだ資料の添付名が表示される | 選んだ資料と確認画面の添付が一致し、別の添付が表示されない |  |  |

注記：文書番号 ABS-2025-RL-003、版 v0.1、基準日 2025-06-30、作成 鈴木裕佳、宛先 伊藤裕章・田中美由。参照：ABS-2025-EV-009 v1.0「担当者の識別表示の方針」。伊藤の実装と適用日は未定。変更後に候補版を特定して確認する。実施日・判定は確認後に記入する。
