# ADR-042　申請デスクR7の受付方式
第0.6版（検討中）　2026年7月8日　作成：田中美由
相談先：佐藤雅之　判定予定：2026年7月13日

## 背景
二重送信による二重受付、代理申請時の確認先、添付差替え後の表示が重大指摘となっている。受付番号を見て利用者が保存の成否を判断できることと、確定前に確認先・添付名を確認できることを両立したい。

## 条件
同時利用40、固定操作比で候補3走の最大p95は184ms。目標184ms以下に対し余裕を確保した。測定結果はABS-2026-PF-002を参照する。重大指摘3件の再審査結論は未決。

## 案の比較
| 案 | 内容 | 評価 |
|---|---|---|
| 同期受付維持 | 確認先を保存前に確定し、添付表示を更新。保存成功後に受付番号を表示し、二重送信は1受付にする | 推奨。完了確認を維持できるが、再審査が必要 |
| 非同期受付 | 受付を後続処理へ渡す | 受付番号発行と業務完了を混同する懸念。今回の変更範囲も広がる。将来の検討余地はある |
| 注意文のみ | 再送に注意するよう案内する | 操作上の注意だけでは二重受付を防げない |

## 決定
採用案：未決（同期受付維持を推奨）。重大指摘の再審査：未決。公開可否：未決。7月13日に佐藤さんと条件・再審査結果を確認して決める。
