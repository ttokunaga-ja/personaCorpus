# 先に受付の返事だけ出す案

伊藤さんとの相談の控え。保存が完了する前に仮の返事を出すと、担当者は番号が出た時点で受け付けられたと思う。一覧でその申請を見つけられなければ、保存を待つべきか再送してよいか分からない。再送すれば同じ申請を重ねて受け付けるおそれもある。

9月8日に佐藤さんと確認したのは、発行した受付番号で同じ受付を照会できることも含む判定。先に返事だけを出す案は、この回の候補調査から外す。保存確認後に番号を返す受付成立の区切りは保ち、まず一覧取得を調べる。速くなったかだけでなく、番号で同じ申請を引けるかを鈴木さんの確認に残す。
