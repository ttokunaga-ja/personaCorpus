# 大島の初回受付設計 引継ぎ

文書番号：ABS-2024-EV-008　版：v1.0
日付：2024年4月26日　作成：田中 美由
宛先：伊藤 裕章、鈴木 裕佳

## 背景

4月18日の設計会議で、大島の窓口別の呼称42行から初回受付名33種を選んだ。配車10、集荷9、配送8、伝票6である。同じ窓口・用件・引渡し先を指す別称9行は、独立した選択肢にせず、4月19日確定の対応表 ABS-2024-RL-001 v1.0 から引く。別称による依頼を受けなくする判断ではない。

25日は中村さん、高橋さんと当番2人で6例を机上で読み合わせた。5例は聞き返し後に受付名と渡し先を決め、紙の種類が分からない1例は中村さん確認に残した。訪問集荷の例では最初に配車の票を選び、聞き返して集荷班へ訂正している。

## 条件

| 依頼の言葉・確認した用件 | 受付名 | 引渡し先 |
|---|---|---|
| 時刻変更：車庫出発の枠 | 配車時刻変更 | 配車班 |
| 時刻変更：集荷先への訪問枠 | 集荷時間変更 | 集荷班 |
| 車番差替え：台数を増やさず車番を替える | 車両変更 | 配車班 |
| 便振替：未配達の荷物を別の配送便に移す | 配送便変更 | 配送班 |
| 控えの再出力：受付番号を発行したときの紙 | 受付控え再発行 | 伝票係 |
| 配達後の受領控え | 配達控え照会 | 伝票係 |

「控え」だけでは二つのどちらかを決められない。紙の種類を聞き、それでも不明なら中村さんの確認待ちにする。棚卸しにない運賃の個別見積りは従来の問い合わせ窓口へつなぐ。

## 担当への依頼

伊藤さん：同じ元の呼称「時刻変更」でも車庫出発と訪問集荷を別に扱い、配車班と集荷班への渡し先をそれぞれ追える設計をお願いします。受付したことと班の業務が終わったことは分けてください。分類名だけでの自動振分けは初回の決定に含めていません。

鈴木さん：実機確認の観点に、車番差替えが配車班へ届く場合との対照として、「便振替」が配送受付の配送便変更となり配送班へ届くことを入れてください。また「控え」だけで選択を確定せず、受付時の紙・配達後の紙・不明を聞き分ける条件を確認してください。

## 決定と次の相談

初回の33種と別称9行の対応は19日の表を基準とする。25日の読み合わせを受けても対象数は変えない。端末と実機確認の日程は次回相談し、利用開始日も未定とする。
