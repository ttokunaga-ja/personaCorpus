# R7 受付の三つの案

6月23日の伊藤さん・鈴木さんとのボードを見ながら、佐藤さんに相談する前の整理。まだ採用は決めない。

## 1. 同期受付を維持し、確認先と表示更新を整理する

確認画面で代理申請の確認先と差替え後の添付名を確定し、保存の成功後に受付番号を表示する。二重送信は一件の受付として扱う。今の完了確認を残せる一方、確認と保存の経路で性能目標を満たす必要がある。重大3件の再審査も必要。固定条件でp95 184ms以下の実測が出るまでは採用未決。

## 2. 非同期受付

受付を先に受け付け、後で処理を進める案。待ち時間の整理に役立つ可能性はあるが、先に番号を出すと受付番号の発行と業務処理の完了を混同させかねない。画面と処理状態の説明も広く見直す必要がある。今回の範囲と利用者への説明を含めて佐藤さんに相談する。将来の選択肢としての価値まで否定しない。

## 3. 再送時の注意だけを加える

画面で再送しないよう注意する案。変更は小さいが、操作する人の注意だけでは二重受付を防げない。通信待ちの間に再送される場合もあるため、重大指摘の解消策には足りない。

次に確認すること：同じ条件で候補を測り直し、鈴木さんの再審査結果と合わせて佐藤さんに提示する。性能の目標値を結果として書かない。
