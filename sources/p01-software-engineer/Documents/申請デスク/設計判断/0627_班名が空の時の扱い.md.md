# 班名が空の時の扱い

伊藤さんへの相談。方針は候補と送信前確認に氏名（所属班）を残すこと。ただし、班が空欄の候補は氏名だけになり、同姓の別人と十分に見分けられないことがある。別の候補に班が入っていても、その値を空欄に補わない。

氏名も班も同じ候補が二つ並ぶ場合も、表示の組合せだけではどちらか決められない。職員番号を追加表示する案は今回に入れない。

いずれも見分けられない候補は選ばず、受付責任者に確認してから進めるよう案内する。送信前に判別できないときも、そのまま送らず確認へ戻す。空欄と同一組合せの両方で、候補と確認の表示を見ておきたい。
