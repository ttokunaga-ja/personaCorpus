# 受付が見えないときの確認順

鈴木さんへ。送信直後に応答が途切れ、結果と番号を表示できなかった場合の案内を整理しました。画面が出ないことだけでは、受け取ったかどうかも再送の要否も決められません。

まず受付一覧で、送った依頼と同じ申請を確認します。

## 一覧に同じ依頼がある場合

申請の種類を確かめ、受付番号を控えて詳細を開きます。Receipt status は受領の状態、Processing status は担当部門の作業の状態として別々に読みます。In review なら作業中であり、番号があることだけで対応完了とはしません。

## 一覧で確認できない場合

送った時刻と申請の種類を窓口で聞き、確認につなぎます。一覧に表示されないことだけで未受領とは断定しません。窓口で確認するまで、もう一度送るよう即座に案内しないでください。

11月28日の控えでは「送信失敗」と即断する案を外しました。今回も、結果不明の表示を受領済みの表示として扱わず、確認した結果に基づいて次の対応を決めます。
