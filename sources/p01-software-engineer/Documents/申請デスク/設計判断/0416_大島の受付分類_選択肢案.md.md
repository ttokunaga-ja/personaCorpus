# 大島の受付分類：伊藤さんとの相談用

窓口ごとの呼称42行を、選択肢にどう置くか。件数は電話の本数ではない。

| 案 | 選択時 | 注意点 |
|---|---|---|
| A：42行を並べる | 現場の呼び方をそのまま探せる | 同じ用件の別名が並ぶ。両方の行を保守し、同名の時刻変更は窓口と用件まで見て選ぶ必要がある。 |
| B：業務33種を並べる | 同じ窓口・依頼内容・引渡し先の別称9行を対応表で引き、同一の受付名を選ぶ | 旧呼称を捨てず、電話で言われた名前から引けるようにする。 |

Bを提案したい。車番差替えは車両変更、便振替は配送便変更に寄せる。一方、車庫出発の時刻変更は配車班、訪問集荷の時刻変更は集荷班へ渡すので二つにする。

「控えの再出力」は名前だけで決めない。受付番号を発行した時の紙か、配達後の受領控えかを聞く。分からなければ伝票窓口で確認待ち。分類名による自動振分けは初回案に入れない。

受付の記録ができたことと、配車班などが依頼への対応を済ませたことは別。受付済みの表示を業務完了として説明しない。18日は初回の対象を決め、設計や確認の予定は別に相談する。
