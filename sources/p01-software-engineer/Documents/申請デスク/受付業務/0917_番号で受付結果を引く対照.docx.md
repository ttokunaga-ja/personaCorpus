# 番号で受付結果を引く対照

文書番号：ABS-2025-EV-007　版：v1.0  
日付：2025-09-17　作成：鈴木裕佳　宛先：伊藤裕章

## 背景

一覧の取得を絞る候補でも、保存確認後に返る受付番号から、送った申請を取り違えず照会できることを確認します。これは次回の対照手順です。実施結果は確認後に記録します。

## 条件

同じ表示名で、内容を見れば区別できる申請を2件用意します。例えば表示名をどちらも「備品申請」とし、一方の内容を「机用照明」、もう一方を「書類棚」とします。送信前に各内容と使用する利用者を控え、照会できる権限で実施します。

## 対照手順

1. 1件目を送信し、返された受付番号を内容「机用照明」と対応づけて控える。
2. 2件目を送信し、返された受付番号を内容「書類棚」と対応づけて控える。番号を表示名だけで見分けない。
3. 控えた1件目の番号で詳細を開き、番号、申請内容、受付状態を送信時の控えと照合する。2件目も同じように照合し、互いに取り違えていないことを確かめる。
4. 各件について番号、送信内容、詳細の内容、受付状態、照合結果を記録する。番号が見当たらない、または内容や状態が合わない場合は、追加送信する前に番号と照会条件を確認し、状況を田中・伊藤へ伝える。

## 判定の範囲

両方の番号から対応する申請と受付済みの状態を確認できることを対照の条件とします。受付済みは受付後の業務処理まで完了したことを意味しません。照会不一致や番号を確認できない場合は、性能値が目標内でも合格にしません。
