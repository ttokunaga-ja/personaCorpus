# 大島の添付7件　調査記録
文書番号：ABS-2025-EV-008　版：v1.0
日付：2025年6月25日　作成：田中 美由　確認：鈴木 裕佳

## 背景と対象
大島ルート配送の中村さんから、申請デスク試行で6月3日から17日に予定と異なる控えを添付した7受付の申告を受けた。6月24日14:00〜14:45に中村さん、鈴木さんと点検した。対象は申告されたSD-5213、SD-5219、SD-5224、SD-5229、SD-5233、SD-5239、SD-5244の7受付である。それ以外の大島の受付は点検していない。

## 照合方法
受付番号ごとに、中村さんの予定資料と班内点検控えを保管資料の内容と照らし、田中が選択時の表示名と受付後の保存名を合わせた。鈴木さんは確認された閲覧・取得の記録を当日の許可範囲と照合した。班外・社外への送付は中村さんの送付控えと班内点検控えで確認した。受付番号別の結果はABS-2025-RL-002 v1.0、点検の議事はABS-2025-MT-004 v1.0に残す。

## 最初に誤認した場面別の受付数
最初に資料や担当者を取り違えた場面で各受付を一度だけ数える。後の確認画面にも同じ姓が現れたことは別の件数に加えない。

| 最初に誤認した場面 | 受付番号 | 件数 |
|---|---|---:|
| 担当候補の選択 | SD-5213、SD-5219、SD-5224 | 3 |
| 別受付の参照 | SD-5229、SD-5233 | 2 |
| 送信前の確認 | SD-5239、SD-5244 | 2 |
| 合計 | | 7 |

候補選択では同じ「佐々木」の候補やその並びを頼りにし、別受付参照では別の受付の同姓を同じ担当者と思って控えを選んだ。送信前確認の2件は候補選択自体は合っていたが、姓だけを見て手元の控えの作成班を取り違えた。

## 確認結果
7件すべてで予定とは別の資料が保管されていた。中村さんの予定資料・班内点検控えと保管資料の対象班を番号ごとに照らして確認した。いずれも受付後の班内点検で差に気づき、班外へ回す前に止めている。

選択時の表示名と受付後の保存名は7件とも一致した。SD-5244も予定の配車の連絡票ではなく集荷の連絡票が選ばれていた。受付後に表示だけが古いという仮説では今回の差を説明できず、取り下げる。

鈴木さんが各番号の閲覧・取得記録と当日の許可範囲を照合したところ、確認された人はすべて範囲内で、対象内の権限逸脱は0件だった。中村さんと送付控え・班内点検控えを照合した範囲では、7件の班外・社外への送付はなかった。この結果は照合した7受付についてのものであり、他の受付や他社、全利用者の状態を示すものではない。

## 次の対応
6月24日の点検では、同姓時に氏名と所属班を候補選択と送信前確認の両方に示す変更を先に進めると決めた。候補順の固定だけでは別受付を参照した2件に対応できない。表示方針は別途整理し、田中が伊藤に見積りを相談し、鈴木さんが変更後の確認観点を6月30日までに整理する。実装と適用日は未定。
