# 次の高橋さんとの相談　当番から中村さんへ渡すメモ

25日の英語草稿への返事を受けて、照合票の引渡し欄も見直したい。電話で「31と32です」だけだと、中村さんが後から一覧を引き直すときに別の日の番号と取り違えやすい。二つ見つかったら、どちらも番号を省略せずに書いて渡す。

依頼控えが聞けなければ「控え不明」。その場で申請種別、対象の便か集荷の訪問枠、何に変更したかったか、送った日とおよその時刻を聞く。電話で聞いた送信時刻と、一覧で読んだ保存時刻は欄を分ける。

## 5月29日の配送便変更を使った記入例

- 電話で聞くこと：控え不明。配送便変更。午後の配送便を15:30便に変更。5月29日10:18ごろ送信。
- 一覧で拾った候補：SD-0529-031（5月29日10:18:20保存）、SD-0529-032（同日10:18:22保存）。一覧上の依頼控えは両方とも「配車控-0529-07」。種別と変更内容は電話の話と合う。
- 中村さんへの申し送り：本人の依頼控えは未確認。候補2件をそのまま引き渡し、どちらも残しておく。

次に高橋さんと照合票を見ながら、誰が取り消しを判断・操作できるか、確認中の相手に電話でどう案内するかを中村さんに聞く。この二つは回答をもらうまで草稿で決めない。
