# 7月に持ち越す確認先

鈴木さんと私へ。大島の担当者表示は、6月24日に点検した7件を受けて、候補と送信前の確認に氏名と所属班を出す方針まで決めた。6月末時点で実装と適用日は未定。適用日が決まるまでは、この未定を消さずに残す。

- 大島の当面の手順については中村さんに聞く。6月27日の班内手順は、予定の班と受付番号を作業控えで確かめ、添付本文の用件も開いて合わせる。判断がつかなければ中村さんに戻す。
- 表示変更の見積りは伊藤さんに確認する。候補と確認の両方で氏名・班を見せることと、狭い幅で班名を確認できることを相談している。費用も適用日も回答待ち。
- 変更後の確認表は鈴木さん。ABS-2025-RL-003 v0.1に同姓別班、班空欄、氏名と班が同じ場合などの観点がある。実施日と判定はまだ空欄。候補版が決まってから確認する。

新たな申告が届いたら、24日に確かめた7件とは別に受ける。まず受付番号、どの段階で気づいたか、確認できる作業控え・閲覧や取得の記録・送付控えを聞く。予定の資料と実際の添付も番号ごとに合わせ、控えがない項目は未確認のまま残す。24日の結果を新しい申告の結論に使わない。
