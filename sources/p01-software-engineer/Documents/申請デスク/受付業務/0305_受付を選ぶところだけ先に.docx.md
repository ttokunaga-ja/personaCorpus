# 旧受付と申請デスクの選び方（読み合わせ用）

文書番号：ABS-2026-NT-002　版：0.1
日付：2026年3月5日　作成：田中 美由
宛先：高橋 和典

## まず入口を選ぶ

大島ルート配送で試行中の申請デスクと旧受付を併用している間の説明案です。依頼を受けたら、初めての依頼か、すでに受けた依頼への折返しかを聞きます。

## 二つの例

- 初めての依頼：申請デスクで受け付けます。一覧の「受付番号」は SD から始まります。
- 旧受付番号のある折返し：旧受付の台帳を開き、番号を全部確認して元の記録を探します。たとえば「受-260225-017」は集荷時間変更の旧受付です。折返しはその番号の記録を見て扱います。
- 番号が分からない場合：受付担当が旧台帳を見て、依頼の手掛かりから該当する記録を探します。

## 6日に確認したいこと

番号が分からないとき、新受付の記録とどう突き合わせるか。旧側の処理が済んでいても結果の連絡待ちがあることを、受付担当向けにどう説明するか。高橋さんとの読み合わせで確認してから、受付班向けに直します。
