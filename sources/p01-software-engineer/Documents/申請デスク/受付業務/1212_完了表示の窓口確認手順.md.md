# 窓口で先に聞くこと

鈴木さん・高橋さんとの説明後の整理。利用者から「完了と出た」と言われても、その言葉だけで担当部門の対応が終わったとは答えない。

1. **どの画面を見たか**：送信後の受付結果か、受付一覧か、申請詳細かを聞く。受付結果は受け取ったことを知らせる画面。
2. **受付番号が手元にあるか**：あれば番号を確認し、同じ申請を一覧から開いてもらう。番号が示すのは申請を探せること。
3. **詳細の処理状況**：Processing status の値を読み上げてもらう。Receipt status の Received は受付の状態なので混ぜない。

Processing status が **In review** なら、まだ確認中として担当部門に確認をつなぐ。「対応は済みました」とは答えない。実際に **Processing completed** と出ている場合は処理欄の表示として伝える。

番号が見えなかった場合は、すぐ再送してもらわず、まず一覧で同じ依頼を探す。見つからない場合も受領・未受領を画面の有無だけで決めず、送信時刻と申請の種類を聞いて窓口で確認する。
