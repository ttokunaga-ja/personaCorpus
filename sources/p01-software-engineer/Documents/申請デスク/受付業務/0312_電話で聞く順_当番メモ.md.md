# 電話で聞く順（高橋さんとの読み合わせ後）

1. 受付番号が分かるか聞く。分かれば番号全文と、どちらに依頼したかを復唱する。旧番号なら旧台帳、SD番号なら申請デスクで元の記録を開く。
2. 番号が出なければ、最初に依頼した日・用件・便を控えて中村さんに渡す。中村さんが旧台帳と申請デスクの候補を見て経路を特定するまで新規登録は待つ。用件名だけでは決めない。
3. 元の記録が分かれば、その番号へ追記する。

例：当日の集荷時間について急ぎの電話があり、番号が分からない。上の3項目を控え、中村さんから配車へ電話で急ぎを知らせてもらう。返事を急ぐために新しい受付を作らない。記録は突合後に元の番号へ。
