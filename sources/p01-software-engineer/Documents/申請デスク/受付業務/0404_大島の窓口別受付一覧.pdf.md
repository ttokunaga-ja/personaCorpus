# 窓口別受付一覧

文書番号：OR-2024-001  
版：v1.0  
日付：2024年4月4日  
宛先：あさひ業務システムズ株式会社 田中美由様・高橋和典様  
作成：大島ルート配送株式会社 中村美喜子

現在、各窓口で使っている受付名と用件、票を渡す先をまとめました。同じ名前でも窓口によって用件が異なるものはそれぞれ記載しています。呼び方が複数あるものも、普段の言い方ごとに載せています。

## 配車受付

| 受付名 | 受ける依頼 | 票の引渡し先 |
|---|---|---|
| 時刻変更 | 車庫出発の時刻を変更 | 配車班 |
| 車両変更 | 便の車両を変更 | 配車班 |
| 車番差替え | 便の車番を差し替え | 配車班 |
| 運転者変更 | 便の運転者を変更 | 配車班 |
| 乗務員差替え | 同じ便の運転者を差し替え | 配車班 |
| 増車依頼 | 通常の便に車両を追加 | 配車班 |
| 追加車手配 | 便に車両を追加 | 配車班 |
| 減車依頼 | 予定便の車両を減らす | 配車班 |
| 代車依頼 | 故障などで予定車を置き換える | 配車班 |
| 積込順変更 | 便の積込順を変更 | 配車班 |
| 車庫出発確認 | 車庫からの出発を確認 | 配車班 |
| 応援車依頼 | 他の担当から応援車を手配 | 配車班 |
| 運行中止連絡 | 予定便の運行中止を連絡 | 配車班 |

## 集荷受付

| 受付名 | 受ける依頼 | 票の引渡し先 |
|---|---|---|
| 時刻変更 | 訪問集荷の時刻を変更 | 集荷班 |
| 集荷先変更 | 集荷する訪問先を変更 | 集荷班 |
| 集荷口変更 | 訪問先の受渡口を変更 | 集荷班 |
| 引取口変更 | 同じ訪問先の受渡口を変更 | 集荷班 |
| 集荷取消 | 依頼済みの集荷を取り消す | 集荷班 |
| 集荷追加 | 集荷の依頼を追加 | 集荷班 |
| 集荷個数訂正 | 集荷依頼の個数を訂正 | 集荷班 |
| 引取個数訂正 | 同じ集荷依頼の個数を訂正 | 集荷班 |
| 集荷荷姿変更 | 集荷する荷物の荷姿を変更 | 集荷班 |
| 集荷保留 | 依頼済みの集荷を保留 | 集荷班 |
| 集荷再開 | 保留していた集荷を再開 | 集荷班 |

## 配送受付

| 受付名 | 受ける依頼 | 票の引渡し先 |
|---|---|---|
| 配送便変更 | 未配達の荷物を別の配送便へ移す | 配送班 |
| 便振替 | 未配達の荷物を別の配送便へ移す | 配送班 |
| 配送先変更 | 未配達の荷物の配送先を変更 | 配送班 |
| 再配達依頼 | 不在で持ち戻った荷物を再度届ける | 配送班 |
| 再訪依頼 | 不在で持ち戻った荷物を再度届ける | 配送班 |
| 到着予定照会 | 荷物の到着予定を問い合わせる | 配送班 |
| 受取人変更 | 荷物の受取人を変更 | 配送班 |
| 持戻り照会 | 持ち戻った荷物の状況を問い合わせる | 配送班 |
| 置き場所変更 | 荷物を置く場所を変更 | 配送班 |
| 配達中止連絡 | 予定していた配達の中止を連絡 | 配送班 |

## 伝票窓口

| 受付名 | 受ける依頼 | 票の引渡し先 |
|---|---|---|
| 送り状再発行 | 内容を直さず同じ送り状を再発行 | 伝票係 |
| 送り状の出し直し | 内容を直さず同じ送り状を再発行 | 伝票係 |
| 送り状宛名訂正 | 送り状の宛名を訂正 | 伝票係 |
| 受付控え再発行 | 受付番号発行時の控えを再発行 | 伝票係 |
| 控えの再出力 | 受付番号発行時の控えを出し直す | 伝票係 |
| 配達控え照会 | 配達後の受領控えを照会 | 伝票係 |
| 返送票発行 | 返送用の票を発行 | 伝票係 |
| 荷札再発行 | 荷札を再発行 | 伝票係 |
