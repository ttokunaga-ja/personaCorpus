# 大島の当番読み合わせ記録

文書番号：ABS-2024-MT-004　版：v1.0
日付：2024年4月25日　作成：田中 美由

## 日時・資料

日時：2024年4月25日 10:00〜10:35
出席：田中 美由、高橋 和典、中村 美喜子、大島の朝の当番・交代の当番の2人
資料：当番読み合わせ表 ABS-2024-RL-002 v0.1、受付分類対応表 ABS-2024-RL-001 v1.0

電話の言い方を一問ずつ読み、聞き返した後に受付名と票の渡し先を答える机上確認を行った。端末での操作確認ではない。

## 論点

| 電話例 | 聞き返しと確認した答え | 結果 |
|---|---|---|
| 車庫を出る時間を遅くしたい | 車庫出発の枠を変更する。配車時刻変更、配車班 | 振分け |
| そちらが出る時間を後ろにしてほしい | 当番は最初、車庫出発と受け取り配車の票を選んだ。便の出発か訪問かを聞き返すと集荷先への訪問時間だった。集荷時間変更、集荷班に訂正 | 振分け |
| 今日の便の車番を差し替えたい | 台数は増やさず車番を替える。車両変更、配車班 | 振分け |
| この荷物を別の便に振り替えてほしい | 未配達の荷物を別の配送便へ移す。配送便変更、配送班 | 振分け |
| 控えをもう一度出してほしい | 受付番号を発行したときの控え。受付控え再発行、伝票係 | 振分け |
| 控えをもう一度出してほしいが、どの紙か分からない | 受付時か配達後かを特定できない。聞き取った内容を中村に渡す | 中村確認待ち |

6例中5例は聞き返しの後に受付名と渡し先を答えられた。残る1例は紙を特定できず保留とした。訪問集荷の例は最初から正答したものとして数えない。

## 決定

初回対象33種は変更しない。時刻変更は車庫出発と集荷先への訪問を先に聞き分け、名前だけで配車に寄せない。「控え」だけでは受付控え再発行と決めず、受付番号発行時の紙か配達後の受領控えかを尋ねる。分からなければ中村に確認を回す。

## 担当と期限

| 担当 | 対応 | 期限 |
|---|---|---|
| 中村 | 読み合わせで迷った点を当番へ伝える | 4月26日の班内共有 |
| 田中 | 配車・集荷の経路と控えの保留条件を設計・確認の担当へ引き継ぐ | 4月26日 |

端末の確認日と利用開始日はこの場では決めていない。
