# 旧受付と申請デスクを使うとき

文書番号：ABS-2026-NT-002　版：1.0
日付：2026年3月6日　作成：田中美由
宛先：大島ルート配送株式会社 受付担当の皆さま

## 併用中の受付

旧受付と試行中の申請デスクを併用しています。すでに受けた依頼への折返しは、元の受付に戻して扱ってください。2月26日正午に確認した旧受付の未処理23件は、終結を確認するまで旧受付で追います。旧受付の終了日は決まっていません。

## 番号が分かるとき

1. 依頼者に受付経路と番号全体を確認します。
2. 旧受付番号がある補足や折返しは、旧台帳でその番号の記録を開き、元の依頼に追記します。たとえば「受-260225-017」は旧受付の番号です。
3. 申請デスクの番号がある照会は、申請デスクでその番号の元の記録に戻します。
4. どちらにも受け付けていない新規の依頼と確認できた場合は、申請デスクで受け付けます。

番号の末尾や用件名が似ているだけで同じ依頼と決めず、受付経路と番号全文を合わせて確認してください。

## 番号が分からないとき

最初に依頼した日、用件、便を聞き取り、旧台帳と申請デスクの記録をそれぞれ見比べてください。候補があっても、用件名だけで同じ案件とは決めません。どちらの経路か特定できない間は再登録を保留し、聞き取った内容と確認した候補を中村さんにつないでください。経路が確認できたら、元の記録に戻します。

## 受付と業務の完了

申請デスクの「受付済み」は依頼を受け取った表示です。配車の回答や依頼者への結果連絡まで終わったことを示すものではありません。旧受付でも、配車内の処理が済んだだけでは結果連絡待ちの案件は終わりません。受付班で依頼者へ結果を伝え、連絡の控えを残してください。
