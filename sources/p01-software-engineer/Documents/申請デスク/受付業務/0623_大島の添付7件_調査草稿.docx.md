# 大島の添付7件　調査記録
文書番号：ABS-2025-EV-008　版：v0.1
日付：2025年6月23日　作成：田中 美由　確認：鈴木 裕佳（予定）

## 背景
大島ルート配送の中村さんから、6月3日から17日の7受付で予定と異なる控えを添付したとの申告を受けた。18日の申告資料と集計は受付番号で対応する。24日に中村さん、鈴木さんと予定資料、保管された資料、閲覧・取得と送付の控えを照合する。

## 条件
最初に誤認した場面で各受付を一度ずつ数える。候補選択はSD-5213、5219、5224の3件、別受付参照はSD-5229、5233の2件、送信前確認はSD-5239、5244の2件。後の確認場面にも同じ姓が出ることと、最初の場面の分類は分ける。

鈴木さんは各受付の当日の許可範囲と閲覧・取得記録を照合できるよう準備済み。中村さんの予定資料と班内点検控え、班外・社外への送付控えの確認は24日待ち。田中は選択時の表示名と受付後の保存名を受付番号ごとに合わせ、資料本文の対象班も確認する。

## 採否
表示名だけの問題か、資料を選んだ時点での取り違えかはまだ決められない。候補の順番だけでなく別受付を参照した場合と送信前確認も見る。氏名と班を候補および確認に残す案を当日提示する。

## 決定
7件の対象内でも閲覧・取得と送付の結論は確認中。送付控えを含めた照合後に結果を記す。他の受付の状態はこの調査の対象に含めない。
