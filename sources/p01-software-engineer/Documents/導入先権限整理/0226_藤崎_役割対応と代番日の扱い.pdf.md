# 役割対応と代番日の扱い

文書番号：ABS-2025-EV-017　版：v1.0
日付：2025年2月26日　作成：田中 美由
宛先：藤崎医療資材株式会社 購買主任 加藤 博典様

## 対象と前提

2月26日の説明で確認した役割の整理と、購買承認の欠員日における仕事の分担を記します。旧7役割の操作を整理後の5役割へ対応させます。

## 旧役割と整理後の対応

| 旧役割 | 整理後の役割 | 主な仕事 |
|---|---|---|
| 発注申請入力 | 申請担当 | 発注を申請する |
| 差戻し訂正 | 申請担当 | 差し戻された申請を訂正する |
| 発注照会 | 購買閲覧者 | 発注を照会する |
| 納品照会 | 購買閲覧者 | 納品を照会する |
| 購買承認 | 購買承認者 | 担当申請を承認・差戻しする |
| 検収記録 | 検収担当 | 検収を記録する |
| 利用者管理 | 権限管理者 | 利用者の権限を管理する |

申請と訂正、発注と納品の照会はそれぞれ同じ担当者の連続する仕事としてまとめます。

## 代番日と未着確認

購買承認の代番は、自分に回った個別申請の明細を確認して承認または差戻しをします。発注・納品の一覧を横断して見る購買閲覧者は兼ねません。当日限りでも一覧へ範囲が広がるためです。朝の未着確認は別の購買閲覧者へ引き継ぎます。取引先へ残数を回答する前に、未着担当が購買台帳と納品控えを突き合わせます。紙の検収回付は続けます。

## 合意した設計と今後の確認

| 区分 | 内容 |
|---|---|
| 説明会で確認した設計 | 7役割から5役割への対応、承認と一覧閲覧の分離、未着確認の引継ぎと帳票照合、紙回付の継続 |
| これから確認 | 購買側の対象者・割当て候補、切替日、移行前の運用確認 |

対象者の割当てと切替日は未定です。役割の設計確認と実際の移行完了は別に扱います。
