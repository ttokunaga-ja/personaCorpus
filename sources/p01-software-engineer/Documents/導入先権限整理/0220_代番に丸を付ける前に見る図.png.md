# 代番に丸を付ける前に見る図

社内確認用。藤崎の二つの仕事を上下の別経路に置く。

上段：箱「承認待ちの1申請」→ 箱「その申請の明細」→ 分岐して箱「承認」または箱「差戻し」。経路の脇に「購買承認者」と記す。

下段：箱「未着の確認」→ 別の箱「発注・納品の一覧」。経路の脇に「購買閲覧者」と記す。

上段の「その申請の明細」と下段の「発注・納品の一覧」は別々の箱とする。上段の承認者側から下段の一覧へ向かう破線を引き、境目に×を置く。破線のそばには「兼任すると一覧まで見える」と記す。実線はそれぞれの仕事の流れ、破線は兼任によって広がる参照を示す。
