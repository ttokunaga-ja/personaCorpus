# 割当ての前に確認してほしいこと

文書番号：ABS-2025-EV-018  
版：v1.0  
日付：2025年2月28日  
作成：田中 美由  
宛先：鈴木 裕佳、山本 真由子

## 対象と前提

2月に両社へ説明したのは役割と受渡しの設計です。藤崎の7役割から5役割への対応と、両社からの兼任相談2件の判断は「役割対応と兼任可否」（ABS-2025-RL-005 v1.0）に整理しました。対象者への割当てや切替え、挙動の確認が完了したことを意味しません。

## 藤崎：操作を残し、一覧を分ける

鈴木さんには、割当て前の確認票に次の観点を入れてください。統合によって必要な操作が欠けないことと、承認の代番に一覧が広がらないことの両方を確認します。

| 確認すること | 確認したい結果 |
|---|---|
| 申請入力と差戻し訂正 | 申請担当が入力と、差し戻された申請の訂正の両方を行える |
| 発注照会と納品照会 | 購買閲覧者が発注・納品の両方を照会でき、未着確認を引き継げる |
| 購買承認の代番 | 回ってきた個別申請の明細を確認し、承認と差戻しをそれぞれ行える |
| 一覧の境界 | 代番の購買承認者が、承認の権限だけで発注・納品一覧に入れない |

加藤さんに購買側の割当て候補を照合いただき、候補の確認後に切替日を相談します。紙の検収回付と、残数回答前の購買台帳・納品控えの照合は続ける前提です。

## 共栄：個別照合の受渡し

保存後75日目の帳票を例に、業務課の代理担当が再発行依頼を承認し、小林さんが対象帳票と理由を経理へ渡せることを確認してください。経理担当は自部署の範囲で原本を個別照合し、可否と再発行判断に必要な結果を返します。業務課が経理権限で原本へ行かず、この受渡しで当日の処理を進められるかを確認します。経理側の窓口は小林さんに確認いただきます。

## 担当と次の段取り

| 項目 | 担当 | 状態 |
|---|---|---|
| 藤崎の割当て候補の照合 | 加藤 博典 | これから確認 |
| 共栄の経理側窓口の確認 | 小林 早百合 | 持ち帰り |
| 移行前の確認票 | 鈴木 裕佳 | 上記観点を整理 |
| 設計と顧客への連絡の整理 | 田中 美由・山本 真由子 | 候補と窓口の確認後に調整 |

確認の実施日と切替日は未定です。結果を確認するまでは、設計上の合意と実際の移行を分けて扱ってください。
