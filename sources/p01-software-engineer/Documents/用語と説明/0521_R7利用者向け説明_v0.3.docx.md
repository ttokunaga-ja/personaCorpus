# Application Desk R7: guidance for reception staff

Document: ABS-2026-EX-002　Version: 0.3  
21 May 2026　Miyu Tanaka

## Scope and intended readers

This draft is for staff who check and submit applications and later look up their status. It groups the proposed explanations around the tasks a reader needs to perform. The references U01–U10 identify the points under discussion; they do not certify a completed change.

## Changes and user actions

### Before submitting

**U03 — Destination for an application submitted on another person's behalf.** Before confirming, review the destination shown on the application. If it does not look right, seek clarification before proceeding. Reviewing a display does not require you to change routing settings.

**U04 — Attachment name.** After choosing a replacement, look at the name displayed before confirmation and check that it identifies the intended attachment. A question about earlier replacements belongs with the investigation team.

**U05 — Returning to the entry.** If a correction is needed at confirmation, use the guidance for returning to the entry and review the information again before submitting. The proposed return guidance still needs a behaviour check.

**U06 — Required fields.** Read the guidance for any missing required information and complete the relevant field before proceeding. The proposed placement of that guidance remains to be checked.

### Check the result before considering a resend

**U01 — Receipt and processing.** A receipt number indicates that the application was received. It does not mean that the business process has finished. Check its processing status separately.

**U02 — Before sending again.** If you have the receipt number, use it to check the saved result before deciding whether another submission is needed. If you cannot find the number or cannot establish the result, raise the situation for enquiry rather than assuming a resend is safe.

**U07 — Checking a long number.** Compare the complete receipt number when matching an application to its result. Do not rely on only the visible beginning if the number is long; the proposed presentation needs confirmation.

### Enquire using the list and detail

**U08 — Moving between views.** Use the list to select an application and its detail to inspect it; return to the list to continue an enquiry. The proposed return position is not yet verified.

**U09 — Two different statuses.** Read the receipt status in the list separately from the processing status in the detail. A received application can still be under review.

**U10 — Identifying an application.** Use the application detail to identify the record rather than relying on a printed heading alone. A change to the printed heading is not yet committed.

## Open questions and review status

U03–U08 include improvement candidates whose behaviour has not been verified. The printed heading in U10 is also unconfirmed. This is a draft for language and audience review, not a release notice. The reception method and release decision remain open; no release date is promised.
