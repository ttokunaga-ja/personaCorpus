# 一枚に詰めた案は読めない

16項目を一枚の利用者向け説明に収める案は取り下げる。確認先を見直して申請する操作のすぐ後に、照合キーを調べる作業を続けると、受付担当が内部のルート設定まで変える必要があるように読めた。

項目数だけ減らしても、誰が確認し、誰が調査するのかという責任範囲は直らない。管理側に必要な情報を消してしまう恐れもある。

明日の草稿は一冊の通知候補として問題を残し、Lauraに語義と読み手の境界を見てもらう。完成した通知として渡すのではなく、どこで読み違えるかを聞くための校閲依頼にする。
