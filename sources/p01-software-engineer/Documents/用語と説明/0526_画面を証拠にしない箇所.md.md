# 保存画面からは確かめられないこと

鈴木さんにR7の動作照合をお願いする前に、Lauraとの説明に使った画面と、別に確かめるべきことを分けておく。

## 画面で読めること

- 5日の一覧には、SD-6831「配送便変更」、受付日2026-05-05、状態「受付済み」がある。25日の同じ申請の詳細では、受付状態は「受付済み」、処理状況は「確認中」。番号が出たことと業務が終わったことは別だと説明できる。
- 14日の通常申請DR-6842「集荷時間変更」の確認画面には、確認先「配車受付」と添付「集荷時間変更.pdf」が見える。申請前に表示された確認先と添付名を見る例として使える。

## 鈴木さんに照合を頼む範囲

1. 代理申請で確認先を確定前に見直す候補について、設計上の表示と実際の挙動を照らす。通常申請の画面だけでは代理申請の修正ができたとは言えない。
2. 添付を差し替えた後、確認画面に出る名前がどう更新されるかを設計と照らす。14日の画面は差替え前後の比較ではない。
3. 受付結果を確認してから再送を考える説明について、結果が分かる場合と分からない場合の動作を設計と照らす。保存した3画面から二重送信の成否は分からない。

各項目について、対象版と確認した条件、実際の結果、設計との差を残してもらう。画面の見え方だけで候補の完了を判断しない。3枚は言葉の説明を助けるためのものとして扱い、性能の実績や動作受入の根拠には使わない。
