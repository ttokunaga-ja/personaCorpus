# 受付当番の読み合わせカード

ヘッダの文書種別：申請デスク 受付業務  
文書番号：ABS-2024-PF-007  
版：v0.1  
日付：2024年6月26日  
作成：高橋 和典  
用途：大島ルート配送の受付当番への説明準備（社内、一枚）

電話役と当番役で一問ずつ。6月14日の電話照合票（ABS-2024-PF-005 v0.1）を手元に置き、電話で聞いた欄と一覧で見つけた欄を順に埋める。

## 「集荷の時間を変えたくて送ったんですが、番号が出ません」

**問い**　送り直す前にどこを見てもらいますか。依頼控えも手元にないと言われたら、次に何を聞きますか。

**当番役の確認**　まず受付一覧へ案内する。依頼控え・申請種別・変更希望の訪問枠・送信した日とおよその時刻を聞く。訪問枠は、元の枠と混ざらないよう「何時から何時に変えたかったですか」と聞く。控えを聞けなければ「控え不明」と書き、聞けた項目と検索結果を中村さんに渡して折り返しを頼む。一覧で特定できない場合も、何を手がかりに探したかを残す。

**根拠**　5月30日の集荷時間変更では番号が出ずに送り直し、その後、同じ控え・変更希望（14:00〜15:00）の受付が一覧で二つ見つかった。

## 「時刻が近い集荷時間変更が二つ。片方は同じ依頼ですよね」

**問い**　保存時刻のほかに、どの欄を見比べますか。希望の訪問枠に違いがあったらどうしますか。

**当番役の確認**　行ごとに依頼控え・申請種別・変更内容を照らす。訪問枠が違えば別の依頼の可能性があるので、違いを照合票に書く。内容まで一致する候補が二つあるときや、枠の違いなどで特定しきれないときは、両方の受付番号全文・保存時刻と照合結果を中村さんへ渡し、判断と折り返しを頼む。当番の判断で片方を取り消さない。

**根拠**　保存時刻は検索の目安。依頼を突き合わせるには控え・種別・変更内容の三つが要る。

最後に申し送りを読み上げる。中村さんが同じ行を開けるか、聞けなかった項目と判断を預けた理由が伝わるかを確認する。
