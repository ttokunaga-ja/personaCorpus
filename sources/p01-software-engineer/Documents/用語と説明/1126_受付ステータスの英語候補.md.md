# 受付に使えそうな英語

受付結果の見出しは、送信ボタンを押した人の行為より、こちらが受け取ったことを伝えたい。担当部門の仕事が済んだという意味にはしたくない。

- **Submitted**：申請者が送ったことを表す候補。送り手の操作としては分かるが、こちらで受け取れたことまで伝わるかは別。
- **Received**：受け取った側の状態を示せる。見出しの第一候補。番号を控えて詳細へ進む画面で自然に読めるか確認する。
- **Accepted**：受け付けた意味にも使えそうだが、内容が承認されたようにも聞こえるかもしれない。

Lauraに聞く：申請結果の見出しに Accepted とあると、受付だけでなく承認まで済んだと感じるか。Received なら、番号が受領の控えであり業務処理の結果ではないことが伝わるか。ボタンだけを抜き出さず、番号と次に開く詳細を一緒に見てもらう。
