# 次の英語確認で拾うもの

次に画面の英語を確認するときは、用語だけで一覧にせず、表示位置、利用者が直前にした操作、その表示から次に開く場所を一緒に控えてください。単語が同じでも、受付の状態と担当部門の処理状況では示す段階が違います。

今回の配送便変更では、受付結果の番号を控え、一覧の同じ申請から詳細へ進みます。一覧の Receipt status が Received でも、詳細の Processing status は In review の場合があります。処理が終わった場合の Processing completed はそのまま使います。検索語だけで Completed を一括置換せず、欄と値を組にして確認してください。
