# 申請デスク 日英用語表

文書番号：ABS-2024-EX-001  
版：v0.1  
日付：2024-11-29  
作成者：田中美由  
確認依頼先：Laura Nichols

## 対象画面と確認範囲

申請者が入力から受付結果、一覧、詳細へ進む利用者向け英語画面を表示位置ごとに整理した。結果が見えない場合の案内も含める。同じ語が複数の場所にあればそれぞれ数える。管理者画面、帳票、通知メール、製品サイトは含めない。

Lauraには、日本語との対応に加え、直前の操作と次の行動から受付と担当部門の処理をどう読めるかを確認してほしい。受付番号は該当する申請を探すための控えで、処理の完了を示すものではない。以下は校閲前の表示。

## 確認と改訂

v0.1：11月29日、田中が利用者画面の64箇所を表示順に整理し、Lauraへ確認を依頼する版。特に受付結果の通知と番号、一覧の状態、詳細の受付欄と処理欄を続けて見たときの意味を確認したい。採否は校閲と読み合わせの後に判断する。
