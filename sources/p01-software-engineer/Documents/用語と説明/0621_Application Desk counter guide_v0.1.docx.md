# Application Desk counter guide

Document number — ABS-2024-EX-003  
Version — v0.1  
Date — 21 June 2024  
Author — Miyu Tanaka  
For review — Kazunori Takahashi  
Intended readers — Oshima Route Delivery counter staff

## Scope and intended readers

Internal draft for staff who take calls about requests sent through Application Desk. The steps follow the proposed screens, and the English labels are provisional.

## Changes and user actions

**Before sending.** Choose **Review details** and check the request reference, the request type and the change you want to make. If a detail is wrong, choose **Back to edit**. The request is still unsent and the fields keep their values. Correct the detail, open the review again and check the corrected value before you send.

**If the result does not appear.** Ask the caller to open the receipt list before trying to send again. A missing number leaves it unclear whether the request was received. If the caller finds the request in the list, ask for the full **Receipt number**. Use that number to look up the received request. For example, finding the number for a collection time change tells you the request was received. Check the outcome of the change separately.

**If the caller cannot find the request.** Ask “Do you have the request reference?”, “What kind of request did you send?” and “About what time did you send it?” Ask which delivery run or collection time slot the caller wanted to change. Compare the answers with the entries in the list. If the caller cannot give the reference, mark it as unknown and pass the details you have to Ms Nakamura. Keep the time the caller gives you separate from the time shown on the saved record.

**If two entries look alike.** Compare the request reference, the type and the requested change for each entry. Two collection requests can have close saved times and different visit slots. Write down both full receipt numbers and their saved times and pass them to Ms Nakamura. Leave both records in place while the details are checked.
