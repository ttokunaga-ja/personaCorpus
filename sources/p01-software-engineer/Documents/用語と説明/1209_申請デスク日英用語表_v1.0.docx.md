## 確認と改訂の追記

v1.0：12月9日、田中とLauraが64箇所の英語文言と表示位置を読み合わせ、受付結果4箇所、一覧2箇所、詳細2箇所を改訂。他56箇所は据え置いた。

23は依頼全体が完了した印象を避け受領を示す。24は担当部門が処理を終えたと断言せず申請の受領を示す。25は業務完了の証明ではなく照会に使う受付番号とする。26は処理途中の申請も開く移動先を示す。39は列が処理の進捗ではなく受付の状態を示すことを明確にし、40は一覧だけで業務対応が済んだと判断させない。53は担当部門の終了日ではなく受付日を示す。54は受付段階の値と明示し、別の処理欄の In review と矛盾して見えないようにする。

Submitted は送り手の操作であり受領確認にならず、Accepted は承認と読める。Successfully completed は完了の対象を特定できないため、受付結果には採用しない。処理欄で担当部門の仕事が実際に終わった場合の Processing completed は維持する。
