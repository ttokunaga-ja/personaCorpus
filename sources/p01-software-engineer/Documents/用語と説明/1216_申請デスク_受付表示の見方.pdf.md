# Application Desk: How to read the receipt message

Document: ABS-2024-EX-002  
Version: v1.0  
Date: 16 December 2024  
Prepared by: Miyu Tanaka, Asahi Business Systems  
For: Oshima Route Delivery reception team

## Receipt and processing are separate

The receipt message tells you that Application Desk has received the application. The receipt number identifies that application when you look it up. Neither the message nor the number means that the responsible department has finished its work.

## Follow an application from receipt to details

For example, after sending a Delivery schedule change, look for **Application received** and **We have received your application.** on the result screen. Write down the **Receipt number**. You can also use **View application details** to open the application.

When returning later, open the application list and select the same application using the receipt number and application type. On the details screen, the receipt information and **Processing status** are separate. Read the processing field:

- **In review**: the responsible department is reviewing the application. Do not tell the requester that the work is finished.
- **Processing completed**: the responsible department's processing is complete.

For instance, SD-241126-018 is a Delivery schedule change received on 26 November 2024. A receipt can be recorded while its processing status is In review. The receipt date is not the date the work was completed.

## If you could not see a receipt number

If the response disappears or the result cannot be displayed after sending, first open the application list and look for the same request. If you find it, note the receipt number and open its details to check the processing status. Do not send the request again just because the result screen did not appear.

If you cannot find the request in the list, contact the reception desk before deciding whether to send it again. Tell the desk the time you sent it and the application type, such as Delivery schedule change, so that the request can be checked. A missing result screen alone does not establish whether the application was received.
