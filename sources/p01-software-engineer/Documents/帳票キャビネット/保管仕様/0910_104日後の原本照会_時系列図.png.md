# 104日後の問い合わせと原本

横軸を「保存時点からの日数」とし、左から0日、30日、60日、90日、104日、180日を同じ尺度で置く。0日に「保存完了」、104日に「問い合わせ例」と縦の目印を入れる。

上段「日常画面」には3本の帯を置く。営業部は0日から30日の境界まで、業務課は0日から60日まで、経理部は0日から90日までとし、それぞれの境界に「期限ちょうどから閉じる」と添える。104日ではどの帯も終了している。

中段「原本の保存案」には別の2本の帯を置く。90日案は0〜90日で終わり、104日の位置に「比較上、保存範囲外」。180日案は0〜180日まで続き、104日の位置に「比較上、保存範囲内」と書く。保存範囲内であることは日常画面を開けることを意味しない。

下段に104日の目印から「小林が対象帳票と理由を受け付ける」→「担当者が保存範囲内の原本を個別に照合」の矢印を置く。90日案では原本が保存範囲外のため照合できず、180日案では保存範囲内で照合を検討できると分岐を示す。

注記：「104日」は発行日からの問い合わせ例を保存日数に当てはめた机上の目安。実際の期限判定は保存完了時刻を起点とする。実機での復元・閲覧の確認結果ではない。
