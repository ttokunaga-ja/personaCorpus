# 二つの保管先を同じ帳票で比べる

渡辺さんへの相談。7月の発行確定3,200件を対象にする。売上明細1,600、出荷控え1,000、締め集計600。再取得・取消は発行確定数に入れない。

既存の共有文書領域と帳票専用領域に、同じ3,200件をそれぞれ全部置いたときの一次保管量を比べたい。片方だけ件数や種類を変えると、置き方の差が見えない。

- 共有文書領域：原本に加え、帳票ごとに持つ付帯情報を数える。
- 帳票専用領域：原本と、帳票間で共用化した付帯情報を数える。共用分を落とさない。
- 種類ごとに容量を出し、合計も比較する。単位をそろえ、減少率を出すときは分母を明記する。

索引、二次保管、作業領域、将来の空き枠は一次保管量と混ぜず、必要量を別に見積もる。投入前後の空き容量の差だけでは、同時に動いた別の作業が紛れないか確認が要る。

閲覧期限の候補は営業30日、業務課60日、経理90日。これは日常の確認期間の話で、比較した容量から原本の保存日数を決められるわけではない。期限後の原本照会も別に詰める。
