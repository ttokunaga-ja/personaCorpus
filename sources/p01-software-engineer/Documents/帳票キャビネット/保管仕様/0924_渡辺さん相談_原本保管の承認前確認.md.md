# 26日の判断前に渡辺さんと詰めること

9月24日

- 9月6日の比較表では、90日から180日にすると税別で月90,000円から150,000円、増分60,000円。一次保管の増分36,000円、二次保管の増分12,000円、復元確認と記録点検の増分12,000円に分けて説明する。この増分で継続して行う作業の範囲を渡辺さんに確認する。
- 初期設定や導入時の準備などの初期作業費は月額比較の外。6万円の枠に含まれると読ませない。初期作業の内容と見積りは別途整理する。
- 鈴木さんと、保存完了時刻を起点とする原本の期限境界と、期限後の例外調査で何を証跡として残すかを確認する。部署別の通常閲覧を閉じる判定と原本の保存を分けて見る。
- 承認依頼は共栄向け初期導入の設計と月額増分に絞る。検証日と全社展開日は決まっていないので、承認資料の確定欄には置かない。利用開始日も別途判断。
