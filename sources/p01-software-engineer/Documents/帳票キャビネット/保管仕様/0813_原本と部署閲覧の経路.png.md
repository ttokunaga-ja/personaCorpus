# 原本と部署閲覧の経路

図の左に「帳票を保存」、中央上に「帳票専用領域　原本」を置き、保存から原本へ矢印を引く。その下に「原本の保存日数：検討中」と書く。原本から右方向に続く線を「原本の保存」とし、部署の閲覧停止線とは別にする。

中央下に「部署ごとの日常閲覧判定」を置き、原本から判定へ線を引く。判定から右に3本の線を分け、それぞれ次の箱へつなぐ。

- 「営業部　30日」→「営業部の日常閲覧を停止」
- 「業務課　60日」→「業務課の日常閲覧を停止」
- 「経理部　90日」→「経理部の日常閲覧を停止」

各停止はその部署の線だけに付ける。停止線を原本の保存線に接続しない。

下段に「期限後の問い合わせ」→「小林が対象帳票と理由を取りまとめ」→「担当者が保存範囲内の原本を個別調査」と矢印で並べ、最後から原本へ照合の矢印を引く。横に「日常閲覧を再開する経路ではない」と記す。原本が保存範囲外の場合は照合できない。
