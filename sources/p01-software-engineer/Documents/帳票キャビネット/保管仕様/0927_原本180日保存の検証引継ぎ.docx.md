# 承認を受けて検証に渡す条件

文書番号：ABS-2024-EV-005　版：v1.0　日付：2024年9月27日
作成：田中 美由　確認者：渡辺 典美、鈴木 裕佳（確認依頼中）　宛先：渡辺 典美、鈴木 裕佳

## 背景

9月26日、佐藤さんは共栄向け初期導入の設計として原本180日保存と税別月60,000円の増分を承認しました（ABS-2024-MT-002 v1.0）。渡辺さんには仕様への反映を、鈴木さんには確認観点の整理をお願いします。以下は検証に渡す条件であり、検証結果ではありません。

## 閲覧と保存の条件

起点はどちらも帳票の保存完了時刻とします。部署に付与された権限の範囲で、営業部30日、業務課60日、経理部90日の日常閲覧をそれぞれの期限時刻ちょうどから閉じます。一覧・詳細・画面からの再取得に同じ判定を適用し、別部署の期限を借りて取得しません。

原本は保存完了から180日の期限で保存対象から外す設計です。日常閲覧を閉じても原本の保存は直ちに終わりません。期限後の問い合わせは小林さんが対象帳票と理由を取りまとめ、担当者が保存範囲内で個別に照合します。通常画面への再公開はしません。

## 検証へ引き継ぐ観点

| 観点 | 確認する条件 |
|---|---|
| 部署別の境界 | 各部署の正当な権限で期限の1分前・ちょうど・1分後を比較し、一覧・詳細・再取得を確認する。 |
| 104日後の照会 | 日常閲覧が閉じた後、小林さんからの個別調査を受け、保存範囲内の原本を照合する経路を確認する。104日は発行日からの問い合わせ例を用いた机上の目安であり、実判定は保存完了時刻から数える。 |
| 原本の期限 | 180日の境界と、実際に期限を過ぎた原本の処理を確認する。 |
| 二次保管 | 必要な原本を二次保管から復元できるか確認し、照合に必要な記録を残せるかを見る。 |

## 次の対応

渡辺さんは期限境界と原本の処理案を仕様に反映してください。鈴木さんは上記の観点と復元確認に必要な条件を整理してください。田中が両方を受けて次の判定材料をまとめます。検証日、利用開始日、全社展開の可否は未定です。
