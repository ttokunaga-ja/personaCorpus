# 一覧の控えだけでは締め訂正を追えない

9月19日　渡辺さんとの相談後

原本は90日で保存対象から外し、発行日と帳票名を並べた一覧の出力だけを長く残す案は、保存期間の比較から外す。

小林さんが9月3日に知らせてくれた問い合わせのうち、発行から147日後の締め訂正では、元の帳票の記載と訂正前の内容を照合する必要がある。発行日と帳票名が分かれば対象を探す手掛かりにはなるが、その行だけでは当時何が記載されていたかを確かめられない。出力を残しても原本照合の代わりにはならない。

10件中、90日を超えた問い合わせは104・121・147・168日後の4件。月間の発生頻度を示す数字としては使わず、原本を残す期間の比較材料にする。発行日からの日数は目安で、実際の期限判定は保存完了時刻から数える。日常閲覧の期限を延ばす話とも分けて、90日と180日の原本保存を費用と一緒に佐藤さんへ出す。
