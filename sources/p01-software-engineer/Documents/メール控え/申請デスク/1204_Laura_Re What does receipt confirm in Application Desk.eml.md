Hi Laura,

Thank you for checking these distinctions. My answers are below.

> 1. When the number appears on the receipt screen, what point has the application reached? Does the number confirm only that it was received, or that the requested work has been completed?

The number is a reference for finding the application we received. It confirms receipt, not completion of the requested work.

> 2. If I see a row in the list, can I tell from that row alone what the responsible department has done? Where should I look for its progress?

No. Open the application details and look at Processing status for the department's progress. Please include the list heading and its status value in your review as well; they should not suggest that the department has finished.

> 3. If the response is interrupted immediately after submission and no number appears, where should the user look first?

First check the application list for the request before sending it again. If it cannot be found, contact the desk to check rather than assuming the submission failed.
