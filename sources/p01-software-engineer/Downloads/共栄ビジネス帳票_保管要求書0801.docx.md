# 帳票キャビネットの保管に関する要求書

文書番号：KBC-2024-RQ-001　版：v1.0  
日付：2024年8月1日  
作成：共栄ビジネス帳票株式会社 業務課　小林 早百合  
宛先：あさひ業務システムズ株式会社　田中 美由様

## 背景と対象

田中様

帳票キャビネットの検討にあたり、当課で扱う帳票の発行量と、締め後の確認についてお願いをまとめました。7月1日から31日までの発行確定分は以下の3,200件です。再取得や取消分はこの件数に加えていません。

| 帳票の種類 | 7月の発行確定数 |
|---|---:|
| 売上明細 | 1,600件 |
| 出荷控え | 1,000件 |
| 締め集計 | 600件 |
| 合計 | 3,200件 |

## 確認する用件

| 部署 | 帳票を開く主な用件 |
|---|---|
| 営業部 | 顧客からの問い合わせに回答する際、発行内容を確認する。 |
| 業務課 | 再発行の依頼を受け、元の帳票と照合する。 |
| 経理部 | 月次締めや締め直しの際、当時の帳票を確認する。 |

部署によって確認する時期が異なります。同じ期限に決める前に、それぞれの用件で何日程度必要か聞いていただきたいです。特に経理の締め直しがあるからといって、営業にも同じ期間ずっと見せる必要があるかは分けて考えたいと思います。

## 原本の照会

日常の閲覧期限を過ぎてから問い合わせを受ける場合もあります。そのときに、対象の帳票と問い合わせの理由を伝え、発行当時の原本を照会できる経路を用意してください。部署の日常的な閲覧を終えることと、原本をいつまで保管するかは別に相談させてください。

7月の期間別・種類別の内訳は別途お渡しします。必要な期間と照会の手順について、打合せで確認をお願いします。
