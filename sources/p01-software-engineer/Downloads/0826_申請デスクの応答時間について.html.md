<section id="product"><h1>申請デスクの応答時間について</h1><p>申請デスクは、申請の受付とその後の一覧・詳細の照会を支援します。操作をお待ちいただく時間は、利用する方の数や作業の内容、通信環境などによって変わります。</p></section>
<section id="response"><h2>操作によって異なる待ち方</h2><p>受付一覧を繰り返し確認する場合は、一覧の取得が何度も発生します。一方、ファイルを添えて申請する場合は、入力された内容に加えて添付ファイルの送信や保管が関わります。同じ一回の操作でも扱う情報が異なるため、それぞれの待ち方を分けて確認することが大切です。</p><p>画面への入力や表示にかかる時間と、送信後に応答が戻るまでの時間、受付後に担当者が確認する時間も区別してお考えください。</p></section>
<section id="consultation"><h2>運用のご相談</h2><p>導入をご検討の際は、同じ時間帯に利用する人数、申請・一覧確認・詳細照会などの作業の内訳、添付ファイルの件数や量をお知らせください。想定される業務の流れを伺い、確認すべき条件をご相談します。</p></section>
