# 照会ポータル 購買部門試行報告

文書番号：FMI-2025-TR-001  
発行日：2025年12月11日  
宛先：あさひ業務システムズ株式会社 田中美由様・山本真由子様  
発行：藤崎医療資材株式会社 購買部門　加藤博典

## 試行の範囲

12月9日から11日まで、購買担当3人で照会ポータルの候補画面を試しました。対象は購買部門内の確認です。取引先への公開案内は行っていません。

## 業務ごとの結果

| 場面 | 試行中に止まったところ | 従来の手順で続けられる範囲 |
|---|---|---|
| 朝の未着照合 | 発注番号を入れても対象が見つからない場合があり、一覧から詳細を見た後に条件が消えると、未着の続きを探し直す必要がありました。 | 購買台帳で未着を照合し、対象を追えます。画面の検索結果が空であることだけを未発注の根拠にはできません。 |
| 納品先への回答前の残数確認 | 一覧では納品済みと表示されても、詳細には残数がある例があり、一覧だけで回答を確定できませんでした。 | 購買台帳と納品控えを照らし、残数を確かめてから回答できます。 |
| 紙での検収回付 | 分納の内訳を印刷すると後半が紙に出ず、回付先が全行を確認できませんでした。 | これまでの納品控えを回付し、紙での検収を続けられます。 |

## お願い

試行画面を日常の確認に使い始める判断と、当面の照会先について、12月12日の電話で確認させてください。特に紙での検収は、印刷の後半が欠けたままでは回付できません。購買内で引き続き気づいたことは私が取りまとめます。
