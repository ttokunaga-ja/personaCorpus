# 発注と納品の照会についての要望

文書番号：FMI-2025-TR-002  
発行日：2025年3月5日  
作成者：藤崎医療資材株式会社 購買部門　購買主任 加藤 博典  
宛先：あさひ業務システムズ株式会社　田中 美由様

## 現在の確認手順

朝は購買台帳を開き、まだ届いていない発注を追っています。納品予定や納品先を見て、確認が必要なものを順に拾います。同じ品を別々に発注していることがあるので、品名だけでなく発注を特定できる情報が必要です。

納品先から電話を受けたときは、まずどの発注と品目の話かを合わせます。その後、購買台帳の注文数量と納品控えの数量を照らし、残数量を確かめてから返事をしています。分けて届く場合は、どの発注に対する何回目の納品かを控えでたどります。

## 照会で確認したいこと

| 場面 | 確認したいこと |
|---|---|
| 朝の未着確認 | 対象の発注を探し、未着のものを順に確認したい |
| 納品先からの電話 | 発注と品目を特定し、注文数量と届いた数量、残数量を照らして答えたい |
| 分納 | 個々の発注と各納品便を結び付け、納品控えと照らしたい |

照会の結果だけで回答を済ませるのではなく、必要な控えと照合できることを希望します。紙の検収回付は、これまでどおり納品控えを使って続けます。画面で確認する情報と紙で残す手順を、打合せでご説明します。
