# 班内の添付確認　当面の手順
文書番号：OR-2025-002　版：v1.0
2025年6月27日　作成：中村 美喜子
宛先：受付当番の皆さん

## この手順を使うとき
申請デスクの担当候補や送信前の確認に「佐々木」が重なって見える場合は、表示が変わるまで以下の順に確認してください。姓だけでは配車班と集荷班の担当を見分けられません。

## 確認の順番
1. 作業控えで受付番号と予定の班を確認します。別受付の控えを開いている場合は、番号を読み直して、今回の受付の控えに戻ります。
2. 添付する資料を開き、本文の用件と作成した班が作業控えの予定に合うか確かめます。名前が似ている資料は、名前だけで決めないでください。
3. 送信前の確認で受付内容と添付をもう一度合わせます。班や用件が合わない場合は戻って正しい資料を選び直します。
4. どちらの資料か判断がつかないときは送信を進めず、受付番号、予定の班、迷った資料を中村に知らせてください。確認してから進めます。

## 引継ぎ
当番を交代するときは、確認待ちの受付番号と中村への連絡の有無を作業控えに残してください。担当者の表示変更の適用日はまだ決まっていません。
