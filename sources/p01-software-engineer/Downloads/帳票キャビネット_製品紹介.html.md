# あさひ業務システムズ株式会社

## 帳票キャビネット

発行した帳票を一覧から探し、必要な帳票の原本を確認するための製品です。帳票名や発行日、帳票の種類を手掛かりに対象を絞り、問い合わせに対応するときや発行内容を確認するときに利用できます。

### 帳票を探す

| 検索条件 | 探し方 |
|---|---|
| 帳票名 | 帳票の名前を手掛かりに対象を絞ります。 |
| 発行日 | 発行日を指定して対象の一覧を確認します。 |
| 種類 | 売上明細など、帳票の種類で絞ります。 |

一覧から対象を選び、発行時の原本を確認できます。必要な帳票が分かっている場合だけでなく、発行時期や種類を手掛かりに探す場合にも利用できます。

### 導入のご相談

帳票の量や確認する業務に応じたご相談を承ります。[相談窓口](mailto:contact@asahi-business-systems.example)へお問い合わせください。
