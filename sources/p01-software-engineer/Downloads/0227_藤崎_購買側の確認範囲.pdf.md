# 購買側の役割整理について確認した範囲

文書番号：FMI-2025-TR-003  
発行日：2025年2月27日  
作成：藤崎医療資材株式会社 購買部門　加藤 博典  
宛先：あさひ業務システムズ株式会社　田中 美由様

## 役割設計について

2月26日のご説明と、役割対応と代番日の扱い（ABS-2025-EV-017 v1.0）を確認しました。購買の旧7役割を、申請担当、購買承認者、購買閲覧者、検収担当、権限管理者の5役割に整理する設計に同意します。申請入力と差戻し後の訂正、発注照会と納品照会は、それぞれ同じ担当の続きの仕事としてまとめます。

承認の代番は、自分に回った申請の明細を見て承認または差戻しを行います。朝の未着を追うための発注・納品の一覧は購買閲覧者が扱い、承認者と閲覧者を同じ人に当日だけ付ける方法も採りません。欠員日は未着確認を別の閲覧担当へ引き継ぎます。

## 購買で続けること

1. 朝の未着確認は、購買閲覧者が引き続き担当します。代番への承認引継ぎとは分けて、未着を追う担当を決めます。
2. 取引先に残数を答える前に、購買台帳と納品控えを突き合わせます。一覧を見ただけで残数を回答しません。
3. 検収の紙の回付は続けます。検収担当の役割を設けることは、紙の回付をやめる決定ではありません。

## これから購買側で確認すること

上記は役割と仕事の分担についての確認です。対象者の割当てはまだ決めていません。私の方で購買側の割当て候補を照合し、その後に切替日と運用の確認を相談します。今回の確認をもって移行が完了したものではありません。
