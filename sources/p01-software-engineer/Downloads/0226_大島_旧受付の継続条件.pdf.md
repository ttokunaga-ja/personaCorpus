# 旧受付を続ける業務条件

文書番号：OR-2026-001
版：1.0
日付：2026年2月26日
宛先：あさひ業務システムズ株式会社 田中美由様・高橋和典様
作成：大島ルート配送株式会社 中村美喜子

## 2月26日正午の残件

旧受付番号を単位に、最終回答が控えにない依頼を数えました。同じ番号への電話の追記や添付差替えは一件にまとめ、次に必要な処理で区分しています。

| 次に必要な処理 | 件数 | 担当と仕事 |
|---|---:|---|
| 配車回答待ち | 11 | 配車が集荷枠などについて回答する。受付班は戻った結果を依頼者へ伝える。 |
| 依頼者の補足待ち | 7 | 受付班が必要な補足を依頼者に求め、受け取る。 |
| 結果連絡待ち | 5 | 受付班が処理結果を依頼者へ発送する。社内の処理が済んでも、連絡するまで追う。 |
| 合計 | 23 | |

## 継続して必要なこと

依頼者が旧番号を伝えて折り返した場合、受付班がその番号の元の控えを閲覧し、補足や連絡を記録できる状態を続けてください。新しい受付への入力をお願いする前に、元の依頼の経過が分かることが必要です。

## 終了に向けた確認

私が受付班の状況と控えを取りまとめます。旧受付の終了を考える前に、対象の各行について処理結果と依頼者への連絡控えを突き合わせられるようにしてください。結果連絡待ちも対象に含みます。終了の日はこの書面では決めていません。
