# Do not reset the clock

18 August — first day

If we start the clock again when AP sends a corrected file back, the time spent putting it right disappears from the comparison. The first eligible 06 is the start, even if 07 returns the file. The 09 approval record is the end; the return does not stop elapsed time.

At the next progress meeting, check with AP that the original 06 date and time stay in the record. Ask them to record the return reason and later recirculation separately, not over the first entry. If there is only a date, keep it as a candidate but do not invent a time for the average.
