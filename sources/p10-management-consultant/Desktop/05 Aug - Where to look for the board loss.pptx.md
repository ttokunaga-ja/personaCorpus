## Slide 2 — Process Figure

Title: Finance — what did we pay for the same weight of board?

Diagram: Net material cost (GBP) ÷ board purchased (kg) → unit price (GBP/kg) → compare periods for the same board grade.

Caption: At a fixed weight, the change in spend is the change in GBP/kg multiplied by that weight.

Speaker notes: Ask for net material cost and the purchased weight behind it, split by grade and period. A higher unit price raises the cost of the same quantity of board, including any board lost in production.

## Slide 3 — Process Figure

Title: Production — how much input came out good?

Diagram: Match input (kg) and good output (kg) to the same run → good kg ÷ input kg → yield (%) on like work across sites.

Caption: Use the same board grade and box specification. Follow the weight difference back to the run and loss records.

Speaker notes: Use production input as the denominator. If purchase price rises while the weight ratio holds, a larger scrap charge can arise without any additional physical loss. A difference in the weight ratio warrants a check of the runs and where the losses were recorded.
