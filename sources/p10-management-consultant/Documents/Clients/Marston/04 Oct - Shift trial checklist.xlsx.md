## Sheet: Shift log

Enter one row for each in-scope run on a shift. Keep the shift and run reference across handover. If a run has multiple changeovers or restarts in the same shift, record each approval time and approver with its event reference in the last field and roll each verified loss into the applicable weight column once.

|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | | | | | | |

Hold first output until three sheets have been checked and the shift lead approves release. If approval cannot be confirmed while the output is held, keep it on hold and call the lead. If a record is missing, leave the relevant weight or time blank and identify the issue and source in the last field. Record an event as absent only when the shift log supports it. A combined loss entry stays open until it can be reconciled.
