## Slide 2 — Two Columns

**Two possible starting points**

Left — Receipt mailbox: start when the invoice first arrives; end when the cost-centre review starts. This includes any missing evidence, matching and return loop before the item can be approved.

Right — Ready and routed: start when the complete invoice, match evidence and allocation have been sent to the cost-centre approver; end when review starts. This isolates the interval before review, provided both events can be established.

Speaker notes: A receipt time can be useful for elapsed time, but cannot alone establish an approval queue.
