# Two returns on the proposed route

| Document | Date | Prepared by |
|---|---|---|
| HRA-WHI-DIAG-EV-2024-005 v1.0 | 13 Nov 2024 | Neha Patel |

For Nicholas Hargreaves, Siobhan Barrett and Connor Atkinson

## Purpose and method

We walked the simultaneous 07 and 09 proposal through two incomplete files at the desk review. Nicholas, Siobhan and Connor joined me. These are route checks, not observations of live transactions or estimates of how often returns occur. In both cases the people intended to handle the proposed route were not all available on the day considered; the simultaneous proposal did not identify a dependable return point.

## Cases

| Case | Missing evidence | What the walk-through exposed | Current return and required correction |
|---|---|---|---|
| 07 cost allocation | The file had no confirmed cost-centre allocation. | The proposed simultaneous route did not make clear who would take the file back when the planned roles were not all present. It was not ready for cost-centre approval. | Return to AP. AP obtains the allocation and routes the invoice, match evidence and confirmed allocation to the cost-centre owner again. |
| 09 exception closure | The file reaching the Finance check lacked evidence that the exception had been resolved. | The proposed route did not establish an available return owner in the absence considered. Finance could not release the file to its approver. | Return to Japan Finance at 08 to track correction; AP supplies the missing resolution evidence. Re-match where required and route the complete file again. |

## Recommendation

Keep AP and Japan Finance as the respective current return points. Establish the 07 hand-off first. Only pass a file for 09 when the 07 approval and exception-closure record are both present. Keep the item outside the relevant approval queue while evidence is missing. Treasury's two checks at 12 remain unchanged.

Siobhan should use these conditions in the sequence; Nicholas should confirm the responsible client roles before setting a start. The desk review does not establish that a live route has been approved.
