# Ask for the point it was ready

Oliver — practice on a real invoice, not “which step is slow?” That question invites a verdict before we know where the clock starts.

Ask: when did it arrive? What was missing then? When were the invoice, match and allocation all available? When did you start working on it? Get each event separately, and ask what record might show it. If an item went back, walk through the return and the next hand-off rather than drawing one straight interval.

If someone says “I couldn't look at it until the next day”, ask separately when it reached the next approver and whether it was complete when sent. A mailbox arrival is not necessarily a ready hand-off. Write down their explanation as their account; don't turn the reason into a timestamp or an established cause. Repeat back the sequence and leave uncertain points open for the other role.
