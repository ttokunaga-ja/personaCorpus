# オルタ拠点ボード　11月の公開予定

掲載者：原田 雅也（プロダクト企画）  
掲載日：2025年9月29日  
対象部門：営業・利用支援・導入・開発・品質

オルタ拠点ボードは、11月7日に公開可否を判定し、確認が通れば11月14日の公開を予定しています。対象期間は暦年2025年Q4／FY2025 Q3です。

この予定は、閲覧権限と集計の品質確認を完了することが前提です。判定前のため、営業からの対外案内はまだ始めないでください。公開対象や日付について問い合わせがあった場合は、プロダクト企画の石田までお知らせください。
