# 巡回チェック　品質照会の記入手順
文書番号：OFS-202411-NT-002｜版：v1.0｜発行日：2024年11月6日｜作成：松田 由香｜配布先：西村さんの窓口チーム

## 選択前から順に記入
受付番号を選んだ後に進まない相談は、窓口の元記録に対応する匿名照合番号で品質へお知らせください。受付番号の実値は窓口の元記録で管理します。聞けなかった値は空欄や推測にせず「未取得」と書き、次に補記する担当を添えてください。

| 記入欄 | 記入する内容 |
|---|---|
| 選択前 | 開始時の画面、表示されていた行と番号、利用者の役割範囲 |
| 操作と時刻 | 番号を選んだ時刻、選択から後の操作順 |
| 期待と実際 | 開くはずだった画面と、実際に表示された画面・メッセージ |
| 利用環境 | ブラウザとその版。聞けなければ未取得 |
| 更新・再試行 | 実施の有無と、いつ行ったか。実施前の状態も残す |
| 未取得と補記担当 | 不足項目、次に窓口で聞く担当と戻し先 |

## 記入例：問合-09
| 欄 | 記入例 |
|---|---|
| 選択前・操作 | 受付一覧に表示された番号を1回選択 |
| 期待 | 受付詳細が開く |
| 申告時の実際 | 一覧のまま、メッセージなし |
| 確認結果 | 10月24日、申告と同じ情報が揃った範囲では詳細が開き、申告の応答は再現しなかった |
| 未取得の書き方 | 例えばブラウザ版が聞けなかった場合は「未取得」と書き、次回補記担当は西村と記す |

この例の再現なしは、修正済みや原因確定を意味しません。次に発生した場合は、更新前の状態を先に控え、更新・再試行を行った順とともに品質へお知らせください。
