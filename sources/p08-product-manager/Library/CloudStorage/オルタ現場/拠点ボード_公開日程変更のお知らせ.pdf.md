# オルタ拠点ボード 公開日程変更のお知らせ
OFS-202510-NT-001 v1.0｜発行：2025年10月22日 10:25｜プロダクト企画 石田 由美子
宛先：営業・利用支援・導入 各位

## 日程の変更
11月14日に予定していた公開（暦年2025年Q4／FY2025 Q3）を取り下げます。公開は暦年2026年Q1／FY2025 Q4へ延期します。新しい公開日は未定です。旧日付を使った案内を止めてください。

## 社内の再判定に必要な確認
2026年1月16日は公開可否の再判定日です。提供日ではありません。1月14日までに次の証跡を揃え、欠けていれば公開保留を続けます。

| 条件 | 持ち寄る記録 |
|---|---|
| 対象外拠点の行と件数が見えない | 太田の役割表・設定と松田の対象外ケースの記録 |
| 解除後に一覧と件数の両方から外れる | 解除担当を含む役割表と松田の解除後ケースの記録 |
| 同一締め・同一範囲で元表と一致する | 三浦の元表と集計の突合、説明できない差がないことの記録 |

## 部門ごとの対応
| 部門・担当 | 停止・変更すること | 2026年1月15日までの準備確認 |
|---|---|---|
| 営業・藤原 | 11月14日の案内を止め、既に日付を伝えた先へ個別に訂正する | 案内先と営業資料の扱いを確認 |
| 利用支援・西村 | 旧日付での回答を止め、日程の問い合わせを石田に集約する | 窓口の回答と連絡先を確認 |
| 導入・中川 | 公開に合わせた仮導入枠を解除し、日付を前提にした予約を止める | 導入枠の扱いを確認 |

再判定を経て公開日が決まった後、石田が改めて案内を起案します。問い合わせ先：プロダクト企画 石田。
