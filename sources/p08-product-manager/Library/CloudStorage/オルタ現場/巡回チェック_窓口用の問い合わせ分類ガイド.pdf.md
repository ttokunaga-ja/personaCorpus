# 巡回チェック　窓口で先に聞くこと

OFS-202508-EX-001　v1.0  
発行日：2025年8月25日　作成：西村 裕二  
宛先：利用支援窓口  
対象資料：利用者向け配布資料「巡回チェック 前の申請を使って下書きする」OFS-202508-NT-001 v1.0

差し替え後の案内について質問を受けたら、最新版を渡すだけで終えず、どの段階で止まったかを聞いて対応メモに残してください。入口を探している相談と、元の申請を開けない相談は分けて記録します。

| 場面 | 最初に確認すること | 次の対応・引き継ぎ先 |
|---|---|---|
| 送信済み申請の詳細を開く前 | 前と似た依頼を作ろうとして、今どこを開いているか。同じ拠点の送信済み申請を探しているか。 | 利用者向け資料の「送信済み申請の詳細から」を案内する。詳細までたどり着けない場合は、開いていた場所と止まった段階を添えて利用支援で引き継ぐ。 |
| 元の申請を開けない | 開こうとした申請が同じ拠点の送信済み申請か、どこで開けなくなったか。閲覧できるかどうかを窓口で推測しない。 | 閲覧権限を判断できないときは顧客側の管理者へ相談してもらう。その元票から再利用を進められないことを伝え、別拠点の申請で代えるよう案内しない。 |
| 下書きから送信できない | 新しい下書きまで進んだか。設備区分・依頼種別・点検箇所を確認し、空欄の希望日を今回分として入力したか。 | 入力と確認の手順を利用者向け資料で案内する。それでも進めない場合は、止まった段階と表示された内容を添えて利用支援で引き継ぐ。 |

下書きは未送信です。内容を確認して送信しても、元の申請は変わりません。対応メモには案内した資料の版と、利用者がどこまで進み、どこで止まったかを記してください。
