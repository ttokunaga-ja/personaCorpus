# 週明け：試行できたら何が決まるか

1月24日、福田さんが認めたのは暦年2025年Q1／FY2024 Q4の試行枠だけ。上限48万円、開発・品質3.0人週。2社の参加同意とデータ許可が揃って初めて始められる。

機能を作っただけでは投資判断にならない。2社それぞれで元表と合うか、合うまでにどれだけかかるかを記録する。中川さんには初回設定と、その後の連絡・抽出支援・照合立会いを分けてもらう。範囲外のデータが出たら止め、終了後の削除まで確認する。

実測した2社を、そのまま有償2社へ繰り上げない。藤原さんの受入価格と稟議の根拠、稼働時期を別に待ち、中野さんに支援費も含めて回収を入れ直してもらう。福田さんに次の投資を相談する候補は3月14日。全体開発も公開日もまだ決まっていない。
