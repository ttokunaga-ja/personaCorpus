# スライド2：指定前から解除後まで
レイアウト：比較
題：同じ申請を三つの時点で追う
| 時点 | 店番12の自店担当 | 店外の候補 |
|---|---|---|
| 指定前 | 自店の申請を表示 | 対象の詳細は表示されない |
| 指定中 | 自店の申請を表示 | 指定された申請1件だけ表示 |
| 解除後 | 通常の自店表示を継続 | 指定された申請は表示されない |
本文：店外の別申請まで一覧に広がらないことも確認する。完了時または指定期限で解除する。
発表者ノート：原田が代理者役で操作し、松田が各時点で見えた範囲を横から記録する。岡本は表示と文言を確認する。指定前と解除後は同じ対象を開けないことまで見る。

# スライド3：通知から入る
レイアウト：本文
題：最初の見出しで代理と分かるか
本文：指定中に個別通知を開き、最初の見出しと対象1件を確認する。自店の一覧を開いたと誤解しないか、対象外を扱えるように見えないかを記録する。
発表者ノート：原田が通知を開き、岡本が第一印象と文言を控える。松田は対象1件以外が表示されないことを別に記録する。

# スライド4：非担当者と持ち帰り
レイアウト：本文
題：表示しない側も確認する
本文：指定のない役割で一覧と詳細を開く。対象の店名や申請名を出さず、承認操作にも進めないことを確認する。見え方と操作可否を分けて記録し、曖昧な箇所は修正先を決める。
発表者ノート：松田が非担当者役を操作し、原田が結果を記録する。試作での確認であり、18店舗の確認結果とはしない。
