# 代理承認の手引き ― 承認担当の方へ
文書番号：OFS-202506-EX-001　版：v1.0
発行日：2025年6月12日　作成者：石田 由美子
配布先：ひかり店舗管理18店舗の正承認担当と事前登録済み代理候補（承認担当者の連絡網）

## 代理者を決める前に
正承認者の不在が事前に分かり、代理が必要な場合、店舗の窓口は竹内さんへ次の4点を申し出てください。

1. 正承認者の不在予定
2. 代理が必要な申請1件
3. 店内に別の有資格者がいるか
4. 希望する期限

竹内さんが資格と重複指定を確認し、店内の有資格者を優先して指名します。店内で足りない場合は、事前登録済みの店外候補から1人を指名します。店舗から候補を伝えることと、竹内さんが指名することは別です。候補を指名できない場合は正承認者へ戻します。

## 指定されたら
通知を受けた方は、指定された申請1件と期限を確認してから承認してください。別の申請を続けて処理する指定ではありません。対象が違う、または指名に疑問がある場合は処理せず竹内さんに連絡してください。

承認が完了すると指定はその時点で解除されます。未処理の場合も指定期限で解除し、正承認者へ戻します。別の候補へ自動で回りません。6月12日の試行では17:00が指定期限です。次に代理が必要なときは、前回の指定を使い回さず、竹内さんに新たな対象と期限を確認してもらってください。

## 他店の申請を見られるか
| 役割 | 見られる範囲 | 承認できる範囲 |
|---|---|---|
| 正承認担当 | 通常の自店の申請 | 自店の担当範囲 |
| 指定された店外代理 | 指定期間中の対象1件 | 指定された対象1件 |
| 指定のない非担当者 | 対象の詳細は見られない | 対象を承認できない |
| 解除後の店外代理 | 代理対象は見られない | 代理対象を承認できない |

例えば店番12の1件を店外代理として指定された方は、その1件を扱えます。店番12の別の申請や別店舗の一覧まで見られるわけではありません。自店の承認担当者は、代理指定の解除後も通常どおり自店の範囲を閲覧できます。

## 問い合わせ
指名、対象、期限、担当交代や資格変更については、ひかり店舗管理の竹内さんへお問い合わせください。配布は承認担当者の連絡網を通じて行います。
