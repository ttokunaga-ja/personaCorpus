# 閲覧を許す条件と止める条件
OFS-202503-RP-002　v1.0　2025年3月21日　作成：太田 久美
宛先：松田 由香、原田 雅也

## 対象と目的
3月5日に合意した代理の条件を、表示される申請の範囲として確認する。店番12の検証用申請を使い、自店担当、指定代理、指定のない非担当者を分けて操作する。役割名が正しいだけでは合格にしない。

## 確認項目
| 項目 | 操作と期待する結果 | 記録する事実 |
|---|---|---|
| 自店の表示 | 店番12の自店担当で一覧と対象の詳細を開ける | 操作者の範囲、見えた申請と詳細 |
| 指定代理の対象 | 店外の指定代理で指定された1件の一覧・詳細を開ける | 指定対象と実際に見えた申請 |
| 指定代理の対象外 | 同じ代理で指定外の申請を開けない | 対象外の申請と一覧・詳細の結果 |
| 非担当者の一覧 | 指定のない人には対象の店名・申請名を一覧に出さない | 操作者の範囲と一覧の表示 |
| 非担当者の詳細 | 同じ人が対象の詳細を開けない | 開こうとした対象と結果 |
| 完了後 | 承認完了で指定が解除され、店外代理はその対象を見られない | 完了時刻、解除後の一覧・詳細 |
| 17時到達後 | 未処理でも期限到達で指定が解除され、店外代理は対象を見られない | 期限と到達後の一覧・詳細 |

## 判定と記録
各項目に操作した人の役割と店舗の範囲、対象申請、操作時点、一覧と詳細の観察結果を残す。期待と観察が一致して初めて適合とする。見えないことは一覧と詳細をそれぞれ確かめ、どちらかが未実施ならその項目は未確認とする。未確認を閲覧0件に算入しない。

## 依頼と扱い
松田さんは各項目の確認と判定を、原田さんは操作者・対象・観察の記録をお願いします。想定外に見えた場合はその範囲を記録して確認を止め、太田に返してください。自店承認担当の通常の自店閲覧は、店外代理の解除後も継続することを区別して確認します。
