# 商談で聞いた受付機能の条件
OFS-202406-RP-001　v1.0　2024年6月14日　作成：藤原修一
宛先：石田由美子、原田雅也

## 整理の範囲
巡回チェックの商談で聞いた受付・起票周辺の候補8件を、先方の業務場面と、営業が次に確かめることに分けました。商談での発言は導入予定や有償化の確約ではありません。同じ趣旨の相談が他の窓口にもあれば、起点を残して照合してください。

## 候補と確認事項
| 候補 | 必要とされた場面 | 営業側の確認事項 |
|---|---|---|
| 一括承認 | 複数の依頼票をまとめて確認し、同時に処理する現場 | 票ごとに結果が異なる場合、どこから再開したいか |
| 別拠点からの再利用 | 応援先と自拠点をまたいで似た依頼を起こす現場 | 元票の閲覧者と起票できる人の範囲 |
| 送信の二重登録防止 | 通信待ちの間に送信できたか分からず再操作する現場 | どの操作で待ちが生じ、何を見て再送しているか |
| 受付一覧の出力 | 受付後の状況を会議前に持ち出して確認する場面 | 必要な列と出力後の受渡先 |
| 期限の通知 | 担当する依頼の対応期限を確認する場面 | 通知先と不要な場合の扱い |
| 設備区分の入力確認 | 依頼時の入力漏れを送信前に見つけたい場面 | 必須にすべき場面と例外 |
| コピー元の確認 | 似た依頼を作った後に元の番号を確かめる場面 | 番号を見せてよい相手と確認のタイミング |
| 入力途中の保存 | 問い合わせ対応で起票を中断する場面 | 再開時に必要な情報と保存期間 |

## 次の扱い
石田さんには顧客観察・利用支援の候補との重なりを確認いただきたいです。原田さんには商談控えの発言と候補を結び、同じ依頼を窓口ごとに別件として数えないようお願いします。工数や提供時期は未確認です。
