# Slide 2 — Four moments in the field
レイアウト：図
図：左から右に4つの場面を並べ、各場面の中で矢印をつなぐ。
- DDP-02: “Find a submitted request you can view at the same site” → “Use its details to start a new draft”
- DDP-05: “Review copied equipment category, request type and inspection location” → “Enter a new requested date — it starts blank”
- DDP-08: “Cannot open the original?” → “Ask the site administrator to confirm access to that request” → “Wait for the answer”
- DDP-11: “Review the new draft” → “Submit” → “New request sent; original unchanged”
発表者ノート：The four moments may involve different people. An administrator's answer must identify the person and request; asking is not the same as receiving an answer. The sales desk does not change permissions.

# Slide 3 — Conditions for the four answers
レイアウト：表
| Request | What the partner can explain | Condition |
|---|---|---|
| 02 | Start a new draft from a submitted request | Same site; the user can view the original. |
| 05 | Review the three copied fields and enter the requested date | The requested date starts blank; check the values for the new work. |
| 08 | Refer an inaccessible original to the site administrator | Ask about this person and this request; await the administrator's answer. |
| 11 | Review and submit the new draft | It is unsent until submitted; the original stays unchanged. |
発表者ノート：Do not substitute a request from another site or offer to grant access. These conditions are part of the answer, not optional follow-up.
