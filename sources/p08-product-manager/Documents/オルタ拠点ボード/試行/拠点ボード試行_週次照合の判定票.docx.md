# 数字が合わない週の扱い
OFS-202501-RP-003 v0.1　2025年1月21日　作成：松田由香　宛先：三浦博典・中川裕太

## 判定の単位
参加先ごとに4回の照合を記録する。各社について、元表と一致し、かつ照合開始から一致確認まで15分以内の回が4回中3回以上であること。別に、承認範囲外のデータ取込・閲覧が0件であることを確認する。両方を満たしたか分けて記録する。

## 各回の記録欄
| 項目 | 記入する内容 |
|---|---|
| 参加先・回 | 01または02、1〜4回目 |
| 対象週・抽出時点 | 元表と集計それぞれの締め・対象拠点 |
| 照合 | 開始時刻、一致確認時刻、所要分、一致・不一致・判定不能 |
| 差異 | 件数と理由、確認相手、再照合の結果 |
| 範囲 | 承認の対象と取込・閲覧したデータ、範囲外の有無 |

## 一致しない・判定できないとき
締め、対象拠点、取消の順に確認し、理由と残る差を記録する。抽出未着や締めの違いで比較できない回は判定不能とし、成功に数えない。15分以内でも不一致なら成功ではない。一致しても15分超なら時間条件を満たさない。

## 範囲外のデータが出たとき
作業を直ちに止め、該当データを隔離する。取込・閲覧の状況を残し、再開前に石田と確認する。範囲外が1件でもあれば0件の条件は満たさない。照合の成功回数とは別に報告する。
