# 受付一覧

受付一覧では、これまでに受け付けた申請を一覧で確認できます。

- [表示期間について](#period)
- [詳細を確認する](#detail)

## 表示期間について {#period}

受付一覧には、指定した期間の受付が表示されます。探したい受付が表示されないときは、受付日の範囲を指定して一覧を確認してください。

記入例：2024年9月1日から2024年9月30日までの受付を確認する場合、開始日に「2024/09/01」、終了日に「2024/09/30」を入力します。

## 詳細を確認する {#detail}

一覧から確認したい受付の受付番号を選ぶと、受付の詳細を表示します。詳細画面で受付内容を確認できます。
