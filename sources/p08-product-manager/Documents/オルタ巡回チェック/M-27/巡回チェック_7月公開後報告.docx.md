# オルタ巡回チェック 7月公開後報告
OFS-202607-RP-002　v1.0　2026年7月24日
作成：石田 由美子　宛先：福田 正志、太田 久美

## 1. 公開後の状況と未達

申請再利用の拠点採用率 M-27 は、2026年7月1日00:00〜7月22日23:59に、対象250拠点のうち46拠点が送信を完了し、18.4%でした。目標22.0%に必要な55拠点に対し9拠点不足、率では3.6ポイントの差です。暦年2026年Q3（7〜9月）／FY2026 Q2（7〜9月）の途中値であり、四半期末の確定値ではありません。

| 項目 | 7月22日締め |
|---|---:|
| 対象拠点 | 250拠点 |
| 採用拠点 | 46拠点 |
| 採用率 | 18.4% |
| 目標 | 22.0%（55拠点） |
| 目標との差 | −3.6ポイント（不足9拠点） |

## 2. 指標の対象と確認結果

分母は6月30日時点で本番利用が有効な拠点に固定しています。停止済み、検証用、7月以降の新規開設拠点は含めません。窓内に再利用由来の申請を1件以上送信完了した拠点を採用とし、取消済みと保存のみの下書きは除きます。ログインや一般の依頼送信を数えた率ではありません。三浦さんに対象と抽出条件を確認し、7月23日の点検で太田さんと数値を照合しました。

## 3. 判断と残る仮説

現時点で公開を停止する判断材料はなく、公開を継続します。採用率が目標を下回ったことと、公開停止の要否は分けて扱います。

未達の原因は確定していません。再利用の入口が見つけにくい可能性はありますが、利用ログだけで導線を原因とは判断できません。教育が対象者に届いているか、教育後にも操作の途中で迷うかを顧客に確認し、教育と導線を切り分けます。若松の確認結果を全顧客の原因に一般化しません。画面改修への着手は顧客確認後に判断します。
