# オルタ巡回チェック 管理者説明会のご案内

文書番号：OFS-202608-NT-001　版：v1.0
発行日：2026年8月21日　作成：中川 裕太
宛先：若松設備管理株式会社 東浜・大橋・西戸崎の各拠点管理者の皆さま（小野 美代様経由）
発信：オルタ現場システムズ株式会社 中川 裕太

## 開催の目的と日時

日頃よりお世話になっております。オルタ巡回チェックの依頼受付について、管理者の皆さまに最初の依頼の送信から、送信済みの依頼を使った再利用までをご案内します。8月20日に小野様に日程をご了承いただきましたので、下記のとおりご案内します。

- 日時：2026年9月3日（木）10:00〜11:00
- 方法：オンライン
- 対象：東浜・大橋・西戸崎の各拠点の管理者
- 進行：中川 裕太

## 当日の流れ

| 時間 | 内容 |
|---|---|
| 10:00〜10:05 | 導入：依頼受付でできることと本日の進め方 |
| 10:05〜10:15 | アカウントと対象拠点、依頼送信に必要な権限の確認 |
| 10:15〜10:40 | 初回依頼の送信練習と、送信済み依頼を選んで再利用する操作 |
| 10:40〜10:55 | 質問：操作中に迷った点や確認したいこと |
| 10:55〜11:00 | 本日の確認と今後の問い合わせ先 |

練習では氏名を含まない巡回依頼を使います。初回の送信を順に試してから、再利用する依頼の選択と送信を確認します。質問の時間は演習と分けて設けます。

## 事前にお願いしたいこと

当日使うアカウントでオルタ巡回チェックに入れるか、対象の拠点を確認できるかを事前にお確かめください。入れない場合や対象拠点が表示されない場合は、無理に操作を進めず、小野様を通じて中川までお知らせください。接続方法は別途ご案内します。認証情報をこの案内に記載したり、返信に書いたりする必要はありません。

当日はお手元で操作できる状態でご参加ください。よろしくお願いいたします。
