# スライド2｜図
題：同一拠点で、前の申請を見てから新しく起こす
図：左から「閲覧できる送信済み申請の詳細」→「この申請を再利用」→「新しい下書き」→「内容を確認」→「送信」。下書きには設備区分・依頼種別・点検箇所を引き継ぎ、編集できる。希望日は空欄から今回分を入力。元の申請は変わらない。
本文：対象は同じ拠点の閲覧可能な申請。コピー元番号は、元を閲覧できる場合に確認できる。
発表者メモ：自動で前回を確定する話ではない。若松の観察では点検箇所が変わる場合もあった。

# スライド3｜2段
題：送信前に確認し、重複を防ぐ
左：設備区分が空欄なら送信前に入力を求める。希望日は今回の依頼に合わせて入力する。
右：同じ下書きの送信応答を待つ間に再送しても、受付を二重に登録しない。修正後の別下書きは新規として扱う。
発表者メモ：対象は公開前の確認を進めている。個別の提供日を約束せず、すでに使えるとは伝えない。
