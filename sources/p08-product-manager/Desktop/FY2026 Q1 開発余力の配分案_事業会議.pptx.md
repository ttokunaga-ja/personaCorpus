# スライド2　配分前の余力

レイアウト　図（4）

題　開発・品質72人週のうち、いま配分できるのは30

図「4〜6月の開発・品質の配員見込み」。横帯全体を72人週とし、幅を数値に比例させて左から「確約済み改修 24」「運用当番・障害対応 12」「共通回帰試験 6」「配分前余力 30」に区切る。軸は左端から累計0、24、36、42、72（単位は人週）。帯下に区分名「既定作業 42」（0〜42）と「配分前余力 30」（42〜72）。帯上に「開発・品質対象 72」。

注記　太田「四半期の開発余力試算」OFS-202603-KM-001 v0.3（3月12日基準）

発表者メモ　太田さんの「配員積算」の7〜13行で、4〜6月の配員期間と巡回チェックへの割当を確認できます。開発54と品質18を足した72は既定作業を含む見込み。24、12、6はそこから一度ずつ差し引きます。30%は差し引き後の30人週に掛けます。40%を取ると新規枠は18で、3件に要る21に3足りません。

# スライド4　先に扱うつまずき

- 詳細への入口6、元票の閲覧4、希望日3

右欄「B案で確保する9人週」

- 入口4　送信済み詳細を探す案内
- 閲覧3　窓口の記録と切り分け
- 希望日2　下書きの空欄を案内

発表者メモ　三浦さんの2月9日〜3月8日の観測は本番の送信完了者168人・26拠点、うち再利用由来54人・15拠点。54人は3件の到達見込みには使いません。西村さんの相談事例は利用人数とは別に読みます。同一拠点の閲覧可能な送信済み詳細から起票する現行の前提で、止まり方ごとに対応を切れるためB案を推します。
