# スライド1：表紙
題：自分で決めてよいか
副題：代理承認の演習／OFS-202506-BR-001 v1.0／2025年6月11日／原田 雅也／暦年2025年Q2・FY2025 Q1
ノート：竹内さんと進行。答えを出す前に、誰に戻すかを話してもらう。

# スライド2：進め方（見出しと本文）
- 事前に分かる不在について、対象は申請1件。
- 各場面で、誰が候補を決め、迷ったら誰に戻すかを話す。
- 承認できることと、閲覧できることを別々に確認する。
ノート：参加者に通常の自店の範囲と、代理指定された1件の範囲を言い分けてもらう。

# スライド3：問1 店内に有資格者がいる（2段）
左：正承認者の不在が事前に分かり、店内に別の有資格者がいる。店舗でその人を代理に決めてよいか。誰に申し出るか。
右：解答は次のページ。
ノート：承認できる対象と閲覧できる範囲をそれぞれ答えてもらう。候補を挙げることと指名を分けて話す。

# スライド4：問1の解答（見出しと本文）
店舗は不在、対象1件、店内候補、希望期限を竹内さんに申し出る。竹内さんが資格と重複指定を確認し、店内候補を優先して指名する。指名できなければ正承認者へ戻す。代理で扱えるのは指定された1件。
ノート：代理の承認範囲と閲覧範囲を参加者に別々に説明してもらう。

# スライド5：問2 店内候補がいない（2段）
左：店内に有資格者がいない。店外の知っている人に店舗から直接頼めるか。誰へ返すか。
右：解答は次のページ。
ノート：代理で承認できる範囲と、他店の申請を閲覧できる範囲を言い分けてもらう。

# スライド6：問2の解答（見出しと本文）
店舗は竹内さんに候補がいないことを伝える。竹内さんが事前登録済みの店外候補の資格と重複を確認し、1人を指名する。指名できないときは正承認者へ戻す。店外代理が見て承認できるのは指定の1件だけ。
ノート：承認の対象と閲覧の対象を別々に確認。他の店舗の一覧が開くわけではない。

# スライド7：問3 通知を受けても対象外（2段）
左：代理の通知を受けたが、別の申請の相談も来た。その申請を開いて承認してよいか。誰に返すか。
右：解答は次のページ。
ノート：承認できる範囲と閲覧できる範囲をそれぞれ参加者に言ってもらう。

# スライド8：問3の解答（見出しと本文）
通知を受けても対象外の申請は閲覧・承認できない。相談は竹内さんに返し、対象と指名を確認してもらう。指定済みの1件以外へ権限は広がらない。
ノート：対象1件についての承認と閲覧を区別して復唱してもらう。

# スライド9：問4 期限を過ぎても未処理（2段）
左：指定期限を過ぎたが申請は未処理。次の候補へそのまま渡せるか。どこに戻すか。
右：解答は次のページ。
ノート：期限後に承認できる範囲と閲覧できる範囲をそれぞれ確認する。

# スライド10：問4の解答（見出しと本文）
期限で指定は解除し、未処理の申請は正承認者へ戻す。次の候補へ自動では回さない。店外代理は解除後に対象を見られない。再び必要なら竹内さんに対象と期限を確認してもらう。
ノート：期限後の承認と閲覧を別々に尋ねる。自店担当の通常の自店閲覧は続くことも区別する。
