# スライド1（表紙）

題：同じ件数でもコードがずれたら
副題：OFS-202605-BR-003 v0.1｜2026年5月11日｜三浦博典｜暦年2026年Q2／FY2026 Q1

発表者ノート：石田さん、松田さんへ。次回の持越し確認で件数だけを合わせないための作業説明。

# スライド2（図）

題：候補と承認をコードで結ぶ

左「候補台帳：次回基準の拠点コード」→中央「同じ拠点か、旧コード対応の根拠を確認」→右「同時点の承認原簿：報告用閲覧範囲・承認番号・有効期間」。対応する行を結び、一覧と集計件数も同じ条件で照合する。

発表者ノート：候補があるだけでは承認済みにならない。松田さんに原簿の根拠を確認してもらい、私が候補との対応を確かめる。

# スライド3（表）

題：件数が合っても対応は誤り得る

次回照合の練習：候補側にOB-029ともう1拠点の計2行があり、承認側にも2行があるとする。OB-029に対応未確認の旧コードを誤って結び、もう1行を正しく結ぶと、結んだ数は2対2でも1件の対応根拠がない。

| 確認 | 件数だけ | コードと根拠 |
|---|---|---|
| 上の例 | 2対2で一致 | OB-029は対応未確認 |
| 扱い | 判定できない | OB-029を確認待ちに戻す |

発表者ノート：これは次回照合の練習であり、旧コードの実際の対応を確定したものではない。

# スライド4（本文）

題：確認待ちに戻す条件

候補側に存在しない、旧新コードの対応が証跡で結べない、報告用閲覧範囲が不明、承認番号や基準時点の適用期間が欠ける、または同条件の一覧と件数が一致しない場合は、確認済みにしない。根拠を揃えて再照合する。

発表者ノート：候補条件と承認の両方を同じ時点で確認する。5月の44は修正しない。
