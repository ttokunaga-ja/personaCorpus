# 3枚目：役割と流れ

レイアウト：役割図

藤原：参加同意・許可の窓口、受入価格と稟議の根拠を確認

→ 太田：検証環境と読取集計、終了後の削除
→ 三浦：各社の元表と4回照合し時刻・差異を記録

発表者メモ：役割は前後して相談するが、許可の確認前に受領しない。削除は太田、確認は松田。

# 4枚目：判定表

レイアウト：表

| 観点 | 見る単位と目安 | 判断できない・逸脱した場合 |
|---|---|---|
| 照合 | 各社4回中3回以上、開始から15分以内に元表と一致 | 未着・締めの違いなど判定不能は成功に数えない。差と理由を記録 |
| データ範囲 | 承認範囲外の取込・閲覧0件 | 作業を止め隔離し、石田と確認してから再開を判断 |
| 定常支援 | 各社4週間の実測が月2時間以内の見立てか | 初回設定を分け、未記録は0分にせず確認する |
| 有償条件 | 価格、稟議窓口・時期、契約見込みの根拠 | 未確認のまま有償社数に入れない |

発表者メモ：支援2時間は回収仮定の確認であり、照合の成否と混ぜない。

# 5枚目：撤収と再判断

レイアウト：流れ図

4週間の照合・支援記録 → 太田がデータ削除、松田が確認 → 石田が結果と未確認を整理 → 藤原が有償条件を確認 → 中野が稼働時期・支援費を含め回収を再試算 → 福田が次の投資を判断

3月14日は再確認の候補日。試行参加は有償契約ではなく、全体開発や提供日も決定していない。

発表者メモ：1月31日に窓口と許可の確認状況を持ち寄る。開始できないときは日程を約束せず、未確認事項を残す。
