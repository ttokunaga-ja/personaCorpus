# 申請再利用　いったん全部入れる案

OFS-202404-RP-001　v0.1　2024年4月18日　作成：石田由美子
宛先：岡本麻紀、太田久美

## 対象と背景

若松設備管理で4月11日に見た受付では、前回控えを照合した後、受付台帳の設備区分・依頼種別・点検箇所を依頼票へ入れ直していた。小野さんの4月1〜5日の記録ではこの転記が14回。3欄が前回と一致したものが10件、点検箇所が異なるものが4件だった。希望日は今回の依頼を確認している。

受付口を増やしても起票時の転記は残る。過去の控えを選び、新しい依頼の下書きを起こせれば、繰り返し入力する負担を減らせるのではないか。

## 再利用案

受付担当者が過去の控えを選び、その内容から新しい依頼を起こす。まずは設備区分、依頼種別、点検箇所、希望日の4欄をコピー候補として並べる。今回と異なる内容を直せる下書きとする。点検箇所が違った4件を考えると、コピーした値をそのまま正解とみなせない。

| 欄 | コピー候補 | 検討する点 |
|---|---|---|
| 設備区分 | 過去控えから | 今回の依頼と照合できるか |
| 依頼種別 | 過去控えから | 今回変更する場合の扱い |
| 点検箇所 | 過去控えから | 違う場所を直せるか |
| 希望日 | 過去控えから | 埋まった日付の訂正を忘れないか |

## 未決事項

希望日を埋めた場合に古い日付を見落とすおそれがある。空欄にする方法も含めて岡本さんと確認したい。どの範囲の控えを閲覧・選択できるかも未決。別の担当や拠点の控えをどこまで見せるか、太田さんに条件を確認したい。

## 次の確認

岡本さんには過去控えを選んでから内容を直す流れを、太田さんには閲覧できる範囲と新しい依頼の扱いを相談する。担当者が最後に確認する操作はまだ詰めていない。この文書は候補を並べた下書きであり、公開範囲の決定ではない。
