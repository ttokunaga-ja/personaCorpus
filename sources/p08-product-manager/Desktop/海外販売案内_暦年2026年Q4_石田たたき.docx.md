# 10〜12月の海外販売案内　判断案

OFS-202609-RP-004　v0.1　2026年9月9日  
作成：石田 由美子　宛先：福田 正志

## 対象と前提

対象は暦年2026年Q4／FY2026 Q3（2026年10月〜12月）。Nathanさんの16要望について、販売窓口に渡す説明範囲の判断をお願いします。16は要望数であり、商談や拠点の数ではありません。

ボードは条件が揃えば順次展開を説明可。（未確定：対象拠点、有効な承認、再試験結果と案内の可否を確認する。）

## 採否の根拠

午前の照合では、巡回チェックの現行手順で説明できる4件を候補とし、残る12件は確認を要するため保留とします。追加機能や提供日を承認する提案ではありません。

| 番号 | 扱い | 場面と理由、確認事項 |
|---|---|---|
| 01 | 保留 | ボード全拠点展開。対象と承認、対象外・解除後・元表一致の証跡が必要 |
| 02 | 候補 | 受付の入口。同一拠点の閲覧可能な送信済み元票から下書きを始める現行手順 |
| 03 | 保留 | 別拠点の元票。閲覧境界と対象外データを確認 |
| 04 | 保留 | 一括承認。途中失敗時の状態を確認 |
| 05 | 候補 | 転記後の点検。3欄を直せ、希望日は空欄から入力できる |
| 06 | 保留 | 前回希望日の引継ぎ。古い日付を見落とさない条件を確認 |
| 07 | 保留 | 期限メール。通知先と解除後の扱いを確認 |
| 08 | 候補 | 閲覧不可時の取次ぎ。管理者に本人の閲覧可否を確認する |
| 09 | 保留 | 拠点横断集計。閲覧者の役割範囲と解除の証跡を確認 |
| 10 | 保留 | 定時CSV。出力先、監査記録、期限切れ権限を確認 |
| 11 | 候補 | 下書きと送信の区別。本人が確認・送信するまで未送信、元票は変わらない |
| 12 | 保留 | SSO。認証と失効の条件を確認 |
| 13 | 保留 | 英語UI。必要な画面と用語の範囲を確認 |
| 14 | 保留 | 初期設定の代行。作業と責任の範囲を確認 |
| 15 | 保留 | 日常運用の代行。標準の問合せ受付との責任分界を確認 |
| 16 | 保留 | 過去依頼の保持延長。期間、対象、削除要件を確認 |

## 販売説明の範囲

02は同一拠点かつ本人が閲覧できる送信済み元票から開始する。05は設備区分・依頼種別・点検箇所を確認・編集し、新しい希望日を入力する。08は管理者へ本人の閲覧可否を確認する。11は本人の確認と送信まで下書きのままで、元票は変えない。いずれも新しい入口、権限変更、自動送信を意味しない。

## 保留と再確認条件

01は海外の対象範囲を特定し、対象外の行と件数の非表示、解除後の一覧と件数からの除外、同じ締め・範囲での元表一致を揃える。5月の社内報告44はこの証跡に使えない。03・04・07・12は権限や挙動の確認が必要で、14・15は作業の責任分界を先に確かめる。条件が揃った後の案内可否は別途判断いただきたい。
