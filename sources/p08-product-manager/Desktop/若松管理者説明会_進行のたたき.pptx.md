# 若松管理者説明会 進行のたたき

## 1枚目：受付の目的（導入 5分）

レイアウト：表紙

題：若松設備 管理者説明会
副題：依頼受付から再利用送信まで／準備合わせ用
OFS-202608-BR-002　v0.1　2026年8月25日　中川 裕太
暦年2026年Q3・FY2026 Q2

本文：9月3日 10:00〜11:00 オンライン／対象：東浜・大橋・西戸崎の管理者

発表者メモ：石田さんとの準備合わせ用。受付は巡回の依頼を届け、その後の状況をたどるための入口。最初から再利用だけを説明せず、一件の依頼の流れを先に見せる。対象は3拠点であり、参加人数を確定した意味ではない。

## 2枚目：始める前に権限を確認（確認 10分）

レイアウト：見出しと本文

- アカウントで入れるか確認する
- 自分の対象拠点が表示されるか確認する
- 依頼を作成・送信できる権限を確認する
- 表示されない、送信へ進めない場合はその場で中川に知らせる

発表者メモ：どの入口から始めるか迷う人を置き去りにしない。ログインできたことと、対象拠点で送信できることは別々に確認する。権限や接続で止まった場合は認証情報を口頭や画面共有で求めず、個別に対応する。

## 3枚目：初回依頼を送る（演習 前半）

レイアウト：図

図の流れ：依頼受付を開く → 対象拠点を選ぶ → 巡回依頼の内容を入力 → 内容を確認 → 送信

練習題材：対象拠点の設備巡回。依頼内容は「共用部の設備を巡回し、異常の有無を確認する」。氏名は入力しない。

発表者メモ：演習25分の前半。受付一覧から新しい依頼を開く場所を画面上で示し、各自が対象拠点を選べるところまで待つ。入力後は確認画面を一緒に見て、送信操作まで進める。結果は当日の観察として別に記録する。

## 4枚目：送信済みの依頼を再利用する（演習 後半）

レイアウト：図

図の流れ：依頼受付一覧 → 送信済みの依頼を選ぶ → 詳細から再利用 → 内容を確認・必要箇所を変更 → 送信

注記：再利用元と今回の対象拠点・依頼内容を送信前に確認する。

発表者メモ：演習25分の後半。最初にどの依頼を選ぶのか、一覧から詳細へ進むところを丁寧に示す。選択できたか、送信までのどこで止まるかを石田さんに見てもらう。結果を先回りして記入しない。

## 5枚目：困った時の窓口（質問 15分）

レイアウト：2段

左：操作中に止まったら
- どの拠点で、どの操作まで進んだかを伝える
- 画面に表示された案内を確認する

右：連絡の流れ
- 当日は中川へ声をかける
- 後日の相談は小野さんを通じて中川へ
- 認証情報は伝えない

発表者メモ：演習と質問の時間を分ける。まず初回送信と再利用の操作で迷った箇所を聞く。画面への要望は演習後に別に控え、その場で改修を約束しない。

## 6枚目：終わる前に確認（締め 5分）

レイアウト：見出しと本文

- 初回依頼を送るまでの流れを振り返る
- 再利用する依頼の選び方を振り返る
- 未解決のつまずきと連絡先を確認する
- 拠点ごとの確認結果を整理し、次の対応につなげる

発表者メモ：参加者の理解や送信の成否は当日確認する。石田さんが拠点別に送信可否とつまずきを記録し、その記録を見て太田さんが改修の要否を再検討する。終了時に効果を断定しない。
