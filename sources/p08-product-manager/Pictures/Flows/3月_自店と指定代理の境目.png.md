# 表示範囲案

中央に「店番12の申請1件」。左に「自店承認者」「自店分を表示」、右上に「指定代理」「指名された申請1件」、右下に「非担当者」「詳細なし」を配置する。

自店承認者から中央を含む自店分へ矢印。指定代理から中央の1件だけへ矢印。非担当者から申請への矢印はつながらない。指定代理の矢印の途中に「承認完了 または 17時で解除」と記し、解除時に接続が切れることを示す。画面操作の見本ではなく、役割と対象の関係を表す概念図。
