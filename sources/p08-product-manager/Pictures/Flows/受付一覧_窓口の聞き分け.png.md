# 受付一覧　窓口の聞き分け

机上で上から下にたどる分岐図。枠と矢印、分岐の答えを次のとおり記す。

開始「いま、どの画面を開いていますか」
→「受付一覧を開いていますか」
- いいえ →「受付一覧を開いていただき、開けたら教えてください」→「受付一覧を開けましたか」
  - はい →「対象の行と受付番号が表示されていますか」へ
  - いいえ →「開いている画面と困っている操作を記録し、窓口で確認を続ける」で終端。
- はい →「対象の行と受付番号が表示されていますか」
  - いいえ →「表示期間と対象範囲を確認する」→「対象の行が表示されましたか」
    - はい →「受付番号を選びましたか」へ
    - いいえ →「確認した期間と対象範囲を記録し、窓口で確認を続ける」で終端。
  - はい →「受付番号を選びましたか」
    - いいえ →「対象の行の受付番号を選ぶよう案内する」→「詳細が表示されましたか」
    - はい →「詳細が表示されましたか」
      - はい →「詳細の表示を確認し、窓口の案内を閉じる」で終端。
      - いいえ →「選択時刻、操作順、期待した表示と実際の応答、更新・再試行の有無を記録する」→「役割範囲とブラウザ版を確認する」→「松田へ照会を残す」で終端。

「番号を選ぶよう案内する」後の「詳細が表示されましたか」も、はい・いいえを同じ終端に結ぶ。聞けなかった項目は推測しない。
