# 巡回チェック　前の申請を使う流れ

操作の流れを左から右へ示す図。左の枠の見出しは「履歴から」。枠内に「同じ拠点で閲覧できる送信済み申請の詳細を開く」。そこから中央の枠「複製」へ矢印を引き、枠内に「内容を引き継いで新しい下書きを作る」と書く。中央の枠から「希望日を入力し、内容を確認」へ矢印、さらに「送信」へ矢印を引く。下書きの脇に「元の申請は更新されません」と注記する。

左枠から分岐し、閲覧できない場合の枠を「対象外」とする。枠内は「元の申請を開けない場合」。その脚注に「開けないときは管理者に相談してください」と書く。対象外の枝は下書きや送信に接続しない。
