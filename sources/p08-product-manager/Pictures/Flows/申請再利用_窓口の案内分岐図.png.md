# 止まったところから誰へ渡すか

## 図に入れる文字

- 題「止まったところから誰へ渡すか」
- 副題「巡回チェック｜岡本・西村 窓口確認｜2026年3月23日」
- 凡例「実線　現行の操作・窓口対応」「破線　4〜6月に検討する案内」

## 上段の流れ

左から右へ、次の箱を実線矢印で結ぶ。

1. 「利用者｜同じ拠点の送信済み申請を探す」
2. 「利用者｜閲覧できる送信済み申請の詳細を開く」
3. 「利用者｜内容を引き継いで未送信の下書き」
4. 「利用者｜今回の希望日を入れ、内容を確認して送信」

箱3の下に「引き継ぐ3欄：設備区分・依頼種別・点検箇所（編集可）」。箱4の下に「元の申請は変わらない」。

## 下段の分岐

| 分岐を出す位置と矢印の文字 | 現行の引き継ぎ（実線） | 検討する案内（破線） |
|---|---|---|
| 箱1から箱2へ進む途中。「送信済み詳細に未到達」 | 「利用支援｜いま開いている場所を聞く」→「利用者｜同じ拠点の送信済み申請の詳細を探す」。箱1へ戻す。 | 利用支援の箱から「検討｜詳細までの探し方を案内に足す」へ。 |
| 箱2の手前。「元票が閲覧不可」 | 「利用支援｜開こうとした元票と止まった箇所を聞く」→「顧客側管理者｜元票の閲覧可否を確認」。矢印に「確認を依頼」と付け、この枝は管理者で止める。 | 利用支援の箱から「検討｜未到達と閲覧不可を窓口の記録で分ける」へ。 |
| 箱3から箱4へ進む途中。「下書きで希望日が空欄」 | 「利用支援｜下書きまで進んだか聞く」→「利用者｜今回の希望日を入力」。箱4へつなぐ。 | 利用支援の箱から「検討｜引き継ぐ3欄と今回入れる希望日を案内で分ける」へ。 |

元票閲覧の枝の末尾に「開けない元票からは再利用を進めない。別拠点への案内はしない」と添える。図は操作の順と担当の受け渡しを示す箱と矢印で構成する。
