# 入社時の受入手順
用途：受入手順
文書番号：MW-HR-202501-REC-001　版：v1.0
作成日：2025年1月6日　作成者：人事 伊藤真由子
対象：人事・受入部署

## 前営業日の確認
入社前営業日の16時に、人事の伊藤は受入部署からの回答の有無を確認する。回答が届いていない場合は、受入部署へメールで催促する。回答を受けたことと、初朝に各項目が使えることは別に確認する。

## 初朝の確認
受入部署は、入社初日の朝に次のものが使えるか確かめる。

| 項目 | 初朝に確かめること |
|---|---|
| PC | 本人が使用するPCを受け取れるか |
| 初回ログイン | 最初のログインができるか |
| 入館証 | 入館に必要な証を受け取れるか |
| 出迎え | 初朝の出迎え担当がいるか |
| 研修予定 | 初週の研修の予定を確認できるか |

不足があれば、受入部署から伊藤へ項目と状況を伝える。人事は連絡を受け、受入部署と必要な対応を確認する。
