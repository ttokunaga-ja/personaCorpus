# 法人研修窓口

法人研修の一次受付・営業への引継ぎ

仙台／正社員／募集1枠

想定年収：360万円〜420万円

## 仕事内容

企業のお客様から届く研修の相談を受け、営業担当につなぐ仕事です。受講人数や希望日、研修の目的を確認し、その日のうちに一次返信します。確認できたことと次に連絡する時刻を営業担当へ引き継ぎます。

たとえば希望日がまだ決まっていない相談では、候補や決まる見込みを伺い、未確定のまま担当へ伝えます。見積や価格、値引き、提案の判断は営業担当が行います。

## 応募条件

顧客への応対と、案件を次の担当へ引き継いだ経験をお持ちの方。
