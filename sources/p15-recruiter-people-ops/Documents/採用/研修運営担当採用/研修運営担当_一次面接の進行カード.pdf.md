# 面接前にそろえる聞き方

MW-HR-202410-REC-001　v1.0　2024年10月1日　佐藤 美穂子

山本さんへ。10月2日・3日の6枠で共通に使う進行カードです。1枠45分、次の枠まで15分を空けます。

| 時間 | 進行 |
|---|---|
| 0〜5分 | 導入。担当者を紹介し、今日は経験と仕事の進め方を伺い、最後に質問の時間を設けると伝える。 |
| 5〜25分 | 経験。複数の関係者の予定を調整した仕事について、条件をどう集め、折り合わない点をどう扱ったかを聞く。 |
| 25〜35分 | 時間変更の例。当初13時の講師が15時を希望し、会場は14時まで使える設定で、代替の確認先、判断を仰ぐ材料、承認後の案内を順に聞く。 |
| 35〜45分 | 逆質問。仕事内容や当番、判断の範囲について質問を受ける。 |

回答を聞き直す必要がある場合は「そのとき、誰に確認しましたか」と一度だけ補足で聞く。実際に話された手順と面接者の解釈を分けて控え、課長に相談したというだけで丸投げと判断しない。

終了時は採否を約束せず、次の連絡は人事の加藤が窓口になると案内する。
