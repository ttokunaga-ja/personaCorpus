# ペア練習　交代するときの手順
文書番号：MW-HR-202606-REC-001　版：1.0
2026年6月1日　人事　佐藤美穂子
対象：顧客窓口の皆さん

## 例：希望日が決まっていない問い合わせ
法人研修を相談したいというお客様からの連絡です。希望日はまだ決まっていません。2人で聞き手とお客様役を決めて始めます。

1. 聞き手は、どのような研修の相談か、参加予定の人数と希望する時期を尋ねます。日が未定なら、未定のまま受け取ります。
2. 聞いた内容を確かめ、次に連絡する時刻を伝えます。営業へ内容を引き継ぐことも伝えます。金額や日程をその場で確約しません。
3. お客様役は、聞こえた言い方を下の欄に印を付けて返します。言い直したい箇所があれば伝えます。
4. 役を交代し、もう一度同じ場面を練習します。

## 見かけた言い方に印を付ける
| 観察すること | 1回目 | 交代後 |
|---|---|---|
| 用件を尋ねた | □ | □ |
| 人数を尋ねた | □ | □ |
| 希望時期を尋ね、未定と受け取った | □ | □ |
| 次に連絡する時刻を伝えた | □ | □ |
| 営業へ引き継ぐと伝えた | □ | □ |

印は言い方を振り返るためのものです。成否や英語力の評点は付けません。
