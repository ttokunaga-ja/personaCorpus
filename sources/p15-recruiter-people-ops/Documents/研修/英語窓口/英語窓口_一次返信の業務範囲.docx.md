# 英語の問い合わせで窓口が担う範囲
文書番号：MW-HR-202504-REC-001　版：1.0
2025年4月7日　人事　佐藤美穂子
宛先：人事

## 小林さんとの相談から
法人研修について英語で問い合わせが来たとき、顧客窓口で最初に受ける内容を研修の対象にしたい。対象は顧客窓口の18人。営業が内容を検討する前に必要な情報を聞き取り、いつ返答するかを伝えたうえで渡すところまでを練習する。

| 窓口で確認すること | 次に行うこと |
|---|---|
| 問い合わせの用件 | 営業に用件を伝える |
| 希望日 | 未定ならそのまま伝え、決まっている場合は希望として渡す |
| 参加予定人数 | 人数を確認して営業へ渡す |
| 返答予定 | 次に連絡する予定をお客様に伝える |

## 営業に残す判断
金額や日程を確約する必要がある場合は営業が判断する。窓口では希望を聞き取っても、その場で価格や開催日を約束しない。研修の範囲と時間を検討するときは、この一次応対と引継ぎを起点にする。
