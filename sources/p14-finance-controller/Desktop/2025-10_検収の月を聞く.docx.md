# FY2026営業申請　検収月と販促費の確認
文書番号：CW-FIN-202510-QUERY-01　版：1.0  
作成日：2025年10月15日  
作成：千田 真理子　宛先：日下部 亮

日下部さん

10月8日の部門集約には、什器の追加枠120百万円と、それに対応する外部販促12百万円が含まれています。受注の見込みと検収予定を一つの欄にまとめると、いつ売上を計上できる根拠があるか追えません。以下を分けて確認し、10月20日正午までに回答してください。

| 確認事項 | 回答欄 |
|---|---|
| 追加枠120百万円の契約の有無、未契約なら現状 | |
| 先方との検収月の合意の有無、合意済みなら対象と月 | |
| 受注の見込みと、検収合意を得た金額の区分 | |
| 外部販促12百万円の発注状況と、費用を止められる時点 | |
| 検収月の根拠が得られない場合の売上・販促費の扱い | |

既存分は追加枠と分け、根拠のある検収予定月を示してください。回答を受けて付議額を検討します。現段階では追加枠の採否を決めていません。
