# FY2026承認予算　部門への配布と執行条件
文書番号：CW-FIN-202512-DIST-01｜発行日：2025年12月18日｜作成：千田 真理子｜版：1.0
宛先：営業・静岡工場・設計・管理の各担当

## 年度の承認額
取締役会決議 CW-FIN-202512-BRES-01 により、FY2026の年度基準は以下のとおりです。単位は百万円です。

| 項目 | 承認額 |
|---|---:|
| 売上 | 9,680 |
| 原価 | 7,219.8 |
| 販管費 | 2,170 |
| 営業利益 | 290.2 |
| 設備 | 138 |

## 執行にあたって
営業は合意済みの検収を売上計上の基準としてください。静岡工場の集塵機90と安全柵30は、発注前に夏季休業日程を確認してください。設計の必要機器の更新18は、発注前に既存機の保守期限を確認してください。

設計の全席展開42は今回の執行枠に含まず、次年度以降に再付議します。利用費12と導入支援6は管理の執行枠から除外しています。

## 差異報告
差異報告は承認予算 CW-FIN-202512-BUDGET-01 版1.0を基準としてください。予測は別表で更新し、承認額と区別してください。
