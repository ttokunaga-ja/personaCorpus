# 排水縦断・接続詳細
工事名：海田西配送棟増築　図番：D-42　RevA
日付：2026年7月13日　作成：白島設計室 小野幸子
状態：設計回答用　縮尺：模式

## 縦断
左から右へ流れる縦断線にP1、M2、M3、M1を置く。区間寸法は順に6m、18m、6m、合計30m。内面管底は順にGL-1200、GL-1260、GL-1440、GL-1500mm。流向矢印、勾配1/100、各桝と接続位置を示す。管は呼び径200、外径220mm。

## 管路掘削・接続詳細
管の断面に内面管底と外面下端を区別して示す。外面下端は内面管底より10mm下。掘削幅1.2m、平均深さ1.5mを寸法線で示す。M1は既存桝、接続内面管底GL-1500mm。高さはGL基準。

## 旧案比較断面（X5-Y3）
旧Y3直進案の交差を別枠で示す。既設雨水管の下端GL-1150mm、旧案排水管の外面上端GL-1230mm、内面管底GL-1440mm。外面間離隔80mm、必要200mm。これは旧案の交差であり、上記迂回縦断の交差位置を示すものではない。

参照：D-41 RevA。施工前に既設位置・高さを確認する。
