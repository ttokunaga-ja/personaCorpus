# 排水平面図
工事名：海田西配送棟増築　図番：D-41　RevA
日付：2026年7月10日　作成：白島設計室 小野幸子
状態：設計回答用　縮尺：模式

## 排水平面
X4、X5、X6、X7を左から右に、Y2、Y3、Y4を下から上に、それぞれ6m間隔で描く。P1をX7-Y3、既存桝M1をX4-Y3に置く。新設経路をP1→M2（X7-Y4）→M3（X4-Y4）→M1の順に実線で描き、流向矢印と区間寸法6m・18m・6m、合計30mを示す。M2・M3は新設桝。管は呼び径200、外径220mm。

管底はP1 GL-1200、M2 GL-1260、M3 GL-1440、M1 GL-1500mm。各区間の勾配は1/100。管底は内面下端を示す。

旧案はP1からY3上をM1へ直進する18mを破線で描き、「旧案・未施工、取りやめ」と記す。X5-Y3に既設雨水管を示し、旧案との外面離隔80mm、必要200mmと記す。凡例は実線＝変更経路、破線＝旧案。

## 条件
既設雨水管は稼働中の機能を維持し、移設しない。M1接続管底GL-1500mmを維持する。詳細はD-42 RevAを参照。設計回答用であり、施工に先立ち既設位置・高さを確認する。
