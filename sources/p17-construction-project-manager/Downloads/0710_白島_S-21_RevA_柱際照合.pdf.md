# 柱・基礎伏図　柱際照合
海田西配送棟増築｜S-21 RevA｜2024年7月10日｜白島設計室 小野 幸子｜照合用・縮尺なし
宛先：湊梁建設 坂本 修一郎様

## 伏図
X4〜X7を左から右、Y2〜Y4を下から上に配置し、隣接芯間は各6,000mm。Y2側を既存棟側、Y4側を増築側とする。Y3・Y4の各X芯交点に柱位置の小矩形と基礎外形の矩形を描く。Y3ではX4に基準墨の起点、X5に柱表との記号照合、X6にアンカー組立順、X7に脱型側の引出しを残す。

Y4の4交点をそれぞれ独立した照会囲いで示し、次の引出しを付ける。既設物は破線、新設柱・基礎の照会外形は実線。X6の新設アンカー照合点は十字、X7の旧図スリーブ心は中心印で示す。

| 番号 | 位置 | 照合対象 |
|---|---|---|
| RFI-24-20 | X4-Y4 | 既存基礎の外形と柱脚の離隔 |
| RFI-24-21 | X5-Y4 | 既存土間端と仮切断線。切断線はA-32 Rev0参照 |
| RFI-24-22 | X6-Y4 | 既設防護柵ベース縁と図上アンカー照合点 |
| RFI-24-23 | X7-Y4 | 既設スリーブの旧図心と基礎立上り |
