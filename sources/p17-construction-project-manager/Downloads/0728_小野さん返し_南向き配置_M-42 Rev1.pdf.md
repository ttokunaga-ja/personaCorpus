# 搬送設備配置調整図

工事名：海田西配送棟増築  
図番：M-42　Rev1  
発行日：2025年7月28日  
作成：白島設計室　小野幸子  
宛先：湊梁建設　坂本修一郎  
状態・縮尺：設計調整図・模式図　単位：mm

## 平面

北を上、東を右とし、X5〜X6とY3〜Y4の通り芯を各6,000mm間隔で描く。X5から東へx、Y3から北へyをとる。Rev0と同じ南基準墨 y=1,000を床上の線として示し、壁ではないと記す。北間仕切り南仕上面 y=4,420を保持する。

設備のガード込み外形を、南西角 (x=1,800, y=1,300)、北東角 (x=3,840, y=3,100) の矩形で描く。東西2,040、南北1,800の寸法線を付ける。南辺に「受渡し・保守面」と南向き矢印を付ける。南端 y=1,300から y=400までを「受渡し・保守域 900」と表示し、短いローラー台を南側に示す。設備東端 x=3,840と東の固定柵端 x=4,500の間に寸法線660を引き、「隔離操作側」と記す。

北端 y=3,100から北壁南仕上面 y=4,420までに寸法線を引き、「北側歩行通路 図上1,320」と記す。要求有効幅1,200は別に記載する。南基準墨から設備南端まで300を示す。

## 注記

1. 壁位置はM-42 Rev0のままとし、General Arrangement Rev Bの外形を反時計回りに90度置き直す。
2. 南側900は保守時に短いローラー台を外して確保する。東側の隔離操作の要求幅は600以上。南側電源引回しは北の歩行帯を横切らない。
3. 参照：M-42 Rev0、General Arrangement — Transfer Unit Rev B、設備取合い確認票 MB-KN-2025-IN-007 Rev0。
4. 寸法は配置上の値であり、据付後の実幅ではない。床下、床固定位置とローラー台を据付前に現物照合し、据付後に突出部を含む通路幅と受渡し・隔離操作を確認する。
