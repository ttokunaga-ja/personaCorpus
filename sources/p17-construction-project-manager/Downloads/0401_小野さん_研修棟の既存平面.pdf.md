# 海田研修棟　既存平面
図番 KT-A-01　Rev0　2025年4月1日　白島設計室 小野幸子
現況読み合わせ用　縮尺：模式図　寸法単位：mm

## 平面
北を上に置き、X1〜X7を西から東へ等間隔に並べる。各芯間は6,000、全長36,000。Y1〜Y4を南から北に並べ、芯間はY1–Y2 2,400、Y2–Y3 6,000、Y3–Y4 1,800。各芯を建物の外側に延ばし、芯名と寸法線を付ける。北矢印を図の右上に置く。

Y2〜Y3に6室を左から順に描く。X1–X2 西研修室、X2–X3 西演習室、X3–X4 中央研修室、X4–X5 中央演習室、X5–X6 東研修室、X6–X7 東演習室。各芯位置に間仕切りを描き、各室のY2側に南廊下への扉、Y3側に北サービス通路への作業用扉を開口と扉の開きで示す。Y1〜Y2は南廊下、Y3〜Y4は北サービス通路と記す。南廊下の西端に西出入口、東端に東避難出口を描く。

凡例：細い一点鎖線＝通り芯、太い実線＝外壁・間仕切り、細い実線と両端の短い斜線＝寸法線、壁の開口と円弧＝扉の開き。施工区分は表示しない。寸法は芯間であり、通路の有効幅ではない。現地で扉と間仕切りを照合する。
