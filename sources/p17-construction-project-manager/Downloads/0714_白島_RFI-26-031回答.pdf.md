# 設計質疑回答
工事名：海田西配送棟増築　番号：RFI-26-031
日付：2026年7月14日　作成：白島設計室 小野幸子
宛先：湊梁建設株式会社 坂本修一郎様
状態：設計回答　縮尺：なし

## 照会
7月8日の排水接続高さと経路の照会について回答します。X5-Y3では旧案排水管と既設雨水管の外面離隔が80mmで、必要200mmを満たしません。既存桝M1の接続管底はGL-1500mmです。

## 回答
D-41 RevA及びD-42 RevAのとおり、P1からY4側を経てM1へ至る30mの迂回経路を設計上採用します。X7-Y4にM2、X4-Y4にM3の桝を設けます。管底と勾配は断面図で確認してください。

| 検討案 | 判断 | 理由 |
|---|---|---|
| Y4側迂回 | 採用 | 既設雨水管を動かさず、M1に接続する |
| 既設雨水管の移設 | 不採用 | 稼働中の雨水機能を維持できない |
| 排水管の浅埋設 | 不採用 | M1接続管底GL-1500と指定勾配を満たせない |

施工側でM2・M3の桝部の掘削数量を再照合してください。本回答は設計上の経路と接続条件を示すものです。費用及び引渡し変更は施主との別協議とし、本回答をそれらの合意又は施工着手の指示とはしません。

参照図：D-41 RevA（2026年7月10日）、D-42 RevA（2026年7月13日）。
