# 海田研修棟改修　南廊下を残す区画
図番：KT-A-12　RevA　日付：2025年4月8日
作成：白島設計室 小野幸子　状態：設計回答　縮尺：模式図
宛先：湊梁建設 坂本修一郎 様

## 平面・境界方針
上を北に、X1〜X7を西から東へ等間隔に描く。Y1〜Y2を南廊下、Y2〜Y3を室、Y3〜Y4を北サービス通路とする。X1〜X3は西研修室・西演習室、X3〜X5は中央研修室・中央演習室、X5〜X7は東研修室・東演習室。それぞれY2に受講者用扉、Y3に作業用扉を示す。

X3・X5の区画境界を破線で示し、Y2側の端部は扉の室内側に納める。X3とX5の端部から共通の「詳細A」へ引出線を引く。南廊下は西出入口から東避難出口まで利用者動線を実線矢印でつなぐ。北サービス通路は作業側として一点鎖線矢印で示す。東出口前の仮置き候補には取消しを示し「東避難出口前の仮置きは取りやめ」と記す。

## 詳細A：代表的な南扉端部
室内を上、南廊下を下にした拡大平面。Y2の壁と扉開口を描き、扉の室内側に仕切り端を止める。廊下側に仕切りを突出させない。X3・X5に共通する方針を示す詳細であり、寸法は現地で照合する。

凡例：破線＝区画境界、実線矢印＝利用者動線、一点鎖線矢印＝作業側動線、取消し線＝仮置き取りやめ。施工順は別途協議。
