# 既存業務の停止条件 協議録

文書番号：MB-KN-2024-MT-001　版：初版
工事名：海田西配送棟増築
協議日時：2024年4月15日 13:30〜14:20
出席：海田流通株式会社 原田裕実、湊梁建設株式会社 青木美紀子・坂本修一郎
宛先：原田裕実様、青木美紀子さん
作成：坂本修一郎　2024年4月15日
対象：X4〜X7の既存車路、荷さばき面、検品者通路

## 協議の目的
仮囲い切替えに必要な停止を、既存の出荷・検品を続けながらどう確保するか確認した。4月11日の旧案は切替えと復旧を各4時間の2夜とし、週8時間を見込んでいた。

## 確認した条件
原田さんから、既存業務の停止は閉鎖準備と復旧確認を含め、週合計6時間以内とする条件を受けた。通常の検品・出荷が集中する平日16:00〜19:00は避ける。荷さばき面と検品者通路を同時に塞がない。車路の切替えだけでなく人の通行も区画計画に含める。

## 対応
旧案の8時間は上限を2時間超えるため、そのままでは使えない。坂本が作業と確認の時間を分けて夜間主体の案を組み直し、青木さんと班割りを確認してから原田さんへ候補を示す。停止を実施する日程はこの協議では決めていない。

次の確認先：青木さんに作業分割と必要な班を確認し、原田さんに修正案と各週の調整方法を確認する。
