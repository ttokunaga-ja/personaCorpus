# 西配送棟　Y4柱際区画図

図の表記は「海田西配送棟増築」「2024年8月23日 午前照合後」「13:30 定例提案図」「模式図」「坂本 修一郎」。

縦芯は左から「X4」「X5」「X6」「X7」。横芯は上から「Y4」「Y3」「Y2」。隣接芯間は各6 mで、X4–X5、X5–X6、X6–X7の各寸法表示は「6 m」。Y4の上側に「増築側」、Y2の下側に「既存棟側」。

Y4上の4交点を、互いに接しない独立した枠で示す。各枠のそばに作業名を付す。

| 枠内の文字 | 枠横の作業名 | 枠の区分 |
|---|---|---|
| X4-Y4／20 | 掘削・型枠 | 実線枠・着手対象 |
| X5-Y4／21 | 土間切断 | 実線枠・着手対象 |
| X6-Y4／22 | 穿孔 | 破線枠・継続保留 |
| X7-Y4／23 | 柱際打設 | 破線枠・継続保留 |

Y2沿いは4区画の枠と離れた連続線で、表記は「Y2 営業車路（維持）」。

凡例の文字は「実線枠　着手対象（個別実施枠は別途）」「破線枠　継続保留」「連続線　営業車路」。  
図の注記「対象は各枠の柱際。作業日は既存動線と個別実施枠を照合のうえ決定。」
