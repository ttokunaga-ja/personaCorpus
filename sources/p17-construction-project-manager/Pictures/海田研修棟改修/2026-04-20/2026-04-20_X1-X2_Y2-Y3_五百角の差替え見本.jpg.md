# 写真
4月20日、青木が太田の受領確認用に見本台を斜め上から撮影。西研修室 X1〜X2／Y2〜Y3 の M-01。再選定の500 mm角を直角治具の二辺に当て、その手前に初回の450 mm角を重ねずに平行に置く。旧片は治具から手前へ少し離してあり、両片の角は揃えていない。治具の角から500 mm片の奥端まで沿う金尺と、奥端の500 mm目盛が見える。両片の織り方向も見える画角。札にはそれぞれ「M-01 再選定 500角」「初回 450角」とある。床への施工は写っていない。
