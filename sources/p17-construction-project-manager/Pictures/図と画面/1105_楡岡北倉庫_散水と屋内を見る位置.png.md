# 楡岡北倉庫　散水と屋内を見る位置

図番：MB-NK-2024-ZP-002 Rev0　作成：坂本 修一郎　2024年11月5日

上下に同じ向きの矩形を二つ置く。上を「屋根側　散水区画」、下を「屋内側　直下の観察点」とし、いずれも上が北、左が西。模式図で縮尺なし。各矩形を西からX1、X2、X3、X4、X5の通り芯で4列、南からY1、Y2、Y3、Y4の通り芯で3帯に区切る。芯間は西から10、10、9、8m、南から12、16、12m。

両面とも南からA、B、C帯とし、区画を下記の通り同じ位置に配置する。

| 北←帯→南 | 西 X1〜X2 | X2〜X3 | X3〜X4 | X4〜X5 東 |
|---|---|---|---|---|
| C（Y3〜Y4） | C1 | C2 | C3 | C4 |
| B（Y2〜Y3） | B1 | B2 | B3 | B4 |
| A（Y1〜Y2） | A1 | A2 | A3 | A4 |

上面の各区画から下面の同番号の点へ対応線を引き、1対1の対応を示す。下面のB3のX4寄りに点と「梁側面・屋根下の重ね目」、C4の北東隅に点と「北東隅」を入れる。他の点は各区画直下に置き、それぞれ同じ区画番号を表示する。散水順は「A1→A2→A3→A4 → B1→B2→B3→B4 → C1→C2→C3→C4」と記す。下端のY1南側に「南庇：契約対象外・荷さばき」と記す。凡例は「枠：区画」「点：屋内観察点」「線：屋根と直下の対応」「矢印：散水順」。
