# 設備を南向きにした場合

海田西配送棟増築　7月22日　小野さん比較用。設備側確認前の案。平面模式図、単位 mm。北上・東右、X5をx=0、Y3をy=0、X5〜X6・Y3〜Y4の芯間は各6,000。

Rev B外形を従来向きから反時計回りに90度置き直し、南西角を同じ床位置(x=1,800, y=1,300)に合わせる。外形は東端x=3,840、北端y=3,100、東西2,040×南北1,800。南面から南への矢印に「受渡し・保守面（要確認）」と記す。北壁南仕上面y=4,420との間に寸法線「北通路 1,320」。壁は現位置のまま。

東の固定柵端x=4,500を破線、南の短いローラー台予定を別の破線で示す。凡例は「実線：設備外形・北壁」「長破線：既設固定柵端」「短破線：ローラー台予定」。台の形と設置は設備側確認前。
