# 海田西配送棟増築　Y4柱際の保留と準備範囲

2024年7月12日　坂本

平面の模式図。横にX4、X5、X6、X7、縦に下からY2、Y3、Y4の通り芯を置く。隣り合う芯間はすべて6m。Y2側に「既存棟」、Y4側に「増築側」と記す。寸法を示す図であり、詳細な施工範囲を確定する図ではない。

Y4上の交点に、互いに接続しない四つの小さな囲いを置く。それぞれに次を記す。

- X4-Y4「20 掘削・型枠 保留」
- X5-Y4「21 土間切断 保留」
- X6-Y4「22 穿孔 保留」
- X7-Y4「23 打設 保留」

Y2沿いのX4〜X7には連続する矢印と「業務車路 有効幅3.6mを確保」。X5〜X6のY2側に「荷さばき」、X7-Y2に「検品者通路の折れ」と記す。増築側の保留囲いの外に別の領域を示し「区画外採寸・墨出し」。型板は「別場所で照合」と欄外に記す。

凡例：「柱際の該当作業を保留」「区画外で採寸・墨出し」「業務車路を確保」。

欄外：「保留区画外の準備も車路を塞がない範囲。停止の個別許可を示す図ではない。S-21 RevAは柱際の照合用」。
