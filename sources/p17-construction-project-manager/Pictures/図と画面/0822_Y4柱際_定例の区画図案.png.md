# Y4柱際　定例の区画図案

図の表記は「海田西配送棟増築」「8/22　定例前の案」「模式図」。

縦芯は左から「X4」「X5」「X6」「X7」。横芯は上から「Y4」「Y3」「Y2」。隣接する芯の距離は各6 m。横方向の寸法列に「6 m」を3つ並べる。上に「増築側」、下に「既存棟側」。

Y4の各交点には離れた橙枠が一つずつ残る。左から図中の文字は「X4-Y4　掘削・型枠」「X5-Y4　土間切断」「X6-Y4　穿孔」「X7-Y4　柱際打設」。見直しの赤い括弧は右の2枠だけにかかり、括弧のそばに「奥側未測」の書き込みがある。橙枠の間には空きがあり、右の2枠も個別の輪郭を保つ。

既存棟側のY2沿いには連続した青灰の線と「Y2 営業車路」。車路はどの候補枠からも離れている。

凡例の文字は「橙枠　着手候補案」「赤括弧　候補から外す」「青灰線　営業車路」。
