# 東端に仮置きすると（旧案の検討図）
横長の模式図。上を北、左を西とし、X5・X6・X7を左から等間隔に記す。Y2〜Y3に東研修室（X5〜X6、14席）と東演習室（X6〜X7、6席）を隣接して描き、南のY1〜Y2に南廊下を横に通す。東演習室のY2側に南扉、廊下の右端に東避難出口を描く。

東演習室南扉と東避難出口の間の廊下に「資材待機」の長方形を重ねる。南扉から廊下へ出る枝に斜線を引き「利用経路が取れない」と記す。東研修室を囲み「旧案で数えるのは1室・14席」と記す。凡例は「斜線：通れない枝」「四角：資材待機」。模式図、縮尺なし。
