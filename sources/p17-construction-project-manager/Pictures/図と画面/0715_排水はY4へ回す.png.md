# 排水経路の比較
原田さんへの説明用。左右に「旧案 Y3直進」と「設計回答 Y4迂回」の平面模式図を並べる。各図とも横にX4、X5、X6、X7、縦にY2、Y3、Y4の通り芯を設け、隣接する芯の間隔を6mと示す。距離の単位はm。

左：P1（X7-Y3）からM1（X4-Y3）までY3上に破線を引き、P1からM1への矢印と「18m」を付ける。X5-Y3に既設雨水管を交差させ、「離隔80mm／必要200mm」と記す。未施工の旧案。

右：P1からM2（X7-Y4）へ6m、M2からM3（X4-Y4）へ18m、M3からM1へ6mの実線を引き、各区間の流向矢印と距離、合計「30m」を付ける。X5-Y3には既設雨水管を置き、迂回路と交差させない。

凡例：破線＝旧案、実線＝設計回答の経路。注記：「既設機能を止めない」「費用協議前」。
