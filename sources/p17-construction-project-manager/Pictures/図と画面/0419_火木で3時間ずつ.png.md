# 火木で3時間ずつ

原田さんへの説明図。横軸は時刻、16:00から23:00まで1時間刻みで、火曜と木曜の2段を同じ尺度で上下に並べる。両段とも16:00〜19:00を「検品・出荷集中」、20:00〜23:00を「停止候補」として描き分け、19:00〜20:00は停止候補に含めない。

各停止候補を20:00〜20:15「開始確認 15分」、20:15〜22:45「切替え作業 正味150分」、22:45〜23:00「復旧確認 15分」の3区分で示す。時間の幅は共通の軸に比例させる。

凡例：検品・出荷集中／開始確認／正味作業／復旧確認。図の下に「停止候補 火3時間＋木3時間＝週6時間（準備・復旧込み）」「正味作業 150分×2＝300分」と記す。候補枠であり実施日は個別確認。
