# 北壁を150振る案

海田西配送棟増築　7月22日　小野さん比較用。平面模式図、単位 mm。北を上、東を右。X5〜X6、Y3〜Y4の各芯間は6,000。X5をx=0、Y3をy=0とする。

Rev Bの設備外形を西端x=1,800、東端x=3,600、南端y=1,300、北端y=3,340の矩形（東西1,800×南北2,040）で示す。既存の北壁は南面y=4,420、北面y=4,520、厚100。移設案は南面y=4,570、北面y=4,670、厚100。北側の固定分電盤面はy=5,420。壁を北へ150移す矢印を付ける。

設備北端から移設案の壁南面までの寸法線に「歩行幅 1,230」、現位置の壁北面から盤面までに「現状 900」、移設案の壁北面から盤面までに「移設後 750」と記す。点検帯の残る750と失う150を別色で塗り分け、凡例にそれぞれ「移設後の点検帯」「移設により失う部分」と記す。既存壁と移設案も線種と凡例で区別する。図上値であり壁移設は未決。
