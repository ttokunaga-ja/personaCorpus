# X5-Y3 離隔確認
2026年7月3日 9:22。試掘部を斜め上から撮影。土の中に露出した既設雨水管と、その下方に旧排水案の外面上端の予定高さを示す水平糸を写す。管の下端と糸の間に目盛り付きの採寸スケールを当てる。管と糸から離隔80mmを読み取る。新設排水管はまだなく、接続された管は写らない。
