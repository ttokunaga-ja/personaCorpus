# X4-Y2 車路の細いところ

2024年4月9日10:06、坂本が青木と現地を歩いて撮影。X4-Y2の既存車路を斜め前方から見下ろす。画面左に既存棟側の縁石、右に車路の端線が入り、手前の測定位置では両方の境が近づいている。縁石の内側から端線まで横断する巻尺が見え、有効幅3.6mを確認できる。左右の境は途中で画角から切れず、手前と奥のつながりが分かる。切替え前の現況で、仮囲いの移設作業は写っていない。
