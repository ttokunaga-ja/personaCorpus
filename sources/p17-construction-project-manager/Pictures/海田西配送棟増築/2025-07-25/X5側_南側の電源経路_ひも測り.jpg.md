# 電源を南へ回す予定線

2025年7月25日09:20、海田西配送棟増築、X5側・Y3〜Y4。西村が坂本と太田への説明用に撮影。

南の床から目線を低くして、設備の南出口予定位置から南側の電源接続予定点までを見通す。床に置いたひもが曲がりを経て接続予定点へ向かう様子と、北側の歩行帯を横断しない経路を一画面に収める。ひもは仮測りであり、敷設済みのケーブルや据付済みの設備は写っていない。
