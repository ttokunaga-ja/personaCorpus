# 7/25　南向き　ひも測り　西村

坂本さんへ　設備はまだ入っていない。床の予定線で見た寸法。

手書きの平面略図。上が北、右が東。中央に南向き設備の予定外形、右に固定柵端、下に南側の空きと電源接続予定点を描く。

- 設備東端予定墨 x=3,840 → 東の固定柵端 x=4,500：**660 mm**（東向きの両矢印）
- 設備南端 y=1,300 → 南の空きの端 y=400：**900 mm**（南北の別の両矢印。保守時は台を外して空ける）
- 南出口から南側接続予定点へ、ひもの曲がりごとに **1,100 + 900 + 600 = 2,600 mm**。各区間を別々に記入。
- リード 3,000 − 2,600 = **400 mm 残り見込み**。曲がりと固定は現物で見る。
- 北の歩行帯を斜めに跨ぐ近道を二重線で消し、「北は通さない」と脇に記す。

紙面は手帳から切り離した白い紙1枚。鉛筆の数字と線、消した近道の跡が読める。少し斜めに置いてスキャンし、紙端と薄い折れ目が見える。
