# 7/23　西口が南に来るか　西村

手帳に二つの略平面。北を上、東を右。

左「今の向き」：南西角を起点に東西1,800、南北2,040の外形。西側に左向き矢印「受渡し・保守」。

右「90°回す」：同じ南西角から東西2,040、南北1,800の外形。南側に下向き矢印「受渡し・保守？」。東側に線を引き「固定柵端 x=4,500」。外形の南端 y=1,300 から南の y=400 まで寸法矢印「900」。東西幅の最初の手書き「1,800」は二重線で消し、横に「2,040」と訂正。南側に「電源の出口？　長さ？」と記す。

方眼入りの手帳の一葉。書いた文字と訂正線が読めるように紙面全体を収め、わずかに傾いた紙の端と薄い筆圧の差が残る。
