# 朝の搬入　2便の立会い

工事名：海田西配送棟増築  
宛先：坂本 修一郎  
文書番号：MB-KN-2025-DR-002　版：Rev0  
日付：2025年1月29日　作成：青木 美紀子

## 受入の経過

第1便は08:16から08:32まで、追加の支持金物4パレットを受けました。X5〜X6のY3増築側の仮置き枠を使い、岡本さんが08:36に枠を空けました。第2便はその後、09:12から09:26まで床養生材6束を同じ枠で受けました。2便分を同時に置いていません。

## 動線の確認

私が立ち会った上記の両便の受入時間中、営業車との重なりはありませんでした。X6-Y2では検品台車の動きを見ながら、搬入側が待って通すことができました。X7-Y2の折れは柱の陰があるので、車が途切れていても検品者の動きを確かめます。

22日は金物だけの試行でした。今日は2便を順に受けられましたが、確認できたのは今日の両便と使用した仮置き枠です。別の日の営業車予定まで確認したものではありません。

## 翌番への申し送り

岡本さん、次に同じ時間枠を使うときも、その日の営業車予定を坂本さんと照合してください。仮置きは1便ずつとし、前の荷を片付けてから次を受けます。検品者や台車を待たせず先に通し、予定外の営業車が重なる回は見送ります。

X6〜X7/Y3の東寄り予備候補は今日も使っていません。養生幕越しの見通しと車両の取り回しは未確認のままです。使用する判断は青木・福田で再照合するまで保留します。
