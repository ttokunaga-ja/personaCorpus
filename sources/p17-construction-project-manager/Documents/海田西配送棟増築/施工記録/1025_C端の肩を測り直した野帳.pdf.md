# 西配送棟 C端　肩の読み直し

|---|---|
| 始点 | C24（距離程24.00m） |
| 途中 | C27（距離程27.00m）。同じ肩の途中、別の始点ではない |
| 終点 | C30（距離程30.00m） |
| 現地読み | C24〜C30 6.00m、対象幅4.00m |
| 拾い条件 | 通常予定底からの増深1.50m。現地で深さを読み取った値ではない |
