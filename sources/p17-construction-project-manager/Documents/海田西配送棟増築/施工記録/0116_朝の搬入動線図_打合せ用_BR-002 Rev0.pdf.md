# 朝の動線　打合せ用模式図
MB-KN-2025-BR-002 Rev0｜海田西配送棟増築｜2025年1月16日｜記録 坂本修一郎
宛先：青木美紀子・岡本哲夫・福田裕次　縮尺なし

## 平面と凡例
X4、X5、X6、X7を左から右、Y2を下、Y3を上とし、各芯間6 mを表示。Y2側は既存棟、Y3側は増築側。Y2に沿う営業車路を実線2本で表し「有効3.6 m」。X5〜X6のY2既存棟側に荷さばき面と間口を示す。検品者通路を車路の既存棟側に実線2本で描き、X7-Y2の柱の脇で既存棟側へ折り、区画柵の内側に連続させる。X6-Y2には台車の横切りを矢印で示す。

X5〜X6/Y3増築側に破線枠「仮置き候補 4.0×2.4 m」。X5からX6方向に1〜5 m、Y3から増築側に0.6〜3.0 m。枠の近くに荷ほどき台。X6〜X7/Y3増築側に養生幕を描き、その東寄りを破線で「予備候補（範囲のみ、未確認）」と記す。返却パレットをX4〜X5/Y3に置く。

凡例：実線＝現況、破線＝候補、矢印＝動き。候補は決定した区画ではない。X6の台車とX7の折れは、時間枠の比較とは別に現地で確かめる。
