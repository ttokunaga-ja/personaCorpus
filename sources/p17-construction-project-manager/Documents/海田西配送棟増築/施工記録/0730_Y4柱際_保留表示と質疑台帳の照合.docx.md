# 柱際の保留表示と台帳の照合

工事名：海田西配送棟増築
文書番号：MB-KN-2024-MT-004／版：初版／2024年7月30日
参加：坂本修一郎、青木美紀子、太田知美
作成：坂本修一郎／確認：青木美紀子、太田知美
対象：Y4のX4〜X7各柱際

4か所を回り、現地の保留表示の位置とMB-KN-2024-RF-001 Rev2の質疑番号・通り芯・保留作業を照合した。7月12日の範囲図も位置の確認に用いた。

| 質疑 | 確認位置 | 台帳と照合した表示・保留作業 |
|---|---|---|
| RFI-24-20 | X4-Y4 | 当該柱脚部の掘削・型枠を保留する表示。台帳の位置と一致。 |
| RFI-24-21 | X5-Y4 | 柱際の土間切断を保留する表示。台帳の位置と一致。 |
| RFI-24-22 | X6-Y4 | 穿孔を保留する表示。台帳の位置と一致。 |
| RFI-24-23 | X7-Y4 | 当該柱際のコンクリート打設を保留する表示。台帳の位置と一致。 |

4件とも技術回答・着工承認は未着であり、表示の照合をもって保留作業を解放しない。小野さんの回答と現地の根拠がそろってから、坂本が着工可否を再確認する。23は西村さんのスリーブ再照合も必要。

青木さんは保留区画外の墨出しを進め、Y2沿いの業務車路を維持する。区画外の採寸と別場所での資材・型板照合も車路を塞がない範囲で続ける。太田さんは20〜23の技術回答日欄を空欄のまま維持する。回答を受けるまでは専用の停止枠を予約しない。停止を伴う作業は原田さんの週ごとの個別確認を要する。
