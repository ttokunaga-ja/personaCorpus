# 搬送設備 南向き取合い確認票

工事名：海田西配送棟増築　文書番号：MB-KN-2025-IN-007　Rev0

位置：X5〜X6・Y3〜Y4　単位：mm

設備の南西角予定は x=1,800、y=1,300。反時計回り90度の予定外形は東西2,040、南北1,800。以下は床の予定墨と資料による照合です。

| 番号 | 位置・点検内容 | 対応根拠・確認内容 | 確認者 |
|---|---|---|---|
| 1 | 南側の受渡し・保守 | 南端 y=1,300から y=400まで900。Interface Note Rev Aの900を配置上確保。保守時は南の短いローラー台を外し、この範囲を空ける。 | 西村 |
| 2 | 東側の隔離操作 | 東端予定墨 x=3,840から固定柵端 x=4,500まで660。同注記の要求600以上に対し60の余地。操作部を含む現物の操作確認は未了。 | 西村 |
| 3 | 電源 | 南出口から南の接続予定点まで、ひもで1,100＋900＋600＝2,600。リード3,000に対して400の残り見込み。北の歩行帯は横切らない。 | 西村 |
| 4 | 南側ローラー受渡し | 設備側の受渡しローラー天端 FL+850、南の短いローラー台予定も FL+850。図上の高さを照合。 | 西村 |

床下と固定位置、ローラー台の現物合わせは据付前に確認する。クリップ位置・結線は現物で合わせる。据付後に北通路の突出部を含む実幅と、受渡し・隔離操作および動作を確認する。今回の確認は配置と寸法の範囲であり、固定や動作の現地確認は残っている。
