# 北通路を開ける前に測るところ

工事名：海田西配送棟増築  
図番：MB-KN-2025-ZP-073　Rev0  
作成日：2025年7月31日　作成：坂本 修一郎  
宛先：青木 美紀子・西村 英二  
状態・縮尺：据付後の測定用・模式図　単位：mm

## 平面図

北を上に、X5〜X6・Y3〜Y4の区画を示す。X5をx=0、Y3をy=0とし、東をx正、北をy正とする。北間仕切りの南仕上面を y=4,420 に引き、設備予定外形を南西角 (1,800, 1,300)、東西2,040、南北1,800 の矩形で示す。外形の北端は y=3,100、東端は x=3,840。東の固定柵端を x=4,500 に示す。南側に受渡し方向の矢印を置く。

凡例：実線＝現況の北間仕切り仕上面・東の固定柵端、破線＝南向き設備の予定外形、両矢印＝据付後に測る有効幅。現況の壁・柵と設備予定を線種と各名称で区別する。

北壁仕上面と設備予定北端との間に「図上 1,320」「必要有効幅 1,200」を並べる。西端 x=1,800、中間 x=2,820、東端 x=3,840 の3か所にそれぞれ壁面から設備側へ南北方向の両矢印を描き、「西端」「中間」「東端」と記す。ガード端または配線が通路側へ突出する場合は、突出の最も通路側にある点から壁面まで追加の両矢印を描き、「突出部があれば追加測点」と記す。追加矢印は位置を確定した実物の表示ではない。

## 持出し時の確認

据付後、壁仕上面からガード・配線等を含む最も通路側の突出まで、通行に使える幅を各点で測る。東端・中間・西端に加え、突出部があればその箇所も測り、どの測点でも必要有効幅1,200mmを下回らないことを確認する。結果は現場で別途記録し、坂本が確認する。

参照：小野 M-42 Rev1、MB-KN-2025-RF-011 Rev0。図上の1,320mmは配置上の寸法であり、据付後の測定結果ではない。
