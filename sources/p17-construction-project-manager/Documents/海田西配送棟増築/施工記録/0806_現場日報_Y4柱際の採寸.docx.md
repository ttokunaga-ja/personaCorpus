# 現場日報　Y4柱際の採寸

工事名：海田西配送棟増築  
宛先：坂本 修一郎  
文書番号：MB-KN-2024-DR-041　版：初版  
日付：2024年8月6日  
作成：青木 美紀子　確認先：坂本 修一郎

## 午前の採寸と区画

7月30日に合わせた保留表示の番号で、5日朝はX4、X5の順、6日朝は西村主任とX6、X7の順で見た。いずれも増築側のY4の柱ごとに測線を取った。巻尺と立会いの位置はその柱際に収め、隣の交点へ移るときは巻尺を戻した。既存棟側のY2沿いの業務車路は採寸区画に含めず、有効幅3.6mを維持した。荷さばき面と検品者通路は開けたまま。

| 日・順 | 通り芯／質疑 | 採寸とその場での確認 |
|---|---|---|
| 8/5 ① | X4-Y4／RFI-24-20 | 柱北面から床墨まで100mm。巻尺を墨に合わせ直し、既存基礎の肩の落ち際まで210mm。柱面からと墨からを略図に分けた。 |
| 8/5 ② | X5-Y4／RFI-24-21 | 柱北面から床墨まで80mm、床墨から欠けのない既存土間端まで125mm。端より北に残る旧仮切断墨は読取り端から外した。 |
| 8/6 ① | X6-Y4／RFI-24-22 | 柱東面から東へ、床墨100mm、柵ベースの手前縁165mm。柵も養生も動かしておらず、柵脚と養生にかかる奥縁には当てられなかった。 |
| 8/6 ② | X7-Y4／RFI-24-23 | 柱北面から北へ、床墨100mm、スリーブの手前口縁265mm。保護材を外せず、反対口縁は測っていない。芯位置は今回の採寸で確定していない。 |

## 申し送り

略図の控えを坂本さんに渡した。太田さんへの転記では、X4・X5の墨からの読みと、X6・X7の柱面からの読みを区別してほしい。次回は西村さんと、設備と養生を扱える条件をそろえてX6の奥縁とX7の反対口縁を確認する。再測日は未定。

4交点とも今日は採寸まで。掘削・型枠、土間切断、穿孔、柱際打設の保留表示を残した。施工着手の判断は次回以降へ持ち越す。
