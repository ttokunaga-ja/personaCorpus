# 1ページ：方眼野帳の筆記

「7/9　海田西　X5〜X6 / Y3〜Y4　西村さんと」

北を上にした略図。下から順にY3芯、床上の南基準墨、設備南西角予定の十字、北間仕切り南仕上面を描く。Y3芯から南基準墨へ矢印「1,000」、Y3芯から設備南西角の横線へ別の矢印「1,300」。墨から十字へ短い矢印「300」。芯からの振りと面間の距離は矢印の始点を分ける。

南基準墨から北壁仕上面までの矢印を西・中・東の3本描き、順に「3,424」「3,420」「3,428」。中央の「3,420」を丸で囲む。横に「最小　仕上面まで」「芯からの1,000を足さない」と記す。北側の線に「壁 南仕上面」、南の墨に「床の基準墨　壁なし」。単位はmm。

方眼紙1枚に鉛筆の手書き。紙端と方眼が見え、筆記と寸法が読めるスキャン。
