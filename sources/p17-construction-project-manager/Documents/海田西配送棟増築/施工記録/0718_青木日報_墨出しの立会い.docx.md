# 現場日報

工事名：海田西配送棟増築  
宛先：坂本修一郎  
文書番号：MB-KN-2025-DR-007　Rev0  
日付：2025年7月18日

## 当日の作業

午前、X5寄りの搬送設備予定位置で、坂本さんと旧外形の仮表示に立ち会った。南西角を起点に、Rev Aの東西1,800mm・南北1,820mmの四隅を床テープで示した。端が浮いた箇所は貼り直し、位置確認に使える状態にした。設備本体はまだ入っていない。

午後、共用テーブル上の図面箱を片付け、次週の朝礼で席を使えるようにした。

## 引継ぎ

床テープは位置の仮表示。打設や穿孔の指示ではない。設備位置と北側通路の取合いは、図面と現地の確認を続ける。テープが剥がれた場合は位置を確かめてから戻す。
