# 測定野帳　見開き

左頁の鉛筆書き：

海田西配送棟　10/16　青木さん読み　坂本控え
X4-Y3 既存床 ±0.00m 基準
起点 Y4から増築側2.00m

| 測点 | 距離程 | 地表高（既存床基準） |
|---|---:|---:|
| A00 | 0m | +0.10m |
| A15 | 15m | +0.20m |
| A30 | 30m | +0.30m |

採用予定底高 −3.00m（地表読みとは別）

A15の地表高は「+0.10」を鉛筆線で消し、その横に「+0.20」と訂正。

右頁の鉛筆書き：

B X5〜X6　起点の旧幅杭　左右の杭間 5.00m（仮幅）
略図：左杭｜← 5.00m →｜右杭。左右の外側にも地面が続く。

C X6〜X7　試掘肩を確認。略図は通常帯の端に肩を示す。端の始点：空欄、終点：空欄（未測）。端の範囲を後日測る。

薄い罫の入った現場用紙の見開き。鉛筆の筆圧差と訂正線が残り、午後に取り込んだ紙の縁が見える。
