# 排水経路の記録照合と立会い箇所
工事名：海田西配送棟増築
文書番号：MB-KN-2026-IN-022 Rev0　日付：2026年9月8日
作成：西村英二　宛先：中野和弘

## 照合の軸
CO-014承認控えと白島設計室RFI-26-031の回答を参照し、D-41・D-42 RevAの経路を使う。P1（X7-Y3）→M2（X7-Y4）→M3（X4-Y4）→M1（X4-Y3）の迂回30m、勾配1/100。8月28日の通水票が8月31日の埋戻し前写真より先の日付であることを照合した。日付順の確認と、各区間の記録内容の判定は分けて扱う。

| 箇所・区間 | 記録で見るもの | 14日に現地で見るもの |
|---|---|---|
| P1〜M2 | P1接続位置、M2桝底の測定票を図面と照合 | 露出部とM2蓋・受枠 |
| M2〜M3 | X6-Y4・X5-Y4の埋戻し前写真と測点、被覆記録 | 復旧面とM3蓋の周辺 |
| M3〜M1 | M1接続記録と8月28日の通水票、経路の位置 | M1蓋と周囲の復旧面 |

写真は8月31日の埋戻し前の位置を図面と合わせて見てください。埋まった管内を現況写真だけで判断しない。M3の蓋の外の復旧面については、周囲の沈みを14日の立会いで確認し、ここでは判定しません。
