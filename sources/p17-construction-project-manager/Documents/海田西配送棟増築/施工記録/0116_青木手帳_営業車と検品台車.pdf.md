# 1/16 朝　西配送棟　青木
坂本さんへ　14日と同じ時間帯をもう一度見た。

横軸 07:40〜10:00、10分目盛。営業車が続いたところに線を引き、それぞれ両端に時刻を書く。
- 07:45 ━━━ 08:10
- 08:40 ━━━ 09:05
- 09:35 ━━━ 09:50

軸の下に「X6-Y2 検品台車：波の間にも荷さばきへ戻る。車が切れても横切りを見る」。特定時刻は記していない。

小図：X7-Y2の柱を四角、既存棟側へ直角に折れる検品者通路を線で示す。柱の陰に「ここで止まって角の先を確認」「相手からも見えにくい」。

欄外「車が途切れた＝歩車が分かれた、ではない。台車と歩く人を別に見る。」

罫線のある手帳の一頁に手書き。紙端と綴じ穴が少し見え、取り込みはわずかに傾く。
