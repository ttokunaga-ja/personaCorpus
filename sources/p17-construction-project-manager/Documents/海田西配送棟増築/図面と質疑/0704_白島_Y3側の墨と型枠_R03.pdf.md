# Y3側の墨・型枠等 回答

海田西配送棟増築｜HS-KN-24-R03｜2024年7月4日｜白島設計室 小野幸子｜回答・縮尺なし
宛先：湊梁建設 坂本修一郎様、太田知美様
参照：S-21 Rev0（5月9日）、A-32 Rev0（5月14日）

Y3側の照会6件について、次のとおり回答します。

| 質疑 | 位置・参照図 | 回答 |
|---|---|---|
| RFI-24-14 | X4-Y3・S-21 Rev0 | 基準墨はX4とY3の交点から振る。 |
| RFI-24-15 | X5-Y3・S-21 Rev0 | ベースプレートの記号を伏図と柱表ともBP-2に統一する。 |
| RFI-24-16 | X6-Y3・S-21 Rev0 | アンカーの組立順は、区画外での型板照合まで可とする。これより先の組立てや設置をこの回答で許可するものではない。 |
| RFI-24-17 | X7-Y3・S-21 Rev0 | 型枠を外す側は増築側とする。 |
| RFI-24-18 | X4〜X5/Y3・A-32 Rev0 | 土間目地の端部は柱際の手前で止める。 |
| RFI-24-19 | X6〜X7/Y3・A-32 Rev0 | 養生境界は打継ぎから増築側に収め、既存通路へ出さない。 |

上記はY3側の照合への回答です。X4・X5・X6・X7のY4柱際は適用範囲に含みません。Y4の既設物との納まりは別途照合してください。
