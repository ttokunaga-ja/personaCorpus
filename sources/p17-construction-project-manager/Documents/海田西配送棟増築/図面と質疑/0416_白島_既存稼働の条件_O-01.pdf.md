# 既存稼働の条件

海田西配送棟増築｜O-01 Rev0｜2024年4月16日｜白島設計室 小野幸子｜条件整理・縮尺なし
宛先：湊梁建設 坂本修一郎様、海田流通 原田裕実様

## 平面

X4〜X7を左から右、Y2〜Y4を下から上に描き、各芯間を6,000mmと記す。Y2側が既存棟側、Y4側が増築側。Y2沿いのX4〜X7に既存車路を二本の実線で描き、線間に「有効幅 3.6m」と記す。X5〜X6のY2既存棟側に荷さばき面を描き、車路に面する間口を一点鎖線で示す。

検品者通路は車路の既存棟側をX6側からX7側へX方向に沿って進み、X7-Y2で既存棟側へ直角に折れてY2から離れる向きに延びる、連続した二本の破線で描く。折れの外側に既存区画柵、折れの近くにX7-Y2の柱を示す。破線を車路の幅線と混同しない。凡例は実線＝車路の幅、一点鎖線＝荷さばき間口、破線＝検品者通路。

## 区画割りの条件

車路有効幅3.6mと検品者通路の折れ・連続を残す位置で区画を検討する。荷さばき面と検品者通路を同時に塞がない。既存業務の停止は閉鎖準備・復旧確認を含め週合計6時間以内。平日16:00〜19:00は検品・出荷が集中するため避ける。

4月15日の原田様・坂本様・青木様の協議条件による。具体的な停止日や区画線は本図では決めていない。
