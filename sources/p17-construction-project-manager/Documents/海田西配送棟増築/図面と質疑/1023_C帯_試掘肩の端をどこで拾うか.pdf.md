# C帯　試掘肩の端をどこで拾うか
文書番号：MB-KN-2024-QT-005
工事名：海田西配送棟増築／2024年10月23日／作成：坂本修一郎／宛先：藤井正和
版：Rev0／資料区分：数量照合用／縮尺：模式図

## 通常底と局部形状の関係
X6〜X7間のC帯を横断して見た模式図。地表から下に幅5.00m、深さ2.60mの矩形を描き、「通常断面」とする。その底の中央付近に、底線を上辺とする幅未確認の矩形を模式的に描き、通常底からさらに下へ1.50mの寸法を付ける。矩形の両側と底は破線とし、「局部形状：横方向の範囲未確認、形は模式」と記す。通常断面とその底より下の局部形状は別々の塗りで区別し、両者を区切る通常底線を残す。幅5.00mの寸法線と、通常深さ2.60m、追加深さ1.50mの寸法線を分ける。基準高はX4-Y3既存床±0.00m。図は数量拾いの関係を示すもので、実測形状や局部幅の確定値ではない。

## 端部の拾い範囲
帯の距離程はY4から増築側2.00mの線を0mとし、通常帯の終端を30mとする。通常帯を0〜30mの帯として示し、末端付近の局部形状の候補範囲を、始点・終点とも未確定の破線で重ねて描く。破線の始点を特定の距離程に合わせず、「端部の実長未確認」と添える。局部の範囲が通常帯の末端と重なる関係は示すが、重なりの長さを確定しない。

藤井さん、通常帯は5.00×2.60×30＝390m³で見ています。局部は通常底から下の増深分を別に拾う前提です。端部の実長と横方向の範囲を現地で確かめ、通常帯と増掘部の境界を拾い時に確認してください。局部の数量は範囲確認後に算出します。Y4柱際の保留区画は対象に含めません。
