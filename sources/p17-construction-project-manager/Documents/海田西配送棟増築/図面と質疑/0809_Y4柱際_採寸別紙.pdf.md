# Y4柱際　採寸別紙

工事名：海田西配送棟増築  
文書番号：MB-KN-2024-IN-041　版：初版  
発行日：2024年8月9日  
宛先：白島設計室　小野 幸子 様  
作成：湊梁建設株式会社　坂本 修一郎  
現地採寸：8月5日 青木 美紀子／8月6日 青木 美紀子・西村 英二立会い

7月の照会4件について、採寸した柱面と対象端を下記に示します。位置の参照はS-21 RevA。寸法は柱面から外向きの水平距離、単位はmmです。X4・X5は床墨までと床墨から測定端までの読みを足し、柱北面起点にそろえました（MB-KN-2024-RF-002 Rev1）。

| 質疑／通り芯 | 起点・方向 | 現地の測定端と柱面からの実測（mm） | 反対端の実測（mm） | 比較欄・断面で確認したい点 |
|---|---|---|---:|---|
| RFI-24-20／X4-Y4 | 柱北面から北 | 既存基礎肩 310（床墨まで100、墨から肩210） | | S-21 Rev0の図上肩240に対し70外側。柱脚と既存肩の離隔を確認願います。 |
| RFI-24-21／X5-Y4 | 柱北面から北 | 既存土間端 205（床墨まで80、墨から土間端125） | | A-32 Rev0の旧仮切断線250より45柱寄り。切断線と補強範囲の関係を示してください。 |
| RFI-24-22／X6-Y4 | 柱東面から東 | 防護柵ベース手前縁 165（床墨100） | | 柵脚と養生で奥縁に当てられず、反対端は未測定。図上のアンカーとの比較に必要な測定端をご指定ください。 |
| RFI-24-23／X7-Y4 | 柱北面から北 | スリーブ手前口縁 265（床墨100） | | 保護材で反対口縁が見えず未測定。現況の芯は未確定。基礎立上りとの取合いに必要な測定端をご指定ください。 |

X4・X5の反対端欄は対象外。X6・X7の空欄は未測定です。返送断面は、どの柱面を寸法のゼロに取るかを明示し、床墨、実測の端、図上の位置を区別してください。別の起点を使う場合は柱面からの振りを併記願います。片側の値で判断できない箇所は、その旨と再測箇所を記載してください。

8月19日までに断面の返送をお願いします。現地照合と回答がそろうまでは4交点の保留を継続します。
