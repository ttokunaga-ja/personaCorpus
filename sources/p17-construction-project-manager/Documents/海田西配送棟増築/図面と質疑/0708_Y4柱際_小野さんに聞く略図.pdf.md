# 柱際の照会メモ（2ページ）

## 1ページ

手書きの題「Y4 柱際　小野さん確認　7/8」。左にX4-Y4、右にX5-Y4の平面略図。各図に柱芯を十字で入れ、「Y4」「増築側」の向きを書く。

左図：柱脚と照会図上の既存基礎端を破線、現地で測った既存基礎端を実線で並べる。照会図上の端から外へ現地の端まで矢印を引き「+70mm」と記す。「RFI-24-20　柱脚との離隔？」「基礎の出る側と納まりを再照合」「掘削・型枠は待つ」と書く。張出しと柱脚の取合いは未確定。

右図：仮切断線と既存土間端を別々の線で描く。仮切断線から柱側の既存土間端へ寸法矢印を渡し「45mm　土間端は仮線より柱寄り」と記す。「RFI-24-21　切断線をどちらに動かす？ 補強に当たらないか」「柱際の土間切断は待つ」と書く。切断線の変更方向と正式位置は未確定。

## 2ページ

題「Y4 柱際　つづき」。左にX6-Y4、右にX7-Y4の平面略図。各図に柱芯と増築側の向きを記す。

左図：既設防護柵のベース外形と図上の新設アンカー照合点を十字で描く。ベース縁から十字へ寸法矢印を引き「35mm 暫定」と記す。「RFI-24-22　アンカーをどちらへ納める？ 柵との取合い確認」「穿孔は待つ」と書く。アンカーの移動方向は未確定。

右図：旧図のスリーブ心と現地の開口心を別の印で描き、旧図心から増築側の開口心へ矢印を引いて「60mm 暫定」と記す。「RFI-24-23　西村さん再照合、基礎立上り断面はどちらへ逃がす？」「この柱際の打設は待つ」と書く。断面の納まり方向は未確定。

2枚とも手書きの線と文字が読める紙の控え。余白に折れや軽い傾きがある。
