# 設備取合い

海田西配送棟増築｜M-31 Rev0｜2024年5月16日｜白島設計室 小野幸子｜照会用・縮尺なし
宛先：湊梁建設 西村英二様、坂本修一郎様

## 平面

X4〜X7を左から右、Y2〜Y4を下から上に置き、芯間は各6,000mm。Y2側を既存棟、Y4側を増築側と記す。Y2沿いに既設の照明（X4-Y2）、呼出し線（X6-Y2）、誘導灯（X7-Y2）を実線で示し、各名称を引き出す。Y3側に新設配線ラック（X5-Y3）と換気ダクト（X6-Y3）を破線で概略表示する。実線＝既設、破線＝新設の未調整経路と凡例に記す。

X5-Y2の点検口を矩形で示す。矩形のX4側端を共通の仮の回転軸として、扉を既存棟側（Y2からY番号の小さい側）へ開く四分円と、増築側（Y番号の大きい側）へ開く四分円をそれぞれ点線で描き、「開閉側候補・未定」と付ける。この軌跡は比較用で、開閉側の決定ではない。ラックとの干渉を含め開閉側と必要な空間を照会する。

## 照会事項

既設照明と誘導灯の機能を切替え時にも維持する段取り、呼出し線の切替え前の確認方法を示してください。新設ラックとダクトの経路・支持位置、点検口の開閉側を既設との取合いで確認します。図の経路は概略であり、未調整部分を確定寸法や施工指示として扱わないでください。
