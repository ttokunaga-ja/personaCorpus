# 既設機能を残す設備取合い 回答

海田西配送棟増築／HS-KN-24-R02／2024年6月20日／白島設計室 小野幸子
宛先：湊梁建設 西村英二様、坂本修一郎様
参照：設備取合い M-31 Rev0（2024年5月16日）／縮尺なし

M-31 Rev0への照会のうち、下記6件に回答します。既設系統を維持しながら新設側を準備してください。切替えを伴う停止の実施は別途、施主の個別確認を受けてください。

| 質疑 | 通り芯 | 回答・設備段取り |
|---|---|---|
| RFI-24-08 | X4-Y2 | 照明の既存点灯を維持したまま、切替えに先立って別系統で新設側を準備する。 |
| RFI-24-09 | X5-Y2 | 点検口は増築側から開閉できる向きとし、開閉に必要な範囲を設備で塞がない。 |
| RFI-24-10 | X5-Y3 | 配線ラックはY3の増築側に吊る。点検口の開閉範囲と取合いを確認して支持位置を定める。 |
| RFI-24-11 | X6-Y2 | 呼出し線は既存接続を切る前に新側の導通を確認する。確認後に切替え手順を調整する。 |
| RFI-24-12 | X6-Y3 | 換気ダクトは柱を貫通させず梁下を通す。ラックとの取合いを現地で確認する。 |
| RFI-24-13 | X7-Y2 | 誘導灯は新灯の点灯確認まで既存灯を残す。確認前に既存灯を撤去しない。 |

以上を設備の段取りに反映願います。照会図の未調整経路を確定寸法として扱わず、支持位置等は取合いを確認してください。
