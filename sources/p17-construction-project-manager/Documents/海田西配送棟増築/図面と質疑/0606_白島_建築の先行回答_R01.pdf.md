# 建築質疑 先行回答
海田西配送棟増築｜HS-KN-24-R01｜2024年6月6日｜白島設計室 小野 幸子｜回答・縮尺なし
宛先：湊梁建設 坂本修一郎・太田知美

既存動線と土間・建具に関する下記7件について回答します。施工区画はA-11 Rev1、土間・建具はA-32 Rev0の該当位置と照合してください。

| 質疑 | 参照図・位置 | 照会事項 | 回答・施工条件 |
|---|---|---|---|
| RFI-24-01 | A-11 Rev1・X4-Y2 | 仮囲い端と車路 | 仮囲いを作業側へ寄せ、既存車路の有効幅3.6mを維持する。 |
| RFI-24-02 | A-11 Rev1・X5-Y2 | 荷さばき面の境 | 荷さばき・検品の間口を残す位置に区画する。 |
| RFI-24-03 | A-11 Rev1・X7-Y2 | 検品者通路の折れ | 既存の折れ位置と通路の連続を維持する。 |
| RFI-24-04 | A-32 Rev0・X4-Y3 | 土間打継ぎ | Y3で新旧土間を区分する。 |
| RFI-24-05 | A-32 Rev0・X5-Y3 | 見切り天端 | 既存床±0を基準とする。 |
| RFI-24-06 | A-32 Rev0・X6-Y2 | 搬送開口 | 有効幅2,400mmを維持する。 |
| RFI-24-07 | A-32 Rev0・X7-Y3 | 建具の開き勝手 | 扉は増築側へ開く。 |
