# 北壁と設備外形の幅合わせ

工事名：海田西配送棟増築  
図番：MB-KN-2025-ZP-071　Rev0  
作成日：2025年7月22日  
作成者：坂本修一郎  
用途：小野幸子氏との照合用　模式図　単位：mm

## 横断図（南から北）

Y3から北向きをyとする。共通の床線上に南基準墨y=1,000、設備南端y=1,300、Rev A北端y=3,120、Rev B北端y=3,340、北間仕切り南仕上面y=4,420を順に示す。南端を共通に旧・改訂外形を重ね、旧北端と改訂北端を線種と文字で区別する。南基準墨は床上の墨であり壁ではない。

寸法線は以下を別々に示す。

- 南基準墨から設備南端：300。
- 設備南端から旧北端：1,820。旧北端から壁仕上面：1,300。
- 設備南端から改訂北端：2,040。改訂北端から壁仕上面：1,080。
- 旧北端から改訂北端：220（ガード込み外形の増加、通路の減少）。
- 必要幅1,200と改訂後幅1,080の差：120不足。220の外形増加とは別の寸法線とする。

参照：Merecairn General Arrangement Rev B、MB-KN-2025-RF-007 Rev1。最小測点の南基準墨から壁仕上面まで3,420を用いた図上照合。従来向きのままでは必要有効幅を満たさない。設備は据付前。
