# Y4から増築側の測点控え
海田西配送棟増築｜MB-KN-2024-QT-002｜2024年10月16日｜坂本修一郎｜初版・照合用・模式図

## 位置図
X4、X5、X6、X7を左から右に6.00m間隔で描く。Y3・Y4を横線で示し、Y3を既存棟側、Y4の向こうを増築側とする。X4-Y3の既存床に基準高±0.00mを示す。Y4上のX4・X5・X6・X7柱際にそれぞれ区画囲いを付け「拾い対象外・保留」と記す。

Y4から増築側2.00mの線を0mとして、増築側へ30m伸びる3本の帯を、X4〜X5にA、X5〜X6にB、X6〜X7にCと配置する。各帯に0・15・30mの横断線とA00・A15・A30、B00・B15・B30、C00・C15・C30の測点名を記す。X芯間の6.00mは芯間寸法であり拾い幅ではない。矢印で増築側を示す。

この図は測点名と基準を揃える照合用。設計図・施工指示ではない。Y2の業務車路を塞がず、柱際の保留表示を維持する。
