# 変更説明・協議記録

海田西配送棟増築　CO-014 費用と追加作業の協議録

## 設計条件
小野：旧Y3直進18mはX5-Y3の既設雨水管との離隔が80mmで、必要な200mmに不足する。D-41 RevAはP1からY4へ迂回しM2・M3を経てM1へ戻る30m、D-42 RevAは接続高さと勾配を示す。既設雨水管を移さず、浅埋設もM1の接続高さと勾配を保てないため採らない。

## 数量と費用
藤井：新設掘削は管路54.0m³に桝部の増し掘り6.0m³を加え60.0m³。桝1基の総掘削6.6m³から管路重複3.6m³を除き3.0m³、2基で6.0m³となる。新設7費目2,230万円から未施工の旧案取りやめ3費目370万円を控除し、税抜1,860万円。消費税186万円、税込2,046万円。MB-KN-2026-QT-014第1版の数量根拠とMB-KN-2026-CO-014第1版を用いて説明した。

## 確認・決定
原田：税抜1,860万円の変更費用と追加作業6稼働日を承認する。最終引渡しの見込みは施工順を精査してから説明を受ける。

坂本：6稼働日を逐次に置いた比較は示したが、工程内での吸収は未決。比較上の日付を最終引渡し日として扱わず、施工順と作業面を検討する。
