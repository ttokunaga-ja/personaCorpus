# 五箇所の作業区画と残す動線
工事名：海田西配送棟増築　図番：MB-KN-2026-ZP-022 Rev0  
2026年9月15日　作成：坂本修一郎　配布：青木美紀子・岡本哲夫・西村英二　状態：残工事調整用・模式図

## 全体図
X4・X5・X6・X7を左から右、Y2・Y3・Y4を下から上に配置する。芯間はいずれも6m。Y2の外側を既存営業車路、内側を増築側と示す。Y2沿いにX4側からX7まで連続する実線の矢印を描き「営業車路を維持」。X7-Y2東寄りで既存検品者通路の折れを実線で連続させ、「検品者通路・折れを維持」と記す。作業面は境界の増築側だけを斜線で囲み、番号を記入する。

| 指摘 | 図中の斜線範囲 | 作業 |
|---|---|---|
| KN-08 | X6〜X7/Y3の鋼製扉下 | 枠脚側を含む充填 |
| KN-09 | X7-Y3の床目地 | 段差の手直し |
| KN-16 | X4-Y4のM3蓋の外の復旧面 | 沈みの復旧 |
| KN-22 | X6〜X7/Y2の増築側盤前 | 回路表示と照合 |
| KN-27 | X7-Y2東寄り、仮柵返しの内側 | 恒久端部取付 |

凡例：斜線＝残工事の作業区画、連続線矢印＝残す動線、折れ線＝仮柵。図は位置関係を示し、作業区画の寸法や通路幅を決めるものではない。

## 拡大 A：M3（X4-Y4）
閉じた蓋を円、受枠を外周線で描く。円の外側に接する復旧面の一部を斜線で囲み「KN-16 復旧面の沈み・蓋の外」と記す。蓋の内部や埋設管を作業範囲に含めない。

## 拡大 B：X7-Y2東寄り
既存検品者通路の折れを連続線で示し、その増築側に折れ曲がる仮柵を描く。柵の内側に斜線と「KN-27 恒久端部取付面」、外側に「既存検品者通路・材料を置かない」。返しを恒久端部取付と現認まで残す。青木は区画を維持し、岡本は取付面を確保する。

参照：指摘一覧 MB-KN-2026-PL-021 Rev1。個々の区画を戻す条件は残工事条件書 UC-021 による。
