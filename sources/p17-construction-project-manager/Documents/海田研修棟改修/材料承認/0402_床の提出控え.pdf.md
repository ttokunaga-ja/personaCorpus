# 床材料 提出控え
工事名：海田研修棟改修　文書番号：MB-KT-2026-MS-001　版：Rev0
提出日：2026年4月2日　提出：三浦正博　宛先：太田知美

床材、接着材と見切りの8件を提出します。荷姿の表示と現物で見る項目を分けています。受付後、小野さんとの照合に回してください。

|番号|材料・適用箇所|提出票・荷姿で確認する表示|現物で確認する項目|
|---|---|---|---|
|M-01|タイルカーペット／西研修室 X1〜X2・Y2〜Y3|提出票の寸法450 mm角、梱包の品名・寸法|色、織り方向、一辺。設計は500 mm角で50 mm不足|
|M-02|床用接着剤／西研修室 X1〜X2・Y2〜Y3|適用床材、容量、使用期限|容器表示の照合|
|M-03|床見切り／西研修室 X1〜X2・Y2〜Y3 出入口|材質、長さ、適用床厚|断面、色、床との段差|
|M-04|長尺床シート／西演習室 X2〜X3・Y2〜Y3|品名、幅、厚さ|色、表面の仕上げ|
|M-05|床シート用接着剤／西演習室 X2〜X3・Y2〜Y3|適用シート、容量、使用期限|容器表示の照合|

|M-07|下地補修材／東演習室 X6〜X7・Y2〜Y3|用途、容量、使用期限|容器表示の照合|
|M-08|端部押さえ／東演習室 X6〜X7・Y2〜Y3|材質、長さ、適用床厚|断面と端部の押さえ幅|

M-01は提出票と現物がともに450 mm角です。既存床との割付に影響するため、500 mm角の設計要求との違いを小野さんに確認してください。現物を受け取ったことは設計承認を意味しません。
