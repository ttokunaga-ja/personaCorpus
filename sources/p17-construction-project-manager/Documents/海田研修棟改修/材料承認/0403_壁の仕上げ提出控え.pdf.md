# 壁仕上げ 提出控え
工事名：海田研修棟改修　文書番号：MB-KT-2026-MS-002　版：Rev0
2026年4月3日　提出：三浦正博　宛先：太田知美

色票は塗装・壁紙の色と表面を見るためのものです。吸音壁パネルは布片を実物として添えています。基材の規格や適用は提出票で確認してください。

|番号|材料・適用箇所|提出票で照合する内容|現物・色票で見る内容|
|---|---|---|---|
|M-09|壁用上塗り／西研修室 X1〜X2・Y2〜Y3|上塗りの種類と適用下地|塗装色票の色・つや|
|M-10|壁用下塗り／西研修室 X1〜X2・Y2〜Y3|下塗りの種類と上塗りへの適合|容器表示|
|M-11|掲示面の壁紙／西研修室 X1〜X2・Y2〜Y3|壁紙の規格と基材|紙色票の色・表面|
|M-12|吸音壁パネル／中央研修室 X3〜X4・Y2〜Y3|パネルの基材・規格|指定は淡灰布、提出布片は濃灰。布目・色を同じ照明で比較|
|M-13|吸音パネル下地材／中央研修室 X3〜X4・Y2〜Y3|下地材の規格とパネルとの組合せ|断面と取付面|
|M-14|吸音パネル端部見切り／中央研修室 X3〜X4・Y2〜Y3|材質・適用厚|断面と表面の仕上げ|
|M-15|壁用上塗り／東研修室 X5〜X6・Y2〜Y3|上塗りの種類と適用下地|塗装色票の色・つや|
|M-16|壁下地調整材／東研修室 X5〜X6・Y2〜Y3|用途・適用下地|容器表示|

M-12は色が指定と異なるため、淡灰の基準布と提出された濃灰布を同じ照明で合わせて確認してください。壁には貼らず、色票や写真だけで実布を代用しないようお願いします。
