# 電気材料 提出控え
工事名：海田研修棟改修　文書番号：MB-KT-2026-MS-004　版：Rev0
提出日：2026年4月7日　記録：西村英二　宛先：太田知美

三篠電設の田村さんから受けた8件をまとめました。化粧面の見本と、壁内寸法・取合いの資料は分けてお渡しします。差のある2件は設計との照合に回してください。田村さんへの確認は西村が引き取ります。

|---|---|---|---|---|
|M-25|東研修室 X5〜X6／Y2〜Y3 照明器具|LED、AC100 V、幅125 mm・長さ1,250 mm|仕様票と取付図で電源・取付寸法|西村|
|M-26|同 壁スイッチ本体|片切、15 A・300 V、1個用|仕様票・寸法図で定格とプレート適合|西村|
|M-27|同 壁スイッチ化粧プレート|1個用、つやありアイボリー。指定はつや消し白|化粧見本と基準片で色・つや|西村|
|M-28|東演習室 X6〜X7／Y2〜Y3 コンセント本体|接地極付2口、15 A・125 V、1個用|仕様票・寸法図で定格と取付寸法|西村|

|M-31|中央演習室 X4〜X5／Y2〜Y3 壁配線ボックス|開口面から内底まで有効42 mm。必要55 mm以上に対し13 mm不足|寸法資料と取合い図で器具裏・壁内背面・引込み|西村|
