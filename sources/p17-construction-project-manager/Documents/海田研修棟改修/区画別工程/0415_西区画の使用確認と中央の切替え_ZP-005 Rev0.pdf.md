# 西を開けてから中央を閉める
海田研修棟改修　MB-KT-2025-ZP-005 Rev0　2025年4月15日
作成 坂本修一郎　宛先 青木美紀子・西村英二・福田裕次　状態：切替え照合用・模式図

## 南扉側の照合
北を上にX1〜X5を西から東へ並べ、Y2〜Y3に西研修、西演習、中央研修、中央演習を描く。各室Y2側の南扉を開口と円弧で示し、南側Y1〜Y2を南廊下として描く。西入口から廊下を東へ通す矢印を引き、図の右端に「東避難出口へ連続」と記す。X3およびX5に区画境界を描き、Y2側の端は扉の内側に納める。

西研修室の扉に「清掃・照明・空調・投影音声」、西演習室の扉に「清掃・照明・空調」の引出しを付ける。中央側南扉の室内側に待機線を置き「西2室の使用可を記録するまで中央を閉じない」と引き出す。南廊下と東出口の通行、南北動線の分離、予約と案内も確認する。

凡例：太い実線＝壁、開口と円弧＝南扉、長い破線＝X3・X5の区画境界、短い点線＝中央を閉じる前の待機線、実線矢印＝南廊下の通行方向。

## 判定と切替え
西が未判定または不可：中央2室と現掲示・予約先を維持し、中央の施工に着手しない。西が可：中央を開けたまま案内と予約先を西に移し、それから中央を閉める。予約枠外で行う。切替日は未定。
