# 掲示前に見る南廊下の案内図
海田研修棟改修　MB-KT-2025-ZP-003 Rev0　2025年4月14日
作成 青木美紀子　宛先 原田裕実・中川美由紀　状態：印刷前の案・模式図

## 南廊下と表示面
北を上にX1〜X7を西から東へ並べる。Y1〜Y2の南廊下を横帯に、Y2〜Y3の6室を上に描き、左から西研修・西演習・中央研修・中央演習・東研修・東演習と室名を入れる。各室のY2側に南扉を示す。西入口から廊下を通り東避難出口まで通過する線を引き、その線から各南扉への枝をそれぞれ出す。

廊下を塞がない壁面の候補として、X1付近に①、X3付近に②、X5付近に③を置く。番号を壁面の外に引出し「表示面候補」と記す。通過線や扉の開きと重ねない。

凡例：太い実線矢印＝西入口から東避難出口への通過線、細い破線矢印＝通過線から各南扉への枝、開口と円弧＝南扉、丸数字①〜③＝表示面候補。通過線は避難出口まで連続させる。

## 欄外の表示候補
I・II：中央研修室／中央演習室。III：西研修室／西演習室。II→IIIは西の使用可を確認し、中央を維持したまま表示を移す。原田さん・中川さんに表示内容と壁面を確認いただいた後に印刷する。日付は未定。
