# 北側で運ぶ範囲
海田研修棟改修　MB-KT-2025-ZP-004 Rev0　2025年4月14日
作成 青木美紀子　宛先 岡本哲夫・福田裕次　状態：作業側調整用・模式図

## 北サービス通路
北を上にX1〜X7を西から東へ並べ、Y3〜Y4を北サービス通路の帯として描く。帯の南側にY2〜Y3の六室を西研修・西演習・中央研修・中央演習・東研修・東演習の順で置き、各室のY3側に作業用扉を開口と開きの円弧で示す。帯の中に作業側の矢印を描き、扉対をI＝X1〜X3の西、II＝X5〜X7の東、III＝X3〜X5の中央と番号で示す。同時に選ぶ扉は各回の施工対象の2室のみ。

南側にはY1〜Y2の南廊下を細い帯で描き「利用者側・資材を出さない」と記す。東端には東避難出口を示し「出口前は通行と避難を妨げるため使用しない」と引き出す。常設予定のない仮置きは描かない。

凡例：破線矢印＝北通路の作業側動線、開口と円弧＝各室の作業用扉、I・II・III＝各回に選ぶ扉対、実線＝壁。Y3〜Y4の1,800 mmは芯寸法で、有効幅ではない。運搬前に現地で有効幅と扉の開閉を照合する。境界はKT-A-12 RevAを参照。
