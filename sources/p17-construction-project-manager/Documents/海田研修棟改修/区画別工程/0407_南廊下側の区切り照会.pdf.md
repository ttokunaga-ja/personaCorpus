# 南廊下側の区切り照会
工事名：海田研修棟改修　文書番号：MB-KT-2025-ZP-001　Rev0
2025年4月7日　作成：坂本修一郎　宛先：白島設計室 小野幸子 様
参照：既存平面 KT-A-01 Rev0　状態：照会用　縮尺：模式図

## 平面
上を北とし、X1〜X7を西から東へ等間隔に並べる。Y1〜Y4を南から北へ置き、Y2〜Y3に6室を一列に描く。X1〜X2西研修室、X2〜X3西演習室、X3〜X4中央研修室、X4〜X5中央演習室、X5〜X6東研修室、X6〜X7東演習室。X3とX5に西・中央・東の3対を分ける境界の破線を引く。各室のY2側に受講者用扉、Y3側に作業用扉を示す。

Y1〜Y2の南廊下に、西出入口から東避難出口までの連続した利用者動線を矢印付き実線で示す。Y3〜Y4の北サービス通路に作業動線を矢印付き一点鎖線で示す。X3・X5のY2側で仕切りが廊下側に出るおそれのある端点を丸で囲み、引出しに「端部の納まり要確認」と記す。

## 照会
小野様、X3・X5の区画境界を設ける場合、Y2側扉の周囲で仕切り端を室内側に収め、南廊下を西入口から東避難出口まで連続して残せるでしょうか。東避難出口前に仮置きしない場合の納まりをご確認ください。4月7日午後に現地を見たうえで、4月8日にご回答をお願いします。

凡例：破線＝区画境界の照会位置、実線矢印＝利用者動線、一点鎖線矢印＝作業動線、丸＝端部照会箇所。芯間は既存平面による。仕切り位置は未確定。
