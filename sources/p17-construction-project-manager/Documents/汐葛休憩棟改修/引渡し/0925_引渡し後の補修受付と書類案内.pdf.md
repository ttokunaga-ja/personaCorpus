# 引渡し後の補修受付と書類のご案内

工事名：汐葛休憩棟改修  
文書番号：MB-SK-2025-HO-002　第1版  
文書日：2025年9月25日  
宛先：汐葛食品株式会社　工場管理　和田 英里 様  
作成：湊梁建設株式会社　坂本 修一郎

和田様

9月26日の残指摘の確認を経て、同日に引渡しが成立することを前提に、引渡し後の連絡先と補修受付についてご案内します。指摘10・11の施主確認および書類と鍵の受領は、現時点ではこれからの予定です。

## 不具合のご連絡

引渡し後に不具合がありましたら、まず坂本がご連絡を受けます。場所、症状、気付かれた時期と、使用に支障があるかをお知らせください。設備に関する内容は西村が確認し、必要な対応を坂本からご連絡します。

## 無償補修の受付

施工に起因する不具合の無償補修受付期間は、2025年9月26日から2026年9月25日までです。通常の清掃および使用による損耗は対象外です。原因や対象となるかの判定が必要な場合は、現場を確認したうえで回答します。

## 書類について

引渡し書類の再送が必要な場合も坂本へお知らせください。書類の確認と再送は工務担当の太田が扱います。書類名や文書番号がお分かりの場合は併せてお知らせください。
