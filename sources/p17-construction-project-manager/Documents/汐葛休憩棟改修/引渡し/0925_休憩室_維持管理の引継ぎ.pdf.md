# 休憩室　維持管理の引継ぎ

工事名：汐葛休憩棟改修  
文書番号：MB-SK-2025-IN-004　第1版  
文書日：2025年9月25日  
宛先：汐葛食品株式会社　工場管理　和田 英里 様  
作成：湊梁建設株式会社　設備主任　西村 英二

和田様

休憩室1〜3の使用にあたり、換気と点検口、収納引手の日常の取扱いをお伝えします。作業が必要な場合や状態の判断に迷う場合は、無理に操作せず坂本へご連絡ください。

## 換気の停止と点検口

- 休憩室1〜3のいずれも、換気を停止する前に、その室の利用状況と停止の必要性を確認してください。利用中の場合は関係者に知らせ、再開の時期を調整してください。
- 点検口を開ける必要があるときは、直下の人や物を移し、床と周囲の物を汚損しないよう養生してください。開放中は直下への立入りを避け、点検操作は西村にご相談ください。
- 休憩室3のX3-Y2の換気点検口脇では、9月19日に掲示した仮札を、恒久点検札「SK-V3」に切り替える予定です。指摘11の現物確認は9月26日10時に和田様・坂本・西村で行います。確認前のため、本書では是正確認済みとしていません。

## 収納引手の清掃

引手は柔らかい布で汚れを拭き取り、落ちにくい汚れも表面を傷つけないよう清掃してください。研磨材でこすらず、がたつきや表面の異常を見つけた場合は状態を坂本へお知らせください。休憩室3のX3-Y1の引手交換は、仮使用条件確認書 MB-SK-2025-UC-001 第1版に基づき9月25日15時〜16時に行い、翌26日10時に確認する予定です。

## 異音などの連絡

換気中に普段と異なる音や振動に気付いた場合は、発生した部屋、気付いた時刻と状態を控え、坂本にご連絡ください。設備の内容は西村が確認します。停止や点検が必要かは状況を確認して相談します。
