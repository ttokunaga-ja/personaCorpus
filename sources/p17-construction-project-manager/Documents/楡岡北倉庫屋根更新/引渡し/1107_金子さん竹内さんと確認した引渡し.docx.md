# 変更説明・協議記録

件名：楡岡北倉庫屋根更新　引渡し確認

## 照合した内容

契約対象は屋根本体1,480m²で、南の荷さばき庇は対象外。竹内の施工報告で10月31日の12区画の更新・端部仕上げ完了を確認した。

午前8:45〜11:20の散水について、屋根側の竹内と屋内側の金子・坂本で、位置図 MB-NK-2024-ZP-002 Rev0 と記録 MB-NK-2024-IN-001 Rev0 のA1〜C4を照合した。各区画の漏水は0件、合計も0件。B3はX4寄りの梁と重ね目を屋内から確認した。9月26日の降雨によるB3の仮閉じ・B4未開放は工事中の措置であり、今回の散水確認と区別して説明した。

## 書類受領

金子さんが次の3点の番号と版を照合し、14:35に受領。施設課の受領票 NW-NK-2024-RC-001 に記載した。

- 坂本：当初工程 MB-NK-2024-SC-001 Rev0 を旧版として残す。雨天後の工程 Rev1 と取り違えない。
