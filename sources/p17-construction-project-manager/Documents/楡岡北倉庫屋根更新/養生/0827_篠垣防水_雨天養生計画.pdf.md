# 雨天養生計画

工事名：楡岡北倉庫屋根更新
文書番号：SG-NK-2024-WP-001　Rev0　発行日：2024年8月27日
提出先：湊梁建設株式会社 坂本修一郎 様
作成：篠垣防水株式会社 施工部 竹内美加

## 対象と順序

契約対象の屋根本体をA1〜C4の12区画に分ける。南帯A、中央帯B、北帯Cの順に進め、各帯は西から東へ1、2、3、4とする。南側の荷さばき庇は施工対象に含めない。

同時に開放するのは1区画まで。当日中に仮養生を閉じられる範囲を見て着手する。隣の区画は開放中の面を閉じてから進める。

## 場合ごとの対応

| 状況 | 竹内・屋根側 | 坂本・青木／直下側 |
|---|---|---|
| 開放前 | 区画と当日の閉じの見込みを坂本へ連絡する | 坂本が青木と直下を確認し、対象区画を共有する |
| 雨が近い朝 | 新たな面を開けず、見送りを坂本へ連絡する | 受けた区画と見送りを青木へ共有する |
| 作業途中で降雨などにより停止 | 開放面を仮閉じし、屋根端部を確認。閉じた区画と状態を坂本へ報告する | 坂本が青木と当該区画の直下を目視する |
| 停止後の再開前 | 仮養生の端部と屋根面の状態を確認し、坂本へ伝える | 坂本・青木が直下を確認し、屋根側の報告と合わせて坂本が再開を判断する |

## 連絡

開放前の予定連絡と、停止後の閉じ・端部の報告を分ける。直下の確認結果を受けるまで次の区画を開けない。9月4日の着工打合せで、竹内から屋根側の確認を説明し、坂本・青木と直下側の受け渡しを確認する。
