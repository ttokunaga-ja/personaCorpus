# 現場日報　B3からの再開

工事名：楡岡北倉庫屋根更新  
文書番号：MB-NK-2024-DR-001 Rev0  
作業日：2024年10月3日  
作成：坂本 修一郎  
共有先：竹内 美加、青木 美紀子

## 中断から朝の確認まで

9月26日9時40分の降雨でB3の更新を止め、10時12分に仮閉じした。B4は開けず、10月2日まで屋根の更新作業を中断した。26日11時に青木とB3直下を見た範囲では滴下なし。

今朝は雨が止んだ後、確認票 MB-NK-2024-CK-001 Rev0 の位置を竹内さん、青木さんと分担して確認した。

| 確認箇所 | 担当 | 朝の所見 |
|---|---|---|
| B3の養生端、X3〜X4・Y2〜Y3 | 竹内 | 端の浮き・固定の外れなし。南側X3寄りの取合いを8時24分に撮影 |
| B3屋根面と隣接面 | 竹内 | 残水なし。作業に支障となる濡れなし |
| B3直下の梁・屋根下 | 青木 | 目視範囲に滴下・濡れなし |
| B4 X4〜X5・Y2〜Y3 | 竹内 | 既存屋根は未開放のまま |

## 判断と作業順

8時40分、坂本が上記の屋根側・直下の所見と雨が止んだ後の予報を確認し、B3から再開可と判断した。9時にB3から作業を再開。B4は同時に開けず、B3を閉じた後に進める。引き続き天候を見て、当日中に閉じられる範囲で進める。

竹内さんは閉じと端部を確認し、状況を坂本へ連絡。青木さんは直下の状態を確認する。工程日付は別途組み直して関係者に知らせる。
