# 楡岡北倉庫屋根更新　雨天養生の打合せメモ

文書番号：MB-NK-2024-MT-001　Rev0
協議日時：2024年8月22日 14:00　作成日：2024年8月22日
出席：篠垣防水株式会社 竹内美加、湊梁建設株式会社 坂本修一郎
宛先：竹内美加、青木美紀子　作成：坂本修一郎
対象：屋根本体 A1〜C4、南庇との境

## 話したこと

南庇では荷さばきが続く。屋根本体を開けたまま雨に遭わないよう、作業の単位と閉じる時の連絡を先に決める。隣り合う2区画を朝から開ける案は、同じ日に両方を閉じ切れない場合があるため採らない。

## 決めたこと

- 施工は南帯A、中央帯B、北帯Cの順。各帯は西から東へ1〜4の順に進める。
- 同時に開放するのは1区画までとし、当日中に閉じ切れる範囲だけを開ける。雨が近い朝は開放を見送る。
- 開放前に竹内から坂本へその日の区画と閉じる見込みを連絡する。坂本は青木と直下を確認し、作業面の下を共有する。
- 作業中に停止するときは、竹内が開放面の仮閉じと屋根端部を確認し、停止後に坂本へ閉じた区画と状態を連絡する。坂本は青木とその直下を確認する。開放前の連絡と停止後の報告は別にする。
- 既存の南庇は今回の対象外。荷さばきに影響する荷の移動が必要な日は施設課へ事前に知らせる。

## 次の確認

竹内は上記を雨天養生計画に整理して坂本へ提出する。坂本は9月4日の着工打合せで青木・金子を交え、屋根側と屋内側の連絡を確認する。
