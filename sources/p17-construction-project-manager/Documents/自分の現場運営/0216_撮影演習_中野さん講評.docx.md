# 撮影演習の講評　位置を言える一枚
工事名：海田西配送棟増築
文書番号：MB-KN-2026-BR-005 Rev0
文書日：2026年2月16日
作成：中野 和弘
宛先：坂本 修一郎、岡本 哲夫、新任監督の皆さん

## 13日の確認
Y3沿いの4地点で3人がそれぞれ撮った初回12枚を、撮影者以外が図に戻して確認しました。8枚は写真の手掛かりから位置を指せました。4枚は初回の画角では位置を特定できず、対象を残して通り芯表示と固定した目印を加えた後、別の受講者が4枚とも図で指せました。初回不明の判定はそのまま残します。

## 位置を示す目印
柱脚の03は保護板の留め方が分かる一方、表示と柱角が画面外でした。03Rでは保護板と留め具を残し、X4・Y3表示と柱の外角を一緒に入れたため、図の柱に戻せました。台車枠の12はL形テープと車輪だけでは似た枠との区別ができません。12Rではそれらに加えてX7・Y3表示のある柱と固定の壁角を収め、位置関係が読めました。

05Rはシートの折り返しにX5・Y3表示と脇の固定床見切りを、07Rは養生吊りにX6・Y3表示と梁の受けを加えています。シートのように動かせる仮設物だけでは、別の地点を除外できません。表示と固定した目印を対象と同時に残してください。

## 次回への申し送り
細部を寄って残したい場合は、まず位置を示す一枚を撮り、その後に寄りを撮って対応を残してください。撮影者が場所を説明する前に別の人が図で確認するまで、二枚を一組として扱います。見た人が場所を指せない場合は、不足する目印を確認して撮り直します。
