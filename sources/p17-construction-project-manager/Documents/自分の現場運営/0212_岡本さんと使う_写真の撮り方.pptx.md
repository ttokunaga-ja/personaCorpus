# スライド1：写真から図に戻る
レイアウト：表題
海田西配送棟増築　新任監督 撮影演習
MB-KN-2026-BR-002 Rev0　2026年2月12日
坂本 修一郎・岡本 哲夫

本文：対象が見えるだけでなく、他の人が場所を図で指せる一枚にする。
発表者ノート：岡本さん、最初に対象を撮る目的と位置を伝える目的の違いを聞いてください。13:30開始、説明は13:40まで。

# スライド2：歩く順と4地点
レイアウト：図
図：Y3を横一直線に描き、左を西、右を東とする。西から X4、X5、X6、X7 の各芯線を交差させる。交点にそれぞれ「柱脚保護板」「養生シートの折り返し」「梁下の養生吊り」「台車の仮置き枠」と記す。地点は模式的な配置で、撮影方向の指定ではない。
本文：3人が各地点で1枚ずつ撮る。足元と周囲の動きに注意し、岡本の誘導で移動する。
発表者ノート：岡本さんは西から順に案内。通路を塞がず、撮影は14:10を目安に切り上げる。

# スライド3：柱脚をどう残すか
レイアウト：左右比較
左図「対象に寄った一枚」：柱脚の保護板と留め具だけを大きく描き、上端で切る。表示も柱角も見えない。
右図「位置を示す一枚」：同じ保護板と留め具を残し、引いて柱の外角と板の上のX4・Y3表示を同じ画角に描く。
本文：対象を見せる寄りは有用。ただし位置を示す一枚と組にする。仮設物だけを位置の唯一の手掛かりにしない。
発表者ノート：「隣の柱脚とどう区別できる？」と聞き、表示と固定した柱角を探してもらう。答えを先に言わず14:15まで。

# スライド4：説明せず図で指す
レイアウト：手順図
1 撮影者が写真を渡す。場所の説明は待つ。
2 別の受講者が写真の芯表示と固定した目印を探す。
3 見る人が図で地点を指し、根拠を言う。中野が判定する。
4 指せない場合は不足を記し、対象を残したまま芯表示と固定した目印を入れ直す。
5 別の人が再び図で確認する。
発表者ノート：岡本さんは「どこに見える？ 根拠は？」と見る側に声をかける。撮影者の補足は判定後。再撮影と再照合は15:10まで、15:30終了。
