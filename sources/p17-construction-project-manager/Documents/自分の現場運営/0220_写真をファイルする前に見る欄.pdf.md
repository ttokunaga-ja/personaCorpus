# 写真をファイルする前に見る欄

文書番号：MB-KN-2026-BR-006　Rev0  
工事名：海田西配送棟増築  
作成日：2026年2月20日  
作成者：坂本 修一郎

岡本さんへ。次の朝礼で、撮った人が当日中に図面と写真を合わせるときの確認に使います。写真を説明してから位置を決めるのではなく、先に別の人が写真と図面を見て位置を指してください。寄りを残すときも、位置が分かる一枚と組にします。

位置の照合：□ 完了　□ 未了

通り芯を読めず照合が終わっていない写真は、根拠候補に回さない。撮影時刻の近さだけで位置を決めない。確認できるまで写真の位置は未確定のままにする。

## 照合が終わらないとき

写真参照：＿＿＿＿＿＿＿＿　不明な点：＿＿＿＿＿＿＿＿＿＿＿＿＿＿

そこで確認する対象・目印：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿  
確認する人：＿＿＿＿＿＿＿＿　予定日：＿＿年＿＿月＿＿日  
確認結果・別に残した記録：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

現場で施工箇所を確認した記録と、元写真の撮影位置を特定した記録は分ける。1月20日のY3の再確認では、X4の基準墨と打継ぎ、X5の柱から一つ目のラック吊り点、X6の梁下ダクトを現場で見た。位置未特定として外した1月の14枚を、その現認だけで根拠に戻さない。

## 朝礼で伝えること

2月13日の演習では、柱脚の保護板には柱表示と外角、台車枠には柱表示と壁角を入れ直した。シートなど動くものだけに頼らず、対象と通り芯表示、固定した目印を一緒に残す。これは日々の写真整理の確認票であり、演習の採点には使わない。
