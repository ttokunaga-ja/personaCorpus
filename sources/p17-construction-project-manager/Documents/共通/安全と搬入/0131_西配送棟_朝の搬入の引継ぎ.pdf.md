# 朝の搬入　引継ぎ

工事名：海田西配送棟増築  
宛先：岡本 哲夫、青木 美紀子  
文書番号：MB-KN-2025-BR-006　版：Rev0  
文書日：2025年1月31日　作成：坂本 修一郎

## 今回の経過

1月22日は第1便のみ、支持金物4パレットを08:17〜08:31に受けた。X6-Y2で08:19に検品台車を先に通した。09時台の受入は行っていない。

1月29日は第1便の追加支持金物4パレットを08:16〜08:32、第2便の床養生材6束を09:12〜09:26に受けた。岡本さんが08:36に仮置き枠を空け、同じ枠を順番に使った。青木さんが立ち会った両便の受入中、営業車との重なりはなかった。これは当日の結果であり、別の日の空きを保証するものではない。

## 次に同じ枠を使うとき

- 岡本さんは08:15〜08:35、09:10〜09:30の枠を使う場合も、その都度、当日の営業車予定を坂本と照合する。予定外の営業車と重なる回は青木さんと見送りを判断する。
- X5〜X6/Y3増築側の仮置き枠は1便ずつ使う。前の荷を片付け、荷ほどき台との使用を分けてから次を受ける。
- 青木さんはX6-Y2の台車とX7-Y2の折れの検品者を確認し、検品者・台車を待たせず先に通す。車が途切れていることだけで歩行者の安全を判断しない。

## 残す確認と判断根拠

干渉08のX6〜X7/Y3、東寄りの予備候補は使用保留。養生幕越しの相互視認と車両の取り回しを、青木さん・福田さんの再照合まで未確認として残す。29日の実績を予備候補の確認には使わない。

1月16日の青木さんの赤入れ図と、08:15〜09:00にまとめた見送り1便案は判断根拠として保管する。1便案は08:40〜09:00の20分が観察された営業車の波と重なり、荷ほどき台も同時使用になるため見送った。再度時間割を組む際は、この理由と当日の予定を合わせて確認する。
