# 1月22日 朝礼連絡　金物の受入

工事名：海田西配送棟増築  
宛先：岡本 哲夫・工事班 各位  
文書番号：MB-KN-2025-BR-005　Rev0  
文書日：2025年1月21日  
作成：坂本 修一郎

岡本さん、明日の朝礼で次を伝えてください。

22日朝の受入は第1便の支持金物4パレットのみです。予定時間は08:15〜08:35。床養生材の受入はありません。

仮置きはX5〜X6／Y3増築側の2.4×4.0 mの区画を使い、Y2側の車路や荷さばき面を塞がないでください。検品者と検品台車は先に通し、X6の横切りとX7の通路の折れに注意してください。

予定外の営業車と重なる場合は、動かし続けず青木さんとその回の見送りを判断してください。時間枠内でも安全を確認できないまま進めないこと。

岡本さんへ：荷ほどき台は第1便が片付いてから使ってください。仮置きと荷ほどきを同時にしないよう、工事班にも伝達をお願いします。
