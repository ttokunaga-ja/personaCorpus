# 朝の搬入を組む前の条件
MB-KN-2025-BR-001 Rev0｜海田西配送棟増築｜2025年1月16日
作成：坂本修一郎　宛先：青木美紀子・岡本哲夫・福田裕次

## 維持するところ
Y2沿いの営業車路は有効幅3.6 mを維持する。X5〜X6の既存棟側の荷さばき間口を、既存の荷さばきと搬入で同時に使わない。検品者通路はX7-Y2で既存棟側に折れて続く。折れを含む通路を塞がず、検品者を先に通す。基図は白島設計室 O-01 Rev0。

## 朝の観察と枠の扱い
1月14日と16日に営業車が続いた帯は07:45〜08:10、08:40〜09:05、09:35〜09:50。これは観察値で、別の日の車両予定を代用しない。枠を選んだ後も当日の状況を照合し、予定外の営業車や検品台車があればその回の搬入を見送る。台車・検品者を優先し、車の切れ目だけで安全を決めない。

Y3側の返却パレット、荷ほどき台、養生幕の陰の小運搬は別に確認する。置き場を一便ずつ使えるか、岡本さんに相談する。今日の打合せでは時間枠の選定と、実施できるかの確認を分けて扱う。
