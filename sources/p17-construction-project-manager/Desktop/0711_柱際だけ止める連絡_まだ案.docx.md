# 柱際の着工保留について（案）

工事名：海田西配送棟増築
文書番号：MB-KN-2024-MT-003／版：案／2024年7月11日
宛先：青木美紀子、岡本哲夫、西村英二
作成：坂本修一郎／確認：未確認／未送付
対象：Y4上のX4・X5・X6・X7各柱際

本日の図面質疑の照合で、下記の四つの柱際について、それぞれの保留作業を止めます。作業範囲と表示を現地で確認してください。

| 質疑・位置 | 保留する作業 | 再確認に必要なこと |
|---|---|---|
| 20・X4-Y4 | 当該柱脚部の掘削・型枠 | 既存基礎張出しと柱脚離隔について小野さんの再照合 |
| 21・X5-Y4 | 柱際の土間切断 | 補強と切断線の関係について小野さんの回答 |
| 22・X6-Y4 | 穿孔 | アンカー位置と既設防護柵の取合いについて小野さんの回答 |
| 23・X7-Y4 | 当該柱際のコンクリート打設 | 西村さんのスリーブ再照合と小野さんの基礎立上り断面回答 |

保留区画外の採寸・墨出し、別場所での資材・型板照合は続けます。Y2沿いの業務車路を確保し、荷さばきと検品者通路を同時に塞がないこと。停止を伴う作業は、週の候補枠だけで実施せず、原田さんの個別確認を受けてください。

参照：MB-KN-2024-RF-001 Rev2、白島設計室 HS-KN-24-R04。次の確認先は小野さん、23の現地再照合は西村さん。回答と現地根拠を確認するまで各保留作業を始めないこと。
