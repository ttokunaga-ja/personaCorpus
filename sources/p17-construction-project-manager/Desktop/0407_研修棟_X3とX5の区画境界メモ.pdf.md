# 無地のメモ紙 1枚
上部に手書きで「4/7　小野さん・青木さんと現地」。

左に「X3」、右に「X5」と書き、それぞれY2の扉と室内側・南廊下側を示す簡単な略断面を描く。各図で仕切り端を室内側に描き、そこから廊下側へ出しかけた端部線を二重線で消す。両図の端部へ矢印を引き「Y2扉の内側」。下に東出口へ向けた矢印と「出口前は置かない」「小野さん明日返し」。

右下の片隅に「中川さん伝言　10日、持参紙は4部で足りる」。

手持ちの無地紙に鉛筆で略図と文字を書き、消した二重線も残る。取り込んだ紙の端が見える。
