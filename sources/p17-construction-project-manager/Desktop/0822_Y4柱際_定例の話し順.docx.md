# Y4柱際　定例の話し順

工事名　海田西配送棟増築  
文書番号　MB-KN-2024-MT-008　Rev0  
文書日　2024年8月22日  
作成　坂本 修一郎　／　回覧・確認先　青木 美紀子  
持参先　8月23日 13:30定例

## Y4を一括して工程に戻す案

1. はじめにS-21 RevAの囲いを指す。7月末に止めたのは、X4の柱脚部の掘削・型枠、X5の土間切断、X6の穿孔、X7の柱際打設。質疑20〜23の番号で追う。
2. S-22 Rev0と小野さんの回答R05を開く。床墨から読んだ値は柱面起点へ直していると説明し、20・21は明朝のIN-042で端と墨がそろったか伝える。22・23は反対端を取れるか西村さんと見る。取れなければ保留を残す。
3. 区画図の枠を一つずつ指して、照合がそろった箇所から工程へ戻せるか原田さんに聞く。班を入れる日は別に詰める。

| 区画 | 採寸した時点 | 23日朝の確認予定 |
|---|---|---|
| X4-Y4 | 8月5日朝、青木。柱北面から既存基礎肩310 mm。 | A–Aの肩310 mmと新設側照合線460 mmを柱北面から当て直す。 |
| X5-Y4 | 8月5日朝、青木。柱北面から既存土間端205 mm。 | B–Bの土間端205 mmと切断予定線285 mmを照合。旧仮墨を予定線と取り違えない。 |
| X6-Y4 | 8月6日朝、青木・西村。柱東面から柵ベース手前縁165 mmまで。 | C–Cのベース奥縁が見えて、同じ柱面からテープを当てられるか先に見る。 |
| X7-Y4 | 8月6日朝、青木・西村。柱北面からスリーブ手前口縁265 mmまで。 | D–Dの反対口縁が見えるか先に見る。 |

## 原田さんに聞くこと

- 照合が取れた交点だけを候補にする場合、作業の切り分けはこの区画図でよいか。
- 実施枠はどの週の出荷予定に当てて相談するか。既存業務に停止をお願いするなら、準備と復旧を含めて週6時間以内で希望を出す。
- Y2の営業車路を通し、荷さばき面と検品者通路を同時に塞がないようにできるか。実施枠と班を入れる範囲を知らせる前に確認する。
