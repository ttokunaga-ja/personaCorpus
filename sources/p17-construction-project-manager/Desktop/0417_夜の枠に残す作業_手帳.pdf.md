# 手帳の見開き

1ページ。坂本の手書き。上部に「4/17 朝礼前　夜の切替え」とある。

左上に旧案の横棒を一本描き、「連続4時間？　切替え」と書く。そこから矢印を右へ伸ばして「昼：採寸・墨出し」「夜：仮囲い切替え」と分ける。

下に同じ長さの横棒を2本並べ、各々「3時間」と記す。どちらの棒も左端15分、中央2時間30分、右端15分の3区分。各棒の両端に「15分ずつ戻し確認込み」、中央に「正味2時間30分」と書く。棒の下に丸で囲んで「青木さんに聞く：各2時間30分で切替え／復旧が収まるか？」と記す。下端に「週6時間の中、準備と復旧も入れる」とある。

手帳の罫線が見え、紙の端にわずかな影。紙面は少し傾き、文字と二本の棒の区分は読める。
