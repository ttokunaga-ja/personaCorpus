# 原田さんに数字を話す順
2024年10月28日　坂本控え

1. 月初の見込は1,260m³。現地の高さと幅、C端の肩を確認して再計算した見込が1,410m³。出来高ではなく、差の150m³が今回の対象。
2. QT-008を開く。Aの深さで60、Bの左右余幅で54、Cの局部増掘で36m³。Y4柱際の保留区画は入れていない。
3. 途中の1,428m³との差を聞かれたら：C24〜30の6m分にC27〜30の3m分が入っているのに、仮拾いで両方を足していた。25日の肩の再測で連続を確認し、重複18m³を外した。土が18m³なくなったという話ではない。
4. 追加150m³に8,400円/m³、税抜126万円。掘削・積込4,200円、場外運搬3,300円、受入900円。税込138万6千円。これは社内試算で決裁前、正式見積ではないと口頭でも確認する。

施工日程の回答は今回求めない。費用資料を社内のどなたへ持ち帰るかを伺い、必要な補足を受ける。説明を承認と記録しない。
