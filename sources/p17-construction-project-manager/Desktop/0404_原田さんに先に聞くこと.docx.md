# 原田さんに先に聞くこと
工事名：海田研修棟改修
文書番号：MB-KT-2025-MT-001　版：草案1
日付：2025年4月4日　作成：坂本修一郎　確認回付先：青木美紀子

## 前提
原田さんの希望は、火・木の午前と午後に講義18人と演習8人を別室で同時に行い、枠外も2室を使えること。初回に西・中央の4室を閉める2回案では、東端の仮置きにより東演習室への経路が取れず、東研修室1室・14席しか数えられない。室数も講義席も足りない。

## 相談する順序案
中央の2室を残し、まず西の2室、次に東の2室を施工対象とする。その後、使用する2室を中央から西へ移して中央の2室を施工対象にする。中央から西へ同日で切替え。

この切替え方で2室を欠かさず確保できるか、当日の確認と移動の順を詰める。日取りはまだ入れていない。

## 確認したいこと
- 小野さんへ：X3・X5の施工区画境界とY2の扉まわりは、南廊下や東避難出口を塞がずに納められるか。施工区画の出口側はどこまで仕切れるか。
- 原田さんへ：火・木の講義と演習の条件に加え、予約枠外も2室を使える状態にしておく扱いでよいか。部屋を移す場合の案内と予約の扱いはどうするか。
- 青木さんへ：この順序と切替えの書き方で、協議に持っていけるか確認をお願いします。
