# Check a partner's notice comparison
Building Proposals from Evidence · ELM-BPE-2024-HO-006 v1.0 · 27 Jun 2024 · Erin MacDonald

## Mark the plan

Exchange worksheets and read your partner's comparison. Circle the condition they intend to change. Underline each condition they intend to hold the same. Check both sides of the plan for the time window, the notice itself and the place where the observer will count.

If one observation is at lunch and the other is in the afternoon, write in the margin which window you would replace and what you would put in its place. Look again for anything else that changes on only one side.

## Ask about the measure

Point to the action the observer would record. If the plan uses stops, ask what else you would need to find out whether a person read the notice.

## Return one question

Choose the question that would help your partner make the clearest revision. You can also write your own.

- Which time window would you use at both walls?
- What could you keep identical about the notice at each wall?
- Where would you stand, and what would count as a stop?
- If you counted more stops at one position, what would you still need to find out?
