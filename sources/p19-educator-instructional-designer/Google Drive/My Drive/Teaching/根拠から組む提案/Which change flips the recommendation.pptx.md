## Slide 1 — Cover

# Which change flips the recommendation?

Building Proposals from Evidence  
ELM-BPE-2025-SLD-004 · 27 May 2025 · Erin MacDonald

Presenter notes: Work with a partner. We will change one condition at a time and say which fact makes an option possible or impossible.

## Slide 2 — Heading and body

# The two routes

Kits are needed by Thursday 10:00.

- In-house: up to 20 kits; two staff needed; no additional cost using stock.
- Print room: 16–32 kits; CAD 2.50 per kit; request received by Wednesday noon for delivery Thursday 09:00.
- If both routes are feasible, choose the one with the lower additional cost.

Presenter notes: Ask pairs to locate the quantity, people and time conditions before choosing. Keep the print-room receipt time visible as a condition, not an assumed fact.

## Slide 3 — Two columns

# Change the number of kits

Wednesday 11:40; two staff available; a print-room request would be received at 11:40.

| 18 kits | 22 kits |
|---|---|
| In-house: possible | In-house: not possible |
| Print room: possible | Print room: possible |
| Recommend in-house: both work, with no added cost in-house. | Recommend print room: the in-house limit is exceeded. |

**Evidence:** What changed? Which condition rules out in-house at 22?

Presenter notes: Give pairs time to name the 20-kit limit and compare it with each quantity. Two staff are available in both cases; staffing did not cause this change.

## Slide 4 — Two columns

# Change the number of staff

18 kits; Wednesday 11:40; a print-room request would be received at 11:40.

| Two staff available | One staff available |
|---|---|
| In-house: possible | In-house: not possible |
| Print room: possible | Print room: possible |
| Recommend in-house: both work, with no added cost in-house. | Recommend print room: in-house needs two staff. |

**Evidence:** What changed? Which condition rules out in-house with one person?

Presenter notes: Ask pairs to point to the two-person requirement. The quantity remains 18, below the 20-kit ceiling; the quantity did not cause this change.

## Slide 5 — Table

# Name the condition, then check the switch

| Comparison | Condition that makes in-house unavailable | What must be checked before recommending print room? |
|---|---|---|
| 18 → 22 kits, two staff | 22 exceeds the 20-kit limit | Request can be received by Wednesday noon |
| Two → one staff, 18 kits | Two staff are required | Request can be received by Wednesday noon |

A switch is a recommendation only after the print room's receipt time is confirmed. If it cannot receive the request by noon, do not promise Thursday delivery; discuss the deadline with the requester.

Presenter notes: Invite each pair to explain one row without borrowing the reason from the other. Ask what they would check if the actual receipt time were unknown. The noon condition supports the switch only when it is met.
