# Slide 2 — At the counter

Layout: Heading and body

> Return items to the counter by 15:00 on the due day.

Who reads this notice? Find the words that give the deadline.

Notes: Allow a silent read, then ask someone to explain “by 15:00” to a person returning an item. Start the board comparison with Reader, Action and Time or record.

# Slide 3 — The receipt entry

Layout: Heading and body

> Proxy receipt — staff use only  
> Name of person receiving on behalf of the counter: __________

Who fills in the line? What could the next person at the desk tell from a completed entry?

Notes: Ask a learner to read “staff use only” aloud. Use the class's answer to add a second line to the board. Keep the return time visible in the first line.

# Slide 4 — Two readers, two tasks

Layout: Two columns

| Public return notice | Staff-only receipt |
|---|---|
| A person returning an item reads the instruction. | A member of staff completes the proxy receipt. |
| Return the item to the counter by 15:00 on the due day. | Record the name of the person receiving for the counter. |

Which part of the board helps you check the deadline? Which part helps you identify the receiver?

Notes: Complete the comparison on the board before opening the next slide. Ask the class to link each answer to a phrase in the original extract.

# Slide 5 — An item arrives at 15:10

Layout: Heading and body

The item reaches the counter at 15:10 on its due day. A member of staff has completed the proxy receipt line.

1. How does 15:10 compare with the deadline?
2. What does the receipt line establish?
3. What evidence would you need before saying this late return is permitted?

Notes: Point back to both board rows. The item arrives ten minutes after the deadline. The receipt identifies the receiver. Ask the class where they would look for authority to accept a late return since neither extract provides it. This is the worked projection example.

# Slide 6 — Individual exercise

Layout: Heading and body

Open **Counter instructions**. For each extract, mark the intended reader. Write the return deadline and explain what information a completed proxy receipt supplies. Use the review box to point to the phrase that supports each answer.

Notes: For a learner who misses Session 2, choose the individual Counter instructions exercise with the review box, plus the return notice and the staff proxy receipt extract. Keep slide 5, the projected 15:10 example, with the classroom materials.
