# Which Friday does the form mean?

Everyday Document Basics | ELM-EDB-2025-HO-004 v1.0 | 10 Mar 2025 | Heather Callahan

## Page 1 — Read the loan notice

This is an Elmwood practice notice. Read both lines before putting anything in the diary.

### Equipment loan

**Return by:** Friday 16 May, 12 noon

**Next collection:** Friday 23 May, 10:00

Return the equipment by the time shown. The next collection is on a different Friday.

### Put each action in the diary

1. Find **Return by**. In the first box write what to do, the day, the date and the time.

| Action | Day and date | Time |
|---|---|---|
| | | |

2. Find **Next collection**. In the second box write what happens, the day, the date and the time.

| Action | Day and date | Time |
|---|---|---|
| | | |

Turn the page to check your entries.

## Page 2 — Check the two Fridays

Look at **Return by** in the notice. Your first entry should say: **Return the equipment — Friday 16 May, 12 noon**.

Look at **Next collection**. Your second entry should say: **Next collection — Friday 23 May, 10:00**.

If you wrote only “Friday”, return to the matching heading in the notice. Add the day of the month and the time to that diary box. Then check the other box separately: the return is on the 16th, while the next collection is on the 23rd. Do not move the time from one line to the other.
