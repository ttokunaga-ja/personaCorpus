# Folio 183 — Parallel Translation

Synthetic companion passage, prepared for Linden Archive Project review. The documents and voices below are invented.

| Source segment | English working translation | Confidence |
|---|---|---|
| La fenêtre reste entrouverte pour le courrier. | The window remains ajar for the post. | high |
| Une date s’efface près du coin. | A date fades near the corner. | medium |
| Nous déposons la copie sans la fermer. | We set down the copy without closing it. | medium |

The word *courrier* is translated as “post” to preserve a modest administrative register. No personal correspondence is represented.
