# Source annotation codebook

| Code | Meaning | Application rule |
|---|---|---|
| OBJ | material observation | State only what is visible in the synthetic surrogate. |
| VAR | textual variation | Quote or paraphrase the local difference. |
| MOT | motif relation | Name at least one comparative folio. |
| UNC | uncertainty | Preserve alternative readings. |
| EDT | editorial action | Record a normalization or lineation choice. |

## Citation convention

Use internal identifiers only: `LA-SRC-B14-F184` for the fabricated focal sheet and `LA-042` for the associated working citation. Do not infer real provenance or identities.
