# Model card review checklist

## Evidence

- [ ] Identity, owner, date, and run identifier are present.
- [ ] Dataset version and record counts reconcile: S1 1,600 plus S2 800 equals 2,400.
- [ ] Exactly five synthetic intent labels are named.
- [ ] Metric definitions and values are recorded with the comparison context.

## Boundaries

- [ ] Intended use is limited to offline synthetic research.
- [ ] Excluded high-impact and live uses are explicit.
- [ ] Limitations cover external validity and label ambiguity.
- [ ] Risk controls name human review and change-management triggers.

## Review outcome

Record acceptance, requested corrections, or rejection with a dated reviewer note. Acceptance confirms documentation quality; it does not approve deployment.
