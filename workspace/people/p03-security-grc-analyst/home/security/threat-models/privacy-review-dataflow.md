# Privacy Review Dataflow

## Purpose

Map the privacy-review workflow for proposed evidence collection and control testing. The aim is
to identify data categories early and minimize personal data in GRC records.

## Flow

A request describes the processing purpose and proposed evidence. Privacy review classifies data
types, confirms necessity, and documents safeguards. The GRC workflow receives a decision
summary and only the supporting detail necessary for assurance. Retained records reference the
privacy decision without copying unrelated personal information.

## Risks and controls

| Risk | Control |
|---|---|
| Evidence includes unneeded personal data | collection checklist and redaction review |
| Review bypassed under deadline | workflow gate before evidence acceptance |
| Retention exceeds purpose | linked retention category and periodic review |
| Decision lacks accountability | named privacy reviewer and decision date |

## Verification

Quarterly samples confirm that high-sensitivity items have a privacy decision, that the GRC
record is minimized, and that disposal/hold handling is consistent with the approved purpose.
