# Control Owner Handoff Threat Model

## Objective

Avoid loss of accountability when a control owner changes role, team, or service boundary.
Handoffs must preserve control context, evidence cadence, open findings, and upcoming decisions.

## Handoff controls

The outgoing and incoming owners complete a structured record covering control objective,
evidence sources, current status, exceptions, due dates, and key contacts. A manager accepts the
handoff and the GRC register records the effective date. Access is reviewed separately from
ownership so a name change never implies continued access.

| Failure mode | Safeguard |
|---|---|
| No accountable owner | weekly orphaned-control report |
| Evidence cadence missed | handoff checklist with next due date |
| Open risk is concealed | required outstanding-items section |
| Old owner retains approval role | entitlement removal confirmation |

## Validation

The GRC lead samples recent handoffs each month and checks the register, evidence plan, and
access recertification for a consistent owner and effective date.
