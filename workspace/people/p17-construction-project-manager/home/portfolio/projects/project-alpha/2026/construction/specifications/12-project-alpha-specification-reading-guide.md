# Project Alpha Specification Reading Guide

Harbor Build / Project Alpha 2026 / Issued 2026-07-29

Read the issued set, then the applicable division section. Use the compliance matrix for evidence tracking and the deviation log for departures. CO-014 is controlled at JPY 18,600,000; it changes requirements only where a written clarification says so.

1. Confirm section and issue date.
2. Check product, execution, and coordination obligations.
3. Record evidence and exceptions before procurement.
4. Escalate unresolved conflicts through the clarification register.
