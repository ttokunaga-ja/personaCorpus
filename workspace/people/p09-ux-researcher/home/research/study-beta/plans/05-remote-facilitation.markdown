# Remote Facilitation Checklist

## Before each session

* Open the synthetic prototype, task links, captions, and fallback screens.
* Confirm the participant code and requested support; do not ask for a diagnosis.
* Verify recording preference before starting any recording.
* Keep observer chat disabled for participant-facing screens.

## During

Use neutral prompts: “What stands out?”, “What would you expect next?”, and “Tell me what you are looking for.” Allow silence. Do not teach the interface, recover a task early, or treat a workaround as a pass without recording it.

If connection quality degrades, offer audio-only, a pause, or annotated fallback screens. Mark the task as interrupted rather than failed when the technical condition prevented a fair attempt.

## After

Save notes under the participant code, separate observations from hypotheses, and log any accommodation that affected the protocol. The facilitator redacts accidental sensitive disclosure from working notes before synthesis. / 終了後は観察と解釈を分けて記録する。
