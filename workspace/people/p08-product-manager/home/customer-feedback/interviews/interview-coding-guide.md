# Interview coding guide - Product Alpha Q3

**Juniper Works · 2026-07-13 · M-27 (2026-09-18)**  
Context only: adoption is 18.4% toward 26.0% across 1,240 synthetic workspaces.

Code discrete participant claims, not researcher assumptions. A passage may receive multiple codes. Record a quote or close paraphrase, participant ID, and confidence. These are synthetic written notes; do not infer timing precision or prevalence from them.

| Theme | Definition | Include | Exclude |
|---|---|---|---|
| time-to-first-value | Friction or proof on the path to the first meaningful outcome | setup sequence, sample workspace, first routed item | general satisfaction after sustained use |
| permissions comprehension | Ability to understand effective roles and access before or after an action | role comparison, missing-role error, visible capabilities | a request for more access with no confusion evidence |
| notification fatigue | Alerts experienced as excessive, repetitive, or poorly targeted | duplicate status alerts, muting, digest preference | a single useful reminder |
| export confidence | Trust that an exported result represents the intended scope | filters, row count, omitted fields, timestamp | preference for a particular file format alone |
| admin automation | Repeated administrative work delegated through templates or schedules | rule templates, bulk apply, scheduled export | one-off manual setup unrelated to repetition |

## Examples

- Participant A-01: "showing what a finished workspace would look like" → time-to-first-value.
- Participant A-03: unable to publish a template because the missing role was unnamed → permissions comprehension; admin automation.
- Participant A-02: uncertainty whether a CSV included the current filter → export confidence.
- Participant B-01: requests acknowledgement after a role-change notice → permissions comprehension, not notification fatigue unless repetition is named.

## Confidence rubric

High: specific observed behavior plus a consequence, corroborated by another participant. Medium: specific behavior or remedy from one participant. Low: vague preference, researcher interpretation, or operational note. Counts are coded mentions, not unique participants or population percentages.

## Synthesis guardrails

Use IDs only (for example, Participant A-02). Keep Alpha and comparative Beta evidence distinguishable. A decision must identify the uncertainty it leaves unresolved and a measurable follow-up before M-27.
