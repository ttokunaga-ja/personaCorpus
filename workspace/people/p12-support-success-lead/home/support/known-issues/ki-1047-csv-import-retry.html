KI-1047 · Workaround ready

CSV import retry

Some CSV imports can stop after a temporary validation timeout.

Scope
Imports with corrected quoted-field formatting may need a delayed retry.
Workaround
Correct quoted-field errors, wait 10 minutes, then retry the same file once.
Owner
Data Import Specialist
Validation
Look for the completion banner and check three imported records.

Please do not submit repeated retries. If the single retry does not complete, contact support with KI-1047 and a non-sensitive file reference.
