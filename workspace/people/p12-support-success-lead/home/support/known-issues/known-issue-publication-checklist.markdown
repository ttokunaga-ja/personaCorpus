# Known-issue publication checklist

- [x] Issue identifier and plain-language title are present.
- [x] Symptom and affected scope are observable and bounded.
- [x] Status is current as of 2026-08-04.
- [x] Owner is a role, with no personal information.
- [x] Workaround is reversible and warns against duplicate actions where relevant.
- [x] Validation tells the reader what success looks like.
- [x] Copy says neither who is at fault nor when a fix will ship.
- [x] Index reflects 17 unresolved tickets and the four-hour SLA.
- [x] Support escalation path remains available when the workaround does not help.
