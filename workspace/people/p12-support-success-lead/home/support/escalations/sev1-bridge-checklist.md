# SEV1 bridge checklist

## Open

- [ ] Confirm the case ID (`HD-260804-2718`), customer, impact, severity, and breached 4-hour first-response deadline from the 09:00 UTC snapshot.
- [ ] Name Support Incident Lead, Engineering Incident Commander, Customer Communicator, and Scribe.
- [ ] Start a bridge record with JST timestamps; log the opening event.
- [ ] Send a meaningful acknowledgement with owner and next update time.

## Run

- [ ] At each 30-minute checkpoint, record facts, mitigation actions, blockers, and next owner.
- [ ] Keep customer-specific information in the Alpha thread only.
- [ ] Escalate a missed checkpoint to the Support Success Lead.
- [ ] Update the executive summary with impact and confidence level; exclude speculation.

## Close or hand off

- [ ] Confirm first response was meaningful and timestamped.
- [ ] State outstanding work, owner, and next customer update.
- [ ] Record SLA result and corrective action if breached.
- [ ] Send the handoff template and obtain owner acknowledgement.
