## 形式の目安

| 拡張子 | 割合 |
|---|---:|
| pdf（テキスト） | 24% |
| docx | 21% |
| pptx | 18% |
| xlsx | 9% |
| csv | 8% |
| eml | 6% |
| png（説明図・画面） | 5% |
| pdf（スキャン） | 4% |
| txt | 2% |
| jpg（教室写真） | 2% |
| html | 1% |

スキャンは手書き課題と講評、html は保存した講座案内。音声と zip は作らない。

## 規模の目安

全体で 2,000 件。最初の区切りは 300 件で、Alpha Term 1、20 点の評価、採点調整、Beta の設計を中心にする。
1 人 1 問ごとの分割は避け、提出物と講評の自然な単位で作る。
