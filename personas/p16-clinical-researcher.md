## 名前の付け方

- 会議記録、日ごとに控える集計、計画や表の草稿は、会議日や保存日の月日を4桁で先頭に置き、アンダースコアで題と区切る。日付フォルダでは同じ日付を重ねない。試験別のフォルダでは文書の種類を先に書き、必要なら相手、提出先、版を足す。施設内の資料は日本語を使い、後藤との英文の相談や所見は英語の題を使う。
- 保存メールは送受信日の月日を先頭に置き、件名か「相手_用件」で残す。返信の件名を使うときは `Re` の後に空白を置く。
- 書き起こした手続図には内容の分かる題を付ける。すぐ見返すだけの白板写真や画面控えにはカメラや Windows の自動名が残ることもある。Downloads では受信添付や発行元の名前を使い、文書の種類が分かりにくい資料には提供元と題を付ける。

| 名前の例 | 用途 |
|---|---|
| `0120_項目別分母表_v0.1.xlsx` | 手元の未承認表 |
| `1015_低用量観察の計画_再提出.pdf` | 協議会への再提出控え |
| `0701_Denominator questions for Koichi.pdf` | 後藤への英文相談書 |
| `0415_Re 完全性点検で承認日欄が空の3件.eml` | 件名で保存した返信 |
| `0611_記録票と分母集計の手続図.png` | 自分で描いた作業手続図 |
| `IMG_0412.jpg` | カメラの名前で保存した白板写真 |
| `スクリーンショット (12).png` | Windows で保存した一時参照用の画面控え |
| `臨床研究運営実務会合_参加費明細.pdf` | 参加登録事務局からのダウンロード |

## 形式の目安

| 拡張子 | 割合 |
|---|---:|
| pdf（テキスト） | 26% |
| docx | 23% |
| xlsx | 14% |
| pdf（スキャン） | 10% |
| eml | 9% |
| csv | 7% |
| pptx | 5% |
| png（手続図・画面） | 3% |
| txt | 2% |
| jpg（会議ボード写真） | 1% |

スキャンは研究運営上の確認票とする。画像に診療情報を入れない。音声と zip は作らない。

## 規模の目安

全体で 900 件。最初の区切りは 300 件で、評価物質の低用量観察研究の計画、48 例の集計、照会と審査、説明手続理解度調査の説明比較を中心にする。
症例ごとの診療ファイルを量産せず、事務局と研究者の文書環境を作る。

## 書かないもの

- ソースコード、ノートブック、SQL、設定ファイル、pcap、解析実行用ファイル。
- 実在の患者、医療者、施設、検査結果、医療画像、同意書、実在論文の転載。
- 個人を特定できる症例情報、認証情報。2.5 mg は架空計画の区分で、医療上の指示を書かない。
