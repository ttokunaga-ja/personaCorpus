## 形式の目安

| 拡張子 | 割合 |
|---|---:|
| pdf（テキスト） | 23% |
| md | 17% |
| csv | 16% |
| png（グラフ・比較図） | 11% |
| docx | 9% |
| pptx | 8% |
| xlsx | 6% |
| eml | 4% |
| tsv | 3% |
| txt | 2% |
| jpg（研究会写真） | 1% |

csv・tsv は結果の表のみ。図は軸・単位・母数を記す。音声と zip は作らない。

## 規模の目安

全体で 2,000 件。最初の区切りは 300 件で、短文受付意図分類の分割見直し、R184、長文点検記録分類の費用評価を中心にする。
同じ実験の指標を細切れにしてファイル数を増やさない。
