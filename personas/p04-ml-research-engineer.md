# p04 ML リサーチエンジニア

## 人物

- **Nadia Vellacrest**、Helix Forge Avenquill Lab の ML リサーチエンジニア。入所 4 年目、分類モデルの実験評価を担当。
- PC は Ubuntu 24.04 の GPU 付き研究ワークステーション。OS は en-US、使用言語は英語。共同研究の連絡も英語で行う。
- 午前に結果の集計表を読み、午後に仮説と次の比較条件を研究会で相談する。良い結果だけを発表に使わない。
- 実験は Model Alpha と Model Beta に分け、条件と結果の対応を自然文の報告書に残す。手元に置くのは研究の説明資料と表である。
- Documents の論点別フォルダに短い読書メモをためる。発表直前の図は Desktop に置き、棄却した解釈にも日付を付けて残す。

## 組織と関係者

- **Helix Forge Avenquill Lab Ltd**：米国の産業文書分類研究会社、研究員 32 人。Alpha は短い受付文、Beta は長い点検記録の分類を研究する。対象文書も研究室内で作ったもの。

  - **Adrian Mornvale**：研究部長。研究計画と対外発表を承認。
  - **Leila Thornmere**：評価担当。データ分割と誤分類の確認。
  - **Caleb Oriswick**：応用担当。利用時の制約と費用を評価。
- 社外：
  - **Sablemere Methods Institute** の **Iris Bellcairn**：独立した結果レビューを担当。
  - **Ternhollow Technical Press** の **Victor Ainsmere**：研究報告の編集窓口。
- メールは `nadia@avenquill-lab.example`、共同レビューは `iris@sablemere-methods.example`。原稿の指摘と回答は別文書で保存する。

## 仕事の流れ

- **2024-04**：Adrian と Alpha の課題を定義。受付文 12 分類を対象に、F1 0.82 を初年度の判定基準と決めた。
- **2024-07**：Leila と文書 4,800 件の分類を見直し。境界が曖昧な 126 件を保留にして、判定基準書を改訂した。
- **2024-10**：Caleb と比較した大型案は F1 0.846 だが処理費用が基準の 2.1 倍。利用案から外し、研究報告だけに残した。
- **2025-01**：Iris のレビューで同一案件由来の文書 84 件が分割をまたぐと判明。結果を撤回し、案件単位の分割で再評価することにした。
- **2025-04**：Leila と再評価。F1 は 0.851 から 0.832 に下がり、漏れのある旧集計には無効の理由を付けた。
- **2025-07**：Adrian が Beta の研究開始を承認。点検記録 2,400 件、8 分類で、Alpha と評価母数を分けると決定した。
- **2025-10**：Caleb が長文切詰めによる見落とし 37 件を報告。要点抽出案は 11 件まで減ったが、費用増 18% のため追加比較を求めた。
- **2026-01**：Iris と誤分類 160 件を読み合わせ。否定表現に関連する 41 件を独立した分析項目にし、結果説明を修正した。
- **2026-04**：Victor への原稿初稿で比較条件 6 項目が不足。Nadia が条件表を補い、対外提出を 3 週間延期した。
- **2026-07-13**：Leila と Model Alpha M-14 の実験 R184 を確定。評価用 1,200 件で F1 0.873、比較対象との差 0.021 と報告し、Adrian が発表を許可した。
- **2026-08**：Caleb と Beta の費用を再試算。見落とし率を 3.2% から 2.4% に下げる案は月額上限を超え、採用を保留した。
- **2026-09**：Iris の最終指摘 9 件へ回答。7 件を反映し、2 件は対象外の理由を記載して Victor に改訂稿を送った。
- 各報告は母数、分割方法、比較対象、指標の定義を持つ。失敗した仮説や小さな差を成果のように書かない。

## 形式の目安

| 拡張子 | 割合 |
|---|---:|
| pdf（テキスト） | 23% |
| md | 17% |
| csv | 16% |
| png（グラフ・比較図） | 11% |
| docx | 9% |
| pptx | 8% |
| xlsx | 6% |
| eml | 4% |
| tsv | 3% |
| txt | 2% |
| jpg（研究会写真） | 1% |

csv・tsv は結果の表のみ。図は軸・単位・母数を記す。音声と zip は作らない。

## 規模の目安

全体で 2,000 件。最初の区切りは 300 件で、Alpha の分割見直し、R184、Beta の費用評価を中心にする。
同じ実験の指標を細切れにしてファイル数を増やさない。
