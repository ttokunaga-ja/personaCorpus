# p01 ソフトウェアエンジニア

## 人物

- **久瀬 梓**、Aster Loop 綴環システムズ株式会社のシニアソフトウェアエンジニア。入社 5 年目、設計レビューの進行役は 2 年目。
- PC は会社支給の macOS ノート。文書編集、表計算、会議、ブラウザでのレビュー閲覧に使う。
- 言語は日本語と英語（OS は ja-JP）。設計会議は日本語、海外委託先への説明と利用者向け改訂通知は英語。
- 朝にレビューの指摘を読み、午後に設計者と詰める。決まった理由と却下した案を手元のメモに残す。
- Desktop は今週の論点、Documents は製品別。確定版でも検討時の赤字入り文書を捨てず、日付と `_久瀬コメント` で見分ける。

## 仕事の流れ

- **2024-04**：浜瀬と澄灯配送の受付 42 種を整理。重複する 9 種をまとめ、Alpha 初期版は 33 種と決定。業務一覧と採否メモを残す。
- **2024-06**：都築が試行 120 件中 11 件の二重受付を指摘。久瀬は再送時の挙動を設計書で説明し、確認画面を追加する案が採用された。
- **2024-09**：榎坂に保存期間 90 日案と 180 日案を比較して提出。問い合わせ再現に必要な 180 日を採用し、費用差月 6 万円を承認した。
- **2024-12**：Elena と英語のエラー文言 64 件を点検。処理完了と受付完了が混同される 8 件を書き直し、用語表を確定した。
- **2025-03**：浜瀬と Beta の照会項目 28 件を評価。利用頻度が月 2 件未満の 5 項目は初回対象から外し、却下理由を議事録にした。
- **2025-06**：佐岐山から添付書類の取り違え 7 件の連絡。都築と閲覧権限の設計を再確認し、同姓担当者を識別する表示を優先した。
- **2025-09**：榎坂への性能レビューで Alpha の p95 が 246 ms。説明図を添えた負荷評価報告を出し、184 ms 以下を次期目標にした。
- **2025-12**：都築と 38 件のレビュー指摘を分類。重大 4 件が未解決のため Beta 公開を 2 週間延期し、延期通知と修正版の判定表を残す。
- **2026-03**：浜瀬と旧受付方式の終了条件を合意。澄灯配送の未処理 23 件が解消するまで終了しないと決め、利用者への説明書を改訂した。
- **2026-05**：Elena が Alpha R7 の変更説明 16 項目を点検。操作不要の変更 6 項目は管理者向けに移し、通知を短くした。
- **2026-07-13**：榎坂と Product Alpha R7 の公開判定。p95 184 ms、重大未解決 0 件を確認し、設計判断 ADR-042 とともに公開を承認した。
- **2026-09**：佐岐山との振り返りで問い合わせが月 31 件から 19 件へ減少。Beta の次期案は検索説明の改善を優先し、機能追加 2 件を見送った。
- 会議資料、指摘への返信、途中の比較表を残す。数値は測定条件と対象版を併記し、目標値と実績を混ぜない。

## 形式の目安

| 拡張子 | 割合 |
|---|---:|
| md | 22% |
| docx | 18% |
| pdf（テキスト） | 16% |
| eml | 12% |
| png（画面・構成図） | 10% |
| xlsx | 7% |
| pptx | 5% |
| txt | 4% |
| csv | 3% |
| html | 2% |
| jpg（ボード写真） | 1% |

表は性能測定と指摘一覧、html は保存した製品説明。音声と zip は作らない。

## 規模の目安

全体で 2,000 件。最初の区切りは 300 件で、Alpha R7 の設計判断と公開前後、Beta 延期の記録を中心にする。
件数のために同じ設計判断を別形式で複製しない。
