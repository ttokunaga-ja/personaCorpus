# p09 UX リサーチャー

## 人物

- **Elise Wetherquill**、Beacon Field Lumenreed Research のシニア UX リサーチャー。入社 5 年目、日米の業務利用者調査を担当。
- PC は macOS のフィールド調査ノート。OS は en-US、使用言語は英語と日本語。
- 計画と分析は英語、日本側の面談と参加案内は日本語。発言を英訳した箇所は原文と訳を対応させる。
- 面談後の 30 分を観察メモに使い、発言と調査者の解釈を分ける。印象的な一言だけで結論を出さない。
- Documents は調査名と日付。音声は Music、写真は Pictures に置く。分析会前の仮説図や、否定された user persona も版を分けて残す。

## 仕事の流れ

- **2024-04**：Hazel と Alpha の課題を相談。操作時間だけでは困り事を捉えられず、引継ぎの失敗場面 4 種を調査目的にした。
- **2024-07**：綾瀬と日英の質問 18 問を試行。誘導的な 5 問を削り、各言語の面談時間を 45 分にそろえた。
- **2024-10**：Gavin の試行面談で同じ画面に 6 回戻る行動を観察。操作忘れではなく情報照合と解釈し、計画を修正した。
- **2025-01**：Rowan と 12 面談を分析。初心者だけの問題という仮説に反する熟練者 4 人を確認し、経験年数別の分類を撤回した。
- **2025-04**：Marcus に user persona 3 案を提示。職位より交代の頻度が説明力を持ち、頻度別の 2 案へまとめた。
- **2025-07**：仲瀬と Beta の試行を実施。引継ぎ事項 9 件のうち 3 件が見落とされ、警告追加より未確認一覧の案を選んだ。
- **2025-10**：Hazel と画面案 2 種を比較。完了率は 8/10 と 9/10 で、優劣断定を避けて誤解内容を中心に報告した。
- **2026-01**：綾瀬が訳文 36 箇所を照合。断定を強めていた 7 箇所を直し、引用付き報告の初稿を差し戻した。
- **2026-04**：Rowan と調査枠を再設計。24 人を交代頻度別に各 12 人とし、日米の均等割当より業務差を優先した。
- **2026-07-13**：Gavin の面談 UX-184 を実施。Alpha 全体 n=24 の 19 人目で、依頼の保留理由が画面から分からない事例を 3 件確認した。
- **2026-08**：Hazel に最終報告。24 人中 15 人の観察を根拠に保留理由の表示を優先し、全利用者への比率の一般化はしなかった。
- **2026-09**：Marcus と調査の振り返り。再利用する質問 11 問と廃止 4 問を決め、録音の保存期限を面談後 180 日として一覧を確認した。
- 音声には対応する逐語録を持たせる。録音・顔・発言は実在の参加者から採らず、この定義内の設定から作る。

## 形式の目安

| 拡張子 | 割合 |
|---|---:|
| docx | 18% |
| txt | 17% |
| pptx | 13% |
| pdf（テキスト） | 12% |
| png（画面案・分析図） | 10% |
| xlsx | 7% |
| csv | 6% |
| eml | 6% |
| md | 4% |
| jpg（現場・付箋写真） | 3% |
| pdf（スキャン） | 2% |
| m4a | 2% |

音声は面談の m4a 2% だけ、zip は作らない。写真と画面案を同じ画像枠で扱わない。

## 規模の目安

全体で 2,000 件。最初の区切りは 300 件で、Alpha n=24、UX-184、日英訳の見直しと Beta の反例を中心にする。
逐語録は面談単位とし、発言ごとには分割しない。
