## 形式の目安

| 拡張子 | 割合 |
|---|---:|
| docx | 18% |
| txt | 17% |
| pptx | 13% |
| pdf（テキスト） | 12% |
| png（画面案・分析図） | 10% |
| xlsx | 7% |
| csv | 6% |
| eml | 6% |
| md | 4% |
| jpg（現場・付箋写真） | 3% |
| pdf（スキャン） | 2% |
| m4a | 2% |

音声は面談の m4a 2% だけ、zip は作らない。写真と画面案を同じ画像枠で扱わない。

## 規模の目安

逐語録は面談単位とし、発言ごとには分割しない。
