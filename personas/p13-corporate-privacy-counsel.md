## フォルダ構成

```text

  Matters/Alpha/保全/          対象区分、期限、終了判断
  Matters/Alpha/保存方針/      改訂案、比較、承認
  Matters/Beta/委託先審査/     質問票、未回答、再審査
  契約検討/Greymallow/         条項比較、修正文案、合意
  相談控え/<年>/               相談内容、前提、回答
  取締役会/                   リスク報告、想定質問

  読み物と論点/               独自の制度要約、検討メモ

  法務共有/                   承認済み方針、会議資料
```

## 形式の目安

| 拡張子 | 割合 |
|---|---:|
| docx | 28% |
| pdf（テキスト） | 24% |
| eml | 19% |
| xlsx | 9% |
| pdf（スキャン） | 7% |
| pptx | 4% |
| html | 3% |
| txt | 2% |
| png（情報の流れ・画面） | 2% |
| md | 1% |
| jpg（研修写真） | 1% |

html は社内で保存する方針説明、スキャンは紙で承認した文書。音声と zip は作らない。

## 規模の目安

全体で 2,000 件。最初の区切りは 300 件で、Alpha の期限付き保全と保存方針、Beta の委託先審査を中心にする。
同じ条項の比較は交渉の節目にまとめ、句ごとのファイルにはしない。

## 書かないもの

- ソースコード、ノートブック、SQL、設定ファイル、pcap、実際の削除処理。
- 実在事件、実在当事者の個人データ、実在の秘匿特権資料、法令原文の長い転載。
- 認証情報、秘密鍵、実在の署名。保全対象の中身ではなく区分と判断の記録を持つ。
