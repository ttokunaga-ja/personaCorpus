## 形式の目安

| 拡張子 | 割合 |
|---|---:|
| docx | 28% |
| pdf（テキスト） | 24% |
| eml | 19% |
| xlsx | 9% |
| pdf（スキャン） | 7% |
| pptx | 4% |
| html | 3% |
| txt | 2% |
| png（情報の流れ・画面） | 2% |
| md | 1% |
| jpg（研修写真） | 1% |

html は社内で保存する方針説明、スキャンは紙で承認した文書。音声と zip は作らない。

## 規模の目安

全体で 2,000 件。最初の区切りは 300 件で、文書保全期限見直しの期限付き保全と保存方針、文書処理委託審査の委託先審査を中心にする。
同じ条項の比較は交渉の節目にまとめ、句ごとのファイルにはしない。

## 書かないもの

- ソースコード、ノートブック、SQL、設定ファイル、pcap、実際の削除処理。
- 実在事件、実在当事者の個人データ、実在の秘匿特権資料、法令原文の長い転載。
- 認証情報、秘密鍵、実在の署名。保全対象の中身ではなく区分と判断の記録を持つ。
