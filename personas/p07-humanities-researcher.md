# p07 人文学研究者

## 人物

- **Clara Mertenshaw**、Linden Archive Brumeleaf Project の研究員。参加 5 年目、都市間の書簡と読書会の比較史を研究する。
- PC は macOS の研究用ノート。OS は en-GB。使用言語は英語、フランス語、ドイツ語、日本語。
- 執筆と日常連絡は英語、史料読解は主にフランス語とドイツ語、日本語は比較研究の読書メモと共同研究者への連絡に使う。
- 午前に転記と読解、午後に章の執筆。読めない字は推定と確定を分け、翻訳で意味を補わない。
- Documents は章別、史料画像は箱別。Desktop に引用確認中のページを置き、古い草稿のコメントを残す。読書メモのファイル名は著者名から始める。

  - **Lucie Vaucleray**：フランス語史料担当。転記と語義の相談相手。
  - **Matthias Dornquell**：ドイツ語史料担当。異綴りと索引の整理。
- 社外：
  - **Archives de Valbrume** の **Élodie Marceval**：史料閲覧と複写の担当。
  - **星汀比較文化研究室** の **越守 由季**：日本語の比較研究会窓口。
- メールは `clara@brumeleaf-history.example`、閲覧窓口は `elodie@valbrume-archives.example`。ここで定義した史料群と関係者だけを用いる。

## 形式の目安

| 拡張子 | 割合 |
|---|---:|
| pdf（スキャン） | 25% |
| pdf（テキスト） | 20% |
| docx | 15% |
| txt | 10% |
| md | 9% |
| eml | 6% |
| jpg（史料・閲覧時写真） | 5% |
| png（関係図・転記照合） | 3% |
| csv | 3% |
| pptx | 2% |
| xlsx | 1% |
| html | 1% |

史料の文面も独自に書く。書籍や論文の実物を転載しない。音声と zip は作らない。

## 規模の目安

全体で 2,000 件。最初の区切りは 300 件で、Box 14、第 2 章、会費集計の訂正、比較研究会を中心にする。
複写と転記は必要な対応関係を持つものだけ併存させる。
