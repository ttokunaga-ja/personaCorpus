## 形式の目安

| 拡張子 | 割合 |
|---|---:|
| xlsx | 32% |
| pdf（テキスト） | 16% |
| pdf（スキャン） | 9% |
| csv | 11% |
| eml | 10% |
| docx | 8% |
| pptx | 6% |
| png・jpg | 4% |
| txt・md | 3% |
| html | 1% |

`tsv`、`json`、`xml`、`log`、音声、`zip` は原則として作らない（`zip` は監査法人への提出一式をまとめたものが数件あってよい）。

## 規模の目安

全体で 2,000 件。最初の区切りは 300 件で、2026-01〜03 の月次締めと年度監査を中心に、各フォルダに実際の仕事がひととおり入った状態にする。

## 書かないもの

- 実在の銀行、監査法人、会計ソフトの名前。
- 個人の給与明細、マイナンバー、口座番号の全桁。口座番号は下 4 桁だけを書く。
- マクロ、スクリプト、SQL、ERP の設定ファイル。
