## 組織共通の識別

- 自社：重ねた2枚の文書枠と照合のチェック、社名の文字。主色は紫灰色 `563F58`、補助は銅色 `B28B65`、本文は墨 `302F33`。集計の淡色 `EEE8EE` は主色の濃淡。白い業務用紙に小さいロゴを置き、法律事務所風の装飾表紙は付けない。
- 宮坂・野田：円内の天秤と事務所名。青灰色 `40566E` と本文の墨 `302F33`。天秤は抽象図形であり、実在の資格章ではない。自社とロゴ・書体・主色を分ける。
- 自社Officeは日本語・欧文とも `Noto Sans CJK JP`、社外Wordは日本語・欧文とも `Noto Serif CJK JP`。TeXは日本語 `Noto Sans CJK JP`、欧文 `Liberation Sans`。既定Normal、見出し、表、入力用管理セルにも実設定し、Officeテーマのフォントと主色も設定した。
- Wordは社名ヘッダと組織・部門／用途・自動頁番号のフッタ。Excelは社名上段と社名・法務部・頁数の印刷フッタ。PPTXはマスター上のロゴ・社名・罫線・部門表記。TeXは社名ヘッダ、法務部・案件名・現在頁／総頁。
- 自社文書番号：`TDS-LG-YYYYMM-用途-連番3桁`。用途は `REV` 判断資料、`CON` 相談記録、`INS` 指示、`RPT` 報告、`REQ` 申出、`REG` 台帳、`CMP` 比較表、`BRF` 会議資料、`CHK` 紙の再審査票。外部回答は `MN-YYYYMM-ADV-連番3桁`。実番号は計画で割り当て、草稿・確定版・Officeから保存したPDFは同番号と版で追跡する。メール・個人メモに無理に番号を付けない。
- 他personaのREADMEとp14・p03のWord実物を開いて書体と見出し色を比較した。既存の緑の木材、赤茶の配送矢印、藍の織り目、柱梁、寸法枠、枝と灯と区別した。

## Wordの成形

`Document(型のパス)` で開く。先頭の見出しの前に `Title` の実題と `TD Metadata` の管理行（番号・版・作成日・作成者・宛先・確認者）を原稿どおり追加する。草稿の承認欄に未実施の承認を入れない。本文は各見出しの直後へ挿入し、不要な節は削除する。

A4縦、左右23mm、上29mm、下23mm。Normal 10.5pt、段落後6pt、行間1.2。Title 22pt、Heading 1は13pt、Heading 2は11pt、題と見出しは組織の主色・太字。`TD Metadata`・`TD Note`・Captionは9pt。`TD Redline` は赤 `B02032` の10.5pt。赤字は原稿にある実際の訂正へ適用し、削除箇所は取り消し線等で変更内容を読めるようにする。型に赤字の仮本文はない。

表を必要な行数だけ追加し `TD Table` を指定する。先頭行は主色の塗り、段落に `TD Table Header`（9pt白字太字）、本文セルには `TD Table Body`（9pt墨色）。`trPr` に `w:tblHeader` を追加して見出しを続頁へ繰り返す。長文に合わせて列幅を調整し、行高は固定しない。社外型も同じスタイル名を持つが、書体と色は事務所のもの。

判断資料・相談回答のPDFは、完成したWordを `bin/office-pdf` で保存する。同じ内容のPDFを別原稿で作り直さない。紙をスキャンする場合も先に内容のある原紙を作る。

## Excelの成形

`load_workbook(型のパス)` で開く。1行目はロゴ・社名、2行目は題、3〜4行目は管理欄、5行目は未書式の余白、6行目は列見出し。7行目以降に空の書式つき明細・合計・数式はない。既定フォントもNoto Sans CJK JP。

1. B3:D3に完全な文書番号、F3:H3に基準日、B4:D4に作成者、F4:H4に確認者と版を入れる。入力セルは9pt・折返し・上揃え、3〜4行は32pt。日付は実日付と `yyyy-mm-dd`。番号が長くなる場合は行高を増やし、隣接欄も埋めて全文が印刷されることを確認する。
2. 実際の明細だけ7行目から追加。文字は `TD Text`（10pt左寄せ）、整数・数式は `TD Number`（10pt右寄せ、`#,##0;[Red](#,##0);0`）、日付は `TD Date`（10pt、`yyyy-mm-dd`）、注記は `TD Note`（9pt）。すべて折返し・上揃え。区分番号は文字列、未知の結果や実施日は0や判断日に置き換えない。
3. 必要な集計だけ最終明細の次に追加する。ラベルと式のセルへ `TD Total`（主色の太字、淡紫灰背景、二重下罫線）を付け、ラベル左・数値右。実範囲を指す `COUNTA`・`COUNTIF` 等を入れる。対象・終了判断・延長判断・実施確認済みは別に数える。比較欄の文章を無意味に合計しない。
4. 見本の明細は42pt。長文は行高を増やし、固定高による欠落を防ぐ。必要に応じて原稿に合わせて列名・幅を変更し、タイトル・管理欄の結合も揃える。印刷はA4横・幅1頁・縦自動、1〜6行を繰返し、C7固定。印刷範囲はA1:H最終使用行、フィルタはA6:H最終明細行。集計・注記はフィルタに含めない。
5. 数式がある完成ブックは `bin/recalc` を実行し、結果と全印刷頁を確認する。CSVは明細データだけで、管理欄・ロゴ・書式を含めない。

## PowerPointの成形

`Presentation(型のパス)` の `slide_layouts[0..4]` は順に表紙、見出しと本文、2段、表、図。題idx=0、本文／副題／表／図はidx=1、2段の右はidx=2。表紙題32pt・副題18pt、他は題30pt・本文20ptを継承。表紙副題に実番号・版・日付・作成者を入れる。

表は `placeholders[1].insert_table(行数,列数)`、先頭行は主色白字、本文は墨色・18ptを目安に実設定する。図はidx=1の範囲（左0.6、上2.2、幅12、高さ4.4inch）に実図形を配置して不要なプレースホルダを削除する。頁番号は各スライド右下（左12、上7.05、幅0.6、高さ0.3inch）へ10ptで追加。会議資料が必要な場合だけ使い、型があることを理由に成果物を増やさない。

## TeXの成形

`TEXINPUTS="$PWD/templates/p13-corporate-privacy-counsel:" bin/tex <今回のscratch内の原稿.tex> <今回のscratch内の出力.pdf>`。`\documentclass{toto-review-sheet}` を使用する。

- `\ReviewHeading{題}{文書番号}{版}{作成日}{作成者}`、`\ReviewSection{見出し}`、`\ReviewNote{注記}`、`\ReviewDecision{判断者}{判断内容}` を必要なときに使う。主色は題・見出し・判断者、銅色はヘッダ罫線、墨色は本文に実適用している。
- `ReviewTable` 環境の列は区分・前提・根拠変更・判断期限・担当。実際の行だけ `区分&前提&根拠&判断&担当\\\hline` で追加。列見出しを続頁へ繰り返す。型に空の記入行や署名はない。
- 署名済みの体裁はこの型だけでは作らない。手書きが原稿で必要になった場合はimagegen skillに従い、内容のある紙面を `bin/scan` に渡す。活字の氏名を手書き署名としない。
