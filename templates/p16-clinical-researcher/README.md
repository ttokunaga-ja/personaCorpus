## 共通の書式と文書管理

- センターは円の中に中心と右上の観察点を置く図形と正式名称を組み合わせる。題・見出しと主図形は赤紫 `742747`、罫線と副点はくすみ紅 `AB586C`、本文は墨 `302830`。白地と赤紫の淡色 `F7EDF1` を背景に使う。
- Officeは和文・欧文とも **Noto Serif CJK JP**。WordのNormal・見出し・表・テーマ、ExcelのNormal・既定フォント・管理入力セル・名前付きスタイル、PowerPointのテーマとレイアウトに設定済み。センターのTeXは和文 Noto Serif CJK JP、欧文 Liberation Serif。
- センターのWord・PowerPoint・TeXはヘッダに図形と組織名。Excelはシートの先頭に持つ。フッタは研究事務局と頁。試料受渡し確認票の部門表記は薬剤管理。吉村のTeXは和文 Noto Sans CJK JP、欧文 Liberation Sans。青 `214D81` をロゴ・題・見出し・下罫、墨 `222D3C` を本文・管理欄に使う。
- センターの低用量観察研究は `KRC-LDO-YYYYMMDD-種別-連番3桁`。種別は `PRO`（計画書）、`MIN`（会議記録）、`QRY`（相談書）、`TAB`（表）、`MTG`（スライド）、`SUM`（概要）。日付は番号を最初に割り当てた文書の作成日。改訂時は元の番号を保ち、版と当該版の作成日を更新する。同日・同種別の別文書は連番を増やす。吉村の所見は `YST-LDO-YYYYMMDD-NOT-連番3桁`。どちらも作成者は実際に文書を書いた人物。
- 4月26日の48例は計画の目安、7月18日の12項目は統計計画の確認項目数。分母・記録あり・理由付き欠測を別欄にし、記録された0と欠測を区別する。
- 審査回答はセンターの種別 `RSP`、対照表は `TAB`、提出前確認票は `CHK`。協議会の照会は `AKE-LDO-YYYYMMDD-QST-連番3桁` とし、日付部分には初回の発行日を用いる。協議会の和文は Noto Sans CJK JP、欧文は Liberation Sans。深緑 `345C47` をロゴ・題・質問番号・下罫、淡緑 `E9EFE9` を題帯、墨緑 `29332D` を本文・管理欄に使う。
- 審査関連の文書は、説明負担の20分から35分への訂正、質問8件と回答、2024年10月15日に田中の承認を得た再提出版を対応させる。田中の確認欄はセンター内の承認を記す。質問の文言、項番、発行日、版、添付名はファイル計画と原稿に従う。
- 観察記録票にはセンターの種別 `FRM`、試料受渡し確認票には `CHK` を使う。受渡し確認票は管理欄の確認日・確認者に橋本が照合した日と氏名を記す。長田の証明書番号は `OSA-YYYYMMDD-CER-連番3桁`。日付部分は発行日。和文 Noto Sans CJK JP、欧文 Liberation Sans。黄土色 `8A521C` をロゴ・題・項目名・罫線、生成り `F2E8D9` を項目欄の地、墨 `292725` を本文と発行欄に使う。

- 完全性点検所見は `REV`、完了報告は `RPT`、承認日根拠確認票は `CHK`、照会割当一覧は `TAB`。4月15日の点検24件と承認日欠落3件は点検の集計。5月15日の照会21件と担当不明4件は割当の集計。日付の根拠は対象版に対応する承認記録で照合し、未確認なら承認日欄を空ける。照会を森に割り当てた後も、未回答の行は継続扱いにする。

- 説明手続理解度調査には `KRC-CMP-YYYYMMDD-種別-連番3桁` を使う。種別は `EXP`（説明文）と `PRO`（実施手順）。説明文の二案には別々の番号を付ける。
- 手続研修には `KRC-TRN-YYYYMMDD-種別-連番3桁` を使う。種別は `MTG`（進行用スライド）、`TAB`（例題解説）、`CHK`（確認票）。どちらの番号も、初回作成日、連番、改訂時の扱いはセンター共通の規則に従う。
- 低用量観察の事象報告の照合にはセンター共通の低用量観察研究の番号を使う。対応表と集計表は `TAB`、報告と照合用控えは `RPT`、確認票は `CHK`。事務局の受付番号と安全管理側の番号は、文書管理欄に入れる番号と区別する。
- 2025年7月29日開始の調査は説明文二案を使う24件。低用量観察の予定48例は別の研究の進捗に記す。8月25日の研修対象は17人、欠測を0と説明したのはそのうち2人、石川が再説明に使ったのは例題3問。人数、調査の件数、観察の例数、例題の数にはそれぞれの単位を付ける。

## Word

1. `Document(型のパス)` で開く。本文の最初の段落（`Title`）に題を入れ、続く2段落（`KRC Control`）に「文書番号・版」「作成日・作成者」を記入する。日付は `YYYY-MM-DD`。計画書は最初の「研究目的」の段落でページを改める。議事録と相談書は同じ頁から続ける。
2. 本文は `Normal` 11pt、段落後6pt、行間1.18。題は25pt、`Heading 1` は15pt、`Heading 2` は12pt。型の節見出しは原稿に合わせて削除・追加し、節の間に本文を入れる。
3. 表が必要な箇所だけ `KRC Research Table` を使い、列幅を合計160mm以内にする。見出し段落は `KRC Table Header` と赤紫 `742747` のセル背景、本文段落は `KRC Table Body`。続頁に見出しを出す表は先頭行に `w:tblHeader` を設定する。数値段落を右寄せする場合は、次の文字セルに左余白を増やす。注記は `KRC Note`。
4. 審査回答は「宛先と照会の参照」の宛先欄を埋め、次段落に協議会の照会番号を置く。「回答と計画書の修正」の中で質問番号と論点を `Heading 2` にし、回答本文と改訂版の参照先を続ける。「添付と提出版」には送付するファイル名と版を入れる。内部草稿の注記は根拠の該当文を独立した run にして `Document.add_comment` で係留し、著者を田中 義之、コメント日時を原稿に合わせる。
5. 観察記録票は節ごとに必要な行だけを作る。3列なら「項目／記入欄／確認事項」を42／54／64mmとし、記入欄は空け、項目名と確認事項を原稿に沿って入れる。表は手順3の表スタイルと見出しの繰返し設定を使う。記入欄の高さは記入量に合わせる。1月28日の試行6件・記入漏れ11箇所は改訂の根拠として記し、票面の欄順は実際に記入する順にする。

6. 完了報告は本文と同じ頁に管理欄を置く。点検所見を文書番号で参照し、点検範囲と残件、保留の扱い、再確認の条件を各節に記す。題に当該版の扱いを示し、保留稿の版と作成日を管理欄に入れる。

7. 説明文二案は同じ型から別々に成形する。手順1の題と管理欄を各案の番号・版・日付・作成者で埋め、参加者向けの本文を各節に入れる。節名は文面に合わせて変更できる。案を使い分ける実施担当向けの指示は調査実施手順に置く。

## Excel

1. `load_workbook(型のパス)` で開く。シート名とA2の題を原稿に合わせ、C3に番号、H3に版、C4に日付型の値、F4に作成者を入れる。番号のC3:F3、日付のC4:D4、作成者のF4:H4は結合済み。管理欄は折返し付き。3行目23pt・4行目25ptを基準とし、内容が長いときは行高を増やしてPDF上で全文を確かめる。
2. 6行目が見出し。明細は7行目から原稿にある行だけを作る。A/C/D/E/Gは右寄せ・整数 `KRC Integer`、B/F/Hは左寄せ・インデント1の `KRC Text`。未入力の数値セルは `None` を代入して書式を付ける。欠測理由はF列に記し、未入力の数値セルは空欄のまま使う。理由別に行を分ける場合、項目の対象数は項目内の見出しとなる行だけに置き、繰り返した分母を足さない。幅はA:Hで7/24/12/12/16/21/12/29。短い明細は24pt程度から。空表の見本は折り返す注記に合わせて48pt。折返しと行高を印刷で確認する。
3. 合計は原稿にあり、対象が重ならず加算できる列だけ作る。明細末尾の次行にラベルを置き、`KRC Total Text` を指定する。同じ行の加算できる列に実際の範囲を指す式を入れ、`KRC Total Integer` を指定する。全行に同じ分母を記す表や空表では合計を設けない。注記は必要なときだけA:Hを結合して `KRC Note` にする。
4. `print_area` はA1から実際の最終欄まで。フィルタは `A6:H<明細の末行>` に留め、合計・注記にはかけない。C7固定、1〜6行の繰返し、A4横・幅1頁・高さ自動を維持する。数式があれば再計算して出力を確認する。短い版と続頁のある版の両方で、番号全文、隣接する版・日付・氏名、数値と文字の境目を見る。
5. 審査対照表も同じ管理セルと印刷設定を使う。Aは質問番号で `KRC Integer`、B〜Hは `KRC Text`。旧記載・改訂後の記載は「20分」「35分」など単位を含む引用として入れる。列幅はA:Hで7/24/22/17/28/26/13/29。明細行は短文なら39pt程度、各欄が長いときは文章量と印刷倍率に合わせて行高を増やす。質問番号は照会原文の順に置き、合計行は設けない。計画書の番号と版など表全体の参照は末尾の結合注記欄に入れる。
6. 成形後の内部プロパティは、表に記した作成者と計画の日付に合わせる。見本では保存と数式の再計算を終えてから `bin/stamp <見本.xlsx> --author <作成者> --date <日時> --timezone Asia/Tokyo` を実行し、`docProps/app.xml` のアプリ名が Microsoft Excel、`docProps/core.xml` の作成者・作成日時・更新日時が指定値になっていることを確認する。配布物への適用は通常の成形後処理で行う。

7. 照会割当一覧は同じ管理セルと印刷設定を使う。A:Hの幅は7／22／36／16／17／17／15／31。Aは `KRC Integer`、B〜DとG〜Hは `KRC Text`。EとFは日付型で `KRC Date`、未確定・未回答の日付セルは空欄にして書式だけ指定する。明細は7行目から作り、1〜2行の短文なら34ptを基準に行高を調整する。会議の引継ぎ注記を付ける場合は、明細末尾の次行のA:Hを結合し `KRC Note` を指定する。照会の一覧に合計行は設けない。印刷範囲・フィルタ・続頁見出しは手順4のとおり設定する。

8. 例題解説も同じ管理セルと印刷設定を使う。A:Hの幅は7／24／10／15／26／26／16／30。A（例題の番号）とC（記録値）は `KRC Integer`、B・D〜Hは左寄せでインデント1の `KRC Text`。Cには原票に記録された値を入れ、欠測と対象外では `None` とする。Dの取扱いとEの根拠で区別する。明細は7行目から書式ごと作り、行高42ptを基準に折返しに合わせて調整する。例題番号と記録値は集計対象にならないため、合計行は設けない。必要な注記は明細の次行のA:Hを結合し `KRC Note` を指定する。印刷範囲とフィルタは手順4に従う。短い版と続頁のある版で、番号の全文と隣接する版・日付・氏名、A→BとC→Dの間隔、続頁の見出しを画像で確認する。型の内部タイトル（`docProps/core.xml` の `dc:title`）は「手続研修の例題解説」。成形時に表題を変える場合は `workbook.properties.title` も更新し、手順6の `bin/stamp` 後に表題と一致することを確認する。

9. 初報と追記の対応表は手順1の管理セルを使い、明細は7行目から作る。受付番号と元の受付番号は文字列、Bは日付時刻型で `yyyy/mm/dd hh:mm`、Gは `KRC Integer` とし、未確認の計上欄は空欄にする。確定版の明細の下で、受付番号の非空欄数、区分が追記の行数、計上欄の合計を明細範囲から別々の式で出す。手順4の設定に従い、印刷時も照合先の説明が読めるよう折返しと行高を調整する。差替え用集計表は共通の管理欄を残し、6行目の見出しと欄幅を原稿の項目に合わせ、未使用列は印刷範囲とフィルタから除く。

## PowerPoint

- `Presentation(型のパス)` で開き、`slide_layouts[0:5]` を順に表紙、見出しと本文、2段、表、図として使う。題はプレースホルダ0。表紙の管理欄・本文・表・図は1、2段の右側は2。表紙の題34ptと副題18pt、他頁の題28ptと本文20pt。副題の1行目に文書番号と版、2行目に作成日（`YYYY-MM-DD`）と作成者を入れる。
- 表は `placeholders[1].insert_table(行数, 列数)`。見本は18ptで赤紫に白抜きの見出し、本文は白または淡い赤紫の地に墨。数値列は右寄せにし、右隣の文字列は左寄せでセルの左余白を0.25インチ取る。図は `insert_picture` した後に、全体が見えるようにトリミングを解除し、位置・幅・高さを明示して元の縦横比で領域内に収める。表・図の領域は左0.72、上2.03、幅11.83、高さ4.55インチ。
- 頁数は成形時に右下（左12.08、上6.99インチ）へ墨色の11ptで置く。ロゴと研究事務局の表記はマスター上にある。見出しや本文が2行になったときは、続く要素との間隔も画像で確認する。

- 研修の進行用スライドもこのマスターを使う。表、二段、図は原稿に必要なものを選ぶ。研修内で人数を示すときは、表の対象と単位を明記する。

## TeX・メール・手続図

- センターは `\documentclass{katsuragawa-summary}`、`\KRCHeading{題}{文書番号}{版}{作成日}{作成者}{確認者}`、`\KRCSection{見出し}`、`\KRCNote{注記}` を使う。確認者は実際にその版を確認した場合に記載する。
- 後藤の文書添付には `\documentclass{yoshimura-statistical-note}`、`\YSTHeading{題}{参照番号}{作成日}{作成者}{宛先}`、`\YSTSection{見出し}` を使う。返信本文だけの場合は通常の英文メールにする。
- 協議会の質問書は `\documentclass{akane-ethics-questions}`、`\AKEHeading{題}{照会番号}{発行日}{担当}{宛先}` を使用する。研究名と回答方法のあとに `AKEQuestions` 環境で質問を順に組む。テキスト層を持つPDFとする。
- 提出前確認票は `\documentclass{katsuragawa-submission-check}`、`\KRCCheckHeading{題}{文書番号}{版}{作成日}{作成者}`、`\KRCSection{区分}`、`\KRCCheckItem{確認項目}{確認欄}{備考欄}` を使用する。原紙の項目と記入欄を組み、手書きの記入がある完成面を `bin/scan <画像またはPDF> <出力.pdf>` に通す。
- 試料受渡し確認票は `\documentclass{katsuragawa-handover-check}`、`\KRCHandoverHeading{題}{文書番号}{版}{確認日}{確認者}`、`\KRCSection{区分}` を使う。`KRCHandoverItems` 環境に `\KRCHandoverItem{確認項目}{結果または引継ぎ}` を必要な分だけ入れる。2月6日の票は証明書6通の照合、ロット記載なしの1通の差戻し、橋本による照合までの受渡し保留を記す。完成面を `bin/scan` で画像だけのPDFにする。
- 長田の試料証明書は `\documentclass{osada-sample-certificate}` と `\OSAHeading{題}{証明書番号}{発行日}{発行担当}{宛先}` を使用する。`OSADetails` 環境に `\OSARow{項目}{値}` を並べる。差戻し対象の受領版は「ロット番号」の項目名を残し、その値を空欄にしてテキストPDFを出す。石井への訂正依頼や観察用の受渡し保留はセンター側の文書に記す。
- 完全性点検所見は `\documentclass{katsuragawa-integrity-findings}`、`\KRCFindingsHeading{題}{文書番号}{版}{作成日}{作成者}` と `\KRCSection{見出し}` を使う。点検範囲、確認できなかった欄、事務局へ伝える条件を順に組み、テキスト層を持つPDFにする。
- 承認日根拠確認票は `\documentclass{katsuragawa-approval-evidence}`、`\KRCCheckHeading{題}{文書番号}{版}{作成日}{作成者}`、`\KRCSection{区分}` を使う。照合先ごとに `\KRCEvidenceItem{区分}{照合資料}{確認結果}{次の確認先}` を並べ、完成面を `bin/scan` に通す。照合資料の発行日と承認日を区別する。
- 森の照会一覧はCSVで照会番号、担当、回答期限、回答日、状態などを独立した欄で持つ。池田の引継ぎはTXTで、担当が決まった行と回答を待つ行の扱いを残す。
- 調査実施手順は `\documentclass{katsuragawa-survey-procedure}`、`\KRCHeading{題}{文書番号}{版}{作成日}{作成者}{確認者}`、`\KRCSection{見出し}`、必要に応じて `\KRCNote{注記}` を使う。説明文の版、手順、聞き取りの記録、進捗の管理を原稿に沿って組み、テキスト層を持つPDFにする。
- 手続研修の確認票は `\documentclass{katsuragawa-training-check}`、`\KRCCheckHeading{題}{文書番号}{版}{作成日}{作成者}`、`\KRCTrainingField{項目名}{記入の案内}` を使う。取り違えた説明、再説明に使った例題、説明し直した内容と申し送りなど、記入する項目ごとに罫線を設ける。手書きの記入がある面を `bin/scan` に通す。
- 事象報告の照合は `\documentclass{katsuragawa-event-report}`、`\KRCEventHeading{題}{文書番号}{版}{作成日}{作成者}`、`\KRCSection{見出し}` を使い、テキスト層を持つPDFにする。事象報告の確認票は `\documentclass{katsuragawa-event-check}`、`\KRCCheckHeading{題}{文書番号}{版}{作成日}{作成者}`、`\KRCEventCheckField{確認項目}{印刷する記入案内}` を使う。手書き記入後の面を `bin/scan` に通す。
- 研修の板書は会議ボードの写真（JPG）として扱い、参加者名や診療情報を含めない。研修後に直した区別が原稿に示される場合は、写真でもその箇所が読めるようにする。
- いずれのTeXもリポジトリ直下から `TEXINPUTS="$PWD/templates/p16-clinical-researcher:" bin/tex <作業フォルダの.tex> <出力.pdf>` で組む。
- EMLは通常のテキストメール。鈴木は `mitsuko.suzuki@katsuragawa-clinical.example`、後藤は `koichi@yoshimura-statistics.example`。返信は件名と返信ヘッダを元メールに対応させ、時刻は日本時間を使う。社名は署名で表す。再提出の送付控えは、照会番号と実際に提出した版・添付ファイル名を本文で対応させる。
- PNGの手続図は原稿の流れに応じて組む。記録票、項目別の対象の確認、集計表の各段階を箱で示し、白地にセンターの色・和文書体を使う。
- 試行の記入漏れ集計はCSVに項目別の数を記し、会議ボード写真は記入順を整理した会議の資料として扱う。石井との返信は証明書番号で照合し、差戻し後の受領や使用の確定は記さない。
