# 佐藤美穂子の文書の型

みらい職場研修株式会社の採用・People Ops、青山キャリア支援合同会社の採用支援、明星採用広告株式会社の掲載見本に使う型。通常のDOCX・XLSX・PPTXを開いて別名保存する。型には組織、見出し、書式だけを置き、事例本文、ダミーの番号・日付、空の明細、仮の合計を置かない。

## 共通の意匠と管理

- 178人の研修会社として、小さな「開いた本」の図形と社名を使う。本の左ページは桑実色 `963A65`、右ページは灰緑 `7B8270`。本文は墨 `34383C`、白地、合計の淡色は桑実色の濃淡 `F5EDF1`。Word・Excelの図形は埋込みPNG、PowerPointはネイティブ図形、TeXはTikZ。外部画像リンクはない。
- Officeの日本語・欧文はともに **Noto Sans CJK JP**。WordのNormal、見出し、表、テーマ、Excelの既定フォント・入力欄・名前付き書式、PowerPointのテーマとプレースホルダに実設定する。TeXの日本語も同フォント、欧文は環境にある **Liberation Sans**。本文色はTeXでも文書開始時に適用する。
- 自社文書番号は `MW-HR-YYYYMM-用途-連番3桁`。用途は `APR`（承認）、`INT`（面接・追加質問）、`NOT`（案内）、`EVA`（評価表）、`EXP`（経費・照合）、`BRF`（報告スライド）、`REC`（確認事項・受入手順PDF）、`REV`（初週の振り返り）、`MAP`（準備の対応表）。同文書の改版・Office由来PDFは同番号で版を区別する。実値は計画と事実台帳で決める。番号を持たない私的メモ・保存メールには付けない。
- 青山キャリア支援の番号は `AY-CS-YYYYMM-NOT-連番3桁`（連絡）、`AY-CS-YYYYMM-BRF-連番3桁`（配布資料）。Wordは日本語・欧文とも **Noto Serif CJK JP**。TeXは日本語 **Noto Serif CJK JP**、欧文 **Liberation Serif**。青灰色 `486477` と墨 `34383C`、白地。山形2本と社名。配布資料の表見出しは青灰色の淡色 `EAF0F3`。相手の発信文書に自社番号を追加しない。
- 明星採用広告の校正番号は `MA-AD-YYYYMM-PF-連番3桁`。年月は初校の発行月で、同じ原稿の再校は版と発行日を変える。四光星・上罫・小見出しは濃い橙 `A84816`、題・本文は濃紺 `273449`、管理帯・表見出しは淡橙 `F8EFE7`。日本語は **Noto Sans CJK JP**、欧文は **Liberation Sans**。明星の番号と佐々木の発行担当表記を用いる。
- Office型の作者・最終更新者は自社が佐藤美穂子、青山が山田修二、基準日時は2026-08-10。成果物では原稿の実際の人物・日時へ設定し直す。
- p03、p05、p12、p14のREADME、およびp03・p12のWord実物のヘッダ、スタイル、埋込みロゴを比較した。封筒と配送矢印／赤茶、織り目／藍、枝と灯／紫、木材／深緑と区別し、本のロゴ・桑実色・PPTの左帯とした。他personaは変更していない。

## Word

`Document(型)`で開く。A4縦、左右24mm、上27mm、下22mm。独立した表紙は設けない。ヘッダにロゴ・会社名・文書用途、フッタに会社・人事（青山は採用支援）と自動ページ番号を持つ。

1. 最初の見出しの前に `Title` の実題と `MW Metadata` の文書番号・版・作成日・作成者を追加する。承認記録は原稿の承認者・承認日・条件も記載し、申請段階で未承認の内容を承認済みにしない。候補者案内は原稿の宛名・発信者を入れる。候補者の私用連絡先を創作しない。
2. 既存の見出しの下へ原稿を挿入する。不要な節は削り、空の見出しを残さない。Normalは10.5pt、段落後6pt、行間1.18。Titleは22pt、Heading 1は13pt、Heading 2は11ptで組織色・太字。Caption・MW Metadata・MW Noteは9pt。
3. 実表が必要なときだけ表を作り `MW Table` を指定。先頭行を組織色の塗りとし、各セルの段落を `MW Table Header`（白・太字9pt）、明細は `MW Table Body`（墨9pt）にする。先頭行の `trPr` に `w:tblHeader` を付けて続頁で繰り返す。各明細行の `trPr` に `w:cantSplit` を付け、行の途中で分割しない。表幅は本文幅162mm以内、列幅と行高は実際の文章量に合わせる。長文を固定高さに閉じ込めない。
4. PDF化する既存Word文書は `bin/office-pdf` で変換する。TeXへ書き直して内容を二重管理しない。

## Excelの入力と行の作り方

`load_workbook(型)`で開く。1行目は埋込みロゴと社名、2行目は題、3〜4行目は管理項目、6行目は列見出し。5行目は未書式の余白。7行目以降にはセル・明細・式・仮の合計を持たない。

1. B3:D3の結合セルへ規定番号全文、F3へ版、B4:C4へ作成日（実日付に`yyyy-mm-dd`）、E4:F4へ作成者を入れる。入力先は空でもNoto Sans CJK JP・9pt・左寄せ・左インデント1・折返しなし・縦中央。B3:D3の結合は維持し、番号を1行で表示する。列幅A〜Fは評価表が19・38・28・14・25・21、経費表が23・39・18・18・17・30（いずれも合計145）。3・4行目は30pt。少数行／複数ページ見本は `MW-HR-202609-EVA-001` / `MW-HR-202609-EXP-001` と日付・作成者を同時に入れて確認する。管理欄は番号全文と隣の版・日付・作成者を同時に入れて印刷し、長い番号や作成者では入力先の結合幅を広げて1行表示を保つ。題・列名・列幅は原稿に合わせて変更する。
2. 原稿にある行だけ7行目から追加する。文字は `MW Text`（10pt、左寄せ、左インデント1）、整数・金額・差分の式は `MW Number`（10pt、右寄せ、`#,##0;[Red](#,##0);0`）、日付は `MW Date`、注記は `MW Note`（9pt）。すべて墨色、折返し・上揃え、細い下罫線。日付・注記の名前付き書式にも左インデント1を設定済み。番号・連番を数値として扱うときは右寄せの `MW Number`、識別子は文字列の `MW Text` とする。数値列の右隣の文字列は先頭の番号列の隣も含め左インデント1を維持し、値を接触させない。列を追加・移動・並替えするときも文字セルへこの書式を適用し、見出しと左寄せの合計ラベルにも左インデント1を付ける。率には原稿に合わせた表示形式を指定する。
3. 評価表は実際の8観点に従い、候補者ごとのシートまたは文書に分ける。シート名と題に対象者、管理欄の後へ原稿の評価日・評価者を追加するなど、作成日と評価日を区別する。事実と解釈を混ぜない。評価尺度は原稿に従う。保留を0点へ変えず、点数の合計を型の都合で追加しない。
4. 経費表は金額（円）と人数（人）を別表／シートに分け、題や列見出しに単位を明記する。3〜5列の差額は原稿の式（例：`=D7-C7`）。合計が意味を持つ場合だけ最後の明細の次へラベルと実範囲を指す`SUM`等を入れ、実セルへ `MW Total` を付ける。淡色背景、太字、上細線・下二重線。ラベルの横位置は左寄せ・左インデント1に変更する。人数の内訳と応募者数を重複加算しない。未知額を0に置き換えない。
5. 注記が原稿にある場合だけ末尾へ `MW Note` の行を追加し、必要な幅を結合する。列幅合計は評価表145、経費表145文字幅。見本では明細行高40pt、合計25pt。長文は行高を増やし、表を分ける。`auto_filter.ref`は6行目から最終明細、`print_area`はA1:F実最終行とし合計・注記まで含める。列を増減した場合は結合・印刷範囲も揃える。
6. A4横、幅1ページ・高さ自動、左右0.3inch・上0.35・下0.45、1〜6行繰返し、C7で固定。40明細の見本は24行目の後へ `ws.row_breaks.append(Break(id=24))` を入れ、自然改ページも使って文字を保った複数ページにする。実内容の折返しに応じて改ページ位置を変える。印刷ヘッダの余白は0.15inch、フッタ余白は0.2inch。会社・人事と `&P / &N` のフッタを維持する。`bin/recalc`で式を計算し、`bin/render`で全ページを確認する。

## PowerPoint

`Presentation(型)`で開く。型のスライドは0枚。図形ロゴ・社名・左帯・下部人事表示はマスターに実装。空の仮スライドや例文は持たない。

| index | 実レイアウト名 | 用途 |
|---|---|---|
| 0 | 表紙 | 題32ptと副題18pt。副題に文書番号・版・報告日・作成者 |
| 1 | 見出しと本文 | 題28pt、本文20ptの要点 |
| 2 | 2段 | 左右の比較、評価と追加確認など |

## TeX

`TEXINPUTS="$PWD/templates/p15-recruiter-people-ops:" bin/tex <指定scratchの入力.tex> <指定scratchの出力.pdf>`。`\documentclass{mirai-recruiting-note}`を指定する。クラスに本文・ダミーの管理情報・空表はない。

- `\MWHeading{題}{文書番号}{版}{作成日}{作成者}`、`\MWSection{見出し}`、`\MWNote{注記}`を使う。欧文Liberation Sans、日本語Noto Sans CJK JP、本文10pt、左右24mm、上29mm、下24mm。桑実色はロゴ・題・見出し、灰緑は右ページのロゴ、墨は本文に実適用する。
- `\begin{MWTable}{列指定}`〜`\end{MWTable}`でlongtableを作る。見出し行頭に`\rowcolor{MWmain}`を置き、**各見出しセル**の先頭を`\leavevmode\color{white}`とする。色指定の前に横モードへ入り、数値の`r`列と長文の`p`列で見出しの1行目をそろえる。見出し行末の`\\`に続けて`\endhead`を入れ、続頁にも同じ行を表示する。
- 先頭の番号など右寄せの数値列に左寄せの文字列が続く場合は、列の境界に既定の列間余白を残す。下記の指定で両端の余白だけを外す。実際の見出しと数値に合わせ、列幅と列間余白の合計を本文幅162mm以内にする。明細には実際の行を入れ、合計が意味を持つ場合だけ原稿の合計を追加する。

```tex
\begin{MWTable}{@{}rp{35mm}p{103mm}@{}}
\rowcolor{MWmain}\leavevmode\color{white}番号 &
  \leavevmode\color{white}担当範囲 &
  \leavevmode\color{white}確認内容 \\
\endhead
% 原稿の明細をここに入れる。
\end{MWTable}
```

直接PDFを作る質問票・確認事項・決定時点の配布控えに使う。Office由来のPDFはOfficeから変換する。

青山の直接配布PDFは同じ `TEXINPUTS` で `\documentclass{aoyama-channel-handout}` を指定する。`\AYHeading{題}{資料番号}{版}{発行日}{作成者}`、`\AYSection{見出し}`、`\AYNote{注記}` を使う。A4縦・左右25mm、上31mm、下25mm。表が必要な場合は `\begin{AYTable}{@{}rp{40mm}p{90mm}@{}}` を使い、見出し行頭に `\AYHeader`、行末の `\\` の後に `\endhead` を置く。本文幅160mm以内で列幅を決め、右寄せ数値列と左寄せ文字列の間の既定余白を維持する。原稿に従い資料番号・版・発行日・作成者を埋め、`bin/render` で全ページを確認する。

明星の掲載見本は同じ `TEXINPUTS` で `\documentclass{myojo-ad-proof}` を指定する。本文10pt、A4縦・左右21mm、上33mm、下23mm。`\MAHeading{宛先}{題}{校正番号}{版}{発行日}{発行担当}` で宛先と左揃えの題、2行の管理帯を出す。掲載される本文と原稿確認の連絡を分け、`\MASection{見出し}` と `\MANote{確認してほしいこと}` で組む。表示項目を表にする場合は `\begin{MATable}{@{}rp{41mm}p{101mm}@{}}` を使い、見出し行頭に `\MATableHeader`、見出し行末の `\\` に続けて `\endhead` を置く。列間は既定の左右各7ptを残し、本文幅168mmに収める。表や注記は原稿にある場合に組む。`bin/render` で番号・発行担当と全ページの表見出し、フッタを確認する。
