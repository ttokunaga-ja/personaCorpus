# 佐藤美穂子の文書の型

みらい職場研修株式会社の採用・People Ops、青山キャリア支援合同会社の採用支援、明星採用広告株式会社の掲載見本、岡部人材評価合同会社の面接者研修に使う型。通常のDOCX・XLSX・PPTXを開いて別名保存する。型には組織、見出し、書式だけを置き、事例本文、ダミーの番号・日付、空の明細、仮の合計を置かない。

### 2024年8〜12月の研修運営担当採用（b003）

- 職務説明の修正稿は `mirai-approval.docx` を開き、ヘッダの用途を「職務説明」に、本文見出しを「募集の背景」「主な職務」「必須の経験と現場の調整例」「改訂と共有」など原稿に合わせて変更する。ヘッダの埋込みロゴを保持し、用途が入った run の文字を変更する。4月26日に山本から受け取った例の、代替講師・会場・受講案内の訂正順を職務に結び付ける。
- 面接枠の割付は `mirai-evaluation.xlsx` を使い、題と6行目を変更する。A〜F列を「枠順／運営上の割付／日付／開始時刻／担当部署／調整事項」（列幅17・32・20・18・22・36）とし、数値から文字へ移るB列・E列は左インデント1。日付は `MW Date`、時刻は実時刻に `MW Number` を付けて `hh:mm` に変更する。応募24件と面接6件は別段階として記録し、選考終了者の個票や氏名を増やさない。
- 歩留まり比較は `mirai-expenses.xlsx` を使い、A〜F列を「経路／応募（件）／書類通過（件）／書類通過率／入社（件）／入社率」（列幅35・21・23・22・21・23）に変更する。件数は `MW Number`、率は同書式で `0%` など原稿の精度を指定。原稿が同じ母集団の応募を分母とする場合はD列を `=IF(B7=0,"",C7/B7)`、F列を `=IF(B7=0,"",E7/B7)` のように作り、全経路の率も集計した分子・分母から求める。注記に集計期間・対象4経路・率ごとの分母を明記する。10月25日の書類通過38%・入社6%の件数と対象期間は原稿に従う。運営職の応募24件は別の集計対象。
- 山田の10月25日配布資料は `aoyama-channel-handout.cls` で直接PDF化しDownloadsに置く。照会と回答はEML、匿名流入の元集計はCSV。12月12日の山本向け説明は `mirai-recruiting.pptx` で、承諾2人・繰延べ1枠と年内の引継ぎを示す。

### 2025年1月の入社支援（b004）

- 初週の振り返りは `mirai-approval.docx` の書式を使う。ヘッダの用途を「入社支援の振り返り」に替え、本文を「照合した記録」「初週に分かった準備の遅れ」「1月23日に決めたこと」「次の受入で確認すること」など原稿に沿って組む。文書番号の用途は `REV`。
- 遅れと事前に確認できる項目の対応表は `mirai-evaluation.xlsx` を使う。シート名と題を変え、A〜F列を「番号／初週の遅れ／照合した記録／入社3日前の確認／確認する担当／未準備時の連絡」（列幅10・23・25・32・20・35）とする。A列は `MW Number`、B〜F列は左インデント1の `MW Text`。第6行は既存の見出し書式で折り返す。文書番号の用途は `MAP`。対応関係を示す明細に集計や評価点は付けない。
- OneDrive「規程と手順」に置く受入手順は `mirai-recruiting-note.cls` を使い、プリアンブルに `\renewcommand{\MWDocumentUse}{受入手順}` を置く。文書番号の用途は `REC`。旧版と改訂版は原稿に従い、同じ手順書なら番号を引き継いで版と作成日を区別する。改訂版では入社3日前に誰が何を確認し、未準備の場合にどこへ知らせるかを読み取れるようにする。
- 匿名の準備状況はCSV、佐藤と伊藤などの担当間の確認はEML。受入担当の案内HTMLと確認日の説明図PNGは原稿から作り、桑実色の見出しと灰緑の補助線を使う。1月23日の判断前後を区別し、新手順の効果は次回の受入で確認する事項として扱う。

### 2025年10月の組織負担調査と研修提案（b007）

- 調査の読み取りと研修案は `mirai-approval.docx` を開き、ロゴを保持したままヘッダの用途を「組織負担調査」に替える。節は「回答状況」「集計と配布前の確認事項」「新任管理者向けに提案すること」など、原稿に沿って置く。確認事項を表にする場合は、番号／項目／確認内容の幅を14／45／103mmとし、番号を右揃え、次の列との間にはセルの既定余白を残す。承認記録と異なり、提案には承認欄を追加しない。
- 分母・丸めの照合には `mirai-expenses.xlsx` を開き、題を「組織負担調査　分母と丸めの照合」、A〜F列を「番号／照合する指標／件数（人）／分母（人）／率（表示）／照合根拠・注記」、列幅を11・29・17・17・19・52に替える。A・C〜E列は `MW Number`、B・F列は左インデント1の `MW Text`。見本は明細行高38pt、合計・注記25pt、長い方は14行目の後に `Break(id=14)` を指定する。回答率は対象174人に対する回答151人で、たとえば `=IF(D7>0,C7/D7,"")` の元値を保持し、`0.0%` の表示で照合する。対象と回答の差23人は調査の未回答。負担設問の42％は報告値として示し、再計算は原稿で確認された設問の分子・分母から行う。報告値から件数を逆算しない。丸め前の率と報告桁の値を比較する場合は別セルで表示し、率の足し算をしない。合計が必要なときは対象を分けた回答と未回答の件数だけを合計し、否定回答や確認事項を加えない。
- 渡辺への投影は `mirai-recruiting.pptx`。表で指標ごとの分母を示し、図で対象174人を回答151人・未回答23人に分ける。42％は設問の報告値として別に注記する。直接組版の会議要旨は `mirai-recruiting-note.cls` を開き、プリアンブルに `\renewcommand{\MWDocumentUse}{組織負担調査}` を置く。10月22日の資料では提案内容と、その後に決める事項を分ける。5月の研修実施は別の記録に置く。
- 受領控えは匿名集計のCSV、伊藤への確認はEML。集計範囲のPNGは対象・回答・未回答を人数付きで図示し、設問の率を別に表示する。共有資料に回答者名や少人数の属性・部署別内訳を載せない。b007 の文書はみらい職場研修の社内様式を使う。

## 共通の意匠と管理

- 178人の研修会社として、小さな「開いた本」の図形と社名を使う。本の左ページは桑実色 `963A65`、右ページは灰緑 `7B8270`。本文は墨 `34383C`、白地、合計の淡色は桑実色の濃淡 `F5EDF1`。Word・Excelの図形は埋込みPNG、PowerPointはネイティブ図形、TeXはTikZ。外部画像リンクはない。
- Officeの日本語・欧文はともに **Noto Sans CJK JP**。WordのNormal、見出し、表、テーマ、Excelの既定フォント・入力欄・名前付き書式、PowerPointのテーマとプレースホルダに実設定する。TeXの日本語も同フォント、欧文は環境にある **Liberation Sans**。本文色はTeXでも文書開始時に適用する。

## Excelの入力と行の作り方

`load_workbook(型)`で開く。1行目は埋込みロゴと社名、2行目は題、3〜4行目は管理項目、6行目は列見出し。5行目は未書式の余白。7行目以降にはセル・明細・式・仮の合計を持たない。

1. B3:D3の結合セルへ規定番号全文、F3へ版、B4:C4へ作成日（実日付に`yyyy-mm-dd`）、E4:F4へ作成者を入れる。入力先は空でもNoto Sans CJK JP・9pt・左寄せ・左インデント1・折返しなし・縦中央。B3:D3の結合は維持し、番号を1行で表示する。列幅A〜Fは評価表が19・38・28・14・25・21、経費表が23・39・18・18・17・30（いずれも合計145）。3・4行目は30pt。管理欄は番号全文と隣の版・日付・作成者を同時に入れて印刷し、長い番号や作成者では入力先の結合幅を広げて1行表示を保つ。題・列名・列幅は原稿に合わせて変更する。
2. 原稿にある行だけ7行目から追加する。文字は `MW Text`（10pt、左寄せ、左インデント1）、整数・金額・差分の式は `MW Number`（10pt、右寄せ、`#,##0;[Red](#,##0);0`）、日付は `MW Date`、注記は `MW Note`（9pt）。すべて墨色、折返し・上揃え、細い下罫線。日付・注記の名前付き書式にも左インデント1を設定済み。番号・連番を数値として扱うときは右寄せの `MW Number`、識別子は文字列の `MW Text` とする。数値列の右隣の文字列は先頭の番号列の隣も含め左インデント1を維持し、値を接触させない。列を追加・移動・並替えするときも文字セルへこの書式を適用し、見出しと左寄せの合計ラベルにも左インデント1を付ける。率には原稿に合わせた表示形式を指定する。
3. 評価表は実際の8観点に従い、候補者ごとのシートまたは文書に分ける。シート名と題に対象者、管理欄の後へ原稿の評価日・評価者を追加するなど、作成日と評価日を区別する。事実と解釈を混ぜない。評価尺度は原稿に従う。保留を0点へ変えず、点数の合計を型の都合で追加しない。
4. 経費表は金額（円）と人数（人）を別表／シートに分け、題や列見出しに単位を明記する。3〜5列の差額は原稿の式（例：`=D7-C7`）。合計が意味を持つ場合だけ最後の明細の次へラベルと実範囲を指す`SUM`等を入れ、実セルへ `MW Total` を付ける。淡色背景、太字、上細線・下二重線。ラベルの横位置は左寄せ・左インデント1に変更する。人数の内訳と応募者数を重複加算しない。未知額を0に置き換えない。
5. 注記が原稿にある場合だけ末尾へ `MW Note` の行を追加し、必要な幅を結合する。列幅合計は評価表145、経費表145文字幅。明細行高は40pt、合計は25ptを目安とする。長文は行高を増やし、表を分ける。`auto_filter.ref`は6行目から最終明細、`print_area`はA1:F実最終行とし合計・注記まで含める。列を増減した場合は結合・印刷範囲も揃える。
6. A4横、幅1ページ・高さ自動、左右0.3inch・上0.35・下0.45、1〜6行繰返し、C7で固定。表が長い場合は自然改ページを確認し、必要に応じて `ws.row_breaks.append(Break(id=11))` のように行の後に改ページを入れる。位置は実内容の折返しに合わせる。印刷ヘッダの余白は0.15inch、フッタ余白は0.2inch。会社・人事と `&P / &N` のフッタを維持する。`bin/recalc`で式を計算し、`bin/render`で全ページを確認する。

`TEXINPUTS="$PWD/templates/p15-recruiter-people-ops:" bin/tex <指定scratchの入力.tex> <指定scratchの出力.pdf>`。`\documentclass{mirai-recruiting-note}`を指定する。クラスに本文・ダミーの管理情報・空表はない。

- 先頭の番号など右寄せの数値列に左寄せの文字列が続く場合は、列の境界に既定の列間余白を残す。下記の指定で両端の余白だけを外す。実際の見出しと数値に合わせ、列幅と列間余白の合計を本文幅162mm以内にする。明細には実際の行を入れ、合計が意味を持つ場合だけ原稿の合計を追加する。

```tex
\begin{MWTable}{@{}rp{35mm}p{103mm}@{}}
\rowcolor{MWmain}\leavevmode\color{white}番号 &
  \leavevmode\color{white}担当範囲 &
  \leavevmode\color{white}確認内容 \\
\endhead
% 原稿の明細をここに入れる。
\end{MWTable}
```
