# 上田由美香の文書の型

灯枝サービスの支援文書と、露原機材販売から届く表の型。通常の DOCX・XLSX・PPTX を開き、別名保存して使う。既存の型を維持し、今回の再検査ではExcelの文書番号欄とTeXのフッタを修正した。型は見出し・組織表示・書式だけを持ち、事例本文、仮の値、空の明細行、仮の集計欄は持たない。

b001では依頼の2025年7月10日〜31日だけを扱う。240件、形式違い18件、残る222件という関係を保持する。型の見本はこの関係の組版確認に限り、技術原因、修正見込、実際の再開日、相談番号を確定しない。これらは計画と事実台帳で定める。PPTXやPDFは計画に必要な場合にだけ使い、型の種類を埋める目的でファイルを追加しない。

## 灯枝サービスの共通書式

- ロゴは紫の幹から斜めに伸びる枝と、枝先の琥珀色の円（灯）、社名の文字。主色は紫 `514369`、補助は琥珀 `CC963F`、本文は墨 `33313A`。白と淡紫 `F0EDF4` は背景。Word・Excelではこの図形と社名を画像として内部に埋め込み、PowerPointとTeXでは図形で描く。外部画像へのリンクはない。
- 日本語は Noto Sans CJK JP。Officeは欧文も同じフォント。TeXの欧文は環境にある Liberation Sans。122人規模のサービス会社の読みやすい小型ロゴと余白にし、大きな装飾表紙は作らない。
- 文書番号は `TS-CS-YYYYMM-用途-連番`。用途は `ESC`（調査・開発照会）、`HND`（引継ぎ）、`ANS`（顧客案内）、`TRI`（切り分け）、`QUE`（未解決）、`BRF`（共有スライド）、`REC`（記録出力）。実際に番号を付ける文書だけ、計画・台帳に沿って設定する。草稿・送付版・PDFは同じ番号で版を区別する。型にダミー番号は焼き込まない。システムの相談番号は文書番号とは別の項目。
- ヘッダは社名と用途、フッタは組織・部門とページ番号。Excelは上部の組織画像とシート名、下部の組織名とページ番号。PPTXは上部の社名と下部の部門名をマスターで継承し、スライド番号は成形時に追加する。

## Word

`Document(型のパス)` で開く。本文は用途別の見出しだけで、空の表や記入を促す仮文はない。先頭の見出しより前へ `Title` の題と `TS Metadata` の文書番号・版・日付・作成者を追加する。顧客向けは原稿に従って宛名と発信者も記載する。見出しは必要なものだけ使用し、空の節を成果物に残さない。

- A4縦、左右23mm、上27mm、下22mm、表紙なし。
- `Normal` 10.5pt、`Title` 22pt太字、`Heading 1` 13pt太字、`Heading 2` 11pt太字。段落後7pt、行間1.18。`TS Metadata`・`TS Note`・`Caption` は9pt。
- 表を追加するときは `TS Table` を指定する。先頭行の段落を `TS Table Header`（9pt太字・白）、本文セルを `TS Table Body`（9pt）にする。見出し行の繰返しは `w:tblHeader` を付ける。先頭行の紫塗りはテーブルスタイルが持つ。長い根拠は本文へ出し、列幅と折返しを内容に合わせて調整する。
- メール本文はWordから自動転載しない。原稿の草稿と実際に送った内容をそれぞれ保存する。作業中の個人メモまで会社の文書書式にしない。

## Excelの明細と合計を作る方法

`load_workbook(型のパス)` で開く。全型とも1行目は埋め込みの組織ロゴ、2行目は用途名、3行目は文書番号・基準日・作成者のラベル、5行目だけが表の見出し。4行目は未書式の余白。6行目以降にはセルも数式も置いていない。明細は原稿にある行だけ追加する。

1. B3に実際の文書番号、D3に基準日、F3に作成者を設定する。全Excel型のB3は9pt・左寄せ・縦中央・折返し、3行目は30pt。`TS-CS-202507-TRI-001` のような規定番号を末尾まで印刷できる設定を維持する。列幅を変える場合も、番号の折返しに応じて管理行の高さを調整する。番号を付けない受領表ならB3は空でよい。シート名・2行目の題・列名と列幅は原稿に合わせる。顧客の添付が対象表とエラー表の別ファイルなら、使わないシートを削除してそれぞれ別名保存する。CSVには書式・ロゴ・管理ラベルを混入させない。
2. 灯枝は `TS Text`、`TS Number`、`TS Date`、`TS Note`、`TS Total`、露原は対応する `TH Text` 等の名前付きスタイルを使う。明細の各セルを作ってから割り当てる。本文10pt、注記9pt、全て折返し・上揃え。文字左寄せ、数値右寄せ。整数は `#,##0;[Red](#,##0);0`、日付は実日付と `yyyy-mm-dd`。時刻も必要なら実値と `yyyy-mm-dd hh:mm` を指定する。番号や先頭ゼロを持つ値は文字列として扱う。
3. 合計が意味を持つ表だけ、最後の明細の次に行を追加し、ラベルと数式の実セルへ `TS Total` / `TH Total` を適用する。ラベルは左寄せに上書きする。淡い背景・太字・二重下罫線を持つ。数える対象と重複除外を原稿に従って定め、実範囲への `COUNTA` / `COUNTIF` / `SUM` 等を使う。未確認をゼロとして足さない。相談件数と取込行数を混ぜない。仮のSUMや合計ラベルを追加しない。
4. 原稿の注記がある場合だけ末尾に `TS Note` / `TH Note` の行を追加する。注記の結合範囲は表の幅まで。長文は行高を増やし、必要ならページを分ける。見本の短い明細は34ptの行高で確認したが、実内容に合わせて調整する。
5. `auto_filter.ref` を見出しの5行目から最終明細まで、`print_area` をA1から実内容の最終行・列まで設定する。集計と注記はフィルタから除く。A4横、幅1ページ・高さ自動、1〜5行目を繰返し、C6で固定、左右0.3inch・上下0.35/0.4inchを維持する。文字が小さくなる場合は表の列を再構成する。数式結果は `bin/recalc` とレンダリングで確認する。

露原機材販売の書式は茶 `7B4C35` と墨、生成り `F4EFE8`。日本語・英語とも Noto Serif CJK JP。番号は同社が管理する添付に限り `TK-IMP-YYYYMMDD-連番` とし、支援側が受領表に番号を追加しない。ロゴは重なる2つの角枠と社名で、機材販売会社の控えめな事務帳票を想定する。灯枝の書式へ置き換えない。今回の依頼にない他社の型は追加しない。

## PowerPoint

`Presentation(型のパス)` を開き、次の実レイアウトから追加する。型のスライドは0枚。マスターとレイアウトに例文はない。題のplaceholderはidx=0、主領域はidx=1、2段の右はidx=2。

| index | レイアウト | 用途 |
|---|---|---|
| 0 | 表紙 | 題と副題。副題へ日付・作成者・必要な文書番号・版 |
| 1 | 見出しと本文 | 経過と要点、本文領域は20pt |
| 2 | 2段 | 確認できたことと次の対応など、左右の本文領域 |
| 3 | 表 | 題とオブジェクト領域。実表に置き換える |
| 4 | 図 | 題とオブジェクト領域。手順・関係図に置き換える |

表紙の題32pt、その他28pt。日本語フォントと紫・琥珀の色をテーマにも設定。表・図の領域は左0.8inch、上2.05inch、幅11.7inch、高さ4.55inch。プレースホルダの座標で表・図を作り、元の空プレースホルダを削除する。表の見出しは紫白字、本文18pt以上、数値右寄せ。注記は12pt以上。下部の部門名を避け、右下（左12.1、上7.05inch付近）へ実際のページ番号を10ptで追加する。発表者ノートも原稿どおり入れる。

## TeX

`tomorie-export.cls` は Office を経ない印刷保存PDF用であり、画面のスクリーンショット用ではない。クラスを指定されたscratchのTeX原稿と同じディレクトリへコピーし、`\documentclass{tomorie-export}` として `bin/tex <原稿.tex> <出力.pdf>` で組む。型自体に本文や仮の表はない。

- `\TSRecord{題}{文書番号}{基準日}{出力日時}` で冒頭の管理情報を設定する。基準日と出力時刻は実際の記録に合わせ、混同しない。
- フッタ左は `灯枝サービス株式会社 | サポート・サクセス`、右は自動ページ番号。問い合わせ記録という用途はヘッダ右に表示する。
- `\TSSection{見出し}` で紫の小見出し。本文10pt、余白22mm、上29mm、下23mm。ページ番号は自動。
- 表は `longtable` を使用し、先頭行に `\rowcolor{TSviolet}`、各見出しセルに `\color{white}`。繰返し見出しを `\endfirsthead` / `\endhead` で指定する。列幅の合計に列間余白を加えて本文幅166mm以内にする。数値列は右寄せ。内容のない行は足さない。

## 型を使わない記録

EMLは送受信ヘッダと本文・引用・必要な実添付を持つ保存メール。CSVは取込ファイルやエラー一覧の素の表データ。TXT・MDは上田の作業中のメモ。PNG・HTMLは検索欄、対象行、状態、表示日時が読める問い合わせ管理画面・保存ページとして作り、帳票のヘッダやロゴを額縁のように足さない。画面の製品名・エラー内容は計画と台帳に従う。これらの形式にOfficeの型を強制しない。
