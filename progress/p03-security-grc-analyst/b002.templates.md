# b002 文書の型の修正と検証

2025年のRISK-031用に既存の8型を使用する。評価表は点検表型、受領証拠の対応表は証跡一覧型、管理会議は中京の説明型、紙の原票はTeX型、旧稿と英文審査要約は中京の回答型で成形する。池田側の発行文書はさくらの型を使う。8月25日の期限超過5件は月次会議全体の数、10月7日の個別判断は2件完了・1件継続。事実台帳を引いた時点でRISK-031固有の証拠や番号の記載はまだなく、見本の細部と番号は組版確認用とした。

- Excel 2型は `CD Text`・`CD Date`・`CD Note` の左インデントを1に設定。先頭連番の右隣と、D7・E7（点検表）およびG7・H7（証跡一覧）の境で数値と文字が離れて見える。短い見本のPDFで数値と「64件を照合」の間が1.86 ptから8.27 pt、連番と対象名の間が1.83 ptから8.24 pt。42行見本の初頁も同じ間隔。
- Word 4型は、文書既定・見出し・表・管理欄・注記で使うスタイルの書体指定を整理。見出しと文書既定のテーマによるフォント継承を除き、表・管理欄などの重複するフォント指定を一つにした。中京はNoto Sans CJK JP、さくらはNoto Serif CJK JP。
- READMEは既存型を使ったRISK-031の成形方法を追記し、旧作業先への参照を今回の `scratch/p03-security-grc-analyst/b002/work/templates-0002/` の見本と画像へ更新した。

書式資産の検証として、Excelは `bin/recalc` で4見本の集計結果（83・980）を照合。短い見本は各1頁、長い見本は各4頁。 `bin/office-pdf` と `pdftotext -bbox` で余白・文書番号・改頁後の繰り返しを検証した。紙の点検票は `bin/tex` で3行・28行を組版し、英文要約は回答型から `bin/office-pdf` で作成。全8型の見本を `bin/render` で出し、計24頁を目視確認した。書体・印刷設定・型に空の明細や仮の集計がないことの検証結果は、同作業先の `logs/structure.txt` に保存した。

紙の見本の検証は組版まで。署名付きスキャンの制作と別実行のtemplates-reviewは後続工程。
