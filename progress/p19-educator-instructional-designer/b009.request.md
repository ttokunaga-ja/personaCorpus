# p19-educator-instructional-designer b009 の依頼

- 範囲：2025年2〜3月 Ashford紹介者向け「学び直し文書入門」の開講設計と紙教材の準備
- 件数の目安：30
- 重点：2月4日にHeatherとBernadetteが紹介18人に全8回、欠席時は紙教材を郵送すると決めた。教室では講師と案内文を読み、自宅では同じ案内から持参物と集合場所を探して自分で答えを確かめられるようにする。計画時に、口頭で補っていた指示を紙面のどこに書き添えるか、相談員が紹介時に何を伝えるかを具体化する。
- 含めたいもの：MailにBernadetteから届いた紹介時の質問と回答のEML。講座フォルダに8回の授業案DOCX、案内状と申込欄を順に読む投影用PPTX、郵送用の読解課題と答えの確かめ方を載せたPDF。授業前の準備に指示語の参照先を手書きした試し刷りのスキャンPDF、Learner-supportに封入する教材と対応する授業を照合するXLSX。
- 避けるもの：8回分の同型の封入表、紹介者別の宛名入り控え、6月の修了実績と相談継続の記録。
