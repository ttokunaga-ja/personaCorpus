# p15-recruiter-people-ops b004 の依頼

- 範囲：2025年1月、入社支援16人の初週振り返りと受入準備の前倒し
- 件数の目安：30
- 重点：伊藤と初週に必要だったものを受入側の準備記録と突き合わせ、準備遅れ5件を拾う。1月23日の判断を境に、入社3日前に誰が何を確かめ、未準備ならどこへ知らせるかを旧手順からたどれるようにする。
- 含めたいもの：入社支援の初週振り返り（DOCX）、匿名の準備状況（CSV）、初週の遅れと事前に確認できる項目の対応表（XLSX）、担当間の確認（EML）、OneDriveの受入手順（テキストPDF）、受入担当用の案内ページ（HTML）と確認日の説明図（PNG）。
- 避けるもの：16人分の同型ファイル、個人の入社書類、変更後に遅れが解消したという実績。
