# p17-construction-project-manager b010 の依頼

- 範囲：2024-08-08〜2024-11-07、楡岡北倉庫屋根更新の契約から雨天養生・散水確認を経た引渡しまで
- 件数の目安：35
- 重点：8月8日に金子と契約した1,480m²の施工範囲を起点に、坂本と竹内が先に決めた雨天時の養生と、実際に雨で工程を8週から9週へ改めた経緯をたどる。計画時に着工日、降雨で中断した区画と再開の判断、12区画の散水記録と図の対応を補足する。11月7日に金子・竹内と漏水0件を確認し、金子が受領したところで閉じる。
- 含めたいもの：Documents/楡岡北倉庫屋根更新に、テキストPDF9件（契約範囲図、竹内からの養生計画・施工報告、散水結果、引渡し控え等）、XLSX4件（面積拾い、当初工程、雨天後の工程、散水記録）、DOCX4件（養生の打合せメモ、工程変更の説明案、再開時の現場記録、引渡し議事録）。JPG4件は養生端部や散水時の屋内側など判断に使った箇所、スキャンPDF3件は区画の手書き割付、雨天当日の野帳、金子の受領票。EML7件は金子との契約範囲・日程の確認や竹内からの現場連絡、PNG2件は養生の区画図と散水位置図、PPTX2件は着工打合せと金子への引渡し説明。
- 避けるもの：海田西配送棟の10月の掘削増分と汐葛の鍵引渡しを持ち込まない。契約日を着工日とみなさず、雨天による中断と散水時の漏水を混同しない。12区画は一つの記録表で追う。
